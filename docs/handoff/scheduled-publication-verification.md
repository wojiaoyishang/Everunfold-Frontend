# 定时发布、列表入口与阅读进度验收

日期：2026-11-06。范围为本轮用户明确要求：移除页面编辑器读取按钮、文章定时发布、右下阅读进度背景、已发布列表前台入口及编辑铅笔。实现决定见[ADR0073](../decisions/0073-scheduled-content-publication.md)，使用见[内容指南9](../development/content-management.md)和[页面指南3](../development/pages.md)。截图仅在本地，不提交用户头像。

## 已实现

- 页面编辑器移除「读取服务器版本」、替换确认弹窗及专用重读函数；初始读取、版本保护、保留输入和独立实时预览保持。冲突提示先复制需要的修改，再刷新核对。
- 文章/说说「发布设置」可选立即或定时，复用日期时间控件。安排发布才冻结已持久确认的协作截点及显式源码，显示执行时间/版本、重新安排/取消和失败原因；保存版本不安排发布，后续编辑留在工作稿，已有公开版本在执行前保持。
- PostgreSQL持久计划包含独立私有快照；取消、立即发布、撤回、回收和整组回收清除计划，恢复不复活。冻结快照参与当前媒体引用保护；密码哈希不返回、不进入队列或公开缓存。
- Scheduler只发送`everunfold.content.publish_due`周期tick。Worker在事务中重查原账号及原API Key、本人/翻译组权限、路径和内容，合并锁有效则等待；公开内容、搜索、不可变Release/Outbox、执行完成及审计原子提交。失败停止并保留原公开版本，数据库异常保留待执行计划。
- 编辑器仅在待执行时串行刷新发布元信息，不覆盖Y.Doc或本地访问输入；执行完成自动更新状态。原未确认请求仍用固定操作ID重试，响应仍严格校验。
- 列表标识待发布/待定时更新；已发布标题旁的外链图标新窗口打开真实公开地址。语言菜单内各已发布译文也有独立前台图标，仍按原文同一行管理；草稿/回收项不提供该入口。编辑按钮加铅笔，无编辑权时查看配眼睛，原回收权限保持。
- 阅读百分比放在右下工具组底部，主题底色上随百分比填充，并有底部细进度线；正常宽度动画150ms，减少动态为0。文章、说说及普通页面支持进度，末尾保留100%，短页面隐藏无意义进度，未新增阅读位置云存储。

## 范围与限制

这是已登记的一次性发布计划，不是通用Cron管理或审核工作流。轮询、合并和服务故障可能延迟执行；不能承诺秒级准点或长期容量。执行时失权/占址/内容失效需检查并重新安排，不擅自更换URL、绕过权限或发布正在编辑的最新版。公开页面其他已打开浏览器仍需刷新/重新导航获取新公开快照；不新增全端主动刷新。全浏览器实机、读屏器和长期负载矩阵未执行。
