## 手工复查

1. 到任意开放评论的文章/说说，打开表情并切换四个分组；颜文字不应断开或被截断，Emoji 和贴纸保持各自尺寸。
2. 用鼠标及 Tab 切换分组/编辑/预览，观察轻量选中态、完整键盘焦点和输入外框。插入一个表情，再预览应得到相同内容。
3. 缩窄到 320px，检查分组、工具栏、正文都不撑宽页面；长内容仍可在输入框内滚动。
4. 打开阅读设置切换主题色和深浅模式；页面、面板、代码和推荐横向轨道应使用相同配色，原生滚动及拖动仍可用。
