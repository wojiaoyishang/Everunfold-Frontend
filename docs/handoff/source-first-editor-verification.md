## 边界

正文与共享属性/结构的保存时机按 ADR0044 分开。当前编辑面内部的正文撤销与跨视图统一历史仍有区别，HTML切换重建编辑面，统一历史留后续。复杂自定义HTML保留安全预览和源码入口，局部保真失败有明确提示。

文件与未提交正文的恢复能力分别受内存和sessionStorage约束，关闭标签页、刷新中的文件恢复、大文档/大房间、实机IME/触摸和外部剪贴板格式矩阵仍需专项验证。本轮原生剪贴板操作通过IAB的实际PNG传输验证。
