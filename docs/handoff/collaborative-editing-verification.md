## 限制与接续

原生中文输入法的组合输入、移动设备实机、大文档/长期协作/高并发尚未验收。当前没有日志删除/历史 GC，本机 ACK 记录也保留；没有跨块连续选区、富文本转换、完整审核、细粒度 ACL、代码页面协同或导出导入器。格式验证失败停止同步并保留导出，自动分叉/重置工作文档后置。新建尚未首次保存的页面没有共享房间/离线持久恢复。

冷启动离线不能以缓存账号绕过后台认证。浏览器配额耗尽会提示导出；媒体引用保守保留可能阻止清理移出正文的资源。公开媒体仍不随文章密码而加密。不要删除检查点/回执或 .next 文件绕过一致性。

API8001 和 Next3000 保留。下一步先让用户试用两种编辑体验，再按反馈细化 Markdown/HTML 工具栏、组合输入和协同结构操作；压缩/GC 和细粒度权限需独立设计/P0。文档双仓库同步，仅本地提交，用户自行推送。
