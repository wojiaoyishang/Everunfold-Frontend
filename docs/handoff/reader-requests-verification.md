## 实际浏览器验证

使用当前机器 Edge 独立测试标签页。正常 3000/8001、隔离生产 3991/8991 和空缓存 3992 分别检查，不操作线上站点。

- 首页只显示通用状态，没有固定“浏览量 / 访客状态”明细。文章页拥有自己的演示身份扩展，切换到其他页面后扩展消失，不要求各页提供同样项目。分类页未登记任何动态请求，显示尚未检查且重新检查按钮禁用，不误报成功。
- 文章页演示访客/读者切换真实请求后更新；断线后不保留“已登录”确认，不把失败当作未登录或假零。恢复成功后数字重新出现。
- 4 秒延迟只加在隔离测试后端的演示端点上。加载中按钮外圈的线段环绕，中心图标无动画，没有右下圆点；完成后外圈退出。开启减少动态后外圈仍提示进行中，但动画为 none。
- 紧凑面板按状态、页面扩展、更新时间/重新检查排列。桌面及 320×844 窄屏已检查：面板约 269px 高，scrollHeight 等于 clientHeight，没有不必要的内部滚动或标题裁切，页面无横向溢出。
- 在隔离测试来源检查蓝色/深色与减少动态：面板、选中控件和图标采用主题变量，之后恢复默认偏好。日常 3000 的阅读偏好没有改动，临时视口已恢复。
- 截图存于前端忽略目录 `var/qa/reader-requests/`，不提交文章媒体或用户缓存。断线场景中的连接拒绝为预期，不能把该场景描述为控制台零错误。

## 边界与未执行项

这是演示读取基线，不是生产登录/计数上线。未执行真实账号、Cookie/CSRF、持久浏览记账、Redis 去重、多 Worker 幂等、评论异步刷新/发布、完整快照通知/撤回/磁盘故障 P0、Safari/Firefox 或屏幕阅读器实机验收。已有模拟点赞/本页评论仍不发布到后端。

未做数据库迁移/整体导入，不写 WordPress 备份或线上站点。后端本机 `reader_preview.enabled` 显式开启且不入 Git，默认配置仍为关闭；正常服务使用 3000/8001。测试拥有的进程与临时副本在交互退出时清理，只有本地提交，远程推送由用户执行。
