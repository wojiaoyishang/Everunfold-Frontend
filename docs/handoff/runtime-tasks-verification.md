## 中间失败与修复

初次运行页契约遗漏success/data外壳，导致客户端无法读取；补齐契约、重新生成并重新检查实页。测试库仍在0031时失败，显式迁移后重跑；新插件使固定目录数量断言过期，修正目录数量。早期核心轮询间隔使旧回调限时断言失败，恢复原1秒检查频率后完整回归通过。常驻检查点/结束事务锁顺序统一后重跑进程检查。

浏览器最初通过非配置来源访问登录受到来源限制；改为测试路由映射保留原浏览器来源，没有放宽CSRF/CORS。运行脚本对带时间文本使用exact定位曾等待失败，修正定位后重新执行；移动切换截图曾早于响应式布局稳定，等待后重新加载并看图。生产检查脚本已加入新增运行页，不以旧路由清单冒充验收。
