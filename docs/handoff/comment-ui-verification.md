本轮不创建、发布、删除或修改评论/内容。两次自建浏览器验收都通过真实接口读取前后完整评论目录，结果逐项一致；回复、保存失败与原文类型变化只在本轮浏览器内模拟。未向业务库写入模拟条目。只退出自己的测试会话，退出返回200并关闭浏览器；账户资料、站点设置、主题、插件及WordPress备份未改。

内置浏览器连接返回需要重新认证，使用容器Chromium/Playwright验收。截图、模拟响应及日志只保留被忽略的var目录，不提交设备地址、凭据或业务数据。启动检查六服务正常、四个端口绑定0.0.0.0，API/代理/后台HTTP就绪。

未重跑后端真实库及跨进程套件，后端代码和契约没有变化；未重跑真实停后端reader矩阵、未配置生产插件的额外Playwright安装生命周期检查。未覆盖全浏览器与长期负载。已通过评论定位复用现有按ID换页/定位组件，本轮没有新建公开评论做端到端定位；验证码页面解锁后评论交互沿用上一阶段边界。公开地址和内容可访问性仍以当前后端与前台发布状态为准，界面不绕过访问验证。
