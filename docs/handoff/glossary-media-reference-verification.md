# 术语媒体虚拟引用与即时回显验收

版本：glossary-media-reference-verification-1；2026-11-11（Asia/Shanghai）。对应 [ADR0108](../decisions/0108-virtual-media-references.md)。

## 检查范围

- 术语特色图从媒体库选择后立即回显输入框和缩略图。
- 绑定媒体显示 `site://media/<UUID>`，实际 URL 不进入输入值。
- 清除绑定后可手动输入有效虚拟地址并重新产生媒体 ID 关联。
- 普通 HTTP URL 不会被解释成媒体库引用。
- 后台术语配置保持左右架构，右侧编辑器填满内容区剩余宽度；公开词条特色图保持原展示。
- 其他媒体入口的稳定 ID/URL 派生边界。

## 检查结果

- 媒体库选择后输入框立即显示 `site://media/fded5f62-...`，缩略图同时出现；清除后手填同一地址可恢复“已关联媒体库（虚拟地址）”状态。
- 后台仍为左侧术语目录、右侧编辑器，目录宽度约330px，编辑器右边缘与后台内容区对齐；公开词条桌面特色图保留标题右侧展示，390px 单列显示，无横向溢出。
- 共享解析测试覆盖 `media:<UUID>`、`site://media/<UUID>`、大小写/空白规范化及非法/普通 URL 拒绝。
- 整轮页面脚本错误0；术语保存、设置保存和媒体文件写请求0。

## ID 与 URL 边界审计

- 术语特色图：保存 `feature_media_id`；后端根据媒体记录返回 `feature_image`。
- 站点头像、主题背景图片/视频、代码字体：保存对应 `*_media_id`；后端重新查询媒体并派生 URL，伪造 URL 不生效。
- 文章/说说封面：保存 `cover_media_id`；正文图片和视频保存 `site://media/<UUID>`。
- 短代码媒体参数：保存 `site://media/<UUID>`，由公开渲染映射解析。
- 手动 URL 只保留在明确允许外部地址的字段，作为独立来源；清空或手填普通 URL 会解除媒体绑定。
