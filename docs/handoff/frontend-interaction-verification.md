## 边界

评论提交、赞同、邮箱和个人网站目前是界面演示，只有历史评论来自公开快照；不承诺真实发布、邮件通知、审核、访客鉴权或持久化。示例人物/对话明确标注虚构，可以隐藏。说说需求已记入 [内容类型衔接](../architecture/content-types.md)，当前尚无说说导入、API 类型升级或专用卡片。

未穷举其他浏览器、所有物理鼠标/触控板、真机键盘和超大评论集。之前的实际滚轮尾程与慢响应证据见整站动效/原站复刻验证，本轮不把这些旧检查写成重新执行。未推送远程、部署或改线上站点。
