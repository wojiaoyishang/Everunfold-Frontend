# Paper精简主题验收

版本：paper-starter-1，2026-11-07。前端源码提交dd515fa；决定见[ADR0080](../decisions/0080-minimal-paper-starter-theme.md)，使用方式见[子主题指南](../development/child-themes.md)。

Paper 2.0.0仅包含theme.ts与styles.ts。所有展示组件、模板和钩子继承Argon；移除原横幅包装、人物模板与页脚说明，采用减淡背景、纯色导航、短横幅、细边框和较紧凑行距。颜色和阅读偏好沿用父主题变量；多级组合示例迁入隔离生产测试夹具。没有新增依赖、后端代码、契约或迁移。

- 原页面/短代码、正文公式与高亮、三语言路由、离线读取、撤回404和损坏快照降级回归通过。插件包HTTP检查通过，未重跑与本轮无关的部署后浏览器热装测试。

## 浏览器实页

容器Chromium独立匿名会话，通过仅供验收的临时路由指定Paper；没有保存文章、页面或全局主题选择，也没有修改实例配置。验收后关闭浏览器与临时转发。

| 场景 | 实际结果 |
| --- | --- |
| 1440桌面首页 | 短横幅约202px，导航约71px；文章卡片无外阴影，细边框正常，没有横向溢出 |
| 390手机文章 | 横幅约199px，标题位于80px导航下方；文章与语言入口正常，没有横向溢出 |
| 深色与减少动态 | 使用真实阅读设置切换到dark/reduced，导航与正文随父变量变化；关闭设置后焦点回到阅读设置按钮 |
| 1440/320人物页 | 等待插件真正就绪后显示原页面与空状态；没有旧Paper额外容器/页脚，没有横向溢出 |
| 下滑导航 | 浅色文章下滑后导航仍使用表面色与正文色，无阴影；未覆盖父主题的交互、焦点和就绪逻辑 |

实页pageerror为0；匿名浏览控制台曾出现401/404资源响应，不计作主题接口成功，本轮未调整对应接口。未执行全浏览器矩阵、长期负载或授权编辑器整套回归。默认主题选择仍为原Argon，Paper可在“主题设置→已安装主题”选择。
