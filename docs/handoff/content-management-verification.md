## 交付限制

这是私有工作草稿的基础 CRUD；没有正式发布/撤回及可靠内容缓存分发、分类/标签/SEO 细设、Y.Doc 协同、完整混合块编辑器、插入媒体界面、跨刷新草稿持久恢复、历史文章导入。页面入口仍是明确的准备状态，完整可信页面注册/启停/暴露选项另做。新增内容不会自动出现在公开首页。

仅本地 Git 提交，远程推送由用户执行。实际配置、上传目录、测试库、日志和生成的公开快照都不提交。
