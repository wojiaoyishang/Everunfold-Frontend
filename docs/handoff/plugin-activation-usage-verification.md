# 插件启停使用提示与页面目录验收

版本：plugin-activation-usage-1，2026-11-08（Asia/Shanghai）。对应[ADR0083](../decisions/0083-plugin-activation-usage-confirmation.md)。前端源码72a4156，后端源码与settings 1.13契约f335cf8。仅本地提交，未push。

## 实现范围

- 页面目录由后端过滤不可用注册页；自定义页面保持。停用保留单页详情与数据，重新启用后恢复原条目，另一已打开的目录随插件清单修订刷新。
- 保存设置前对整个工作稿计算有效启停差异，检查应用页面、已发布正文及冻结的定时正文；同一内容多次调用只计一次。响应仅包含注册情况和计数，不返回私有正文、标题、路径或元数据。
- 有使用时使用共享ConfirmDialog，可继续保存或取消。未使用直接保存，切回原状态不检查。检查失败保留工作稿且不保存；归属清单未知时提示人工核对。原设置修订、授权、部署一致性和可靠应用守卫保留。
- 不执行插件或JavaScript、不推断配置/脚本隐式依赖，不扫描仅工作稿或历史版本；预检是当前影响提示，不锁全站内容。没有数据库迁移、新增依赖或媒体/文章修改。

- 最终隔离npm run verify:admin退出0，34个私有入口200/private/no-store/noindex；公开原功能、源码/人物/荣誉页、缺实现503、父子主题、可配置语言、离线/撤回及损坏副本检查通过。未声称本轮执行额外的生产浏览器后装包矩阵。
- 后端完整运行242通过、1个新增测试失败；失败是夹具随机插件ID可能以数字开头，已加字母前缀。随后真实数据库重跑新增文件7项全部通过，合计243个用例均已覆盖。主套件已包含真实双API竞争、Worker/Scheduler、Node可靠接收P0；新增P0验证停用后目录隐藏、按ID数据保持、停用状态仍有应用计数、重新启用恢复条目。

## 实页与数据恢复

- 使用容器Chromium与既有Playwright，通过本地转发保留配置的浏览器来源；未修改全局设备地址或降低Origin/CSRF要求。截图、原设置副本和脚本只在被忽略的var/qa与var/container。
- 1440桌面、390英文与320窄屏确认窗口显示，计数左右对应、无横向溢出。中文/英文提示、深色/减少动态和项目进退动画完成；取消保留开关工作稿，并恢复“保存更改”焦点。
- 实际停用core.honors前提醒1个已应用页面；继续后另一已打开目录隐藏条目，公开/myhonor返回404。重新启用前仍提示1个应用页面；继续后目录恢复、公开200，24张记录卡恢复。前后逐项比较原有页面详情DTO及站点设置value，完全一致；仅正常设置修订和审计推进。没有重新导入证书或修改原记录。
- 在“插件管理”修改后切到“站点设置”保存，仍出现重新启用提示，验证预检不依赖具体设置子页。未使用的core.gallery停用/启用各一次查询、直接保存且无确认弹窗，最后恢复原设置。core.people与core.honors同时停用只出现一份含两项的确认窗口，最终取消并撤销工作稿。
- 浏览器拦截检查请求：等待时保存按钮显示检查状态并禁用；网络失败时出现“设置尚未保存”，开关工作稿保留、服务器修订不变；恢复请求后可继续保存。未把拦截当作真实后端故障测试。
- 拦截设置PATCH返回409，确认后弹窗保留错误并恢复按钮可用；取消后撤销工作稿，实际站点设置value等于原值，全部启用节点applied。最终pageerror 0、原生dialog 0；退出本次会话200，测试浏览器与本地转发关闭。API/Worker/Receiver已重载，启动脚本检查六服务RUNNING、四端口0.0.0.0及API/代理/后台HTTP200，保持HTTP供验收。
- 调试中发现预检会暂时禁用触发按钮，导致取消后焦点落到body；共享弹窗增加可选returnFocus并实页重测通过。初次类型检查对有默认值的生成字段要求空值回退，已按契约修正。既有荣誉插件README表格格式使format检查失败，仅规范排版后通过。HMR和错误定位器引起的脚本超时均在读取真实状态后重跑，不当作产品成功。
