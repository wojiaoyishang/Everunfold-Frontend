## 边界

未做旧内容批量转换、精确文章引用图/数量、独立模板多人协同、任意SVG/布局图形编辑或跨浏览器/读屏器完整矩阵。HTML注释、脚本等非文字节点单独保留，不执行它们，也不锁住相邻文字。后台预览可先看到主库新应用定义，公开节点以持久回执为准。

CSS使用不可由模板选择器直接命中的外层绘制隔离容器，内部才是模板作用域；只输出实际引用样式。原始正文、实际配置、数据库记录与测试输出不提交。服务继续HTTP并监听0.0.0.0，WordPress备份只读，Git仅本地提交，由用户推送。
