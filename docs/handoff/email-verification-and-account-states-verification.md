# 邮箱验证、用户管理确认与账号状态页验收

版本：email-verification-and-account-states-verification-1，2026-11-11。决定与安全边界见[ADR0115](../decisions/0115-account-email-verification-and-admin-mutations.md)。

## 已实现

- 账号中心邮箱输入右侧增加“验证邮箱”；服务端用6位一次性验证码确认控制权。
- 验证码由Worker通过现有SMTP发送，15分钟有效；60秒发送冷却、每账号每小时最多5次、最多5次确认尝试。
- 成功后原子写入邮箱与`email_verified_at`；修改邮箱自动清除验证状态。未验证邮箱不能用于登录或找回密码。
- 验证码待发送明文只在Worker认领后用于发信，并在任何发送尝试后清空；数据库长期保留加盐摘要。
- 管理员创建/编辑用户、角色、授权和启停移除当前密码确认，继续要求Session、CSRF、`users:manage`、账号管理事务锁、修订守卫和审计。其他敏感操作继续要求当前密码。
- `accounts-v1 1.6.0`新增请求/确认邮箱验证接口；迁移`0045_email_verification`已应用到开发库和`everunfold_test`。
- 账号加载和失败状态改为居中的状态卡：加载显示指示器、进度线和返回站点；失败显示原因、重新检查、前往登录和返回站点。

## 自动检查

- 隔离PostgreSQL+本地SMTP测试覆盖验证码实际发信、限频、错误码尝试、成功验证和修改邮箱失活。
- 账号、预设与邮箱验证定向11项通过，包含无当前密码创建/编辑用户仍受权限和事务边界保护；后端完整真实数据库套件349项在371.08秒内通过。
- Ruff、格式、两个数据库的`alembic check`通过。
- 前端`npm run check`370项通过；lint、TypeScript、格式、契约与扩展准备通过。

## 实页检查

- 账号中心正常态显示邮箱验证按钮；验证码弹窗在1440px实际打开，输入框、说明与共享确认按钮完整。
- 加载态与主动断网失败态均居中显示，不再出现左上角小段错误文字和孤立按钮。
- 用户编辑页“确认操作密码”数量为0，保存栏独立位于角色授权之后。
- 评论区提交按钮图标与文字间距为9px；浏览器实测成功提示10.675秒后完成退场，进度条同步显示10秒生命周期。
- 浏览器无`pageerror`、无原生弹窗。前端实页验证码请求使用拦截夹具，未向真实邮箱发信；真实SMTP仅由自动测试的本地服务器接收。

## 限制

- 当前没有邮箱修改冷却期、旧邮箱通知、退信抑制或多渠道找回。
- 移除用户管理当前密码确认后，持有有效管理员Session与CSRF的会话可直接执行这些操作；这是用户明确要求的安全取舍。
