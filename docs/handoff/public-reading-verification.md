## 视觉依据和限制

已读本地 Argon 主题代码和真实公开设置，沿用星空全页背景、透明横幅、#673bb7、双栏、8px 卡片和约 16.5px 字号；背景与头像有来源和哈希。线上自动读取遇到 Cloudflare challenge；浏览器连接要求重新认证，本机浏览器工具随后因无法可靠识别当前 URL 停止，未绕过。

**未完成浏览器截图级视觉验收，也未在真实浏览器验证深浅色、移动侧栏、键盘/目录交互或窄屏溢出。** 本阶段已实现相关组件/响应式样式并通过编译，HTTP 检查不能代替这些交互。用户按公开阅读运行指南的手工清单验证后继续修视觉差异。

登录/后台写入、评论提交、协同、内部缓存接收、可靠撤回、镜像/CDN 和生产 SEO/故障验收不在本次完成范围。当前没有推送或部署；原始数据、实例配置、生成快照与文章媒体保持在忽略目录。

## 复现

依次运行 `npm.cmd run check`、`npm.cmd run build`、`npm.cmd run start -- --port 3000`；另一终端运行 `npm.cmd run verify:http -- http://127.0.0.1:3000`。本机数据已经准备好，新克隆须先按运行指南导出真实快照，不提供产品假数据回退。
