# 原站前台复刻差距与下一步

日期：2026-10-30。状态：**已审阅，以下改进尚未实现**。

用户本轮要求先用内置浏览器看 https://lovepikachu.top，再整理改进项。新目标是逐项复刻原站的公开前台外观和交互；已有功能检查通过不等于已达到原站体验。本轮只补审阅记录，没有修改应用代码、配置或数据库，也没有停止用户的 3000/8001 服务。

## 证据与限制

- 实际打开原站首页，检查顶部截图、向下翻页后截图，以及从列表进入公开文章《入戏太深？》。原站页面读取较慢，开始有超时，之后截图和 DOM 检查成功。
- 首页顶部滚动位置为 0；背景 video 的 autoplay=true、muted=true、paused=false、readyState=4。文章页同样播放。
- 原站回顶按钮在顶部带 fabtn-hidden，实际高度为 0；下滚截图显示其出现在右下工具列上方。夜间模式、设置按钮为同一纵列，实际约 42×42，间隔 8px。
- 原站实际加载 smoothscroll1.js；备份同名源码含滚轮/键盘平滑滚动和减速逻辑。具体输入设备上的惯性强度尚未做逐帧测量，不能用静态截图声称手感已复刻。
- 本地浏览器检查：首页背景当前正在播放，但回顶按钮在顶部仍可见，播放按钮横排在它左侧。进入公开文章后正常呈现；本次单次点击未捕获短暂 loading 中间态。用户已报告该问题，代码中确实仍有替换主内容的根 loading.tsx。
- 原站首页含近期受保护文章与说说；本地公开导出内容数量不同。外观对照应使用相同公开文章；本审阅不扩大为导出受限正文或修改访问策略。
- 亚秒级切换没有完整录制。原主题源码存在 NProgress/PJAX 动画，也存在平滑滚动下的整页导航兼容回退；不能把所有源码分支都写成线上每次实际发生。新站应以用户要求的连续阅读体验验收。

## 第一批：连续性与用户明确要求

| 项目 | 当前差距 | 目标与验收 |
| --- | --- | --- |
| 默认动态背景 | 已有播放功能，但源地址需客户端初始化后才设置，暂停偏好/浏览器策略可能影响实际首访体验；用户反馈默认未播放 | 正常首次访问静音自动播放，切页保持视频进度，隐藏标签再恢复时继续。检查首次访问、手动暂停、刷新和播放失败各状态，不用上一轮已播放的浏览器状态代替首访验证 |
| 浮动工具列 | 回顶始终可见，播放按钮横向独立固定；尺寸、形状也与原站不同 | 一个固定纵列统一管理回顶、背景播放及后续阅读工具；对齐原站按钮形状、约 42px 尺寸与 8px 间距。顶部隐藏回顶，下滚后显示，出现与消失均有过渡，收起后不残留空白/点击区域，其余工具自然重新排布 |

## 第二批：逐区域对齐原站

1. **首页与文章卡片**：原站有封面时，标题和元信息叠在封面下方区域并有遮罩；当前标题位于白色正文区。调整封面比例/裁剪、文字位置、摘要密度、标签样式、卡片间距与悬停，移除不属于原站的额外列表提示布局。
2. **顶栏与横幅**：对齐品牌大小、导航图标/间距、横幅标题垂直位置与内容起点。现有滚动后变色已实现，仍需对照原站的高度、紫色透明度、模糊与过渡，而非当成全新缺失功能。
3. **侧栏**：恢复原站标题与副标题、当前菜单高亮、分级导航及展开反馈；对齐头像、统计、外部主页与 Links 区的密度和间距。不同内容数量不得伪造为原站统计。
4. **阅读细节**：按真实旧页面补阅读进度、评论定位、目录高亮/跟随、图片查看、折叠块和提示块；已有只读评论保持真实能力，写功能按后续范围开发。
5. **移动端与主题**：按相同原站页面检查窄屏按钮列、侧栏抽屉、遮罩、暗色及减少动态设置。先补关键交互，再校准统一动画时长/缓动，避免每个组件独立设置不同节奏。

## 组件与目录安排（提案）

继续保留 RootLayout 的单一公共壳。把浮动工具容器、滚动状态/控制、导航进度与内容切换协调划为清楚的组件或 hook 边界；具体文件名随实现确定。背景播放状态与按钮展示解耦，使按钮加入共享工具列。核心导航纯策略继续放 core/navigation，主题外观和动效留在 themes/argon，沿用现有 styles 分工。

原站参数是参考数据；不直接把整套旧主题 JS 粘进 React，也不为样式复刻改后端契约。需要的新依赖在实现时再按协议评估。
