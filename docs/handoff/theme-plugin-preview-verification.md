# 主题与插件特色图验收

版本：theme-plugin-preview-verification-1；2026-11-11（Asia/Shanghai）。对应 [ADR0110](../decisions/0110-theme-and-plugin-preview-artwork.md)。

## 检查

- 主题详情 Argon 预览：图片元素与满宽预览容器等宽，`object-fit=contain`，水平居中偏移不超过1px；截图中右侧空白消失。
- 通过模拟前端插件 `preview` 元数据，插件列表出现裁切缩略图；打开详情后大图满宽、等比居中，背景留白左右对称。
- 无特色图时主题/插件保留稳定占位；插件预览仍经 `resourceUrl` 安全校验。
- 现有搜索、启停、详情关闭和焦点均由原组件执行，无新增写请求。

## 范围

仅前端展示与样式调整。插件 `preview` 继续使用原部署清单字段，无契约、设置修订、数据库迁移或后端业务变化。未覆盖所有外部图片服务器和所有浏览器，但包含同源透明区域与不同纵横比的真实预览。
