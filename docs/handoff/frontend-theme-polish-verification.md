## 手工复查入口

1. 首页右下齿轮 → 首页内容，依次选择文章/说说/全部，刷新、分页，再从文章返回首页；打开 /?type=all 应保持显式全部。
2. 右下主题色切换蓝/绿/紫，观察顶栏、左侧标题卡片、菜单高亮与卡片底色；再切深色并刷新，检查颜色和白字清晰度。
3. 打开最新文章 /入戏太深？.html 和最早文章 /gz-1.html，到文章末尾看占位、虚化封面、推荐阴影和组件间距。使用 Tab 浏览推荐，或横向滚动/触摸浏览。
4. 手机宽度查看首页长说说、图文卡片和文章末尾；展开全文/查看图片继续复用既有功能。真实手机触摸和全部浏览器组合未在本轮验收。
