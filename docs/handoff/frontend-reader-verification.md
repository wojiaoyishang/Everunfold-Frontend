## 实际执行的检查

- 前端 ESLint、类型检查通过；39 项测试通过，包括草案形状/混合查询、历史纯文本、Markdown 危险链接/图片、脚注安全及代码字面量、外观存储/对比度、推荐排序、公开元信息。
- `npm run verify:http`：23 个页面/搜索/分类标签/真实 404 请求通过，另有 ready、背景与 4 个贴纸资源请求通过。首页检查更新为文章/说说混合 10 项；明确说说搜索不混入文章；关闭评论详情不输出 composer。
- `npm run verify:production`：独立临时副本中的 Next.js 16.4.3 Turbopack 生产构建通过，生成路由包括 /ss 与 /article；没有覆盖开发实例的 .next，工具清理自己的副本。
- 后端草案 5 项针对性测试、Ruff 格式/检查通过；mypy 检查两个新增源码文件通过。运行中 API、数据与 0.1 契约未变，因此未重跑旧多进程/数据库验收。
- 本机 3000 返回新页面；没有停止原开发实例。后端地址约定仍为 8001，未占用 8000。

发现并修复：Markdown 新版类型差异；旧格式测试对 HTML 结构的过度约束；混排后旧 HTTP 脚本仅计文章导致的失败；相同缩略图重复点击导致加载状态不结束；闭合分享弹层的 display 继承；长内容首次渲染的整篇展开跳动。此处源码修复不代表已经通过视觉验收。

## 本轮未执行的浏览器验收

Browser Use 连接器返回 UNAUTHORIZED、要求重新登录。转用本机 computer-use 时收到“用户物理 Escape 中止”的结果；立即停止应用输入，没有继续用其他浏览器方式绕过。因此本轮**没有**完成桌面/手机视觉、焦点回归、触摸滑动、实际全屏/剪贴板、偏好跨刷新和动画观感验收。旧记录中的 Edge 验收只对应旧代码，不能写成本轮通过。

## 用户验证入口

前端继续使用 http://127.0.0.1:3000，无需为样例启动导入器。

1. 首页切换「全部动态 / 文章 / 说说」；/ss 中检查无标题、长文展开/收起、图片、正文链接和喜欢按钮互不抢点击。示例均有标识。
2. /shuoshuo/preview-long-walk：检查代码复制/折行/展开、脚注来回跳转、两张图片切换/缩略图/缩放/全屏；按 Esc 关闭查看器后焦点和页面位置应保留。
3. 在该页评论输入 Markdown 链接/列表/代码，选择恐龙或小花贴纸，切换预览，再填写虚构昵称并「添加到本页」；仅为本页演示，不发送真实评论，刷新清除。历史评论请在 /1861.html 对照阅读。
4. /shuoshuo/preview-quiet：显示关闭评论状态，没有写留言入口；分享仍可使用。
5. 顶栏搜索按钮打开弹层，输入「皮卡丘」并选择说说；应软导航到结果页；空查询/无结果/翻页保留所选类型。
6. 右下设置选择主题色、系统/深浅色、纯黑和背景播放，刷新检查保留；设置打开/关闭不应使页面左右位移。短说说和评论区域不显示阅读百分比。
7. 任意真实文章检查推荐卡片、分享面板和复制反馈；/article/ 为通用年月归档。再以约 390px 视口检查弹层、贴纸和表单不溢出。
