## 纠正和边界

首轮P0用严格h3字符串断言，与正常渲染自动添加标题属性冲突，改为核对结构/内容后完整套件通过。前端最初正则将样式字符串误认HTML，改为核对实际class；随后实页发现前端画廊样例丢失，以及模块加载时过早捕获CSS白名单导致热加载样式被剥除，均修复并增加行为测试，重新运行完整check及生产检查。类型联合收窄和格式问题在最终检查前修正。

生产复测有一轮在动态插件检查期间以SIGTERM/143结束，没有成功结论；下一轮完整执行退出0，未移除或跳过动态插件检查。最后一轮曾长时间等待删除插件后的视图刷新，随后自行完成；没有据此声称轮询延迟有严格上限，长期热更新压力仍未覆盖。浏览器定位器曾因按钮文案不匹配等待超时，调整为实际控件后继续，未把定位器失败当成功。

后端Python变更需受控重启并显式同步目录，当前没有同进程Python热替换、在线安装任意依赖、自动迁移或多副本部署控制器。模板更新不需重建前端主体，React交互仍由独立前端插件包提供。没有完整浏览器矩阵、正式验证码供应商域名认证或长期压力结论。

六个开发服务运行，四个端口继续绑定0.0.0.0，API/代理健康检查和后台HTTP200。实际设备地址/凭据仅在忽略配置；源码与共同规范分阶段本地提交，未push。
