AGENTS.md、development/protocol.md（development-2）加入“页面交互控件必须使用自行封装组件”与统一配色规则，决定见 [ADR 0012](../decisions/0012-shared-controls-and-theme-consistency.md)。ESLint 在页面/主题层阻止裸 button/input/textarea/select/option/dialog/form/a 及 div popover；原生语义只在 ui/ 封装层实现。现有 AppLink/SearchForm 继续负责站内软导航，安全正文渲染为独立边界。

| 排查位置 | 修改结果 |

## 内置浏览器实际验证

使用真实 3000 页面，保持原开发服务和后端 8001。后半段使用独立预览标签，保留用户原阅读页。

- 默认桌面窗口及 320×844：搜索下拉框在视口内，没有页面横向溢出；实际键盘选择、Home/End、Escape 只收起子菜单、Tab 转到搜索按钮；真实查询得到 `/search?q=我&type=article`，结果页保留类型。
- 自选色面板：有效十六进制即时联动，非法 `#xx` 显示错误且不污染配色；RGB 键盘滑块、Escape/完成焦点返回；窄屏面板左右均在可视范围，父阅读设置保持打开。
- 复选框可勾选/取消，字号键盘增减与显示值同步；测试后恢复原字号/配色/浅色/完整动效。
- 浅蓝、绿色和深色实际显示，选中按钮与导航/卡片同色系；首页页面顶部 `background-color: rgba(0,0,0,0)`，轨道同步透明；滚动后的导航颜色延伸至右侧轨道。打开阅读设置/搜索时内容宽度稳定。
- 推荐栏上实际滚轮使横向位置从 0 增加，页面纵向位置保持不变；到末端再次向下滚，页面纵向继续移动。代码与测试同时处理反向边界、无溢出、原生横向/缩放输入和减少动态。
- 点击评论 @：滚动中无定位标记，到达后焦点落在原评论并启动头像/名字强调；重复定位可触发，原评论没有整行底色或外框。减少动态时动画名为 none，静态提示约 2 秒后消退。
- 独立预览标签未记录 error 日志。临时视口已恢复；没有演示评论提交或后端数据写入。

截图保存在前端忽略目录 `var/qa/shared-controls/`：`comment-location.png`、`search-menu.png`、`narrow-controls.png`；检查日志同目录。截图用于交付复查，不进入仓库。

## 复查入口与边界

1. 阅读设置切换主题色，观察选中按钮、卡片表面、导航及滚动条；打开自选面板试试 RGB/十六进制。
2. 打开顶栏搜索，用方向键选内容类型后搜索；搜索结果页复用同一个选择器。
3. 在文章末尾的推荐图片上滚轮，检查横移和两端继续滚动页面。
4. 在评论中点击 @ 对象，停稳后观察头像与名字；重复点击或改为“减少动态”。
