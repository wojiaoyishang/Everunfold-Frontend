# 编辑器预览操作顶栏验收

日期：2026-11-04。范围：ADR0054，文章编辑页三个预览操作随滚动进入固定导航栏。运行环境仍为容器内HTTP入口，公开服务继续绑定0.0.0.0。

## 已完成

前端共享组件 `src/themes/argon/admin/layout/scroll-header-actions.tsx` 负责单一Portal容器、滚动边缘与8px归位滞回、尺寸占位、焦点恢复、监听清理和第二行高度。后台壳提供空插槽，DraftEditor只包裹预览组；紧凑按钮样式可随组移动，属性栏避开额外导航高度。没有依赖、API、协同协议或保存/发布逻辑变更。

## 实际检查

- 内置浏览器保持admin会话，使用既有自建测试文章 `cdf7eadc-dee0-4ac6-8fc6-8ec535635ec1`。下滑出现顶栏预览组，上滑回到原操作行；始终只有一组、三个操作，没有重复控件。原位尺寸保留，保存草稿持续禁用，本轮未输入、保存、撤回或发布内容。
- 1440px宽屏与原工作空间操作同行；1024px使用第二行。发现第二行曾遮挡固定属性栏后加入实际高度避让，复查导航下边约100px、属性栏顶部126px，不再遮挡。
- 390px、320px宽度检查进入/归位，三操作可见、标签完整，整页无横向溢出。320px实际内容宽308px，scrollWidth同为308px。最终已调用视口reset。
- 键盘Tab聚焦「前台预览」后向上滚动，归位后焦点仍在该按钮且有可见焦点框；「正文预览」模式随组进入顶栏后仍为「返回编辑」/aria-pressed=true，点击可回到编辑，焦点保持。
- 正常模式进入动效为 `admin-header-dock-enter`、180ms，归位反向动效实页可见；临时切换后台减少动态，进入与归位均为animation:none。验收后恢复原「轻量动效」。
- 顶栏点击「前台预览」后原按钮恢复可用，服务实际收到对应私有preview页面请求并返回200。内置浏览器未把弹出窗口列入可检查标签，本轮没有把该窗口内容作为视觉验收；原私有预览实现未改。查看前台仍保留既有公开路径与独立窗口链接。
- 通过后台文章导航离开编辑页后，顶栏插槽innerHTML为空、预览组消失、高度变量清理；再点文章标题进入，滚动行为正常，保存仍禁用。
- 最终 `npm run check`：错误页生成一致、ESLint、严格类型、Prettier及207项测试通过。`npm run verify:admin`：隔离生产构建、18条私有入口、匿名SSR/private/no-store/noindex、正文资源按需、离线阅读/撤回/设置损坏检查通过；未覆盖运行中的.next，开发服务保留。
