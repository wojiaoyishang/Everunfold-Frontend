# 评论发送验证与账号弹窗验收

版本：comment-submit-verification-2，2026-11-10。对应[ADR0097](../decisions/0097-demand-comment-verification-and-account-dialogs.md)。

## 实现

标准评论区移除页内验证码和预留空隙，先校验表单再按需检查服务器规则。需要验证码时打开主题共享小窗，确认后发送；无需验证时直接真实提交。确认回执为pending后提示等待审核并清空正文，失败/取消/未知结果保留输入和稳定提交编号。成功、错误及发送过程使用页首颜文字横幅，未知进度不伪造百分比。正文/身份输入框增加border-box避免小窗及手机裁边。

账号中心站内离开、切资料标签、退出使用共享确认，取消保留输入；不再挂账号的浏览器原生卸载警告。公共云端菜单新增退出，真实CSRF回执成功后才匿名；同页和跨标签通知仅含无凭据提示，重新鉴权。签出提示会取消旧查询、清除旧身份，迟到响应不再污染lastReady。

前端源代码ef44aa2。本轮只修改前端业务，后端契约、迁移、评论审核和会话接口不变。主站配置/内容/用户资料/邮件没有修改。
