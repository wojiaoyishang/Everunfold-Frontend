## 已交付

- 头像上传限制的“管理员当前密码”改为“当前管理员密码”，相同后台密码标签一并统一。
- 用户管理顶部新增“身份预设”，独立页支持新增、修改、删除名称/说明/按应用能力及本人/全部范围。0022迁移提供可编辑/删除的初始“编辑”“审稿人”，不改现有用户；预设名称按casefold去重、期待修订保存、软删除、稳定回执及审计。
