# 多邮件发信配置验收

日期：2026-11-11。后端`837c8d8`、前端`e465f28`。本次仅修改本地开发与测试环境，未连接真实供应商、未向外部邮箱发送邮件。

## 已实现

- “通知与消息 → 通知平台”展示站内、邮件和插件渠道；邮件卡片下方可直接维护最多20套发信配置。
- 支持新增、复制、编辑、设默认、停用、删除和逐套测试发件；密码只写，留空保留原值。
- 通知策略的邮件规则新增“发信配置”，可选择默认配置或具体配置；非邮件平台不显示该字段。
- 旧单套 `_mail_private` 配置自动归一化为“默认邮件配置”，首次保存后转换为稳定 ID 列表。
- 原 `/admin/settings/mail` 从侧栏移除，但作为隐藏兼容路由跳转到通知平台发信配置区。
- 投递、测试邮件和邮箱验证记录发信配置身份；排队后配置修订变化、停用或删除时不静默换号。
