版本：page-script-position-1，2026-11-07。源码：后端b6fbaf7、前端1b86420。决定见[ADR0081](../decisions/0081-authored-page-script-position.md)，操作见[页面指南](../development/pages.md)。

## 交付

自定义页面增加“脚本执行位置”：head在正文解析前执行，body_end在作者HTML之后、结束body标签之前执行。缺省body_end，旧工作稿/快照缺字段时保持末尾执行。选择随草稿与应用源文保存；前台、新窗口与实时预览共用原沙箱，位置变化参与渲染标识和依赖。关闭脚本时两种位置均不执行，HTML内脚本保持原位置并受原开关限制。注册页面不接受此作者选项。

后端权威契约pages1.6/public0.9/content-admin1.13，前端锁定b6fbaf713b298cc6e05bc6b8dd1bdcba30c62077及各自SHA；生成物仍只在忽略的var/cache/contracts。没有新依赖或数据库迁移。更新接收器、API和Worker后完成实际发布/撤回。
