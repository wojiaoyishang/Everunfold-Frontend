# 术语管理菜单可见性修复

状态：已实现并验证。日期：2026-11-10。前端提交 `6b2f03e`；后端业务、术语路由与数据未改。

## 原因

`/admin/glossary` 已注册到后台页面目录和“内容”分组，但统一权限映射没有对应条目。后台导航把未知管理路径映射为 `unregistered`，因此即使拥有内容权限，术语页也会在渲染侧栏前被过滤。

## 修复

- 将 `/admin/glossary` 明确映射为 `content:read`，与文章、说说和分类标签管理使用同一读取能力。
- 管理员和具备 `content:read` 的成员在“内容”分组看到“术语表”；无内容读取权限的账号继续隐藏。
- 菜单只负责可见性，直接访问仍经过后台路由和 FastAPI 插件的实际权限检查。

## 验证

- 以管理员身份执行后台导航装配，输出包含“工作台、媒体库、文章、说说、术语表、页面、分类与标签……”等入口。
- 账号权限、后台注册和内容管理定向测试共 17 项通过；ESLint、格式和 TypeScript 检查通过。
- 未用真实账号在浏览器中执行写操作；本次修复只改权限映射与回归断言。
