- 说说导入/展示、kind → type 契约升级、后台类型编辑规则尚未实现；需求与顺序见 content-types.md，不能把当前 78 篇文章统计当作包含说说。
- 浏览器业务 API 客户端和开发代理、内部 HTTP 接收端/真实 socket IP 校验、完整缓存通知/撤回/恢复、镜像与 CDN。
- 当前只支持受控导出的公开数据，不代表完整访问策略、生产搜索或实时发布同步已实现。
- 展示短代码 collapse/fold、alert/admonition、tooltips 已实现；未知或不完整语法仍字面降级，独立应用链接保留原站。完整 WordPress 格式/插件迁移、主题调色器和全部像素细节尚未完成。
- 旧公开阅读阶段的浏览器访问失败保留为历史；本轮使用用户实际 Edge（系统减少动态=true）完成桌面/390 视口交互。未穷举其他浏览器、所有物理鼠标/触控板或真机。
