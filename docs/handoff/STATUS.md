## 最新交付：实际 Edge 的整站动效修复

用户反馈背景不播放、操作生硬、设置隐藏滚动条、滚轮无惯性。在实际 Edge 查到系统 reduce=true 把旧 CSS/视频/滚动全部关闭；原滚轮阈值和模态设置还各有独立问题。已改为本站默认完整动效，设置提供跟随系统/减少动态；移除会话暂停继承，覆盖小数滚轮输入，设置改成不锁滚动条的浮层，并补齐侧栏/标签面板/正文折叠/图片/主题/按钮双向动画。见 [ADR 0005](../decisions/0005-site-motion-policy.md) 和 [整站动效验证](frontend-global-motion-verification.md)。之前的内置浏览器验证不能代表用户实际 Edge 环境，旧记录保留为历史。

## 未实现与验收限制

- 登录/用户状态、后台写入、评论提交、协同编辑、源码编辑器、可信插件 SDK；没有假提交成功按钮。
- 浏览器业务 API 客户端和开发代理、内部 HTTP 接收端/真实 socket IP 校验、完整缓存通知/撤回/恢复、镜像与 CDN。
- 当前只支持受控导出的公开数据，不代表完整访问策略、生产搜索或实时发布同步已实现。
- 展示短代码 collapse/fold、alert/admonition、tooltips 已实现；未知或不完整语法仍字面降级，独立应用链接保留原站。完整 WordPress 格式/插件迁移、主题调色器和全部像素细节尚未完成。
- 旧公开阅读阶段的浏览器访问失败保留为历史；本轮使用用户实际 Edge（系统减少动态=true）完成桌面/390 视口交互。未穷举其他浏览器、所有物理鼠标/触控板或真机。
- ESLint 9 受当前 Next 配套插件 peer 范围限制，工具维护状态及来源见根 README；未来升级另行验证。
