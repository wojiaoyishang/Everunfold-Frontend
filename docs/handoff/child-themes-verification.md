# 父子主题与前台钩子验收

版本：child-themes-verification-1，2026-11-07。源码提交：前端721f0bb；实施约定先在前端5feb4b1、后端3c928b8存档。本记录只描述本轮实际执行项。

## 交付

Argon为默认父主题，paper为可运行子主题。主题按目录自动发现，可多级继承具名组件、逐层组合模板、按稳定ID覆盖单页、追加/清空插入钩子和按父到子输出作用域CSS。ParentThemeComponent可复用上级实现；缺失组件显示占位，缺失模板保留父结果。循环/缺父级明确失败。

公开壳、页眉、横幅、侧栏、页脚、浮动工具、文章/说说/列表卡片、页面外壳/标题及授权前台预览接入。文章、页面和Shell提供before/after位置。页面外壳透传就绪回调，不把外壳加载当作内部iframe/插件就绪。共享Modal/ConfirmDialog、寄语弹窗与Toast保留展示容器的主题作用域。

服务端[theme].active缺省argon，可用FRONTEND_THEME覆盖。配置读取在服务端，浏览器仅接收主题身份。已构建主题更改选择后刷新生效；新增源码仍需构建。后台保持Argon上下文，不新增后端主题选择字段或安装器。
