# 术语管理后台视觉重构验收

状态：已实现并完成实际视觉检查。日期：2026-11-10。前端提交 `403eb62`；范围是术语管理页及其共享控件，不改术语 API、匹配规则或数据库。

## 设计调整

- 页面接入后台现有 `admin-settings-page`、`admin-panel`、`SettingsSection` 和 `admin-settings-savebar`，不再使用脱离设置容器的裸 `label.admin-field`。
- 左侧术语目录使用统一搜索、状态下拉按钮、`admin-draft-empty`、状态徽标和选中态；目录在宽屏保持粘性，在窄屏回到正常文档流。
- 右侧编辑区拆为“基本信息、匹配规则、提示内容、发布状态”四个设置区块；标签、帮助文字、TextArea 和选择器分别与控件对齐。
- 新建、搜索、刷新、清空和保存操作复用 `AdminActionButton` / `IconButton`；保存栏在桌面保持可用，在窄屏回到表单末尾，避免首屏遮挡字段。
- 权限只读时隐藏新建入口并禁用表单；不再依赖提交后由后端拒绝写操作。
- `Select` 增加可选 `id` 与 `aria-describedby`，让显式标签和帮助文字能绑定到真实 combobox 触发器。

## 实际检查

- 使用真实 `GlossaryAdminPage`、共享设置组件与共享后台 CSS，在 1440×1000 浅色、1440×1000 深色和 390×844 手机视口检查。
- 新词条、已发布词条、草稿、归档状态均可见；归档筛选只保留归档词条，搜索“篝火”只返回对应词条。
- 点击“金灵”后标题、语言、路径、别名、提示和 Markdown 说明正确回填；填写新词条并保存后显示成功提示与已发布状态。
- 390px 页面 `scrollWidth` 等于 `clientWidth`，没有横向溢出；编辑区块、状态选择和保存操作完整可用。
