## 实际发现与修复

初次公开契约的 x-version 元数据触发 Ajv 严格校验，导致接收器不能启动；改为剔除契约元数据、保留业务 Schema 的严格校验。独立编辑页最初采用宽泛前缀匹配，会错误接纳未知后台地址；已改为类型注册声明的精确子路由。事务失败测试最初期待 500，但项目的数据库异常约定为 503，已对齐并验证回滚。完整测试第一次还暴露专用测试库未迁移；通过明确的 `init.database.py --config config.test.local.toml` 升级后全部通过。未隐瞒失败，也未用跳过数据库测试替代验收。

## 限制与下一步

首次完整分发上限 8 MiB，保留不可变旧版本，尚无增量/分片/GC、节点心跳、向已打开浏览器主动刷新或完整 source_epoch 灾备自动化。已同步只代表最后持久 ACK；未收到撤回的离线节点仍只能知道自己的旧版本，恢复后应用最新 release。浏览器历史后退未实现全面未保存拦截，刷新后本地输入不恢复。

新文章/说说当前为公开发布，暂不做定时/密码/成员限定、分类标签/SEO 细设、封面、媒体插入器、Y.Doc 和完整代码页面设置；原 WordPress 公开内容尚未转成新草稿编辑记录。后续在此事务与版本边界上继续，而不是直接覆盖快照文件。仅本地 Git 提交，用户自行推送。
