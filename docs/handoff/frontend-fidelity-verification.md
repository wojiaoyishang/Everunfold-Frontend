# 原站前台复刻：本轮实现与验证

日期：2026-10-30。用户已授权修改。对照依据为 [上一轮审阅](original-site-ui-audit.md)，本轮实际修改前端；后端只同步文档。

## 实现范围

- 普通新会话默认播放原 WebM；本标签会话可暂停，保留当前帧和跨页时间。播放按钮加入右下纵向工具列；回顶在 400px 以下隐藏，展开/收起及间距都有过渡。
- 有限滚轮插值、平滑回顶/锚点、页面及锚点历史位置；点击文章/分页/搜索共用保留旧内容的 transition，顶部累计假进度完成后淡出。删除根加载占位。
- 封面内标题/元信息、遮罩、标签、浅紫卡片、横幅与内容起点、带图标的完整公开导航、侧栏标题与分级菜单、概览外链。公开内容数量保持真实。
- 目录高亮与跟随、阅读进度、评论定位、图片查看/左右切换/Escape、字体/字号/阴影/滤镜/圆角设置；旧折叠和提示语法安全转换。
- 新增组件及 core/browser、rendering/shortcodes 等边界；没有直接复制运行原主题脚本，没有增加运行依赖。

## 未穷举与接续

- 没有逐一切换真实系统的减少动态/省流量设置，也没有覆盖所有触控板、鼠标和移动真机；代码已有保守降级，最终惯性强度请用户以实际设备体验。
- 当前设置支持字体、字号、阴影、滤镜、圆角和深浅色；完整主题调色器和全站所有细节未逐像素复刻。
- 展示短代码不是旧插件运行环境；未列入支持范围的语法、特殊布局、链接图片的原链接行为仍保留。没有开放登录、评论提交或管理后台。
- 本轮未改真实配置、公开快照、后端代码/数据库/契约、备份或线上站点；未重跑后端测试，不把历史后端检查写成本轮新结果。
