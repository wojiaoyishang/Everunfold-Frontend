# 导航与慢网反馈交付验证

日期：2026-10-31。前端功能提交 `2e300d1`，最终横幅样式提交 `175572d`；后续交接文档提交见日志。分阶段本地提交，没有 push。

## 本轮结果

顶部导航背景完全透明；移除永久选中下划线和鼠标点击残留框，保留键盘提示、aria-current 及侧栏选中项。普通导航先完整读取目标公开文档，再交给 Next 切换；新 DOM 提交后定位正文，旧页不预先上滚。5 秒后进度展开为颜文字横幅，20 秒超时显示失败和重试/继续阅读；支持取消、重复点击去重及最后一次选择优先。

用户本轮最后确认的展示要求是**导航栏下方的通栏延伸**。最终横幅放在 SiteHeader 内，按实际导航高度定位；浅色表面、主题色文字/细进度线，菜单始终可操作。没有采用悬浮卡片，也不覆盖导航。

内置浏览器使用临时本地代理 3901 注入延迟/状态，正常服务仍为 3000/8001，未重启。测试后恢复到 3000，关闭代理并恢复原视口。

## 明确限制

- 准备文档后仍有 Next 路由传输，增加一次 HTML 请求；未增加正文缓存或私有 RSC 接口。详见 [ADR 0009](../decisions/0009-navigation-readiness-and-feedback.md)。
- 单独让 Next RSC 阶段立即返回 503 时，框架回退到完整文档加载，最终文章可打开但 scrollY=0；这一路径不是软失败提示。准备后立即完全断网、生产代理/CDN 故障和跨会话阅读位置未验收，不能承诺所有网络失败均保留当前文档。
- 20 秒是本轮工程初值，集中常量可调整；后台主题设置、正式写入、整体导入、生产部署和生产多进程缓存验收不属于本轮。

复查步骤见 [慢网预览指南](../development/navigation-network-preview.md)。公共说明和原基线在双仓库核对哈希同步；后端仅更新交接文档，不重复执行后端业务测试。
