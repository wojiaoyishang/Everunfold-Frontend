## 功能与部署

- 本地生成图片为默认提供方，另交付Google reCAPTCHA v2 Checkbox、Cloudflare Turnstile适配器与独立前端插件。全局登录、文章/说说/页面阅读和评论开关，单篇inherit/required/off覆盖，私有配置独立修订/CSRF与密钥不回显。
- 受限内容的正文/摘要/媒体映射、页面HTML/CSS/JS/options不进入公开SSR/快照/正文搜索；私有解锁返回阅读回执，评论落库为待审核。密码、评论开关和可见性继续独立生效。
- API Key必须明确包含阅读/评论免验证码权限并得到全局许可才豁免对应挑战，默认每Key阅读侧预算60次/分钟。既有Key不增权；无效/过期/撤销/错误audience均不降级匿名。验证途中撤销在提交围栏被拒绝，回执与挑战禁止跨凭据使用。
- 后端源码统一app/plugins，删除根plugins旧占位；前端根plugins仍是独立产物目录。迁移0028_captcha已显式应用于容器开发库与专用测试库，启动无自动迁移；无新增依赖。六个服务继续HTTP调试并绑定0.0.0.0，实际地址和凭据仅保留忽略的本机配置。
- 契约锁定：captcha1.1.0、content-access1.3.0；auth0.3.0、content-admin1.14.1、collaboration2.3.0、pages1.7.1、public0.10.1、settings1.15.0及presentation0.2.0-preview.2。后端先提交权威Schema，前端按提交与SHA生成；不手改var/cache生成物。
