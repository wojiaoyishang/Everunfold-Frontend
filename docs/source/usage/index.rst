站点后台使用
============

这些步骤适用于有相应权限的编辑者和管理员。后台菜单依当前账号权限、站点配置和已启用插件显示。
若从公开站点进入，在 ``/login`` 登录后通过账号中心进入工作台。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 任务
     - 入口
   * - 编辑并发布文章或说说
     - 「内容」下相应列表，见 :doc:`writing`。
   * - 创建页面、模板或组件布局
     - 「内容 → 页面」，见 :doc:`pages`。
   * - 更新品牌、导航或搜索展示
     - 「站点设置」和「外观」，见 :doc:`site`。
   * - 维护账号、评论和投递
     - 「成员与互动」「通知与消息」，见 :doc:`accounts` 与 :doc:`notifications`。
   * - 启用与配置扩展
     - 「设置 → 插件管理」，见 :doc:`extensions`。
