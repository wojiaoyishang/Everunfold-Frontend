账号、访问和评论
================

配置账号入口
------------

1. 在「通知与消息 → 通知平台」先准备认证邮件需要的发信配置，再到
   「成员与互动 → 访问与安全」选择默认配置。
2. 按站点需要选择关闭注册、仅限邀请或开放注册，并单独决定是否允许全站找回密码。
   邀请注册时，从同页的邀请区创建所需邀请码。可以按实际目的设置数量与失效时间。
3. 登录、注册或邮箱发码使用的验证码在「设置 → 系统设置」配置。
   验证码供应商、账号验证用途、阅读验证和评论验证各自检查。
4. 用普通测试账号确认注册、邮件收取和登录。通过邮箱验证码完成的注册会记录邮箱已验证。
   站点用户如需换绑，在账号中心验证新地址。

管理员可以在「用户管理」创建用户、维护权限，或对邮箱验证执行人工通过和撤销。
人工通过和本人验证是不同的验证来源。用于登录和找回密码的邮箱应通过本人验证。
两步验证由账号中心管理，可用性取决于后端主密钥配置。启用后保存恢复码，
登录时按账号实际要求完成第二因素。

评论审核
--------

「讨论设置」控制访客评论、自动审核和关键词规则；单篇内容的评论仍可单独关闭。
审核员在「评论管理」检查待审核记录，通过后评论进入公开可见状态。
评论通知的审核链接进入管理员确认页。收到重复通知时，以评论管理中的当前状态为准。

邮件、模板和投递记录的操作见 :doc:`notifications`。阅读授权与验证码问题可查
:doc:`../operations/diagnostics`。
