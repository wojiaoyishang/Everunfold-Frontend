AI 写作助手
===========

配置服务商
----------

1. 启用「插件管理 → AI 写作助手」。打开「设置 → AI 写作助手 → 模型服务商」。
2. 新增服务商，填名称、OpenAI 兼容接口地址和模型 ID。按服务商要求填写 API Key，
   使用 HTTPS。私有网关由部署侧设置允许来源。
3. 保存配置后选中服务商并点击「测试连接」。可独立测试每一家，再设定默认服务商。
4. 打开总开关，并在「生成入口」逐项启用摘要、页面说明、搜索标题或分享文案等字段。
   保存后打开对应编辑器确认按钮出现。

生成并采用
----------

编辑者点击字段旁的「AI 辅助生成」，先核对弹窗展示的素材与服务商。
默认选中站点默认项，可以手动切换。点击「生成」才会请求模型。
排队和生成时会显示状态与加载条，开启减少动态效果时显示静态指示。

生成结果在弹窗内预览。选择「采用」后文本回填该字段，按编辑页原有流程继续保存或发布。
更换服务商会清掉上一条候选结果，可以按所选服务商再次生成。
遇到受限内容时，仅确认适合发送的材料。若显示配置变更，关闭弹窗再打开。
