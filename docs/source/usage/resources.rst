媒体、分类、术语与短代码
========================

媒体、图标与字体
----------------

- 「资源 → 媒体库」用于上传、选择与管理文件。保存前确认展示图、替代文字和链接。
  从编辑器打开选择器时，调用方决定是否允许多选。例如画廊需要多张图片，
  普通封面只选一张。
- 图标和字体分别在「资源 → 图标库」及「资源 → 字体库」管理。
  主题或编辑器中选择资源后，务必在匿名公开页检查能否加载。
- 删除资源前检查正在使用它的正文、封面、导航或主题。变更后核对公开页面，
  避免残留指向已移除资源的链接。

分类与标签
----------

「内容 → 分类与标签」管理文章的归档维度。分类支持组织结构，标签适合同一主题跨分类索引。
修改名称或固定标识后，检查文章关联、站点导航和归档链接。书籍类页面把选定分类作为目录来源，
因此调整分类可能改变书籍页面所列文章。

术语和短代码
------------

「内容工具 → 术语表」维护词条、别名和说明。配置术语后在公开正文检查悬浮提示和文末脚注。
词条有独立的编辑与发布状态，正文的识别还受全站与内容设置影响。

「内容工具 → 短代码库」列出可用短代码，编辑时优先用编辑器的短代码按钮生成调用和参数。
例如画廊可从媒体库多选图片。回复可见和密码可见的区域由后端校验，
可在匿名窗口核对访问条件，避免把受限内容手动复制到公开摘要或 SEO 字段。
