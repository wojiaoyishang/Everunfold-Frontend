站点、外观、语言与搜索
======================

站点品牌与主题
--------------

在后台打开「设置 → 站点设置」。右侧「快速导航」可以跳到「基本资料」。

.. figure:: /_static/screenshots/site-profile.webp
   :width: 100%
   :figclass: annotated-shot
   :alt: 后台基本资料，①站点名称，②站点图标及媒体库按钮。

   「基本资料」的名称和图标字段。图中的媒体引用已遮盖。

1. 修改 ①「站点名称」。如果首页正在使用主题自定义标题，接着检查下节的主题设置。
2. 在 ②「站点图标」点击「媒体库」选择图片。该设置用于登录页、后台标识、浏览器标签页及默认邮件图标。
3. 点底部「保存更改」。去「节点状态与维护 → 节点缓存」确认「站点设置」版本已应用，
   再打开公开页和登录页核对名称及图标。浏览器标签页仍显示旧图时，可用新窗口核对。

**修改前台顶栏和侧栏头像**

打开「外观 → 主题设置」。以当前内置主题为例，右侧快速导航选择「顶栏标识」。

.. figure:: /_static/screenshots/site-theme.webp
   :width: 100%
   :figclass: annotated-shot
   :alt: 主题的顶栏标识，①标识显示方式，②顶栏实时预览。

   在「主题设置」中调整顶栏首页链接的文字和图片。

1. 在 ①「标识显示方式」选择适合的样式，填写「顶栏文字」或从「媒体库」指定「顶栏 Logo」。
   顶栏文字留空时依次使用横幅标题、站点名称。
2. 在 ②「顶栏实时预览」核对结果。若选了图片但仍显示文字，先检查「顶栏 Logo」是否已选中。
3. 博主头像在「侧栏博主卡片」，首页的大标题和副标题在「站点横幅」。
   保存后打开首页，并在桌面和移动抽屉中分别核对。

调整菜单时，打开「外观 → 导航菜单」，检查菜单顺序与目标。关联某个页面时可选已登记的站内资源。
主题侧栏默认沿用顶栏菜单，单独设置侧栏菜单时，分别点击两个位置的链接进行核对。

内容与界面语言
--------------

打开「站点设置 → 语言」，启用所需语言，核对显示名、路径前缀和「默认语言」后保存。
例如启用英文后，回到文章编辑页，通过「管理语言与译文」创建英文版本并发布。
核对公开页面的语言切换入口及两种语言各自的 URL。修改默认语言或路径前缀时，另外检查旧链接。
界面按钮等文案可在「外观 → 翻译字符串」维护。

搜索与订阅
----------

在「站点设置 → 搜索展示」可填写默认标题格式、描述和站点收录策略。
例如 ``%s · %site%`` 会把页面标题和站点名称组合起来，填写后可用同页「搜索展示预览」核对。
单篇文章的标题、描述和分享图在编辑页「搜索与分享」设置。
阅读权限由对应内容的访问设置决定。

.. figure:: /_static/screenshots/site-discovery.webp
   :width: 100%
   :figclass: annotated-shot
   :alt: 站点地图与订阅设置，①站点地图及订阅开关，②站点地图预览、XML 和 RSS、Atom 链接。

   「站点地图与订阅」同时提供设置和实际输出入口。

1. 在 ① 启用「生成站点地图」或「启用 RSS / Atom 订阅」，按需修改订阅条数和正文范围。
2. 点「保存更改」，待目标节点应用后，使用 ② 的「查看站点地图」检查给人阅读的列表。
   再打开旁边的 ``sitemap.xml``、``robots.txt``、RSS 和 Atom，核对程序读取的输出。
3. 如果刚发布的测试文章在地图里找不到，先检查文章是否公开且允许收录，再去
   :doc:`../operations/nodes` 核对「公开内容」版本。站点地图会跳过预览、受保护及不允许收录的内容。
