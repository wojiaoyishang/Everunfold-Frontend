站点、外观、语言与搜索
======================

站点品牌与主题
--------------

「设置 → 站点设置 → 基本资料」维护站点名称、作者名称、简介和站点图标。
站点图标用于站点标识。要修改主题中的博主头像、横幅或顶栏品牌，
到「外观 → 主题设置」编辑对应项。顶栏的可选形式取决于启用的主题及其声明。

在「外观 → 导航菜单」检查菜单顺序、链接和当前主题的导航位置。
关联某个页面时可优先使用已登记的站内资源，调整页面后再核对导航。
把长标题或标识放入主题设置时，检查桌面侧栏、移动抽屉和登录入口的实际效果。

内容与界面语言
--------------

站点支持启用或禁用内容语言、设置默认语言以及按站点规则输出语言路径。
先启用所需语言，再从内容编辑页建立译文。界面文案使用「外观 → 翻译字符串」维护，
内容译文从对应文章、说说或页面进入。修改语言设置前核对公开入口和旧链接。

搜索与订阅
----------

- 「站点设置 → 搜索展示」配置默认标题格式、描述和站点收录策略。
  标题格式可用 ``%s · %site%``，分别代入页面标题和站点名称。
  默认描述留空时使用站点简介，文章优先使用各自摘要。
- 文章、说说、页面和术语编辑页的「搜索与分享」可设置单项标题、描述、分享图片和收录选项。
  访问权限仍由对应内容的阅读授权决定。
- 「站点地图与订阅」控制 Sitemap、RSS 和 Atom。保存并等待节点应用后检查
  ``/robots.txt``、``/sitemap.xml``、``/feed.xml`` 和 ``/atom.xml``。
  浏览器可使用站点地图预览入口，程序从 XML 地址读取。若站点关闭索引或订阅，
  以当前设置对应的 HTTP 结果为准。

保存站点或主题设置后，到「节点状态与维护」检查应用结果。后端已保存时，
前端节点仍可能正在接收；此时用目标节点的公开 URL 验证最终效果。
