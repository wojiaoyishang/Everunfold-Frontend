启用插件与切换主题
==================

「设置 → 插件管理」显示当前节点登记的已部署插件。部署由维护者在前端或后端完成，
后台负责启用、停用和打开已注册的设置入口。部分插件会在侧栏注册独立页面，
也可以从插件卡片的「配置」打开设置。

1. 确认部署清单已刷新，当前节点已经登记需要的插件和主题。
2. 启用插件后核对对应的页面类型、短代码、表单入口或后台菜单是否出现。
   需要配置的扩展先保存配置，再进行测试。
3. 有主题推荐列表时可选择批量启用，以当前清单中可启用的插件为准。
   停用前检查文章、页面、导航和短代码依赖。
4. 切换主题后，在「外观」调整主题专属配置。检查公开页面和移动导航，
   并查看节点是否应用了新设置。

自定义扩展由开发者按对应仓库的开发章节实现。涉及文件部署和节点登记时，
见 :doc:`../operations/nodes`。
