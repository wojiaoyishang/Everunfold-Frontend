文章、说说与发布
================

创建草稿
--------

.. figure:: /_static/screenshots/writing-editor.webp
   :width: 100%
   :figclass: annotated-shot
   :alt: 新建文章界面。标记 1 指向标题和固定链接，标记 2 指向 Markdown 正文。

   新建文章时，先确定标题与地址，再编辑正文和保存草稿。

1. 从后台左侧「内容」打开「文章」或「说说」，点击右上角「新建文章」或「新建说说」。在编辑页的 ① 处输入标题，
   查看下方自动生成的「固定链接」。需要自定义时点击「编辑」。创建前用「内容语言」选定语言。
2. 在 ② 处的 Markdown 区块中输入正文。需要另一种格式时点击「添加区块」，再选 Markdown 或 HTML。
   插入图片可使用工具栏中的媒体入口。
3. 打开右侧「内容设置」，按需要设置分类、标签、可见性、评论及「搜索与分享」。摘要在正文下方；
   留空时可从正文生成。搜索标题或描述留空时，在前台预览中核对实际显示。
4. 点击顶部「创建草稿」。已有草稿通过「保存版本」记录修改。用「正文预览」检查排版，
   或点「保存并预览」在新标签页查看完整主题；已经保存时，入口显示为「前台预览」。
   草稿预览需要相应后台权限，读者仍看到当前已发布版本。

发布与撤回
----------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - 操作
     - 如何确认
   * - 立即发布或更新发布
     - 在已保存草稿右上角点「发布」或「更新发布」。打开「查看前台」核对正文；
       发现仍是旧内容时，到「节点状态与维护」查看前端应用回执。
   * - 定时发布
     - 展开「内容设置」中的「发布设置」，把「发布方式」切换为「定时发布」，
       按当前设备时区填写「定时发布时间」，再点顶部「安排发布」。在内容列表的「待定时发布」中核对计划。
   * - 撤回
     - 在编辑页点击「撤回」并确认。等目标节点应用新版本后，用未登录窗口检查原地址。
   * - 移至回收站
     - 在文章或说说列表点击对应条目末尾的垃圾桶图标。需要找回时切换到「回收站」，点击「恢复草稿」。

提交成功和节点已经应用是两个状态。若后台确认已发布但公开页内容未更新，
先在 :doc:`../operations/nodes` 对照后端修订和节点回执。

协作与版本
----------

区块模式下，同一语言版本的工作草稿可协同编辑。在标题下方的协作栏观察「正在实时保存」和
「已保存到服务器」。断网时点「继续本地编辑」，恢复连接后用「比较与合并」查看本机与在线稿件的差异。
从协作栏的「版本」也可查看已保存的历史。若仍未连上，使用「导出草稿」保留一份本机内容。

切换「组件模式」前先保存当前内容，再进入「实时预览」工作区添加和编辑组件。

在已保存稿件的标题下方点击「管理语言与译文」，可创建译文或关联已有稿件。原文与译文共享翻译组，
各自有地址和发布状态。发布具体语言的版本后，读者即可访问。修改站点启用的语言见 :doc:`site`。
