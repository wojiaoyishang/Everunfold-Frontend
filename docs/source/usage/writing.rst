文章、说说与发布
================

创建草稿
--------

1. 在「内容」打开文章或说说，新建草稿。填写标题，检查固定链接与内容语言。
   调整已有公开内容的地址前，先记录旧地址和站内链接。
2. 按需要添加 Markdown、HTML 等区块。插入媒体使用编辑器的媒体入口，
   推荐在媒体详情填写读者需要的替代文字。分类和标签用于公开归档。
3. 设置摘要、分享图、可见性、评论和搜索展示。搜索标题或描述留空时，
   预览实际页面使用的回退值由站点与内容配置决定。
4. 保存草稿或版本。用前台预览确认标题、段落、媒体与移动端排版。
   草稿预览需要后台权限。公开页面仍使用当前发布版本。

发布与撤回
----------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - 操作
     - 如何确认
   * - 立即发布或更新发布
     - 编辑页确认发布状态。在「节点状态与维护」核对前端应用结果，再打开公开 URL。
   * - 定时发布
     - 先核对时区和计划时间。到点后检查运行记录、最终发布状态与前端应用结果。
   * - 撤回
     - 编辑页确认撤回后，用匿名窗口检查原地址。等相关节点应用新版本。
   * - 移到回收站
     - 从列表或编辑入口执行，之后可在回收区域处理。永久删除前检查关联媒体和链接。

提交成功和节点已经应用是两个状态。若后台确认已发布但公开页内容未更新，
先在 :doc:`../operations/nodes` 对照后端修订和节点回执。

协作与版本
----------

区块模式下，同一个语言版本的工作草稿可以协同编辑。发生断网时保留本机草稿，
恢复连接后核对同步反馈。遇到并行修改时，可以先打开版本对比，再决定是否合并、恢复或重试。
组件模式通过实时预览工作区编辑。切换编辑模式前先保存当前内容，并核对协作状态。

原文与译文共享翻译组，各自有内容、地址和发布状态。新增译文后，读者只有在该语言版本发布后
才能访问正文。修改站点启用的语言见 :doc:`site`。
