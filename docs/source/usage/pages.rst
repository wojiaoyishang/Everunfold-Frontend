页面、模板与实时编辑
====================

选择页面类型
------------

后台左侧打开「内容 → 页面」，点击右上角「新建页面」。在「选择页面类型」中找到要使用的卡片，
再点击卡片内的「新建页面」。已有页面可从页面列表点击标题进入编辑。

.. figure:: /_static/screenshots/page-types.webp
   :width: 100%
   :figclass: annotated-shot
   :alt: 选择页面类型界面。标记 1 指向内置的自定义页面，标记 2 指向前端插件提供的页面类型。

   选择一个页面类型后，可以为每个页面独立填写配置。

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 类型
     - 编辑方式
   * - 自定义页面
     - 在 ①「自定义页面」卡片点「新建页面」，再选择组件模式或源码模式。
   * - 前端注册页面
     - 从 ② 标有「前端插件」的卡片中选择类型，在编辑页的「页面选项」中填写该页面的参数。
   * - 自定义页面模板
     - 从页面列表点击「创建自定义页面模板」。已有模板可从类型卡片编辑，
       也可在模板编辑器点击「使用模板新建页面」。

前端注册的类型和页面实例之间是一对多关系。同一个书籍页面类型可以建立多个实例，
各自选择封面和文章分类。代码注册页面的语言行为由页面实现负责。
自定义页面的语言版本可由管理员维护。

在实时预览中编辑
----------------

在自定义页面顶部输入标题，核对下方的「固定链接」。新页面未填写标题时，保存会按日期和时间补上标题。
「页面布局」可选全宽、带侧边栏、全宽无容器背景或空白。选择「组件模式」后，点击「前往实时预览」。
如果有未保存的更改，应用会先保存草稿，再打开独立的实时工作区。

.. figure:: /_static/screenshots/page-live-editor.webp
   :width: 100%
   :figclass: annotated-shot
   :alt: 自定义页面的实时编辑器。标记 1 指向左栏的搜索组件和布局卡片，标记 2 指向右侧画布中的「将组件拖到这里」。

   空白草稿打开实时预览后，可从左侧组件库搭建右侧页面。

1. 在 ① 的「搜索组件」输入名称，或直接从「布局」中选取容器或网格。
2. 将组件拖到 ②「将组件拖到这里」所在的画布。例如先插入网格，再将标题或图片拖入网格。
   点选组件后修改属性，用顶栏的设备图标核对不同宽度下的排版。
3. 组件可通过「作为参数」将选中的属性暴露给模板使用者。在画布上选择 HTML 或 Markdown 组件，
   打开相应编辑器即可更新内容。需要直接维护整页 HTML、CSS 或 JavaScript 时，在「编辑方式」改选源码模式。
4. 在「阅读显示」找到「隐藏页面标题」，可用页面自己的标题组件代替自动标题。完成后点击「保存草稿」，
   再用「前台预览」核对。准备公开时，在「访问与评论」启用页面，再点「保存并应用」。
   关闭「启用页面」时，应用动作显示为「保存并停用」。

版本恢复
--------

1. 打开已有页面或模板，点击顶部「版本」。从历史中选取左侧版本，在「查看差异」确认变更范围。
2. 点击「恢复左侧版本为草稿」。恢复模板时，先在确认框中核对「受影响的页面」，再点击「恢复为草稿」。
3. 回到编辑器确认草稿。页面用「保存并应用」，模板用「应用模板」。应用完成后，查看前台和
   :doc:`../operations/nodes` 的节点回执。
