页面、模板与实时编辑
====================

选择页面类型
------------

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - 类型
     - 编辑方式
   * - 自定义页面
     - 选择组件模式或源码模式。可直接新建，也可从自定义页面模板新建。
   * - 前端注册页面
     - 由插件定义页面渲染和配置表单，按页面实例填写参数。页面代码可以声明是否开放 SEO 编辑。
   * - 自定义页面模板
     - 管理共享结构和可供页面覆盖的参数。模板有自己的版本和应用步骤。

前端注册的类型和页面实例之间是一对多关系。同一个书籍页面类型可以建立多个实例，
各自选择封面和文章分类。代码注册页面的语言行为由页面实现负责。
自定义页面的语言版本可由管理员维护。

在实时预览中编辑
----------------

1. 从「内容 → 页面」新建或打开自定义页面，确认固定链接、页面布局及编辑方式。
2. 组件模式点击「前往实时预览」。按需要拖入容器、网格、标题、Markdown、HTML 或媒体组件，
   从右侧网站画布核对位置和不同尺寸。通过编辑入口修改源码组件，再确认预览。
3. 要让模板使用者能配置某个组件属性，在组件检查器勾选「作为参数」。
   需要保留自定义 HTML、CSS 和 JavaScript 时使用源码模式。脚本需在授权的隔离环境运行。
4. 在「阅读显示」控制是否隐藏自动页面标题等选项。布局可选全宽、带侧边栏、
   全宽无容器背景或空白。完成后保存草稿，使用前台预览核对，再保存并应用。
   停用会更新读者可见状态。

版本恢复
--------

页面或模板的「版本」入口支持查看差异和恢复到草稿。恢复模板后先核对影响页面清单，
再确认应用。需要撤回变更时，选择历史版本恢复并重新应用，随后检查受影响页面与节点回执。
