前端开发
========

Next.js 负责公开页面、管理工作台和可信扩展的运行。FastAPI 负责账号、权限、
编辑数据和发布事务。前端节点保存后端投递的公开副本，向读者提供公开内容。

从这里开始
----------

- 想找到一项功能对应的源码，从 :doc:`architecture` 按路由、请求和语言定位。
- 改动编辑器、页面和发布链路时，阅读 :doc:`content`，先确定正在编辑的文档格式、版本和可见范围。
- 为站点扩展能力时，按 :doc:`extensions` 选择插件、短代码、组件或子主题。
- 提交或排查故障时，使用 :doc:`checks` 的命令和故障分类。
