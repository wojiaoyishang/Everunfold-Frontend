读者渲染、受限内容与媒体
========================

正文与插件输出
--------------

公开页面由 ``src/themes/argon/`` 展示。编排时使用
``src/core/rendering/render-content-server.ts`` 的服务端渲染以及
``src/core/rendering/content.ts`` 的共享规则。
原文包含 Markdown 或 HTML 区块、短代码及媒体引用。展示时调用当前插件与已发布定义，
并根据宿主的清理规则输出内容。依赖代码高亮、公式或媒体的页面应测试首屏以及随后加载的增强效果。

引入新展示效果时，在素材选择、私有预览和公开阅读分别验证同一份内容。
用户可见文字按所在上下文处理，片段调用参数需要转义。媒体通过稳定引用链接到被验证的媒体资源，
展示时使用解析得到的地址；不要将临时上传占位写入已发布内容。

受限正文
--------

密码内容、阅前挑战以及回复可见或密码区使用适用的后端授权。服务端渲染
和公开副本只能持有后端允许分发的内容。需要解锁时，前台从
``src/core/content/use-protected-content.ts`` 等适用入口获取授权视图。
索引、订阅、搜索、社交卡片以及插件功能都要沿公开条件分类读取。
测试时在不同会话中分别检查匿名、授权和授权失效后访问。

媒体和增强交互
--------------

共享媒体选择器维护资源引用，统一查看器提供适用页面的图片浏览。
词条列表和正文关键词提示读取各自需要的公开词条，避免为了提示装饰阻塞正文。
新资源类型或阅读增强应测试资源不存在、组件停用和后端暂时不可达时的页面表现。
读者数据、设置副本和失效状态见 :doc:`snapshots`。
