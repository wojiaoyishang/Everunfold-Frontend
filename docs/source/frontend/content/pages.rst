页面、模板与实时预览
====================

选择页面类型
------------

- 自定义页面的内容可由组件模式或源码模式编辑。页面路径、布局、标题、语言及阅读设置
  属于页面实例。组件或源码的编辑发生在对应的编辑区和实时预览环境。
- 自定义页面模板保存可复用布局和编辑字段。模板没有公开路径；由模板创建的页面
  持有自己的路径、语言和参数值。
- 代码注册的页面类型由可信插件实现；后台为每个实例保存选项，
  后端发布选项和类型身份。编写这样的插件参见 :doc:`../extensions/public-components`。

后台路径与版本
--------------

``/admin/pages`` 维护页面实例。``/admin/pages/types`` 展示页面类型，
``/admin/pages/templates/<id>`` 编辑模板；
``src/themes/argon/admin/pages/`` 包含这些界面与版本工具。
``src/core/pages/`` 处理路径、语言、配置、公开选择及预览。

编辑一项时先保存草稿。页面「保存并应用」提交当前稿件供公开读取；
停用页面也需要应用当前状态。版本工具可以对比保存稿及应用版本、恢复选中版本为草稿。
恢复模板前检查受影响的页面；需要让新模板进入公开页面时，再明确执行应用。
模板子页尚未应用的实例修改仍独立保留。

组件与源码实时编辑
------------------

实时编辑页使用当前主题。组件模式在画布中插入、重排容器和节点，
源文组件沿用正文使用的编辑器，模板可将组件属性标成参数。
源码模式使用自定义 HTML、CSS 和可选的隔离 JavaScript；脚本可用性由对应配置决定。
测试时检查手机、平板和桌面宽度、返回焦点、保存结果，以及预览和公开页的差异。

草稿预览在管理路径中使用当前用户权限读取相应草稿；公开路径由
``src/core/pages/resolve.ts`` 根据节点副本解析页面。修改布局或语言路径时，
同时检查未发布页面和已停用页面对匿名请求的结果。
