内容语言、路径与界面翻译
========================

选择当前语言
------------

站点语言目录由站点设置维护。每项包括语言代码、可选 URL 前缀、启用状态和
界面语言包 ``ui_locale``，基础目录及校验逻辑位于 ``src/core/i18n/``。
前台路径解析先找到实际内容或托管页面，再根据匹配的语言目录解析
可带前缀的固定路由。检查路径时同时验证默认语言、启用的前缀语言及无翻译的情况。

内容翻译和界面翻译
------------------

文章、说说和托管页面的多语言稿件以翻译组关联。每份内容有自己的稳定 ID、
路径、修订和发布状态。切换内容语言时应使用真实可用的译稿；仅保存草稿的译稿
不会成为公开入口。插件可为登记的页面启用多语言路径并共用选项，
组件通过 ``useRegisteredPageLocale()`` 读当前语言。

界面翻译只处理程序文案。中文默认文字及英文基础包在 ``src/core/i18n/``，
站点自定义译文按 ``public``、``admin``、``backend`` 和语言存储。
前端优先使用当前语言的自定义译文，再按基础界面包与源码默认文案回退。
文章正文、分类名称和用户输入仍由各业务组件处理。

修改一处界面文案
----------------

1. 找到对应的程序字符串，打开 ``src/core/i18n/en.json`` 核对已有位置和英文词条。
2. 需要动态值时保留命名占位符，例如 ``{count}``，将值交给对应翻译函数。
3. 分别验证前台和后台显示，再切换内容语言核对选中的译稿和当前 UI 语言。
   如改动 URL 前缀或原始路径，还要按 :doc:`../content/discovery` 核对
   canonical 与 hreflang。
