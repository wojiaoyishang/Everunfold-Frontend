前端故障排查
============

页面访问或登录失败
------------------

1. 先核对浏览器当前站点地址和实际请求的 API 地址，再分别看前端和后端的
   ``/health/ready``。前端判定是否具备公开内容；后端检查数据库、Redis 和迁移。
2. 检查会话请求是否成功。涉及 Cookie 或 CSRF 的问题，应记录响应状态和 Origin，
   避免把认证头或 Cookie 内容复制到日志及提交记录。
3. 公开路径在有效快照中不存在时检查已发布路径、语言前缀和页面状态。
   快照不可读时按 :doc:`../content/snapshots` 核对节点。

保存成功但读者未看到新内容
--------------------------

在后台查目标内容的草稿修订、已发布版本和节点同步回执。页面还要核对「保存并应用」结果，
以及当前网页进程和接收器使用的来源 UUID 与目录。只调整浏览器缓存无法改变节点上已应用的版本。
需要重新同步时从「节点状态与维护」操作，等待回执后重试匿名页面。

插件页面或组件未出现
--------------------

检查独立构建目录、插件清单和后台启停状态。后台插件还需要当前账号具备已声明权限。
修改宿主 SDK 或独立构建工具后重启开发协调进程；多节点部署同时检查每台节点。
公开类型、短代码与编辑器组件见 :doc:`../extensions/public-components`，
后台路由与字段动作见 :doc:`../extensions/admin-plugins`。

构建时找不到契约
----------------

确认 ``EVERUNFOLD_BACKEND_PATH`` 或同级后端检出的 Git 历史包含锁定提交。
运行 ``npm run contracts:prepare`` 复现，检查提示的文件与摘要。
更换机器后不要手改 ``var/cache/contracts/`` 来绕过锁；契约更新应提交到相关仓库。
