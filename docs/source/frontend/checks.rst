开发检查与验证
==============

提交前运行锁定依赖下的完整检查。涉及权限、内容发布、节点同步或编辑器运行行为时，
再选择对应的隔离验证。运行时故障按浏览器、API、节点副本和扩展包的顺序定位。

工具链
------

:doc:`checks/commands` 列出基础检查和各项生产验证命令。

验证一次改动
------------

先记录受影响的路径、权限、公开状态和已有数据，再选择隔离环境及对应验收场景。

排查运行问题
------------

按故障现象使用 :doc:`checks/troubleshooting` 区分配置、缓存副本和扩展包问题。
