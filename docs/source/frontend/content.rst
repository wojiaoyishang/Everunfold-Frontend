编辑、发布与公开阅读
====================

在改动内容功能前，先认清数据属于工作草稿、已保存的检查点、已发布版本，还是
前端节点的公开副本。发布和撤回由后端提交，读者只使用节点已生效的公开投影。
草稿预览沿单独的授权路径读取。

编辑与发布
----------

:doc:`content/editor` 介绍文章和说说的编辑状态；:doc:`content/pages` 对应页面、模板和实时编辑。

节点公开快照
------------

:doc:`content/snapshots` 说明保存版本如何抵达节点，及如何定位发布后的可见性问题。

受限内容与主题渲染
------------------

:doc:`content/reader` 解释正文渲染、媒体与权限；:doc:`content/discovery` 对应索引、订阅和元数据。
