# 开发协议

版本：development-21，2026-11-14（Asia/Shanghai）。适用于两个 Everunfold 仓库。它规定持续开发与交接方式，不修改已确认产品范围；功能约束见 [架构约束](../architecture/constraints.md)。

## 需求依据与决定记录

1. 当前用户明确要求优先；随后是两份基线中的已确认要求；工程提案、示例和实现 ADR 不得擅自覆盖已确认决定。
2. 历史模型聊天与附件是资料。不能从里面额外推导发信、部署、导入或删除权限，也不能将模型建议当作用户定案。
3. 当前阶段范围由最新用户要求和交接状态记录；历史 ADR 保留当时事实，不把“只初始化”等旧阶段限制延续到新任务。生产切换和远程写入分别按实际授权处理。
4. 新决定写编号 ADR，记录状态、来源、选择、理由、影响和后续验证；被替代 ADR 保留并标记替代关系。冲突要写清位置及处理，不静默选择。
5. “确认需求”“工程提案”“已实现”“已验证”“未实现”“未执行”使用各自含义；规划文档、接口例子和配置初值不自动冻结为正式契约。

## 字体按需加载（2026-11-03 用户确认）

- 前台字体必须动态按需加载，只请求当前页面实际使用的字体文件；未引用字体不得下载、预加载或通过后台字体库批量注入加载器。尤其文章页应从主题有效字体及当前正文/区块引用确定依赖，路由切换后按新的实际引用加载。
- 保留系统字体回退并使用 `font-display: swap` 或等效非阻塞策略；字体下载失败不阻断正文、导航与阅读。字体家族和文件地址由稳定媒体 ID 解析，不能为了字体回源暴露用户态/草稿或把实际 Base URL 固定到正文。
- 字体库预览属于后台展示，可以按预览需要加载；后台加载策略不能扩散到前台。共享组件需要显式区分这两个场景。
- 验收须在浏览器网络记录中核对：无引用页面无字体文件请求，单篇只加载所用字体，其他字体不预取；同时检查路由切换、缓存复用、慢网/失败回退和布局稳定性。

## 代码与公式按需能力（2026-11-04 用户确认）

- Markdown/HTML必须复用统一代码高亮、公式引擎和插入/预览组件，正文保留原代码、语言与LaTeX；不得保存派生排版结果或为两种格式独立实现。
- 资源遵循字体相同的按需原则：当前正文未使用就不下载/预加载公式样式、字体或高亮引擎/语法；不能在根布局批量导入。公开首屏优先服务端生成可读代码与MathML，客户端引擎只在确有需要的消费者加载。
- 系统内置公式字体与用户上传字体分责；资源失败不阻断其余正文。核对含/不含功能文章的真实浏览器资源清单，见[ADR0049](../decisions/0049-shared-code-and-formula-features.md)和[指南](content-features.md)。
- 代码片段参数保留在原始Markdown围栏或HTML pre白名单属性中，不保存高亮DOM；复制保留原代码。公开正文、预览、评论复用共享阅读框，全站默认沿后端theme.code，读者折行/展开只属本页交互。代码字体仅在含代码的正文声明，不因全站配置就对所有文章加载，见[ADR0052](../decisions/0052-shared-code-frames-and-source-options.md)与[代码指南](code-blocks.md)。

公式编辑复用主题结构化窗口、CodeMirror 与原 KaTeX 校验，保持原始 LaTeX 和整篇保存；编辑器及内置字体只在窗口打开时加载。界面 SVG 尺寸不得影响公式内部图形。见 [ADR0050](../decisions/0050-structured-formula-editor-and-theme-toasts.md)。

## 项目与命名

| 项目 | 约定 |
| --- | --- |
| 后端 | 包名 `app`，Python 模块/函数/变量 `snake_case`，类 `PascalCase`，常量 `UPPER_SNAKE_CASE` |
| 前端 | `src/app` 使用 Next.js 文件约定；组件 `PascalCase`，函数/变量 `camelCase`；普通模块按所在目录风格保持一致 |
| 业务标识 | 模块/插件/块/权限使用稳定、有命名空间的 ID；ID 不随展示名称或域名变化 |
| 文档 | 中文说明，文件名使用明确英文主题；ADR 四位递增编号，链接使用仓库内相对路径 |
| API/事件 | 字段和大小写按后端发布契约决定，不把示意 JSON 当成最终 Schema |

两个仓库各自可由 IDE 打开、安装、检查、构建和部署，不引入第三个长期维护的共享代码仓库。运行命令与环境细节在各仓库根 README 和交接状态中维护。

## 依赖与代码风格

- 后端采用 Python 3.12、uv、`pyproject.toml` 与 `uv.lock`，本机 `.venv` 独立且不提交；复现使用锁文件，不用全局 Python 安装项目依赖。
- 前端采用 Node.js 22、npm、`package.json` 与 `package-lock.json`；CI/复现优先 `npm ci`，不混用 pnpm/yarn 锁文件。实际 Node/npm 兼容范围由项目声明，精确依赖以锁文件为准。
- 新增/升级依赖先确认用途、官方兼容约束和许可证影响，提交清单及锁文件；不得为了目录占位引入整套尚未采用的 UI、编辑器或认证框架。
- Python 按项目 Ruff 配置格式化和静态检查，公共接口及重要边界写类型标注。TypeScript 保持严格模式，遵守项目 ESLint/格式化设置，避免用无依据的 `any` 隐藏边界错误。
- 注释解释原因、约束和边界，不复述代码。错误和日志不得暴露堆栈、连接凭据、Authorization、Cookie、验证码或敏感用户输入。
- 小函数/模块围绕实际职责组织；不为假设需求预建复杂抽象。空目录不等于模块完成，未实现入口应明确失败或暂不提供，不能静默返回成功。
- 改行为时同步文档；不以大规模无关格式化掩盖功能改动。

## 可复用结构与事务

- 后端按实际业务模块组织 `models/schemas/repository/service/router`。路由处理参数、身份依赖与响应，服务组织一次业务用例，数据库访问层只读写；只有实际职责出现时才拆文件，不为每张表生成整套空壳。
- 每个请求/任务使用独立数据库 Session；用例边界统一 commit/rollback。业务变更、审计、可靠 Outbox 同事务，文件/网络/邮件不放在长事务中；读接口不私自提交。
- 前端薄路由复用数据服务与主题组件。基础能力放 `src/core/`，主题放 `src/themes/argon/`，页面/短代码等可信扩展集中在src/plugins，主题控件在src/themes。共享导航、卡片、分页、空/错误状态集中维护，不复制粘贴整页实现分类/标签/搜索。
- **所有页面交互控件必须使用项目封装的组件**，包括按钮、链接、输入框、文本域、选择框、复选框、开关、滑块、颜色选择器、表单、弹窗/弹出面板和横向列表交互。当前基础控件入口为 `src/themes/argon/components/ui/`；站内导航/搜索表单继续使用 AppLink/SearchForm。新增第三方控件也必须先适配封装，不在页面直接使用或恢复浏览器默认外观。
- 数据库删除、撤回、放弃未保存修改等二次确认统一使用 `ConfirmDialog`；未保存的本地正文块移除按用户明确要求使用共享 `ConfirmPopover` 就地确认（ADR 0036），不能扩大为永久删除的默认形式。业务提供文案、选项、请求状态和动作，禁止页面自行拼接确认区或使用 `window.confirm`。组件负责水合/焦点/嵌套模态隔离及处理中防重复，详见 [ADR 0028](../decisions/0028-shared-confirmation-dialog.md)。
- “放弃修改并离开”的站内目标必须在确认退场后走 Next.js 客户端导航，不得使用 `location.assign` 触发整文档刷新；只有跨域目标或确实需要新文档的外部协议才使用浏览器文档导航。共享离开守卫负责统一该行为。
- **所有交互都必须有与状态变化对应的动效反馈**：悬停/按压、选择/切换、展开/收起、弹层进退、等待/结果提示都在共享组件中实现，页面只声明状态。新增或修改控件时同时验收进入与退出，不能只给出现过程加动画；不使用 `transition: all`，不以动画延迟业务请求或键盘响应。
- 2026-11-04 用户明确区块的源码/可视化切换即时完成，省去模式切换动画并恢复选区/焦点。此项是上条通用动效规则的限定例外，见 ADR0044。
- 正常关闭或导航应在当前弹层退场后发生；不能先卸载再期待 CSS 播放。关闭期间防止重复动作，成功、失败、卸载和动效中断均须可完成；退出等待必须有上界。统一确认窗口的 `onConfirm` 返回成功布尔值，`onConfirmed` 在退场后关闭/导航；详见 [ADR 0029](../decisions/0029-interaction-motion-lifecycle.md)。
- 动效继续服从当前展示区的减少动态偏好，保留可见状态/键盘焦点；前台与后台偏好独立。减少动态时无需等待退场，持续动画只用于真实等待状态；正常反馈采用轻量颜色、透明度与小幅变换，避免布局跳动或反复晃动。
- 封装层保留原生语义、标签、键盘操作、焦点、表单值、禁用及错误状态；不要用不可访问的 div 模拟按钮。普通排版标签无须制造同名空包装；文章/用户正文的安全渲染不视为页面控件。ESLint 阻止页面/主题封装层以外新增裸交互标签，新增例外必须说明实际边界。
- 品牌填充、文字强调、淡色背景、选中/悬停/焦点和渐变统一消费主题变量；禁止在组件中写死品牌紫色。文字强调色与白字按钮填充色分责；深色、自选色和纯黑模式一并验证。错误/警告等语义色、独立头像识别色和原始媒体颜色保留各自含义。
- 后台展示仍归前端主题，但按 public/auth/admin 分区提供样式和语义变量。后台外观/密度/动效可以独立，个人偏好与前台阅读偏好分开；CSS 选择器、浏览器副作用及 Portal 弹层必须覆盖隔离边界。权限、请求和业务规则不进入主题。新设计及分阶段拆分见 [后台界面与主题架构](../architecture/admin-ui.md)，当前已按展示区隔离；后续组件和弹层继续遵守该边界。
- 每完成一个新增或修改的可见组件，立即在内置浏览器检查实际页面后再继续，不能只依靠构建或累计多处改动后才查看。必须实际查看截图，并核对标题/说明/标签/控件之间的上下间距，不能把仅生成截图当作视觉验收；发现通用样式覆盖时，同时复查代表页面。记录桌面/窄屏、打开和关闭、键盘/焦点、减少动态的实际结果；截图只保存本地自建测试内容。日期/时间输入统一复用主题 `DateTimeField`，不得退回裸文本日期或浏览器默认控件；见 ADR 0035。
- 后台不使用宣传、欢迎或重复介绍来填空；文案只保留功能名称、会影响用户选择的具体说明、范围/风险和真实状态。页面标题能说明的内容不再复述。
- **Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.** 避免不必要的辅助标签与说明。通过位置、分组、留白和状态表达层级；保留控件名称、无障碍读屏标签、必要状态、错误和风险提示。
- 界面方向箭头统一使用 SVG 图标组件，不以 Unicode 箭头、尖括号字形等字符充当图标；纯图标按钮须有可读名称。用户正文和评论中的符号保留原文，不做界面图标替换。
- 生成代码只由契约脚本更新。抽象须能减少已存在重复或隔离已明确边界，不预建通用插件框架、事件总线或页面搭建器。
- 时间存储/接口使用带时区 UTC，展示按站点/用户时区；源数据缺失/无效日期必须显式报告转换规则，不因本机时区改变导入结果。

## 本地资源与测试隔离

开发库 `everunfold_dev` 与测试库 `everunfold_test` 分开；集成测试必须显式指定测试连接且拒绝开发库，不静默回退。Redis 采用项目及环境命名空间，测试再用独立运行标识；测试数据清理不影响开发队列或其他项目。

旧站导入只读取允许的公开字段；用户账户、密码文章、草稿、私有内容、评论邮箱/IP 不进入公开产物。下载资源记录来源、哈希与用途，签名链接不写入公共清单；本地生成的内容快照和文章媒体不提交 Git，主题必要公开资产可提交。用户要求参考旧站外观，不能把不同布局/配色作为无说明的替代。

## 配置与安全

根 `config.example.toml` 从工程原文提取，是规划模板；当前未具备完整显式加载/校验前，不宣称其参数生效。实现加载器时再交付配置 Schema、覆盖表、来源优先级、校验和脱敏说明。

实际 `config.toml`、本地环境文件、凭据和数据目录忽略提交。模板只含公开示例或环境变量引用，不能复制 WordPress 实际数据库密码、密钥、Cookie 或备份内容。不要把 `config.example.toml` 自动当生产默认配置。

服务地址、Cookie/CORS 和节点地址可配置，不能把本机/示例域名写成生产默认。前端公开配置只允许明确列出的非敏感字段；整个 `[backend]` 和内部覆盖地址不得注入客户端。

所有有状态业务由 FastAPI 授权；前端可见性不是权限校验。业务写事务、审计和 Outbox 协调提交，事务中不执行外部网络副作用。内部认证保持真实 IP 与 Token 的 AND 校验；任何例外必须有明确设计及验证，不能降级成信任请求头。

## 契约发布与兼容

- 后端 `contracts/` 是 API/WS/事件契约权威定义或导出位置；每次发布记录契约版本、源代码版本及兼容范围。
- 前端从明确的后端 tag/commit 或发布产物生成类型和客户端，记录产物来源及校验值；不从未锁定分支自动拉取并覆盖生成代码。
- 生成文件不手改。需要修改先改权威 Schema、重新导出，再更新前端锁定来源并生成。
- 协调破坏性变更前先说明迁移、发布顺序和兼容窗口；两个仓库不假定同一时刻部署。首版不兼容发布可使用维护窗口。
- 核心/插件、快照/渲染器及来源代际是不同版本维度；不得只增加应用版本就假定缓存、Schema 和旧浏览器全部兼容。
- 开发代理只是路径转换；生产跨源、Cookie、CSRF 和 WS 单独验收。不得把 `/api` 前缀写入后端业务契约。

## 统一上传与删除

所有当前及后续上传入口都使用 core/http/upload-transport、core/media/upload-queue 和主题封装 FilePicker/UploadQueueView；业务适配只负责校验、准备稳定请求 ID、调用后端生成客户端。必须支持多文件、逐项进度/停止/重试及失败隔离。浏览器无法提供上传进度时退回单次请求加不定进度，不能伪造百分比；100% 传输不等于后端保存成功。禁止在页面另写一套上传传输、队列或原生 input[type=file]。

正文图片上传使用主题全局 ToastProvider/useToast 适配同一队列，不另实现上传浮层或伪进度；完整媒体管理页保留队列视图。通知封装进退场、关闭、焦点/悬停暂停计时及错误动作，调用者按稳定 ID 更新并只清理自己拥有的通知。详见[指南](formula-editor-and-toasts.md)。

新增上传类型和删除行为须先更新后端契约。前端不自行计算引用数量或删存储路径。媒体默认回收；永久删除使用范围预览、版本/摘要保护和稳定操作 ID，明确区分当前记录、安全保留共享原件与整组清理。新增媒体引用写入者必须加入引用检查与协调守卫，包括将来的正文修订、协同草稿和插件数据。完整不变量见 [ADR 0027](../decisions/0027-shared-upload-queue-and-safe-removal.md)。

## 公开首屏与动态补充

以下约束用于动态请求持续开发，设计说明见 [公开首屏与动态数据](../architecture/public-dynamic-data.md)，本轮演示基线见 [ADR 0014](../decisions/0014-page-registered-reader-requests.md)；规则不代表所有正式业务能力已经上线。

- Next.js 应能从合法公开快照输出正文、关键元信息和可发现链接，公开首屏不依赖浏览量或用户态接口；浏览器业务请求直接访问配置的 FastAPI，不下发整个服务端 `[backend]` 配置。
- 浏览量等可选实时字段必须区分未知、等待、成功的真实零值与失败；按本轮要求在未成功时隐藏，成功后自然显示，不挤动阅读位置。不把可选字段加入导航就绪条件，也不为它们反复弹出页面导航错误横幅。
- 公开评论遵循快照先读、浏览器异步更新；失败保留仍允许公开的快照。用户主动提交的失败必须明确反馈，不能套用指标静默隐藏规则。
- 公共快照无时间 TTL；动态补充、用户态与公开内容缓存分别管理，已知撤回/转受限时禁止旧内容回退。用户态不得进入公共 SSR/共享缓存，退出/切换账号必须清理旧状态。
- 状态图标只能表达实际检查过的能力及时间；一次 API/健康检查成功不证明节点快照同步或所有写能力可用，取消/过期请求不归为服务故障。
- 当前页所需请求由页面/功能组件注册，公共面板不写死业务字段清单；额外展示使用页面插槽。未注册项目不算失败，无项目不显示同步成功；卸载/换页要释放，避免遗留请求或面板内容。
- 动态请求复用共享协调与生成客户端，考虑批量/去重、取消/乱序、部分失败与有界超时重试；指标与状态控件继续使用项目封装和统一主题变量。
- 读取统计不产生浏览记账副作用；业务写入的幂等和持久成功由后端保证。计数口径、建议时长和接口形状须在正式契约/实施决定中明确，不能把设计提案当成已确认产品参数。

## 检查与完成判据

按改动风险选择检查，记录实际运行命令及结果：

| 改动 | 必要检查方向 |
| --- | --- |
| 初始化骨架 | 依赖可从锁文件复现、格式/lint/类型检查、最小行为检查；前端构建 |
| 文档/配置模板 | 链接、范围/状态、TOML 语法、原始文件哈希及双仓库同步；不编写镜像实现的无效测试 |
| HTTP/权限 | 真实状态码和响应外壳、未授权拒绝、CSRF/CORS、重试幂等和冲突行为 |
| 数据/任务 | 真 PostgreSQL 约束与事务、Outbox 恢复、重复任务、尝试预算与未知态 |
| 协同/缓存 | 真实多进程、丢通知/重连、持久 ACK、撤回/乱序/磁盘故障，按原文 P0 门槛 |

检查通过后不无故重复扩大测试；有新变化、失败或未决风险时再补充。受本机平台、服务缺失或权限限制未执行的检查必须写“未执行”及原因，不写成通过。CI 只表示其实际覆盖范围，初始 CI 不是完整生产验收。

完成一次交付至少满足：范围内实现可审阅、必要检查有结果、无秘密或备份入库、相关文档与状态更新、剩余工作清楚。成功启动不等于就绪；不要让占位健康检查声称数据库、队列或缓存已经可用。

## Git 与远端协作

- 开始前看分支、状态和远端，保留用户与协作者修改。先检查远端已有历史，不以空本地目录推断远端也为空。
- 日常功能建议短分支、聚焦提交；小改动可按明确授权直接提交。提交说明可使用 `chore:`、`feat:`、`fix:`、`docs:` 等前缀，主题写清实际结果。
- 依赖清单与锁文件同交付；契约变更与兼容说明一起交付。避免提交本地缓存、构建产物、虚拟环境和大媒体。
- 提交前核对暂存文件、变更摘要和敏感信息。禁止强推、无依据重写历史、递归清理计算出的未知路径或重置他人修改。
- 推送使用用户指定仓库与正常 fast-forward 语义；有远端变化先读取并正常整合。遇到冲突保留双方意图，记录实际解决方式。
- 2026-10-30 最新工作约定：每完成一个可检查阶段及时本地提交，只 stage 本阶段所属文件，避免夹带协作者未完成修改；交付时由用户自行 push，代理不执行远程推送。此前初始化推送授权只属于已完成的历史阶段。

## 数据与 WordPress 迁移

全量备份包含账户、评论者信息和配置凭据，只读预检，禁止加入任一代码仓库。不要执行备份中的 PHP/插件，或将原始 SQL 直接导入生产。迁移实现时先输出统计、映射、短代码/过滤差异和 URL 冲突报告，再按任务范围执行可重复核验的导入。

保留原媒体、正式修订及已确认协同数据的恢复能力；不能以临时清理、缓存回收或插件卸载名义删除业务事实。不在共享 Redis 使用 `FLUSHDB/FLUSHALL` 清理项目。

## 文档与跨上下文交接

- 每次有意义交付更新 `docs/handoff/STATUS.md`：本轮目标、已完成与未完成、精确依赖/契约版本、检查及结果、限制、下一步、未决事项。
- 运行细节写可复现命令，避免只留“测试通过”。状态应描述当前事实，历史过程可放独立记录，勿让下一位开发者从长聊天反推。
- 当前容器的具体测试IP与临时公开URL只保留在本地忽略配置及运行记录中；交接说明测试范围、通用步骤和结果，不记录该设备IP或将临时测试入口升级为长期部署约定。通用监听/回环示例不代表项目部署地址。
- 新架构/契约/迁移文档放对应子目录并更新索引；新决定写 ADR；有冲突时将来源与解决写入决定/状态。
- 公共文档双仓库同步规则见 [基线说明](../baseline/README.md)。原始附件保持字节不变，状态和实现说明不要求两仓库相同。
- 结束或发生上下文压缩前，优先将当前证据、剩余步骤和实际阻塞写进文档。不得在交接中将未验证建议提升为事实。

## 注册式编辑器与协同试用

正文格式与可信编辑器实现分开，插件不得创建另一套文档、历史或发布用例。复用宿主的整篇 Y.Doc、媒体选择/上传与当前主题控件。协同 ACK 等待 PostgreSQL 提交；IndexedDB 跨标签页事务合并状态、outbox 与 ACK，禁止最后写入覆盖另一窗口。导出剔除密码并包含移除块源文；失效会话仅允许导出已授权页面的本机副本，不凭缓存身份开放新页面。

真实双 API/数据库/Redis 故障验收不能用前端单测替代；日志压缩/GC 未实现时必须明示。接口、目录、试用命令与边界见 [ADR 0037](../decisions/0037-plugin-editors-and-collaborative-drafts.md)、[协同架构](../architecture/collaborative-editing.md) 与 [开发指南](editor-plugins.md)。

## 源码正文与上传补充

HTML/Markdown 插件统一消费宿主源码字符串，正文输入先保留在本标签页，整篇保存才提交 block_sources。禁止在模式切换时重新序列化全块，源码映射无法保持结构时明确引导使用源码。旧源码应用协议作为兼容保留，当前入口按 ADR0044 执行。

前台草稿预览属于私有管理路由：复用正式阅读组件，身份确认后直接读后端，SSR/共享缓存不得含草稿。当前“保存并预览”明确先整篇保存，预览不发布、不提交浏览或互动，失败不回退公开正文，见 [ADR0051](../decisions/0051-private-frontend-content-preview.md)。

图片、媒体和上传入口位于工具栏，插入动作直接展开，底部仅保留共享状态栏。二进制图片粘贴复用统一上传队列，临时占位与后端持久媒体分开，正式保存必须通过就绪校验。UI 配色从后台表面色、文字色、边框及强调变量派生，见 ADR0045。

## 独立页面与实时预览（2026-11-06）

独立页面源码仅在不透明来源iframe及CSP内渲染，主编辑页不挂内联预览；注册组件始终来自可信构建清单。页面/文章/说说的独立实时预览复用原编辑器及保存/权限/协同，设备视图和拖动分隔不重建文档，不在URL或公开存储传草稿。内部页面元数据走专用私有接口与独立修订，禁止进入公开页面配置副本。详见[页面指南](pages.md)与ADR0072。

## 插件/主题发现与构建产物（2026-11-07）

遵循ADR0077：只扫描固定可信目录，页面/短代码通过插件setup贡献，不生成组件注册文件。模型组件名开放，主题/插件提供实现，未知展示组件占位而非中断整个表单。src/generated和registrations移除；Git保留精确contracts.lock与工具，var/cache/contracts与var/cache/build忽略，检查/构建统一prepare。生成器内容不变时不得触碰mtime，内容变化原子发布，避免开发编辑器反复重载。数据方法和回调边界先更新规范再实现；没有真实消费者的后端操作不写假成功接口。原var副本不迁移。


## 独立插件包与主题选择

ADR0079覆盖插件随主体编译的旧规则。主体只静态发现主题；插件通过独立编译器和SDK，在生产plugins目录运行时发现。开发源码仍在src/plugins，dev自动编译/监听；不要手工维护摘要文件或恢复generated注册。生产资源先到、清单最后原子替换，失败保留上次可用包；编辑器遇到包集合变化先保留当前构建。Next锁定版本的Refresh宿主适配与Babel转换共同测试，升级依赖须复测兼容Hook状态保留。

主题选择/插件停用列表由后端设置事务及可靠投递管理，Node仅报告受信部署目录。登记真实socket IP AND节点Token，代码与页面私有数据不随清单上传。原运行副本位置保持，根cache合并var/cache；所有派生包/契约/构建数据不入Git。新增主题仍随主体编译，不扩展为动态安装后端代码。详见运行规范和开发指南。
