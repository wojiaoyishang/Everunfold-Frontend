# 多邮件发信配置与测试发送

版本：mail-6；2026-11-11。配置、主动测试、业务通知和账号邮箱验证已实现；邮件提供方插件尚未实现。

## 使用入口

后台「通知与消息 → 通知平台」同时展示站内、邮件和插件渠道。邮件卡片进入“发信账号与默认身份”区域，可添加最多20套 SMTP 配置；原「设置 → 邮件配置」菜单已移除，旧地址 `/admin/settings/mail` 会跳转到发信配置锚点。

读取配置需要 `settings:read`；修改、测试与读取测试结果需要 `settings:write`，沿用会话、CSRF 和 API Key 权限约束。

## 配置模型

每套配置拥有独立稳定 UUID、名称、启用状态与默认状态。非空配置必须恰有一套默认配置；默认配置可以停用，但此时未显式选择配置的邮件提醒会被抑制。

| 配置 | 初值或规则 |
| --- | --- |
| 配置名称 | 必填，1–80字符，站内不重名 |
| 启用发信 | 关闭；停用后不会自动改用其他配置 |
| SMTP 服务器 | 空；主机名或 IP，不带协议、端口或账号 |
| 端口 | 587；允许1–65535 |
| 连接加密 | STARTTLS；也可选直接 SSL/TLS 或不加密 |
| 连接超时 | 15秒；允许3–120秒 |
| 服务器需要认证 | 开启；关闭时可使用无需认证的中继 |
| 用户名、密码或授权码 | 密码只写，读取仅返回是否已配置 |
| 发件邮箱、发件人名称 | 邮箱填写单一地址 |
| 回复邮箱 | 可选；留空使用发件邮箱 |

启用配置时，服务器、发件邮箱及认证所需的用户名和密码为必填；已有密码可以留空保留。添加、复制、设为默认、停用和删除先修改本地草稿，点击“保存发信配置”才提交。删除仍被提醒规则引用的配置会被后端拒绝。

旧版本的单套配置在首次读取时归一化为“默认邮件配置”，保留原密码状态和 SMTP 资料；首次保存多配置后转换为稳定配置列表。

## 接口与存储

settings 契约 `1.32.0`：

| 方法与路径 | 操作 | 参数 |
| --- | --- | --- |
| GET `/v1/admin/settings/mail` | readMailSettings | 无 |
| PATCH `/v1/admin/settings/mail` | saveMailSettings | expected_revision、profiles |
| POST `/v1/admin/settings/mail/test` | sendTestMail | request_id、expected_revision、profile_id、recipient |
| POST `/v1/admin/settings/mail/test/status` | readTestMail | id |

读取只返回 revision、稳定配置 ID、名称、启用/默认状态、SMTP/发件人公开字段和 `password_configured`。保存锁定站点设置行，冲突返回409，字段错误返回422；同一事务写 `_mail_private` 与脱敏审计，公开投影不包含该私有段。密码仍为后端私有数据库内容，**未新增字段级加密**。

保存只更新配置和审计，不连接 SMTP、不生成邮件任务、不触发前台同步。未保存离开使用项目弹窗；并发冲突保留输入。

## 提醒与投递解析

通知策略中的邮件提醒可以选择“默认配置”或某个稳定配置 ID。未指定时在投递生成阶段解析当前默认配置；显式选择则固定该配置。

生成投递时快照配置 ID 与邮件配置修订。Worker发送前重新确认配置仍存在、启用、完整且修订未变化；任何不一致都标记为抑制，不静默换用其他账号。SMTP 结果未知时仍不自动重发，避免跨配置故障转移造成重复邮件。

账号邮箱验证固定使用默认配置。测试邮件必须指定具体配置，并使用该配置已保存的参数。

## Scheduler 与 Worker

管理员明确提交才创建 queued 记录和审计。每位用户每分钟最多5次，超限429；同一 request_id、用户、发件配置、收件人及配置修订重复提交返回原结果。

Scheduler 的 `core.mail-test` 向 Worker 指派扫描；任务不包含密码、正文或目标邮箱。Worker 使用行锁认领记录，提交 sending/租约后从私有配置获取参数并连接 SMTP。API 与 Scheduler 不执行网络发件。

- 排队时邮件配置修订变化：`configuration_changed`，本次测试取消。
- 队列等待超过10分钟：`queue_timeout`。
- SMTP 明确接受：`sent`；不保证收件人最终进入收件箱。
- 明确拒收或连接失败：`failed`。
- DATA 阶段失联、租约到期或整体超时：`unknown`，不自动重发。

SMTP 使用 Python 标准库；TLS 使用系统信任验证，不在 STARTTLS 失败后回退明文。测试区继续复用统一任务进度、脱敏 SMTP 会话和最近任务恢复，不把密码或邮件参数写入浏览器长期存储。
