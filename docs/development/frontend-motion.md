# 前台动效开发与验证

2026-10-30。本机前端 `http://127.0.0.1:3000` 已由用户运行 next dev，支持热更新；本轮没有停止它，后端继续使用 8001。

## 直接检查

1. 首页应播放星空背景，右下角可暂停/继续；暂停后进入归档、文章、搜索再返回，视频不应回到第 0 秒。
2. 点击文章、分页、导航和正文站内链接，只更新主内容并短暂显示顶部进度；顶栏/侧栏保留。搜索按 Enter 和浏览器前进/后退也应软切换。
3. 文章目录应随文章变化，返回首页清空；点击目录定位正文，固定顶栏不遮挡标题。
4. 窄屏展开侧栏，检查遮罩/入场，按 Esc 关闭并恢复按钮焦点；检查深浅色、悬停/焦点、卡片入场及回到顶部。
5. 在系统开启“减少动态效果”或浏览器启用省流量后，背景默认静态、内容始终可见；可手动选择播放。隐藏标签暂停视频，恢复后按偏好继续。

外部网站、新标签、Ctrl/Command 点击、下载、纯锚点保留浏览器行为。源代码修改根布局或 Client/Server 边界时，Next Fast Refresh 可能进行一次完整重载；这与普通站内导航重挂载是两回事。

## 自动检查

```powershell
npm.cmd run check
npm.cmd run verify:http -- http://127.0.0.1:3000
```

当前 16 项单测覆盖原公开阅读行为、导航边界、目录注册/迟到释放及同路由错误清理；HTTP 检查覆盖原 14 个页面与 ready/背景。浏览器实际验收见 [本阶段记录](../handoff/frontend-motion-verification.md)。

## 保留开发服务时验证生产构建

```powershell
npm.cmd run verify:production
```

工具只在系统临时目录复制构建输入和现有依赖，使用同一锁定 Next.js 的默认 Turbopack 构建，不重装包、不复制真实配置/内容快照、不覆盖当前项目 `.next`。结束后只清理经路径验证的临时副本，原开发服务保留。Windows 的跨盘目录链接不适合作为 Turbopack 构建边界，因此使用真实依赖副本。

普通 `npm.cmd run build` 仍可用于开发服务已经停止的情况；不要与 next dev 同时写当前项目 `.next`。
