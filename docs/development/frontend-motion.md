# 前台动效开发与验证

2026-10-30。本机前端 `http://127.0.0.1:3000` 已由用户运行 next dev，支持热更新；本轮没有停止它，后端继续使用 8001。

## 直接检查

1. 未设置偏好时首页默认播放星空背景；在右下阅读设置内切换“动态背景”，明确播放/暂停跨刷新保留。恢复默认后回到完整动效/背景自动播放。工具列不再单独放播放按钮。下滚超过 400px 显示回顶，返回顶部时平滑收起且不留空位。
2. 点击文章、分页、导航和正文站内链接，旧内容应保留到新内容就绪，顶部进度从左推进、完成后淡出；顶栏/侧栏保留。搜索按 Enter 和浏览器前进/后退也应软切换。
3. 文章目录应随文章变化，返回首页清空；点击目录定位正文，固定顶栏不遮挡标题。
4. 窄屏展开侧栏，检查遮罩及滑入/滑出，按 Esc 关闭并恢复按钮焦点；检查深浅色图标、悬停/按压/焦点、卡片入场及回到顶部。目录/概览切换应平滑改变高度；一路有你的折叠块应来回开合。
5. 阅读设置默认选择“完整动效”，即使系统减少动态查询为 true 也应有动画。选择“跟随系统”时才继承系统；“减少动态”始终关闭非必要运动，可单独播放视频。测试后恢复完整动效；不修改用户 OS 设置。
6. 打开/关闭阅读设置，滚动条应一直存在、内容横向位置保持；鼠标移到正文仍能滚动。设置和图片查看器都有退出过程，Esc 可关闭。
7. 用鼠标滚轮连续下滚再停手，应有减速尾程；反向滚动应及时响应。缩放手势、代码区和内嵌滚动保持原生。不能用“回顶很平滑”代替实际 wheel 验证。
8. 首页点击摘要/空白进入文章，分类/标签保留各自目标；检查二级菜单键盘开关、文章头图和无图标题。评论可回复/预览/加表情/本页添加，明确显示演示状态；刷新应清除临时留言。
9. 修改字号/字体/圆角/阴影/滤镜，确认实际正文和卡片样式，再刷新检查保留。测试后恢复用户原来的偏好，不改系统设置。

外部网站、新标签、Ctrl/Command 点击和下载保留浏览器默认行为；同页锚点保留历史语义并使用共享平滑定位。源代码修改根布局或 Client/Server 边界时，Next Fast Refresh 可能进行一次完整重载；这与普通站内导航重挂载是两回事。

## 自动检查

```powershell
npm.cmd run check
npm.cmd run verify:http -- http://127.0.0.1:3000
```

当前 30 项单测覆盖公开阅读、导航、目录注册、滚动、动效/背景策略、安全短代码及评论纯策略；HTTP 检查覆盖 16 个页面与 ready/背景，历史评论按来源跨页比对 ID。最新实际 Edge 验证见 [前台功能验证](../handoff/frontend-interaction-verification.md)，前一阶段记录保留为历史。

## 保留开发服务时验证生产构建

```powershell
npm.cmd run verify:production
```

工具只在系统临时目录复制构建输入和现有依赖，使用同一锁定 Next.js 的默认 Turbopack 构建，不重装包、不复制真实配置/内容快照、不覆盖当前项目 `.next`。结束后只清理经路径验证的临时副本，原开发服务保留。Windows 的跨盘目录链接不适合作为 Turbopack 构建边界，因此使用真实依赖副本。

普通 `npm.cmd run build` 仍可用于开发服务已经停止的情况；不要与 next dev 同时写当前项目 `.next`。
