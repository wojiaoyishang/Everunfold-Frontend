# 字体库与按需加载

版本：font-library-1，2026-11-03。已实现；[ADR0042](../decisions/0042-visual-editors-and-font-library.md)与development-11定义边界。

## 使用

后台字体库为独立注册菜单 /admin/fonts。支持搜索、分页、预览文字、资料/删除、多个WOFF2/WOFF/TTF/OTF文件上传，单文件20MiB。上传复用统一队列、真实进度、不定进度降级、稳定请求ID、失败隔离及哈希复用。标题等普通资料使用现有媒体窗口；字体家族、样式、字重和格式由实际文件读取。

HTML工具栏的字体选择和主题设置的全站字体都能打开同一字体库选择/上传。全站字体与文章内字体独立；主题默认留空使用既有系统字体。测试字体只包含A字形，其他字形回退，不能把它当成生产完整字库。

## 保存与分发

- 配置继续使用后端media.uploads_path与media.base_url，文件按原媒体目录归档，不覆盖原件。数据库MediaAsset.font_info记录家族、格式、样式、字重范围；CSS家族别名为ef-font-UUID，避免同名字体冲突。
- /v1/admin/fonts/query提供有权限的目录；上传仍走/v1/admin/media/upload的font用途。后台自定义字体库不使用另一个传输入口。/v1/fonts.css为可选声明端点，前台默认不全局引用。
- 正文保存site://media/UUID；公共/解锁映射按实际引用返回MediaURL.font。主题设置保存font_media_id，后端解析font_url/font_info；前端不得提交自造的元数据代替数据库事实。
- CDN切换仍只改Base URL并同步原上传文件，持久正文不改地址。字体文件服务需允许前端Origin跨源读取，并提供正确MIME；本机8001→3000已实际加载成功。外部CDN部署尚未验收。

## 前台加载规范

根布局不请求整个字体目录，不挂全库CSS，不批量preload。当前内容渲染收集data-font稳定引用，只生成对应@font-face；浏览器仅在文字实际使用时下载字体。当前主题选择的全站字体单独声明，未选择就不产生该请求。声明font-display:swap，失败/缺失字形回退系统字体，不隐藏文章，不等待字体才展示正文。

新增正文块、插件、SSR、受限内容及主题必须使用相同依赖收集规则。列表仅显示纯摘要时不应下载文章内字体；普通文章不加载其他文章或字体库的文件。移除引用后新页面不再声明该字体，不以清浏览器缓存维持一致性。后续子集化、unicode-range、字体授权信息及编辑器更多字体样式尚未实现。

验收：查看浏览器字体资源，未使用页面无8001字体库请求；引用文章只有所用文件，无其他字体或批量preload。当前真实结果见[验收](../handoff/visual-editor-font-verification.md)。
