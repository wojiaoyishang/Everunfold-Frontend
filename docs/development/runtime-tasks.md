# Scheduler、Worker 与运行管理

版本：runtime-tasks-1；2026-11-09。状态：开发规划，以下能力按阶段实现并在 STATUS 标注验收结果。

## 产品约定

Scheduler 是唯一调度程序。定时任务由它派发给 Celery Worker，长连接是它管理的常驻任务，以内部子进程执行；没有单独部署的长连接服务。启动、停止、插件启停、状态查询均归属于 Scheduler。主循环不执行插件业务，也不调用 API router_init。

后台提供运行概览、计划、执行记录与 Scheduler 常驻任务。进程心跳、调度进展和连接状态分别显示；未知不能冒充成功。Redis 保存有期限的运行快照，PostgreSQL 保存计划、执行结果、认领及恢复信息。任务运行期不采集无限增长的时间序列。

## 实施顺序

1. 发布运行契约、插件任务 SDK、数据库迁移。计划 ID 与计划时间唯一；业务效果仍须幂等。保留现有设置投递、应用回调和文章排期行为。
2. Scheduler 独占、持久派发与恢复；Worker 执行记录、超时与故障归类。注册的执行恢复投递，未登记周期漏跑默认跳过；文章单次排期仍恢复执行。
3. Scheduler 子进程管理常驻任务，租约、所有权代次、停止信号、退避重启、持久检查点。线程仅可作为子进程内部适配，不占调度循环。外部效果无法保证绝对一次，插件使用对端幂等键。
4. 管理页面展示实例、心跳、队列、计划、执行结果及连接信息；按权限查询和操作。仅允许代码明确开放的手动任务。配置从数据库读取，通知只加速，周期校对兜底。
5. 插件全宽列表，前端/后端/前后端来源、版本、作者、主页、许可证、可选特色图片及安全 Markdown 详情弹窗。插件停用包含任务影响；取消恢复开关。
6. 登录无验证码、无错误时移除空白占位。前台标签按真实数量形成可点击、无重叠词云，保留可访问列表和窄屏排版。

## 注册与运维边界

仍只固定 app/plugins/*/plugin.py。入口通过函数或类注册普通任务与常驻任务；其余文件自由组织。Python 代码更新需要重启并显式同步目录，配置无需改代码。停用后禁止新执行，已运行任务协作停止，保留历史及检查点。默认不开放任意命令执行、强制清队列或删除业务记录。

## 验收

真实多进程验证双 Scheduler、重复消息、执行途中终止、Broker 故障、租约接管、常驻子进程异常、父进程退出、插件停用与恢复；检查审计、权限及敏感字段隔离。每完成可见组件立即进行桌面/窄屏视觉检查，包括空态、错误态、焦点和减少动态。阶段性本地提交，不推送；同步两仓库文档。
