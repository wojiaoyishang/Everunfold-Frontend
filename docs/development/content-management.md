# 文章与说说管理

版本：content-management-9，2026-11-06。当前：文章/说说、多块协同实时保存、版本/离线合并、发布同步、定时发布、密码访问、定时开放及多语言关联。基础决定为 ADR0030–0035，最新多语言规则见[ADR0066](../decisions/0066-configurable-languages-and-grouped-translations.md)及[当前指南](../architecture/multilingual-content.md)。历史验收不替代[本轮检查](../handoff/multilingual-verification.md)。

## 数据范围

功能测试只使用新后台创建并发布的内容。旧 WordPress 78篇文章/9个页面已撤回，原行/媒体/评论保留；不恢复或重新导入来填充界面。2026-11-02阶段曾保留两篇文章、两则说说，以及新建「编辑功能验证」「密码保护阅读验证」供联调，均由后端产生，前端没有硬编码内容。示例数量随管理操作变化。

显式开发工具 `uv run python -m tools.withdraw_wordpress_preview` 默认预检，`--apply` 才撤回；只接受本机开发/专用测试库，业务、审计、release和Outbox同事务，重复执行不升版。恢复历史内容需用户明确调整范围，不手工删除快照或过滤前端。

## 编辑与发布

入口 `/admin/content/article`、`/admin/content/shuoshuo` 分别管理注册类型。新建 `/admin/content/{type}/new`，编辑 `/admin/content/{type}/{id}/edit`，不使用弹窗。页面管理独立，源码与可信注册页面见[页面指南](pages.md)。

1. 右上操作区提供保存版本/发布/查看前台；标题及固定链接位于正文上方。首次保存使用所选语言当前配置的前缀，生成 `/{前缀}/{标题别名}.html`，默认语言空前缀时仍为根级，无 posts 前缀；同名加序号，无标题说说使用稳定 ID。保存后修改标题或全站语言前缀不自动改址，点「编辑」手改路径；系统保留路径/占用路径拒绝。改址不创建历史重定向。
2. 正文可添加多个 Markdown/HTML 文本块，稳定 ID，支持排序、删除确认、安全预览和共享媒体库插入；完整富文本工具以后细化。正文媒体存 `site://media/{id}`，不用磁盘路径；封面选择稳定媒体 ID。
3. 右侧属性包含显示时间、置顶、可见性、定时开放、封面、分类、标签、评论和 SEO。窄屏切换「正文 / 内容设置」。显示时间使用日历/时分控件；留空保留原时间，新的内容使用发布时间，显示时间不能晚于实际或安排的发布时间；延后发布使用独立的定时发布设置。界面按浏览器本地时区选择，提交带时区 UTC。
4. 分类为勾选树，可切所有/最多使用，新增分类可选父级，成功后自动选中。名称在同类型内唯一，暂不移动已有分类或建立同名不同分支。标签支持逗号分隔、移除和展开常用标签云，字号来自新系统已发布内容的实际关联数，不伪造热度。
5. 已有草稿正文和共享属性实时持久保存，状态栏区分本地与服务器确认；新建表单先保存取得内容身份。「保存版本」创建检查点，「发布 / 更新发布」等待确认并更新公开投影，访问密码仍经私有业务操作。正文、属性、索引、审计、不可变 release 和 Outbox 同事务。已发布后新修改只进入工作稿，前台保留上一发布版本；列表标记有未发布修改。离线/合并详见[版本指南](draft-versions.md)。
6. 「前台内容已同步」仅表示配置节点最后一次持久 ACK；「重新同步」可以重发最高版本。已打开的其他浏览器标签需要刷新或重新导航，没有主动广播全端刷新。
7. 「撤回」在同步后返回404；垃圾桶移入可恢复回收站并撤回已发布内容，恢复仍是草稿，需要再次发布。列表支持筛选、搜索和分页，预览为纯文本而非 HTML/Markdown 源码。

保存失败保留输入；未知结果用固定操作 ID 重试，版本冲突保留本地修改并允许重读。离开弹窗、确认、保存和弹层继承统一动效。刷新/关闭使用浏览器离开保护；已有草稿现支持协同和 IndexedDB 恢复，首次保存前的新建页面尚无共享恢复；全面历史后退拦截仍后置。

## 定时发布

在「内容设置 → 发布设置」选择「定时发布」，用统一日期/时间控件选择未来时间，再点击顶部「安排发布」。此时才创建一次性计划并冻结本次检查点；只保存版本不安排发布。排期卡显示时间、版本和取消入口，顶部可重新安排。按设备时区选择，接口用带时区时间；显示日期不决定是否公开。

后续编辑继续自动保存为工作稿，到点发布冻结版本；已有公开文章在等待期间保留原公开版本。文章/说说列表标记待发布或待定时更新，已发布标题旁提供新窗口前台入口，编辑按钮配铅笔。翻译各自独立排期，仍归原文同一行入口；列表语言菜单内各已发布译文也提供独立前台图标。

到点由Scheduler投递tick、Worker处理。进程停机时已登记计划保留，恢复后执行；合并锁有效时等待，不改变最新版。轮询、服务可用性及合并可能造成延迟。公开内容与可靠同步提交后，各节点应用才可见，不以浏览器计时器代替发布。

取消、立即发布、撤回或回收会清除计划；恢复回收后不会自动重排。权限/原API Key失效、地址占用或正文/媒体失效会停止排期，编辑器提示原因；修改后重新安排。数据库提交失败保留计划重试，不留下半次公开内容。排期时间改变不会自动修改已发布URL。

右下阅读工具底部百分比具有主题背景填充及细进度线，文章、说说和普通页面读到底部保留100%；短页面不显示无意义的进度。它只表示当前浏览器的位置，不代表云端已保存阅读位置。

## 密码与开放时间

可见性选择「密码保护」后设置文章密码，后续留空保留已有密码。密码以 Argon2 私有列保存，不返回原文、哈希或回执中的密码字段；审计修订不含秘密。

定时开放仅在密码保护下设置；开放之前可用密码提前阅读，到点按后端时间公开。访问策略即时判断，Worker 负责刷新派生快照；投递停止时前台仍可动态检查到点状态，公开 SSR 在进程恢复后更新。这不是定时发布草稿。

未解锁正文、摘要、媒体、封面、自定义 SEO 和正文统计不进入公开快照。阅读页 POST `/v1/reader/access`，private/no-store，校验精确 Origin、真实来源 IP 限流；成功正文只存在当前页面内存，刷新重新输入，没有长期授权 Cookie。公开静态文件仍可直接访问，文章密码不使文件本身保密。受限内容正式评论与浏览量待做，本期不发起未接通的私有指标请求。

## 启动与检查

新环境先显式初始化（当前 head 为0025_scheduled_publication），服务不自动迁移；本容器开发启动方式见[部署指南](container-deployment.md)：

```powershell
uv sync --frozen
uv run python init.database.py --no-create-database
uv run uvicorn app.entrypoints.api:app --host 127.0.0.1 --port 8001 --no-proxy-headers
```

另开终端运行投递辅助命令，Next3000可持续保留：

```powershell
uv run python -m tools.run_settings_dev --frontend-root E:\Programming\Node\Everunfold-Frontend
```

辅助命令运行独立 Node3001 接收器、Celery Worker 和 Scheduler，不替代 API/Next。配置沿用 frontends.<node>.settings_receiver_url 和稳定节点凭据；生产分别部署，浏览器不配置内部Token。详见设置指南。

后端端点包括：GET `/v1/admin/content/editor-options`；POST `/v1/admin/content/categories`、`create`、`detail`、`save`、`publish`、`withdraw`、`trash`、`restore`；读公开受限正文使用单独 reader/access，所有类型和客户端从契约生成，不复制字段定义。

后端完整检查仅使用专用测试库：

```powershell
uv run python init.database.py --config config.test.local.toml --no-create-database
$env:RUN_DATABASE_TESTS = '1'
uv run pytest -q --tb=short
```

前端 `npm run check`、`npm run verify:admin` 在临时副本生产验证，不覆盖正在使用的 `.next`。每完成一个可见组件立即在内置浏览器实测，见开发协议。

## 架构与剩余边界

当前content-admin1.8.0和settings1.10.0从后端已提交ba4025f生成，public0.6.0、presentation0.2及collaboration2.0相关详情字段同步消费；准确来源和摘要见src/generated/*-source.json。public历史文件名保留public-v0.1.schema.json。0011/0012增加编辑属性、私有访问与分类，0013–0017接入协同、原生短代码和版本，0018增加语言/翻译组，保留既有内容与历史。

后端 draft_* 处理工作版本，editor_schema/editor_service/content_paths 隔离属性和路径，publication 负责公开投影，access_policy/access_router/timed_projection 处理读取和到点刷新。前端 core/content-management 管请求/状态，themes/argon/admin/content 管展示；标题、正文、分类、标签、属性独立，DateTimeField复用共享控件。媒体删除守卫覆盖当前草稿、修订与发布引用。

Markdown/HTML编辑、协作、版本、页面设置和定时发布已按各自指南接通；历史迁移、完整分类管理、受限互动及媒体说明自动填充仍需后续独立实施。完整快照8MiB，无增量、磁盘GC、心跳，最高版本损坏/已知撤回后不回退旧正文；不能把当前交付当完整生产缓存系统。

## 就地删除和前台编辑入口

块垃圾桶打开旁边的确认气泡，取消/点外/Escape不改变正文，确认退场后只移除当前草稿中的块；最后一块不可删除。数据库删除、撤回及放弃未保存仍为全局确认窗口。

前台文章/密码壳/说说详情在浏览器调用GET `/v1/admin/content/actions?id={UUID}` 后，如后端当前账户确有此内容编辑权，则渐显编辑链接。当前仅管理员具备编辑权，普通用户、匿名、未知目标或网络失败不显示；不使用演示身份，不写公开快照。重新回到标签页会复核，后台入口和写接口还会重新授权。

已有草稿使用私有 collaboration-1 接口及整篇 Y.Doc，原 JSON 保存不再覆盖共享内容。当前检查点/日志/回执显式迁移到 0013_collaboration。标题/正文/SEO/分类等共享；访问密码/策略保留业务 API。源码编辑、撤销、离线/多窗口合并、导出与实际限制见 [运行指南](editor-plugins.md) 和 [验收](../handoff/collaborative-editing-verification.md)。

## 紧凑列表与搜索（2026-11-05）

文章、说说列表共用封面缩略图：有可用封面时显示46px裁切图，无封面或加载失败显示类型图标。桌面显示标题/单行摘要、作者、分类、标签、已审核评论数、状态/日期和操作，常规行最小82px；窄屏改为带字段标签的多行布局。置顶、示例、有未发布修改仍有标记；已发布条目显示发布时间，其他条目显示修改时间。

输入关键词后点“搜索”或按Enter，覆盖标题、摘要、正文、作者、分类与标签，仍按当前文章/说说类型及全部/草稿/已发布/回收站过滤。搜索会回到第一页；下方显示实际生效的关键词和“清除搜索”，刷新重试保留当前条件。未提交的输入不会逐字查询。分类与标签列当前只展示名称，未增加独立筛选、列排序或批量操作。

新接口字段只属于管理员查询结果：cover_url、categories、tags、comment_count、pinned，不返回正文数组或访问密码。封面及评论计数按当前页批量读取；不新增迁移、依赖或公开内容字段。当前实时保存、离线分支和版本操作详见[版本指南](draft-versions.md)，本轮列表/工具决定及实页检查见[ADR0063](../decisions/0063-compact-content-lists-and-editor-tools.md)与[验收](../handoff/content-list-tools-verification.md)。

## 多语言管理（2026-11-06）

每组只显示原文一行，译文编辑入口在标题旁语言菜单中。筛选某语言、搜索译文也返回原文行，分组后计数/分页；编辑页“管理语言与译文”可新建、复制、关联、解除、核对及单独回收恢复。列表回收/恢复作用于整组，确认时显示版本数量。

语言目录来自站点设置，不把中英文写成允许列表；未选择新建语言时由后端当前默认值决定。每个译文拥有独立ID、实时协同文档、历史、发布与访问策略，原文更新只提示核对。合并锁/版本冲突/幂等仍由后端检查。详细入口、前台搜索和SEO边界见[多语言指南](../architecture/multilingual-content.md)。

## 独立实时预览（2026-11-06）

文章、说说与页面共享独立“实时预览”窗口：左侧编辑、右侧前台，顶部右侧原保存/发布、左侧完整编辑器，提供设备视图与拖动分界线。沿原协同/离线/合并守卫，不新增整篇写入或重复Y.Doc；见[页面指南](pages.md)。
