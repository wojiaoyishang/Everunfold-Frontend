# 页面管理与实时预览指南

版本：pages-runtime-12，2026-11-10。产品边界见[页面架构](../architecture/registered-pages.md)和[ADR0072](../decisions/0072-managed-pages-and-people-messages.md)。

## 管理页面

列表仅展示可用插件的注册页面；插件停用或部署不可用时隐藏相关条目，已有配置与应用快照保留，重新启用并部署一致后恢复。自定义源码页不受此过滤影响。插件管理在保存启停时检查已应用页面及正文引用并提供继续/取消提示，见[ADR0083](../decisions/0083-plugin-activation-usage-confirmation.md)。

在后台“页面”查看来源、启用状态、草稿/应用修订，按标题或路径搜索。新建自定义页面，输入标题和站内绝对路径，分别编辑HTML/CSS/JavaScript。页面和JavaScript默认关闭；“保存草稿”不影响公开内容，“保存并应用”才更新入口；关闭启用后“保存并停用”。改址后旧路径失效，不产生别名。

JavaScript仅在独立沙箱内运行；启用后显示脚本提示，维护启用脚本仍仅限管理员，不再要求重复输入密码（ADR0075）。沙箱没有同源权限，不能直接操作站点DOM或调用管理Session。脚本关闭时HTML事件也关闭。HTML/CSS不进入管理页文档，文章/短代码继续保留原安全过滤。

源码区的“脚本执行位置”提供两个选项，控制JavaScript编辑区中的脚本：

- 正文加载前（Head内）：在正文解析前执行，适合初始化变量或注册事件；此时document.body与正文元素尚未生成。若要操作正文，先监听DOMContentLoaded。
- 正文加载后（Body末尾）：在作者HTML解析完毕后执行，可直接访问已有正文元素。这是缺省值，旧页面保持原行为；不表示等待图片、视频等资源全部下载完成。

可以先选位置再开启脚本；关闭JavaScript时，两种位置都不会执行作者脚本。位置随页面工作稿保存，点击“保存并应用”才更新正式前台，预览立即使用当前选择。HTML编辑区自行写入的script仍在其原位置执行，不随此选项搬移。前台和两种预览使用同一生成器，实际检查见[脚本位置验收](../handoff/page-script-position-verification.md)。

注册页标记“前端注册”，只能维护暴露选项和通用设置。当前“一路有你”支持页面介绍、姓名云/人物卡片、显示搜索及人物姓名、分组、头像地址、寄语和顺序。姓名必填；人物数量上限300、姓名/分组80字、寄语5000字。没有真实人员种子数据；注册组件不可在后台改源码。

“我的荣誉”由独立core.honors插件注册，支持证书网格/时间线、任意分类、年月/年月日、奖项说明、媒体库选图、搜索和证书弹窗；配置及当前实例导入内容见[荣誉页指南](honors-page.md)。两种注册页面均从插件目录自动发现，新增页面不改中央注册表。

回收自定义页面会停用并保留源码；恢复后仍停用。注册页可停用，通过代码部署维护清单，不能在后台删除登记。普通编辑页不再提供「读取服务器版本」按钮。版本冲突保留输入；先复制需要的修改，再刷新页面核对最新版本，不重放过期版本覆盖他人修改。

## 评论区

页面通用设置增加“允许评论”，新页与旧页默认开启。关闭只禁止新评论/回复，已有审核留言仍可读；保存草稿不改变前台，保存并应用后生效。HTML页面使用沙箱外的宿主评论区；插件页面可放置`PageComments`、指定正文内选择器，或通过SDK自行实现界面。详见[页面评论指南](page-comments.md)。预览不发起评论互动请求。

## 预览入口

普通编辑页将预览、保存、发布/应用放在顶部同一操作组，下滑时一起进入固定导航，上滑后归位；返回页面列表在左侧。文章/说说采用相同规则，键盘焦点和按钮状态保持，见[验收](../handoff/editor-actions-dock-verification.md)。

小图标旁的文字区分“前台预览”和“实时预览”，悬停有用途说明。页面前台预览可展示当前未保存输入；文章/说说沿原保存/ACK准备后预览。

实时预览打开独立工作界面：左侧编辑、右侧实际前台。顶部左侧用退出图标返回当前窗口的完整编辑器；保存和发布在右上角。控件直接调用当前编辑会话，页面仍需显式保存/应用，文章/说说仍实时持久化；公开发布都需明确操作。

拖动分界线调整左侧宽度；聚焦分界线用左右键16px微调，Shift为64px，Home/End移到边界，双击恢复390px。左侧限制300–720px并保留右侧空间。电脑视图自适应，iPad上限820px，手机上限390px；可用空间不足时自动适配。设备切换和宽度调整不重建编辑窗口。窄屏用“显示编辑器/查看页面”切换，不丢弃输入。

预览窗口内编辑涉及离线、合并或权限变化时遵循原文章流程；预览不绕过只读/合并锁，不自动发布、不提交浏览/点赞/评论。主编辑页不再嵌入页面的即时预览或双栏，复杂内容保持隔离。

页面编辑设置保存 `show_glossary_tooltips` 与 `show_glossary_footnotes`，默认开启。它们属于当前页面配置并随 revision/应用快照保存；站点总设置只控制正文关键词识别能力。跨页面钩子可在术语编辑页把词条绑定到该页面的 CSS 选择器。

## 登记新的可信组件

1. 在`src/plugins/<插件>/plugin.ts`的同步setup调用`pages.register`，页面配置、schema、渲染和样式保留在同一插件目录。主题/插件具名组件在`components.tsx`导出；固定目录原生自动发现，不编辑中央列表，不生成组件文件。详见[插件开发指南](frontend-plugins.md)。
2. 页面模型用开放组件名，后台通过主题hook渲染；未知组件显示占位，配置保留并可用JSON继续编辑。`fields`仅为旧表单描述，新的`settings_schema`与`defaults`由pages1.5支持，任意JSON配置不按字段白名单裁剪。保存是完整对象替换；首次登记使用默认值，重新登记不覆盖已保存数据。
3. 开发/构建运行`npm run prepare:local`；Git只保存源码与`contracts.lock.json`，契约类型/客户端/Schema在忽略的`var/cache/contracts`恢复。不存在`src/generated`或`registrations`目录。运行副本仍位于var，未迁移。
4. 显式登记（在前端根目录执行，后端环境与配置需已准备好）：

```sh
npm run plugins:build
npm run themes:catalog
npm run extensions:register -- --node-id web-main
```

`pages:manifest`仍可只输出源码声明供审阅；`extensions:register`从已编译包和主题目录形成清单，经stdin调用相邻后端安装器，可指定`--backend`、`--config`、`--python`。`pages:register`保留为同一命令的旧名称。构建不连接数据库；dev/start协调进程已支持鉴权后自动登记，首次创建停用工作稿、后续保留用户数据。详见[独立插件指南](frontend-plugins.md)。

表单与JSON修改同一options对象，未知键和嵌套值保留。无效JSON保留输入并阻止保存/应用，预览维持最后有效值；项目内离开使用主题确认。配置可含嵌套对象、数组、null、布尔与有限数字，最多32层/256KiB，整页仍512KiB。配置和页面源码只在显式应用后影响公开副本；内部元数据不公开。

## 内部元数据接口

自pages1.1.0起提供管理Session专用接口：

| 方法/路径                                | 权限与行为                                                                                                       |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| GET `/v1/admin/pages/{page_id}/metadata` | pages:read；返回page_id、独立revision、JSON对象value；初值revision0/空对象                                       |
| PATCH 同路径                             | pages:write、精确Origin/CSRF；请求expected_revision、operation_id、value；成功递增内部revision，来源页面修订保持 |

请求包含JSON封装的HTTP上限64KiB；非有限数值拒绝，元数据不是源码执行入口。相同操作ID/载荷重试返回原回执；过期修订返回40999，输入应保留、重读、合并后用新操作ID提交。更新与回执、审计同事务，不发布公开快照。回收保留元数据，但须恢复页面才能修改。

从后端已提交契约生成的前端客户端使用示例：

```ts
import { readPageMetadata, savePageMetadata } from "@/core/contracts/pages";

const current = await readPageMetadata(baseUrl, pageId, { signal });
await savePageMetadata(
  baseUrl,
  pageId,
  {
    expected_revision: current.data.revision,
    operation_id: crypto.randomUUID(),
    value: { ...current.data.value, import_cursor: "next-record" },
  },
  csrfToken,
  { signal },
);
```

客户端供已授权管理表单使用；普通访客和自定义iframe脚本不能调用此管理能力。私有元数据不包含在页面目录/详情或公开DTO中，不存公开前端副本；需要时单独私有读取。现有页面设置只在应用后进入公开`public-content`完整快照，继续由已有接收器及文件存储维护版本、失效与离线读取。无需新增“任意缓存键/任意后端URL”接口。

## 语言版本与列表启停

文章和说说共用既有语言组。自定义页面也采用原文一行、译文收进语言菜单的方式；在编辑器的“语言版本”中添加译文，可以复制源码或关联同语言的独立页面。译文单独编辑、保存和启用。新增语言先在站点设置的语言目录中启用，不限定中英文。复制后保持停用，脚本开关关闭；原文应用更新后，译文提示待检查，可标记“已核对”。

可解除译文关联、回收或恢复单个语言。回收原文时，剩余有效成员成为列表入口；全部回收后，恢复任意成员会重新成为可见组入口，恢复仍停用。注册页面显示“此页面的多语言由前端代码管理”，不使用用户译文管理器。

列表直接提供启用Switch，不再重复显示已启用/已停用badge；编辑器同样去重。目录开关只启停最近已应用源码，保留后续未应用的草稿内容和路径。没有保留应用源文的页面，首次启用弹窗明确确认应用已保存草稿；涉及脚本时仍仅管理员可维护，不再要求重复输入密码。路径被其他内容占用或实现缺失时启用失败，不自动改址。

注册实现可在可信`localizedPageImplementations`中选择语言路由能力；当前`core.people`使用站点语言目录的前缀，共用人员选项并由代码翻译界面，不生成多份数据库页面。实际自定义页面/文章地址优先于代码语言路径，不把已有内容覆盖为注册页。新增注册实现应自行实现其语言数据与展示策略；不在后台任意登记执行模块。

## 实时预览的离开与更新

页面、文章、说说共用实时预览。页面顶部的“保存草稿”只保存工作稿，“保存并应用/停用”才改变前台。离开按钮、页面内导航和浏览器返回使用主题确认弹窗；取消保持输入，确认放弃后离开。直接关闭浏览器标签或强制刷新无法用站内弹窗接管；嵌入编辑器不会叠加原生离开框。

右侧等待当前修订渲染完成后才结束loading；等待时显示loading，超时提供重试。HTML源码还等待匹配的隔离文档准备确认，迟到的旧确认不结束新更新。重试不清空左侧输入，设备视图和分界拖动也不重建编辑会话。复杂源码始终在独立iframe中，后台表单不渲染用户源码。

人物卡片打开主题弹窗，支持Escape、遮罩、关闭按钮、焦点回归与进退场。打开播放有限烟花，结束或关闭即清理；使用站点“减少动态”偏好时关闭烟花。实时编辑人物寄语时，已打开的右侧弹窗也更新内容。

HTML预览只替换内层隔离iframe，保持srcdoc和不透明来源；不反复导航同一个内层框架，不把每次源码更新写进浏览器联合历史。渲染确认同时核对当前iframe窗口与源码标识，包含内容回退为先前源码时的情况。左侧编辑器和右侧前台工作框架不重建。
