# 可视化组件编辑器

在「页面 → 新建页面 → 自定义页面」打开画布。左侧选择或拖入组件，也可打开结构树；右侧编辑选中组件或查看页面参数。工具栏切换预览宽度。窄屏用「组件」「画布」「属性」切换区域。

勾选组件字段的「作为参数」后，可给参数命名并决定新实例是否保留当前默认值。点击「另存为模板」，或者直接在页面列表创建模板；模板不需要 URL。新建时可选择模板，也可直接创建独立页面。模板子页单独填写参数、布局、标题、语言和路径。保存模板会更新使用它的公开页面；子页未应用的修改仍保留为草稿。

文章与说说在普通编辑器工具栏点击「组件模式」，进入同一实时画布。保存草稿后生效，可以发布或定时发布；切回区块模式会恢复原区块，已发布版本仍需重新发布才改变。组件模式不连接协同编辑。

## 扩展

受信任的前端插件通过 `setup({ builder })` 调用 `builder.register({ type, label, component, fields })`，组件 ID 使用插件命名空间。插件自行导出具名渲染组件，宿主传入稳定节点 ID、字段值、阅读语言、媒体和预览状态。插件停用时保留文档和原参数，编辑器显示不可用项。代码注册页面通过 SDK 的 `useRegisteredPageLocale()` 或现有 `useT()` 读取当前阅读语言，无须建立后台翻译副本。

## 短代码与部署

短代码库允许管理员添加 JavaScript，脚本中使用 `root` 或 `rootSelector` 访问当前实例。实例不共享脚本环境，预览画布和订阅不执行实例脚本。

用「回复可见区域」要求登录读者已有通过审核的评论；用「部分密码加密区域」为当前区域生成密码凭据。口令无需写进正文或模板。密码区依赖后端 `auth.application_master_key_env` 指定的既有部署变量（默认 `EVERUNFOLD_API_APPLICATION_MASTER_KEY`）。变量须保持稳定，勿复制进配置文件、日志或仓库。未设置时仍可使用其他组件及回复可见。

升级现有环境前备份数据库，显式运行 `alembic -c migrations/alembic.ini upgrade head` 应用 `0060_shortcode_regions`、`0061_component_documents`，再重启前后端、接收器和任务进程。已有页面、模板、区块正文和公开 URL 无须转换。
