# 可视化组件编辑器

在「页面 → 新建页面 → 自定义页面」填写页面设置，点击「进入实时编辑」。进入前会先保存当前草稿；之后的组件修改需点击顶栏的「保存草稿」或「保存并应用」。

两种模式共用实时编辑工作区。顶栏「＋」打开组件库或区块库，齿轮打开页面设置，设备图标切换预览宽度，眼睛图标在新窗口打开当前编辑内容的前台预览。工作区菜单可收起或恢复编辑栏。保存草稿、另存为模板等选项在主按钮右侧的下拉菜单。

组件直接在当前主题的页面预览中编辑。点击组件，左栏显示属性；点击「结构」，在画布上展开浮动层级面板。点击组件卡片添加；鼠标可以按住卡片任意位置直接拖动，触屏短按住后拖动，键盘用空格拾起和放置。画布末尾的「＋」可添加容器或网格，文件夹图标可插入已保存模板。网格可分别设置桌面、平板和手机列数。编辑画布按当前列数绘制空位：空网格显示一整行，已有组件时补齐末行。把组件拖到空格会按顺序填入下一个位置。纯预览和公开页面不显示占位。

点击画布上的标题即可在原位置输入。按 Enter 或移出焦点保留修改，按 Esc 取消。HTML 与 Markdown 从画布选框或左栏打开组件下方的浮层。编辑时上方预览实时更新，使用对勾保留修改，按 Esc 取消。浮层直接使用正文区块的编辑器，可切换源码并插入媒体或短代码。预览里的折叠和音视频控件可直接操作，当前浮层会保持打开。参数标记仍由左栏管理。勾选「作为参数」后，可命名并决定是否保留默认值。模板无需 URL；模板子页独立填写参数、布局、标题、语言和路径。保存模板会更新关联的公开页面，子页未应用修改继续保留为草稿。

常规页面编辑与实时侧栏采用相同的设置分组。常规编辑在宽屏分栏，实时侧栏默认展开基本信息。右键菜单在点击外部或按 Esc 时关闭。

文章和说说的区块模式在左栏直接编辑，右侧即时反馈。切换组件模式后，原区块仍保留，组件模式不参与协同。保存草稿、发布和定时发布使用原有流程。

## 扩展

受信任的前端插件通过 `setup({ builder })` 调用 `builder.register({ type, label, component, fields })`，组件 ID 使用插件命名空间。插件自行导出具名渲染组件，宿主传入稳定节点 ID、字段值、阅读语言、媒体和预览状态。插件停用时保留文档和原参数，编辑器显示不可用项。代码注册页面通过 SDK 的 `useRegisteredPageLocale()` 或现有 `useT()` 读取当前阅读语言，无须建立后台翻译副本。

## 短代码与部署

短代码库允许管理员添加 JavaScript，脚本中使用 `root` 或 `rootSelector` 访问当前实例。实例不共享脚本环境，实时预览和订阅不执行实例脚本。

用「回复可见区域」要求登录读者已有通过审核的评论；用「部分密码加密区域」为当前区域生成密码凭据。口令无需写进正文或模板。密码区依赖后端 `auth.application_master_key_env` 指定的既有部署变量（默认 `EVERUNFOLD_API_APPLICATION_MASTER_KEY`）。变量须保持稳定，勿复制进配置文件、日志或仓库。未设置时仍可使用其他组件及回复可见。

升级现有环境前备份数据库，显式运行 `alembic -c migrations/alembic.ini upgrade head` 应用 `0060_shortcode_regions`、`0061_component_documents`，再重启前后端、接收器和任务进程。已有页面、模板、区块正文和公开 URL 无须转换。
