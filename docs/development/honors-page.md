# 我的荣誉：注册页面与证书配置

版本：honors-page-1，2026-11-07。实现为`src/plugins/honors/`中的独立`core.honors`插件，决定见[ADR0082](../decisions/0082-honors-registered-page-plugin.md)，实际导入及检查见[验收](../handoff/honors-page-verification.md)。参考原页[我的荣誉](https://lovepikachu.top/myhonor)，本项目缺省地址为`/myhonor`。

## 后台维护

进入“页面→我的荣誉”。通用标题、路径、收录和启用仍由页面管理负责；插件提供介绍、证书网格/成长时间线、录入/日期排序、搜索/年份筛选/统计开关，以及可增删改、上移下移的荣誉记录。分类由记录自动生成，不限于原页的三类。

每条记录可设置荣誉名称、分类、时间文字、奖项或任职、说明、证书图片和相关链接。时间支持年、年月或年月日，使用点、横线或斜线分隔；未知时间可留空或保留文字，不强行补成具体日期。无法解析的时间排序靠后。图片可从原媒体选择器选择/上传，仍受媒体权限约束，也可填HTTP(S)或站内绝对路径。没有图片的记录仍可展示文字。

保存草稿不改变公开内容；应用后沿原可靠投递同步。列表启用Switch只启停已应用内容。预览与实时预览使用同一组件，切换布局及改动记录会更新右侧；用户数据不编进插件包。

## 前台

分类、年份和搜索组合筛选；日期排序保持原有日期精度，未知日期置后。网格按分类展示，时间线可按日期排列。统计中的证书数量按不同图片地址去重，同一张证书用于多条记录只计一次。

点击图片打开证书弹窗，图片保持完整比例；支持上一张/下一张、左右方向键、原图入口、Escape及焦点回归。仅在当前筛选结果的证书中切换。减少动态偏好关闭弹层动画，颜色继承当前主题。

## 插件开发与数据

身份、模型、数据投影、控件、渲染、文案和CSS均在本目录；文件分工见前端仓库的`src/plugins/honors/README.md`。`core.honors.field`先翻译本包字段标签，再委托主题的具名表单控件；`core.honors.image`使用SDK媒体选择器。新增页面不修改宿主中央注册列表或全局语言字典。

默认配置没有荣誉记录，首次登记停用。已有配置重登记不会被缺省值覆盖。当前已导入的24条记录与22张不同证书是本实例业务数据，保存在后端及媒体存储，Git只保留代码；跨设备恢复应使用业务数据库和媒体备份。导入来源、SQL/原图指纹存页面私有metadata，不放在公开options或插件源码。

`localized:true`沿站点语言目录生成启用前缀，当前`/en/myhonor`也可访问。界面中英文词典在插件内，未知词原样保留；荣誉名称、介绍和说明属于用户内容，不自动翻译。停用本插件沿原机制关闭页面可用性，保留配置和媒体。
