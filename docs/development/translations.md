# 自定义翻译字符串

版本：translations-runtime-5，2026-11-11。架构决定见 [ADR0111](../decisions/0111-sparse-custom-translation-overrides.md)。

## 使用

管理员在“外观 → 翻译字符串”选择界面范围和语言，再搜索原文、消息键或当前翻译。范围默认选择“全部范围”。列表以紧凑三列展示键名、原文和最终译文，长内容使用省略号；点击任一整行进入详情视图。

详情保留同一组范围、语言、状态与搜索工具，并继续显示可过滤的原文列表。主栏使用共享代码编辑器，按“原文在上、译文在下”排列；右侧只读展示上下文、范围、语言、所有者、日志键名和翻译状态。列表和详情共用一条彩色进度条，按当前范围和语言分别统计站点自定义译文、默认基础译文和未翻译条目的占比。

- 详情视图的译文编辑器创建实时草稿；译文留空并发布时恢复基础文本。
- “还原默认值”会删除该条覆盖，立即回到基础 JSON。
- 发布是批量且带 `expected_revision`；冲突时保留草稿输入。
- “未翻译”表示目标语言没有原生基础词条；使用 `ui_locale` 回退时可在“使用回退”筛选中查看。
- “原文已变化”表示发布覆盖后基础原文发生了调整，应重新核对。

## 实时草稿与发布

编辑译文或导入 JSON 后，修改会在约160ms内自动序列化为当前站点、当前账号的本机草稿；刷新页面或重新打开详情会恢复草稿。底部状态明确显示“草稿已实时保存到本机 · N项待发布”。本机存储失败时保留内存草稿并提示，不会自动发布。

只有点击底部“发布”才会调用服务器写入数据库并触发节点同步；“撤销修改”同时清除当前本机草稿。草稿按站点与账号隔离，不跨设备共享，也不进入公开设置快照。

## 导入与导出

“导出 JSON”下载当前全部稀疏覆盖，并合并实时草稿；“导入 JSON”读取同一版本化格式，先校验范围、语言、键、长度和占位符，再合并为实时草稿。导入文件不会直接写数据库，仍需使用底部“发布”确认。

```json
{
  "format": "everunfold-translations",
  "version": 1,
  "exported_at": "2026-11-11T00:00:00.000Z",
  "overrides": {
    "public": { "zh-CN": { "工作台": "大香蕉" } },
    "admin": {},
    "backend": {}
  }
}
```

导入采用合并语义：文件中未出现的键不会删除现有覆盖；显式空字符串会作为删除该覆盖的待发布修改。单文件上限8 MB、最多10000条；发布时每批最多500条并按服务器返回的新修订继续提交。

## 作用域

| 作用域    | 使用位置                       |
| --------- | ------------------------------ |
| `public`  | 前台阅读、搜索、评论和主题组件 |
| `admin`   | 后台页面、表单状态和管理提示   |
| `backend` | FastAPI 返回的稳定程序消息     |

文章内容、用户名称、评论、分类与标签名称不进入翻译目录。

## 解析与缓存

```text
数据库覆盖
  → 当前语言基础 JSON
  → ui_locale 基础 JSON
  → 源码默认文案
```

前端基础 JSON 位于 `src/core/i18n/en.json` 和中文源码默认值。数据库只保存覆盖行，不重写文件。公开/后台覆盖通过 `PublicSettings.translations` 随可靠设置快照分发；节点确认新的设置修订后才应用。后端消息覆盖保存在进程缓存，每30秒与 PostgreSQL 对齐。请求同时发送实际语言 `X-Site-Locale` 和基础界面语言 `X-Site-UI-Locale`，覆盖缺失时回退到基础界面包。

覆盖值最多4000字符，仅支持纯文本和当前 `{name}` 占位符，不允许 HTML 或脚本。占位符集合不一致时后端拒绝保存。

### 模板兼容

程序文案允许保留单花括号命名字段作为模板，例如 `“{query}” 找到 {count} 条内容`。渲染时只替换调用方明确提供的字段：

- 缺失字段保留原占位符，前端不抛异常；后端记录带键名和语言的警告后返回可用文本。
- 双花括号 `{{name}}`、过滤器表达式和其他模板语法原样保留，不交给 Python `format` 或任意模板引擎执行。
- 空白覆盖视为缺省并继续使用基础译文或原文。
- 译文可以省略原文中的可选占位字段，但不能引入原文不存在的占位字段。

发布响应代表数据库已提交。若“系统设置 → 节点与发布”仍显示同步待重试，使用“重新同步”；设置接收器在设置契约升级后也必须重启，否则旧进程可能继续按旧 Schema 拒绝新字段并返回 409。

## 限制

当前后台目录按源码中文原文作为兼容消息键。新增代码应逐步使用稳定语义键；基础原文变化时旧覆盖保留供核对，但管理界面会标记来源变化。当前不包含机器翻译、复数规则编辑器、翻译审批流或服务器端跨设备草稿。
