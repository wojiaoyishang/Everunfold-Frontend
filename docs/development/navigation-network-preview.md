# 导航慢网与失败复查

仅供本机开发验证，2026-10-31。正常入口为 http://127.0.0.1:3000，后端 8001；不要改动或重启用户现有实例。

## 临时代理

在前端目录运行：

```powershell
node tools/preview-navigation-network.mjs
```

打开 http://127.0.0.1:3901/?type=article。代理仅监听 127.0.0.1，将普通请求转发到 3000，支持开发热更新；默认没有延迟。不要把这个端口当作部署入口。终端每行接受一个 JSON 场景，只有匹配的路径和阶段受影响：

```json
{"path":"/where-i-go.html","delay":12000,"phase":"prepare"}
```

点击对应文章，检查旧 URL、正文和滚动位置保持。5 秒后导航栏下方展开颜文字横幅；响应完成后才显示目标文章并定位。菜单应始终可见、可操作。

```json
{"path":"/where-i-go.html","delay":25000,"phase":"prepare"}
```

20 秒后显示单行超时提示：短暂变红并轻抖一次，恢复配色后开始 5 秒倒计时，整块横幅底色的右边缘从右向左退去，伴随微光/气泡，归零后自动收起。横幅不含任何操作按钮。可增加 status:404 或 status:503 验证失败文案；disconnect:true 模拟断开。prepare 场景不影响直接打开页面。phase:rsc 隔离验证准备完成后 Next 传输阶段的延迟/错误，相关框架回退限制见 ADR 0009。

输入 `{}` 恢复正常请求，再次点击原文章链接即可重试。输入 `quit` 关闭本工具及其连接，浏览器返回 3000。场景只驻留本工具内存，不写应用配置、不改变系统网络设置。

## 必查交互

- 等待中不预先回顶；失败后继续阅读，位置不变。连续点击不同文章只接受最后一个意图；旧响应及旧提示的倒计时不能覆盖新导航。可通过返回或新选择中断等待，不再提供横幅取消按钮。
- 前进/后退恢复位置；评论 hash 正确定位；同页锚点仍有独立历史。外链/新窗口/下载保持默认语义。
- 桌面和窄屏横幅上边缘等于 header 下边缘，左右通栏，无浮层间距。菜单、搜索、手机侧栏不被遮挡。
- 首页 scrollY=0 时导航背景透明、无阴影/模糊。鼠标点击不留焦点框；键盘仍可识别焦点。
- 减少动态时关闭抖动/气泡，保留失败文字、红色强调和倒计时。不要修改 OS 偏好。

运行 npm run check、npm run verify:http；生产构建使用 npm run verify:production 的独立副本。实际结果和未验证项见 [交付验证](../handoff/frontend-navigation-verification.md)，不要把本页清单当作全部已通过。
