# 架构约束与范围

版本：bootstrap-24，2026-11-10（Asia/Shanghai）。依据为 [设计基线 v2.11](../baseline/01_Design_Baseline_v2.11.md) 与 [工程规范 v0.14](../baseline/02_Engineering_Plan_v0.14.md)。本页提炼边界，不替代原文和正式契约，也不宣称这些功能已经全部实现。

## 已确认的范围

- 单站点、多用户、前后端分离的博客与轻量 CMS；不做多租户站群，不合并 ChatWithMe 等独立应用。
- WordPress 迁移文章、普通页面、媒体、所需分类/标签与保留的历史评论，不迁移原账户。源备份只读使用，旧 PHP 主题仅供视觉和交互参考。
- 普通用户默认无发文权；公开注册与注册申请默认关闭；管理员管理账户。支持游客评论、邮箱验证能力、可选 2FA，预留第三方登录。
- 可信前端代码负责主题、页面和交互组件。正文允许安全过滤后的 Markdown/HTML，不允许文章/短代码中的数据库脚本、运行时热安装或通用可视化搭建器。2026-11-06用户新增独立页面源码授权：仅自定义页面可显式启用隔离iframe内的JavaScript，默认关闭、管理员维护并显示脚本提示（ADR0075取消重复输入密码），不能注入本站顶层；详见ADR0072与[页面架构](registered-pages.md)。
- 2026-11-05用户明确转向原生短代码，不再做旧兼容；需要后台样式库、可创建纯HTML/CSS的自定义定义，以及代码注册条目的只读展示。受控展示模板和作用域CSS是该需求方向，不能扩展为数据库脚本或任意组件执行。原生协议、真实目录和受控模板已实施，旧兼容路径已移除，详见[短代码架构](shortcodes.md)及ADR0057；HTML源码可通过可视化修改，保留源文和可信协同边界，见ADR0058。
- 2026-11-01 用户明确后台简洁专业，视觉可独立于公开博客，但样式/布局仍由可信前端主题管理；按 public/auth/admin 展示分区，权限与业务仍在 core/后端。隔离与目录见 [后台界面设计](admin-ui.md)，后台壳、设置与媒体业务已落地；文章/说说私有草稿 CRUD 见 ADR 0030，发布/撤回和可靠完整快照同步见 ADR 0031；页面管理已按ADR0072接入自定义源码与可信注册两种来源、独立实时预览及私有元数据。2026-11-02 编辑工作台、媒体/封面/分类标签/SEO/讨论属性已接通，根级标题路径、密码与定时开放按 ADR 0033/0034；公开快照只含允许公开的正文，受限读走 private/no-store，原静态媒体仍公开。
- 云端公开只读镜像是长期目标；主动校对、CDN 自动清理和自动故障切换留在后续阶段，首版不依赖它们运行。备份由外部运维服务负责。

## 进程、数据与任务

| 部分                    | 边界                                                                                                |
| ----------------------- | --------------------------------------------------------------------------------------------------- |
| PostgreSQL / SQLAlchemy | 内容、身份、正式修订、协同持久状态、计划及投递记录的权威存储；数据库差异仍需适配                    |
| FastAPI                 | 授权、业务事务、数据 API、协同 WS；可多进程                                                         |
| Celery Worker           | 具名业务任务、派生媒体、通知与节点投递；可多执行单元，不渲染文章 HTML                               |
| 自研 Scheduler          | 独立单进程，周期计划唯一投递者；从数据库读取计划，按持久 Outbox/执行标识恢复，不加载业务实现        |
| Redis                   | Celery Broker、FastAPI 广播、协同、Scheduler 唤醒及任务运行快照，各自隔离命名空间；通知不是持久事实 |
| Next.js                 | 可信内容渲染、主题、页面与公开数据/渲染缓存；公开快照不能回写主库                                   |

后端只有一个 `app` 根包。模块静态 Manifest 预检后，由唯一 `router_init(ctx)` 装配当前 FastAPI 进程；`ctx` 不进入普通路由、任务或请求资源。Worker 加载独立任务模块，Scheduler 不调用 FastAPI 注册器。核心及插件数据库迁移由管理员在部署流程显式执行，进程启动不自动迁移；移除代码不清理插件历史数据。

FastAPI 普通广播只同步进程状态：`emit(scope="process")` 本地分发一次后发到其他进程，忽略自身 Redis 回环。任务使用 Celery 原生 API；Scheduler 唤醒与协同拥有各自通道。不能把广播回调当成全局只执行一次的业务任务。

## 接口与配置

- 浏览器向 Next.js 获取公开页面，直接向 FastAPI 执行业务操作；Next.js 不是必经业务代理。公开 SSR 不混入身份和私有内容。
- 业务路径 `/v1/*`；FastAPI 内部 `/internal/v1/*`；Next.js 缓存 `/internal/cache/v1/*`；协同路径 `/ws/v1/collab/{draft_id}`（试用契约 collaboration-1）。除已定前缀外，具体端点/字段仍需正式契约。
- 可选开发代理把 `/api/v1/*` 仅剥离一次 `/api`，转发为后端 `/v1/*`；不得代理内部接口。生产仍验收浏览器跨源访问。
- `BACKEND_BASE_URL` 是不含凭据、`/v1`、`/api` 的绝对 HTTP(S) 地址，没有固定生产域名。前端服务端可用 `[backend].base_url` 显式覆盖；该覆盖不改变浏览器公开地址。
- 后端 `frontends.<node_id>` 绑定地址、投递 `enabled`、双向 Token 环境变量引用；根级 `FRONTEND_NODE_ID` 标识前端。更换域名不改变身份，`enabled` 不授予或撤销入站权限。
- 前端连接、来源限制与双向 Token 引用统一位于仅服务端 `[backend]`，不另设 `[internal_auth]`，不整体公开给浏览器。实际密钥从受控环境解析，不保存于任务载荷。
- Redis 项目主键来自后端 `[project].key`，示例保留 `lovepikachu`；scope 非空时生成 `{project.key}:{scope}:`。业务 Key、频道及 Celery 适配前缀集中派生，不因项目改名擅改运行命名空间。
- 后端发布版本化 OpenAPI 与 WS/事件 Schema，前端从精确提交/SHA锁文件恢复类型和客户端，不手工另建业务字段定义。按2026-11-07用户最新要求，根cache合并到var/cache，生成物写入被Git忽略的var/cache/contracts与var/cache/build，删除src/generated；稳定core/contracts模块隔离访问。原var公开副本不迁移。
- 业务 JSON 外壳为 `success/code/msg/data`，`code` 是整数，`data=None` 可省略，使用真实 HTTP 状态。文件、流、WS、204/304 等例外；`msg` 只供本地化展示。

## 身份与安全

浏览器默认由 FastAPI 管理 HttpOnly Cookie Session；CORS 精确来源、Cookie Domain 与 CSRF 分开设计。API Key 不突破所属用户当前权限。请求身份、语言和数据库 Session 按请求/任务隔离，不共用可变全局上下文。

基础浏览器认证见[ADR0018](../decisions/0018-authentication-and-admin-entry.md)。2026-11-06按[ADR0069](../decisions/0069-accounts-api-keys-and-signed-callbacks.md)完成账号中心、改密/会话、用户管理、细分本人/全部授权、个人受限头像库与API Key双向接入，见[操作指南](../development/accounts.md)。用户/可撤销Session/Key摘要与授权存PostgreSQL，密码Argon2id；登录/退出要求预会话CSRF和精确Origin，后台按当前能力授权。Key使用显式权限交集，不能借管理员角色或Cookie越权。`/v1/auth/*`、`/v1/account/*`、`/v1/admin/*`禁止共享缓存，账号资料不进入公开快照；注册、找回密码、邮箱验证和2FA仍未实现。2026-11-06按[ADR0071](../decisions/0071-user-permission-presets.md)增加可配置成员身份预设：应用时复制并校验权限，来源快照只作显示；修改/删除预设不联动既有账号，不扩大基础管理员角色。

内部接口要求真实 socket 来源 IP 允许列表 AND 接收 Token，随后检查最小权限。转发头不是原始来源事实；空允许列表、未知 peer 不放行。不能假定 Next.js App Router 暴露 socket；实现须选择可验证的适配层或受控入口并阻断旁路。内部路径仍需公网隔离。Token 不进入浏览器、URL、公开配置、日志或数据库任务参数。

## 内容、URL、协同与媒体

- 正式正文为 `[{id,type,content}, ...]` 有序 JSONB 列表，稳定块 ID，支持多个混合 Markdown/HTML 块。发布状态与访问策略分离；正式 Revision 保留整篇完整快照。
- 同语言内容一个共享工作草稿、一个 Y.Doc/WS 房间；标题、摘要、分类/标签、SEO 与正文协同。发布审核/权限通过独立业务 API，不实时覆盖已发布版本。
- Yjs 更新须在 PostgreSQL 提交后才确认；同更新去重落库，ACK 可重发；Redis 漏消息从权威持久状态恢复。浏览器 IndexedDB 保留未确认更新，恢复先重新鉴权；Awareness 是临时在线身份/光标状态。
- 各语言内容独立ID、审核及发布历史，通过翻译关联；URL语言决定SSR。只展示真实已发布译文，无译文回原文。2026-11-06已实施初始zh-CN/en、可扩展语言目录/默认语言/中文前缀和标志，原文一行管理各语言，界面包独立且缺包时回退；已有内容URL不批量改写，见[ADR0066](../decisions/0066-configurable-languages-and-grouped-translations.md)及[实际范围](multilingual-content.md)。
- 2026-11-10起，站点导航写入当前主题的`theme_options[themeId].navigation`，不同主题各自维护；旧`site.navigation`只作兼容回退，显式空菜单不得回退。语言目录、内容语言与主题导航名称仍为不同概念，见[ADR0105](../decisions/0105-admin-navigation-and-glossary-media.md)。
- 代码路由优先，冲突阻止发布；草稿 URL 发布时才激活。改址后旧地址失效，不维护历史别名或自动 301/308；首次迁移尽量直接保留旧路径，不能保留则出差异报告。
- 原媒体不可变，新文件新 ID，WebP 是同媒体的派生表示；默认本地文件系统、公开静态分发。正文保存虚拟 URI，FastAPI 随内容返回映射，Next.js 按节点/属性渲染替换，不猜桶路径或逐图回源。
- 2026-10-31 新要求：业务媒体经后端媒体库上传/登记，无 CDN 时由后端提供；规划静态 Base URL 与支持相对/绝对路径的 Uploads Path，并预留云端接管上传能力。[媒体存储设计](media-storage.md) 给出目录、列表、适配接口和缓存切换建议；本地上传、Base URL、Uploads Path、元数据/编辑和安全删除已实现，远端提供器与完整引用图仍未交付；前端现有媒体目录是试导入过渡。
- 文章/页面/媒体默认软删除；物理清理须检查历史引用并由有权管理员明确发起。媒体永久删除按用户最新规则区分安全删除（只移除当前记录，最后同哈希记录才清理文件）和整组同哈希清理；保留内部墓碑/操作回执供审计与重试，详见 ADR 0027。页面受限不让公开媒体自动变成私有。
- 首版搜索使用可重建的 PostgreSQL 搜索文档，不新增独立搜索引擎；不能泄漏私有标题、摘要、数量或片段。
- 评论保留回复关系，显示统一缩进一级，全局从早到晚；历史评论邮箱关联前验证控制权，关联不授予编辑/删除导入评论权限。

## 缓存与可靠性

公开快照无时间 TTL，Next.js 框架缓存是派生层，不随机删除 `.next`。普通刷新可保留仍允许公开的完整旧快照；已收到撤回/转受限则阻止旧正文、更新列表/搜索、保留较新不可见标记，回源失败也不回退旧正文。源站不可达与不存在须区分。

业务变更与可靠 Outbox 在 PostgreSQL 同事务登记；Worker 逐节点投递并保留稳定事件 ID、资源代次、尝试与回执；接收成功不等于落盘/激活/预热完成。计划执行以 `schedule_id + planned_run_at` 唯一标识，已登记工作须恢复，停机未登记的错过计划默认跳过。跨服务不承诺恰好一次外部效果。

2026-11-06新增一次性定时发布：排期时冻结协作检查点，PostgreSQL保存已登记执行的时间、修订与私有快照；Scheduler只投递tick，Worker按事务完成公开投影与可靠Outbox。重复/重启安全，合并期间等待；取消/撤回/回收清除计划，执行时复核原发布人和原Key权限，失败显式提示。此为已登记单次执行的恢复，不是未登记周期漏跑；见[ADR0073](../decisions/0073-scheduled-content-publication.md)。定时开放仍是独立访问策略。

## 统一插件与主题（2026-11-07）

按ADR0077，页面和短代码均由src/plugins内的可信插件贡献，固定路径自动发现插件与主题。设置模型只声明组件名/配置，主题hook提供具名控件实现，未知组件占位并保留数据；权限/事务/持久回执仍由宿主负责。配置与模型可运行时下发，新组件源码需重新构建。数据拉取/通知接口先形成规范，真实后端资源沿既有鉴权/契约/Outbox接入，不提供未授权的万能数据代理。

## 父子主题展示边界（2026-11-07）

Argon作为默认父主题，子主题继承具名组件、逐级可组合模板与作用域CSS，并可使用前台展示钩子。主题仅选择/渲染已允许下发的数据；路由、SEO、受限内容门禁、正文安全渲染、预览鉴权与回执由宿主保持。现有管理界面不随公开主题切换。规范见[父子主题](frontend-themes.md)和ADR0078。

## 独立前端插件与扩展偏好（ADR0079）

主题源码随主体构建，部署后只切换已编译主题；前端插件源码单独编译为前端仓库的plugins/<目录>，主体不打包它们，可运行时新增/更新完整可信包。不设版本目录，按资源SHA与SDK协议校验；SDK共用宿主React，缺失展示组件占位，生产编辑器保留正在使用的构建。

PublicSettings.extensions是后端权威偏好，沿原审计/可靠投递，不以节点本地开关替代。节点清单登记为POST /internal/extensions/{node_id}，正文协议extensions-1，真实IP AND节点Token、512KiB边界，只接受元数据。首次创建停用页面工作稿，重新登记不覆盖已有数据。所有迁移显式执行，运行时包不是后端迁移或恶意代码沙箱。

## 验证码规则与插件（2026-11-09）

已按[ADR0086](../decisions/0086-captcha-providers-and-content-policies.md)实施本地图片与可信提供方插件、全局/单篇规则、一次性校验及受限正文投影。后端扩展唯一源码目录为app/plugins；根plugins旧占位移除。验证码配置/密钥仅专有私有接口访问，Redis保存短时挑战，公开快照不含受限正文/页面配置或读取回执。正式评论提交后待审核；审核/回复/编辑/回收已按ADR0088接入独立权限、修订、幂等、审计及公开投影，验证码不取代原有访问/发布权限。

API Key仅凭明确授予的阅读/评论免验证码权限及全局许可豁免对应挑战；不自动给已有Key授权。阅读侧请求每Key限流，提交前重新检查撤销/缩权；凭据无效不得回退匿名，回执不得跨凭据使用。登录、文章密码、内容可见性和评论审核保持独立。机器查询/Callback沿原签名协议，不引入人工挑战。

## 单入口后端插件（2026-11-09）

可信后端插件统一从 `app/plugins/*/plugin.py` 发现，导出 `Plugin` 或 `define_plugin` 构造的对象；只固定入口，其余文件由作者安排。同步 `setup` 登记短代码、验证码提供方与文案，API 生命周期负责进程资源，核心模块仍沿 `router_init(ctx)` 装配，Worker/Scheduler 不执行 API 启动钩子。定义冲突、依赖错误会阻止装配。

发现与数据库部署分开：显式命令将目录快照写入私有站点数据，修订、审计和可靠 Outbox 同事务；服务启动不写目录或迁移。公开模板从当前已应用配置下发，前端主体不再内嵌后端短代码定义。后台统一启停并检查引用，源码/历史数据保留；验证码要求插件已登记、启用且匹配当前进程，失效不放行。Python 修改后受控重启并同步目录，不提供同进程热替换或在线上传执行。见[ADR0087](../decisions/0087-single-entry-backend-plugins.md)与[开发指南](../development/backend-plugins.md)。

## 运营与搜索发现（ADR0088）

评论归属于文章/说说或管理页面之一，审核修改与Outbox同事务；公开评论及点赞继续检查原文可见性，回收可恢复。工作台只返回当前账户有权限的待办数量/标题，不生成虚构指标。全站及单篇收录属于宿主业务设置，站点地图、订阅、结构化数据和语言链接仅从已应用可公开/可收录投影派生，主题不放宽权限；robots并非鉴权。正文撤回后发现入口同步撤回，改址不创建自动别名。实现/未覆盖范围见[指南](../development/operations-and-search.md)。

## 术语表与主题私有设置（2026-11-10）

术语由后端插件独立保存，正文是与文章一致的安全 Markdown/HTML 区块列表。文章级接口先在后端按已公开正文和语言匹配，只向对应文章的缓存补充实际命中的已发布词条；未命中返回空数组，不得下发整份术语目录。文章正文快照与术语缓存分离，前端在空闲后懒加载并保留失败降级；后台编辑器、公开详情与 Tooltip 富文本复用文章共享安全和按需资源链路。详见ADR0099与[术语表指南](../development/glossary.md)。

主题切换属于公共设置入口，主题表现和阅读默认值属于各主题自己的`theme-settings.tsx`与`theme_options[themeId]` profile。顶层`theme`只作为活动主题兼容投影；站点资料、页脚、SEO、术语及其他非主题业务继续属于公共设置。详见ADR0100与[主题设置指南](../development/theme-settings.md)。
