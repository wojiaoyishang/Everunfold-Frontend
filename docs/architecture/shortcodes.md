# 原生短代码与后台短代码库

版本：shortcodes-design-1，2026-11-05（Asia/Shanghai）。状态：**需求方向已确认，交互与实施方案待评审，运行功能尚未切换**。本轮只读调研、设计与交互草图，不以草图中的保存/应用冒充真实后台能力。决定见[ADR0056](../decisions/0056-native-shortcode-catalog.md)。

## 1. 已确认方向与现状

用户要求去掉旧短代码兼容，转向自主定义的新体系；后台有专门入口展示全部短代码样式，允许创建自己的纯HTML/CSS样式短代码；部分由前后端代码注册的条目可展示但不可编辑实现。

当前前端只有 `core/rendering/shortcodes.ts` 中的封闭兼容词表和展示转换，名称包括collapse/fold/alert/admonition/tooltips/ref；没有独立短代码注册表、定义存储或管理页。正文渲染和摘要清理都引用它，reader.css与sanitize白名单含legacy类名，参考资料汇总也消费其生成的标记。后端尚无短代码业务模块。

“不要旧兼容”是后续约束：新体系不提供旧名称、旧参数或别名转换，不并行保留旧解析器。清理应覆盖上述渲染、摘要、CSS、白名单和旧兼容测试；通用HTML过滤、媒体、目录、代码/公式等阅读能力继续复用。旧文章原始正文与WordPress备份保留，先输出受影响清单，不能静默删掉旧标记中的内容或批量覆盖文章。

## 2. 入口与画廊

建议在「工作空间」分组中，媒体/图标/字体等资源入口旁新增 **短代码库**，建议路由 `/admin/shortcodes`。沿现有后台导航注册，真实路由、侧栏、手机导航、面包屑和登录回跳共用登记，不创建第二套导航。路由和SDK名字属于提案，尚未冻结。

- 主页默认展示样式卡片，每张含真实渲染样例、名称、来源和可编辑/只读状态；有参数变体的条目可在详情中试参数，不能把只读实现变成可写。
- 点卡片看详情：效果、说明、稳定标识、参数/正文插槽、来源模块、调用示例；提供复制调用。动态组件用明确标注的演示数据，不在样式库产生浏览记账、表单提交或其他写操作。
- 自定义条目提供「编辑模板」，代码注册且只读的条目完全没有该按钮。只读详情不显示灰掉的实现编辑器，不把缺少后端能力伪装成可以修改。
- 「新建短代码」进入独立编辑页，保留充足的HTML/CSS编辑与预览空间。窄屏画廊和详情顺序排列，编辑区与预览上下排列。

草图：[样式库](../design/shortcode-catalog-proposal.jpg)、[自定义编辑](../design/shortcode-editor-proposal.jpg)。图片中的短代码与统计值都是设计样例，页面尚未接入真实服务。

## 3. 来源与操作能力分开

| 类型 | 样式与参数说明 | 实现编辑 | 管理方式 |
| --- | --- | --- | --- |
| 系统内置 | 可展示/复制调用 | 默认只读 | 随受信代码部署 |
| 前端或后端模块注册 | 可展示，必要时标注数据/权限条件 | 默认只读；若模块开放配置，只改声明的选项 | 代码声明能力，不从数据库加载脚本 |
| 用户自定义HTML/CSS | 可展示/复制调用 | 可编辑模板、样式、参数及示例 | 管理员创建的站点共享定义 |

来源是说明，不是授权判断。统一视图声明查看、编辑模板、修改默认配置、归档等能力；后端只允许修改自定义定义，保留系统/模块命名空间，不能只隐藏前端按钮。文章中填写一次调用的参数与“修改短代码实现”是不同操作：前者只影响该处，应用模板新版本会影响所有引用位置。

注册条目统一为一个稳定ID。前端显式导入的展示器、后端模块提供的能力元信息和数据库自定义定义，按可信来源确定性汇总；前后端共同提供一个组件时声明同一个所有者和展示器关系，不互相覆盖。缺少展示器/业务模块时给管理员可排查状态，不下载任意远端代码补齐。

## 4. 自定义编辑体验

编辑页左侧：名称、稳定标识、HTML/CSS两个源码标签；右侧：使用正式阅读样式的预览、样例参数与调用示例。复用已有CodeMirror封装、语法高亮、查找/撤销、媒体选择与上传队列；自定义定义先用版本冲突检查，不额外引入一套文章协同文档。

第一版建议只开放纯展示模板：文字参数、枚举、开关、数值/颜色、经过校验的链接或媒体引用，以及一个正文插槽。初始模板提供阅读主题变量；纯HTML的details/summary等合法结构可保留，不提供JavaScript、事件属性、React表达式、任意模板函数、循环或数据查询。

示意HTML：

```html
<aside class="reading-tip">
  <strong>{{title}}</strong>
  <div>{{body}}</div>
</aside>
```

`title`等普通参数按上下文转义，`body`是专门的已过滤正文插槽，不能把任意字符串当作可信HTML。模板中的标记不是脚本语言；模板本身不递归调用其他模板，嵌套来自文章正文的语法树。参数与插槽记法仍是提案。

建议流程为 **编辑 → 保存草稿 → 应用**：保存不改变已发布页面；应用前显示引用范围和变更，生成不可变定义版本，保留回退能力。标识创建后固定，显示名称可改；引用中的参数类型变更需显式报告影响。已被引用的定义优先归档，停止新插入而保留已有文章所需版本，不直接删除引用目标。

## 5. 新调用语法建议

建议用带命名空间的独立协议，例如：

```text
[custom:reading-tip title="阅读提示"]
这里可以写 **Markdown**，也可以嵌套新的短代码。
[/custom:reading-tip]
```

内置可用core命名空间，模块使用各自命名空间，自定义只使用custom；中文显示名称不作为调用身份。这里只建议语法方向，不冻结名称和参数契约。

实现使用可定位范围的语法树，校验引号、参数、配对和有界嵌套，不以全篇正则替换充当新协议。代码围栏、行内代码、pre/code、HTML属性与注释中的例子保持字面量。未知或错误的新调用在编辑器给出位置诊断并保留源文；不吞正文、不让整篇阅读崩溃。

旧的裸名称不进入新注册表，也不转译成新名称。旧标记作为普通源文保留，切换前报告受影响内容并逐项处理；这不是新的兼容层。

文章/说说仍在原Markdown或HTML块字符串中保存调用，不新增每个短代码独立的正文块类型或Y.Doc。后续编辑器的短代码插入器复用同一目录与参数定义，选区可进入body，插入走原源码变更/整篇保存；可视化适配需保留调用源文，不能保存展开后的DOM。

## 6. 渲染、样式与资源边界

- 浏览器编辑预览、正文预览、私有前台预览与公开SSR消费同一编译/渲染规则，不能各自维护一套输出。后台预览使用隔离的阅读表面，用户样式不能覆盖后台壳。
- HTML与CSS都需服务端校验；浏览器校验只提供即时反馈。CSS按语法树限定到组件作用域、重命名动画等标识，并约束逃出容器的布局规则；不能靠简单字符串前缀或仅用Shadow DOM就宣称安全。拒绝全局规则、脚本、外链导入和未授权资源；报错保留输入，不悄悄丢掉样式。
- 普通模板可以使用约定的阅读主题变量和显式颜色参数。后台控件/内置组件继续遵循主题变量；读者减少动态、键盘可达性与明暗模式纳入验收。
- 图片、附件和字体引用复用稳定媒体ID、引用保护与既有上传/解析能力；只为当前页实际使用的短代码加载样式/字体。没有短代码的文章不批量加载整套画廊资源。
- 受信代码注册的动态组件继续通过已声明FastAPI用例和按页请求能力读取数据，公开SSR/共享缓存不含用户态或受限数据。样式画廊的试参数不提交真实业务。

## 7. 保存与发布衔接

建议独立短代码模块保存自定义定义及不可变版本：稳定ID、名称/说明、作用类型、参数与正文Schema、HTML/CSS源文、示例值、草稿/已应用版本和审计信息。正式模型与API由后端发布契约后生成客户端，本文不是可直接调用的接口定义。

“应用”在数据库中提交版本、审计及持久投递意图；前端节点确认后才显示已生效。复用现有Outbox/节点投递机制，增加独立定义资源，而不是覆盖文章正文或任意合并进主题设置JSON。SSR/渲染缓存包含已应用定义修订，变更与回退后失效受影响页面；不能只替换浏览器CSS却继续使用旧SSR。

第一版可先使用统一目录修订作为缓存依赖；引用索引逐步用于影响范围、归档和媒体删除保护。定义、使用它的已发布文章、草稿及历史修订都需要明确保留关系，不因删除模块或归档样式失去原始内容。

## 8. 实施顺序与本轮验证

建议先做新协议/目录/编译器与去兼容清单，再落后台画廊及自定义模板CRUD/预览，然后接正式SSR、定义投递与编辑器插入。正式切换时一并删除旧兼容转换器、legacy输出规则、摘要特殊清理和旧名称别名，替换相应测试；不先把旧别名搬进新的注册器。

后续验收包括：只读条目直接写入拒绝、名称冲突与版本冲突、嵌套/字面量保护、HTML/CSS越界、草稿不影响公开页、应用/回退与缓存、离线节点/投递重试、资源按需及媒体引用保护。涉及数据库、权限和可靠投递时按现有P0要求做真实多进程验证。

本轮只完成方案与本地交互草图：桌面画廊/只读详情、自定义编辑/HTML与CSS标签、试填参数、应用范围确认/取消、新建及演示保存经过内置浏览器检查；320px宽度修复了面包屑换行，未出现整页横向溢出。草图中的源码区用于说明编辑流程，没有实现通用HTML/CSS编译或真实存储；没有调用项目写接口、修改文章/数据库、重启应用服务或移除运行代码中的旧解析器。临时预览已关闭。没有重复211项测试或后端P0，因为未修改业务实现。
