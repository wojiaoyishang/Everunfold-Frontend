# ADR 0075：页面脚本与头像限制改为权限校验和提示

状态：2026-11-07，按用户最新明确要求实施；本条覆盖ADR0072/0074与旧账号指南在这两个入口要求再次输入密码的规则。

## 决定

自定义页面的JavaScript默认关闭，仍只有管理员可以启用或修改启用脚本的源码；启用后展示醒目提示。保存、应用及目录启停不再要求当前管理员密码。页面仍运行于无同源权限的srcdoc沙箱，脚本/CSP、应用草稿分离、权限、CSRF、修订检查及审计保持。

头像上传限制仍只允许具有用户管理能力的登录会话修改，表单提示这些限制影响所有用户的头像上传；不再要求当前密码。上传大小/尺寸/频率/保留数范围、跨进程配额、操作幂等、修订竞争和审计保持。

这不是取消其他账号安全确认。改密、身份/授权管理、Key签发和应用凭据等继续按既有规则确认。兼容旧请求中可选的current_password字段但不再校验这两个入口的该字段，不额外记录明文密码。

pages1.3提供applied_javascript_enabled供目录判断管理员维护范围；旧enable_requires_password固定false。accounts1.5把AvatarPolicySave.current_password改为可选。契约先提交，再生成前端。

## 侧栏修正

移动端触控行由42px变为44px，旧高亮仍按42px高度、47px步长定位，导致靠后项逐渐错位。行高和间距统一为CSS变量；链接、背景高度和位移共用同一值，桌面42px、移动44px。保留原菜单、权限过滤、键盘焦点与主题动效。

## 检查

后端验证管理员不填密码维护脚本、原CSRF/Session与普通成员边界；真实双API头像配额P0改为无密码保存限制并保留越权拒绝。前端需实际检查提示/无密码字段、保存草稿、目录启停，以及移动/桌面多个导航项的背景与链接矩形，结果以交接为准。
