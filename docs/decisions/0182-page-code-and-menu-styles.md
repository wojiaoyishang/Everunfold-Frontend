# ADR 0182 · 页面代码与菜单项样式

2026-11-17，已实现。前端独立插件 `core.page-injections` 在「外观 → 页面代码注入」登记规则编辑器。只有浏览器登录的站点管理员可以读取草稿和保存，普通设置权限和 API Key 不能发布代码。后端在已有站点配置中保留独立规则版本，使用原事务和投递通道，无数据库迁移。普通设置写入对页面代码字段不生效。

规则可选择范围、页面类型和 URL 路径，条件同时满足。公开运用的规则进入公开设置快照；只作用于后台或账号中心的规则不随公开快照发送，登录后读取对应规则。登录、节点控制台、规则编辑页和插件管理页不执行注入。HTML 依然过滤；CSS 与 JavaScript 只接受管理员明确发布的代码。软导航回收插件创建的样式、HTML 和脚本元素，JavaScript 可用清理钩子释放自己的事件与计时器。

导航项新增可选的 `extra_class`、`extra_css`，空值不序列化。CSS 用现有作用域编辑器编译，只影响该项的展示行及其子元素，不能突破作用域。顶部、侧栏的桌面与移动渲染提供同一 `data-menu-item-id`，可结合 `data-menu-position` 定位。
