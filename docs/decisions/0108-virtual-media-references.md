# ADR0108：媒体虚拟引用与术语特色图输入

版本：ADR0108-1。状态：已实现并验证。日期：2026-11-11。补充 [ADR0025](0025-recursive-menus-and-icon-library.md)、[ADR0105](0105-admin-navigation-and-glossary-media.md) 与 [ADR0107](0107-admin-sidebar-scroll-restoration.md)。

## 背景

媒体选择器同时返回稳定媒体 ID 和后端派生的实际 URL。输入框若只显示实际 URL，会和普通手填地址混在一起，也容易让管理员误以为域名被写进业务字段。术语特色图片选择完成后，输入框还需要等待派生地址重新解析。

## 决定

1. 媒体库绑定统一显示 `site://media/<UUID>` 虚拟地址。实际 HTTP(S) 地址只用于缩略图、大图预览和公开渲染，不写回媒体引用输入。
2. 已绑定媒体的输入框只读；清除后可重新从媒体库选择，或手动输入完整有效的 `site://media/<UUID>`。有效虚拟地址会立即解析为稳定媒体 ID。
3. 无效虚拟地址显示明确错误，不保存为媒体 ID。允许普通 URL 的既有字段仍可手动输入 HTTP(S) 地址；这类地址不会伪造媒体关联。
4. `site://media` 的规范化和解析集中在共享 core/media 模块，正文插入、短代码与设置媒体字段使用同一表达。
5. 术语选择媒体后立即更新时间对应的输入框和缩略图，不等待下一次设置读取或保存。保存仍只提交 `feature_media_id`。
6. 后台术语配置继续使用左侧目录与右侧编辑器的双栏架构。术语页不再继承通用设置页的1120px宽度上限，左侧目录保持原宽度，右侧编辑器填满剩余内容区；公开术语详情与特色图片展示保持原布局。
7. 后台术语列表批量解析已绑定特色图的真实地址并返回 `feature_image`。左目录优先显示该图，没有图片时继续使用术语图标；不为每一行单独请求详情。

## 影响

- `glossary-v1` 升至 `3.6.0`，后台列表项新增可选 `feature_image`；术语插件升至 `1.7.0`。无数据库迁移。后端继续验证媒体 UUID、类型和可用状态，并从媒体记录派生真实 URL。
- 媒体域名或路径变化不需要修改术语、设置或正文中的虚拟引用。
- 手动外部 URL 与媒体库引用保持不同语义；清空媒体绑定不会删除媒体文件。

## 验证

术语特色图从媒体库确认后输入框立即显示 `site://media/<UUID>`，缩略图同时更新；清除后手动粘贴同一虚拟地址可重新建立媒体 ID 关联，普通 HTTP 地址不会被当作媒体引用。左目录中已绑定图片的词条显示同一特色图，其他词条保留图标。后台保持左侧术语目录、右侧编辑器，编辑区右边缘与后台内容区对齐；公开词条页特色图仍位于标题右侧，390px 时单列且无横向溢出。检查期间没有术语或设置写请求，脚本错误为0。
