# ADR 0125：站点阅读与文章显示

站点设置保存站点图标、日期格式、时区、静态首页、文章列表页、订阅正文模式和新文章默认值。首页与文章列表页绑定已公开的自定义页面 ID，选择失效时回退到原有列表。公开页面的地址和内容的已保存地址继续按原记录读取。新文章地址支持标题、内容 ID 和日期变量，并自动加语言前缀。分类和评论默认值只在创建时应用，显式传入的值优先。

Argon 主题独立保存顶栏 Logo、侧栏博主头像和文章阅读默认值。未单独设置主题头像时继续读取旧站点头像。邮件品牌图标留空时取站点图标。文章可覆盖布局、目录、分享、推荐和文末附加内容，并使用独立分享图及公开署名。公开署名不改变内容归属或编辑权限。分享图按媒体引用解析，未解锁的内容不投影分享图。

站点及文章设置沿用现有修订、协同与前端节点投递。新字段在 JSON 中按需读写，兼容已有记录和快照，无数据库结构迁移。更新后端后同步前端契约及服务。
