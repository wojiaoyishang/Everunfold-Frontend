# ADR 0035：后台面板层次与编辑控件

日期：2026-11-02。状态：已实现，实际验证见 [编辑工作台验收](../handoff/editor-workspace-verification.md)。依据为用户要求：标题放到最上面、日期必须有日期/时间组件、后台各页参考 WordPress 明确背景和边框，每改完一个组件立即在内置浏览器查看效果。

## 决定

- 后台工作区使用独立灰蓝底色，输入/编辑/资料面板使用白色或深色表面、细边框和轻量分区标题。统一从 `admin/styles/tokens.css` 派生，不让页面单独选择背景色。概览、内容列表、设置、媒体、图标和代码页面目录共用这一层次。
- 编辑器标题在正文和属性面板上方，固定链接紧随其下；保存/发布最终按 ADR 0036 移至右上，与查看前台并排。桌面为正文加属性侧栏，窄屏以正文/内容设置切换，避免把很长的属性列堆在正文之前。
- 日期和时间使用封装 `DateTimeField`，内部复用 Button、Select、Popover 及定位就绪门控，提供月历、年/月、时/分、现在/清空/确定、方向键与翻月。日期处理位于 core，展示位于主题。界面按浏览器本地时间选择，提交带时区 UTC；前台开放时间明确标示北京时间，站点时区统一选择后续细化。
- 日历可以在视口内与触发器重叠，防止短屏上出现上下均放不下的裁切。默认下拉选择器保持原定位行为。所有控件继承当前展示区的主题及减少动态设置。
- 每个新增或修改的可见组件完成后，立即在内置浏览器检查实际页面，发现问题先修复再推进下一组件；检查不能只看构建。桌面、窄屏、焦点与进退场结果及截图留在验收文档中。
- 前台滚动条顶部填色依据实际导航栏高度（包括慢加载横幅）测量，不再只依赖固定高度。手机高度变量保持正确优先级；回到顶端仍透明。后台样式不污染前台导航。
- 受限正文只在当前阅读组件内存中呈现，内容 ID 或发布更新时间变化时重新挂载，避免导航保留旧解锁正文。未成功读取的浏览量不展示；本期受限阅读不发起尚未接通的私有浏览量请求。

## 边界

本决定不引入新的主题、UI 依赖、浏览器业务缓存或第二套权限系统。媒体/图标管理、同步和确认弹窗沿用已有用例。完整富文本编辑、拖拽块、协同、站点时区设置和受限内容互动另做，不因界面完成宣称已交付。
