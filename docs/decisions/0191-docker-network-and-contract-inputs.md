# 0191 部署地址与锁定契约输入

状态：接受。日期：2026-11-20。

## 决定

部署向导在已有地址字段接受 Docker 网络名，并在根配置的部署元数据中保存网络名。每次由 setup 启动时根据 Docker IPAM 生成运行地址。来源集合使用子网，HTTPS 代理来源与宿主绑定使用网桥网关，独立容器的进程绑定使用容器自身在该网络上的 IP。统一部署的内部通信使用本机回环。旧的网络白名单和反代网络设置在启动时迁移。

前端节点控制台允许单独配置访问来源，使用实际 TCP 对端并保留已有鉴权与 HTTPS 代理检查。前端构建优先使用本地后端源码和持久的契约缓存，随后按配置下载，每份契约都根据锁文件验证 SHA-256。npm 依赖安装继续使用独立的 Registry 与原有的锁文件完整性校验。
