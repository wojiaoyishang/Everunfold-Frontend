# ADR 0054：编辑器预览操作随滚动进入顶栏

日期：2026-11-04；扩展：2026-11-06。状态：已实施。来源：用户在文章编辑页选中「正文预览、前台预览、查看前台」，要求页面下滑时自然出现在导航栏中。沿用 ADR0029 的动效与焦点规则、ADR0051 的私有预览行为。

## 决定

- 共享 `ScrollHeaderActions` 把预览、保存、发布与撤回操作作为一组；原操作行抵达固定顶栏边缘时进入顶栏，向上滚回后归位。归位留 8px 滞回区，避免临界位置反复切换。2026-11-06用户要求将保存/发布一并移动，替代最初仅移动预览的范围。
- 同一个 React Portal 容器在原位与后台壳插槽之间移动，不复制按钮、不随滚动更换 Portal 目标。预览模式、准备请求等组件状态保持；迁移前的按钮焦点用 `preventScroll` 恢复，原位保留尺寸以免引起页面跳动。
- 宽屏与工作空间操作同行；视口不超过1200px时使用导航下方的一行，允许必要换行。第二行不撑高原顶栏，避免改变滚动判定；ResizeObserver 记录其实际额外高度，编辑器固定属性栏据此避让。配色使用后台统一变量。
- 进入与归位分别用180ms透明度/小幅位移动效。后台减少动态及对应系统偏好关闭这两段动效，操作与焦点即时响应。迁移不等待动画，不延迟业务请求。
- 页面卸载时释放监听、观察器及待执行帧，移除自身容器并清理额外高度；后台壳不遗留上一个编辑页的操作。

## 边界与验证

此项只改变主题布局；没有新依赖、业务接口、保存/发布用例、认证规则或数据库变化。文章与说说复用同一编辑器；实页验收使用已有自建文章，未写入或发布正文。见[验收记录](../handoff/editor-preview-dock-verification.md)。

## 2026-11-06扩展

文章/说说完整编辑操作组复用稳定Portal宿主移动，页面也合并实时/前台预览与保存/应用，返回列表左置。窄屏换行，沿原额外高度和固定区块避让。实时预览内的保存控件继续投射到父窗口工具栏，不复制第二套或改变原表单校验。管理组无障碍名称改为“编辑操作”，支持界面翻译。

验收另发现旧协作回执Schema遗漏已有owner_id，已发布collaboration2.1.0并更新生成客户端，严格字段校验及所有业务/WS守卫保持。当前检查、保存回执回归、清理与限制见[完整操作组验收](../handoff/editor-actions-dock-verification.md)；原2026-11-04记录仅对应当时预览范围。
