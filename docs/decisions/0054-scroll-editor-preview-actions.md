# ADR 0054：编辑器预览操作随滚动进入顶栏

日期：2026-11-04。状态：已实施。来源：用户在文章编辑页选中「正文预览、前台预览、查看前台」，要求页面下滑时自然出现在导航栏中。沿用 ADR0029 的动效与焦点规则、ADR0051 的私有预览行为。

## 决定

- 共享 `ScrollHeaderActions` 把三个预览操作作为一组；原操作行抵达固定顶栏边缘时进入顶栏，向上滚回后归位。归位留 8px 滞回区，避免临界位置反复切换。保存、发布、撤回仍在原操作区。
- 同一个 React Portal 容器在原位与后台壳插槽之间移动，不复制按钮、不随滚动更换 Portal 目标。预览模式、准备请求等组件状态保持；迁移前的按钮焦点用 `preventScroll` 恢复，原位保留尺寸以免引起页面跳动。
- 宽屏与工作空间操作同行；视口不超过1200px时使用导航下方的一行，允许必要换行。第二行不撑高原顶栏，避免改变滚动判定；ResizeObserver 记录其实际额外高度，编辑器固定属性栏据此避让。配色使用后台统一变量。
- 进入与归位分别用180ms透明度/小幅位移动效。后台减少动态及对应系统偏好关闭这两段动效，操作与焦点即时响应。迁移不等待动画，不延迟业务请求。
- 页面卸载时释放监听、观察器及待执行帧，移除自身容器并清理额外高度；后台壳不遗留上一个编辑页的操作。

## 边界与验证

此项只改变主题布局；没有新依赖、业务接口、保存/发布用例、认证规则或数据库变化。文章与说说复用同一编辑器；实页验收使用已有自建文章，未写入或发布正文。见[验收记录](../handoff/editor-preview-dock-verification.md)。
