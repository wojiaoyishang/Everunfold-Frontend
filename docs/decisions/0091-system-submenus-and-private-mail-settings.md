# ADR 0091：系统子菜单与私有邮件配置

版本：ADR0091-1；日期：2026-11-09。状态：接受；菜单与配置已实现，发送按阶段规划。

## 来源

用户指出系统设置和运行与任务使用相同图标，希望形成子菜单，移动端为手风琴；同时要求检查其他重复图标，将邮件发送和配置加入路线，先交付配置，实际参数由用户填写。

## 决定

后台注册表增加带命名空间的 `branches`，页面通过 `menu.branch` 归属子菜单。先过滤页面权限，再剔除空父级；扁平路由目录继续服务路由守卫、面包屑和登录返回校验，不把父级按钮当成业务路由。主题负责手风琴、动效、焦点、语义图标和当前项展示；折叠子菜单不可聚焦。

将系统设置、运行与任务、邮件配置放在「系统管理」下。插件、应用接入、媒体、图标库、短代码、分类标签等采用独立语义图标，不以同一个云朵表达不同职责。实际高亮背景附着链接，替代假定固定行高的索引滑块。

邮件配置使用独立修订、私有后端存储和标准权限，不进入公开站点投影、Node 设置同步或浏览器长期缓存。密码只写，空值保留、显式清除；保存事务及审计一致。复用既有表，无隐式迁移、自动连接 SMTP 或测试发送。

## 后续与验收

Worker 执行发送，Scheduler 负责指派到期和重试；提供方可由插件实现，业务授权、凭据读取、通知偏好和可靠投递由核心统一处理。具体配置规则和未实现路线见[邮件指南](../development/mail.md)，实际验证与限制见[验收记录](../handoff/navigation-mail-verification.md)。
