# ADR0104：多语言导航标签与跨页面术语钩子

版本：ADR0104-1。状态：已实现并验证。日期：2026-11-10。补充 [ADR0066](0066-configurable-languages-and-grouped-translations.md)、[ADR0101](0101-glossary-rules-and-reader-ui.md) 与 [ADR0103](0103-dynamic-glossary-footnotes.md)。

## 背景

现有内容与术语正文已有语言字段，但导航菜单只保存一个名称，术语目录、详情、提示和搜索结果仍混有固定中文；术语匹配也只能从文章/说说正文文字产生。用户要求按实际配置语言独立设置菜单名称，并增加与关键词匹配正交的跨页面页面元素钩子。

## 决定

### 多语言导航

1. `MenuItem.labels` 保存语言代码到菜单名称的稀疏覆盖，`label` 始终作为默认回退。没有配置某语言时不生成空字段；设置弹窗采用“添加语言名称”方式，仅显示已配置覆盖，可删除覆盖。
2. 标签解析顺序为精确语言代码、基础语言代码、默认 `label`；空值不覆盖。header、桌面/移动侧栏、子菜单、页脚及相关 `title`/`aria-label` 都消费同一解析结果。
3. 语言旗帜优先使用站点配置；纯 ASCII 国家/地区代码（如 `CN`、`GB`）规范化为 emoji 旗帜，已有 emoji 保持。管理弹窗使用共享 Modal、Select、TextField 和 LanguageLabel；语言名称字段沿用后台表单的白色/深色表面、40px 高度、细边框和强调色焦点环，并补齐占位文字、悬停与减少动态兼容。
4. `settings-v1` 升至 `1.28.0`。旧菜单没有 `labels` 时继续使用原名称。

### 正文术语显示归属

5. 悬浮提示与脚注不是站点总设置，而是每篇文章、说说和页面自己的编辑设置：`show_glossary_tooltips`、`show_glossary_footnotes`，默认开启。它们随草稿、协同设置、版本和公开快照保存；站点级只保留匹配总开关、上限和默认提示来源。
6. `content-admin-v1`、`pages-v1`、`public-v1` 与 `presentation-v0.2` 分别升级到 `1.18.0`、`1.9.0`、`0.13.0`、`0.2.0-preview.4`。页面使用同一对字段，内容设置面板新增独立可折叠的“术语提示”区。

### 跨页面术语钩子

7. 钩子归属于具体术语，在术语编辑页的“页面触发”分组维护，不单独设置导航入口。每条触发选择一名术语，范围为所有公开页面或最多 32 个指定文章/说说/页面目标，并保存启用状态、优先级和修订。
8. 首批支持常见 CSS 选择器，包括 `#id`、class、属性、后代和组合选择器；拒绝伪元素、`html/body/*`、危险字符及超过 256 字符的规则。每页最多连接 20 个元素，指定内容优先于全站规则，再按优先级和稳定 ID 决胜。
9. 公开接口只返回当前 surface、内容/页面 ID 和语言命中的启用钩子，最多 50 条；不下载无关钩子。前端在页面 presentation 就绪且空闲后加载，按 60 秒缓存；MutationObserver 处理后续 DOM，SPA 切页重新解析。
10. 钩子与关键词 Tooltip 共用弹层、动画、详情、词条链接、键盘和触屏行为。同一元素只挂一个钩子；链接、按钮等原生交互元素首次点击保持原行为，悬停和键盘聚焦仍能打开提示。
11. 管理员可选用“JavaScript 挂载”作为危险触发方式，使用现有 JavaScript CodeMirror 编辑器；普通内容编辑者不能创建或保存。脚本最多 20KB，运行在公开页面主线程，提供便捷 API `glossary.select(selector)` 和 `glossary.mount(element)`；`element`接受`document.querySelector()`等原生DOM对象。保存区始终显示明确安全警告，脚本异常只禁用该条触发，不阻塞页面或其他钩子。
12. 钩子使用 `glossary_hooks`、`glossary_hook_operations` 与显式 `0039_glossary_hooks`、`0040_glossary_hook_scripts`；支持操作幂等、修订冲突、归档和术语停用后的自动失效。`glossary-v1` 升至 `3.4.0`，插件升至 `1.5.0`。

### 搜索与复制

13. 搜索类型增加“术语”。选择术语时只加载术语索引，不查询文章/说说/页面；在“全部内容”中继续保留术语分组。无结果和索引失败有明确状态，不显示空白页面。
14. 代码复制先使用 Clipboard API，失败后降级为临时 textarea + selection + `execCommand("copy")`，两种路径都失败才提示手动复制。降级后清理节点并恢复焦点和原选区。

## 安全与限制

- JavaScript 触发是站点级同源可信代码能力，不等同于沙箱页面脚本；只允许管理员保存，并需在启用前人工确认来源。本轮不提供脚本市场、自动安装或远程代码加载。
- 钩子只处理当前公开主题同源 DOM，不进入后台、iframe、Shadow DOM 或跨域页面；页面自定义 iframe 内部元素只能由页面自身脚本处理。
- CSS 选择器不执行代码，但宽泛选择器仍应避免；运行时和后台均限制单页挂载数量。

## 验证

- 1440/390 实页检查：多语言菜单只显示已有覆盖，中文/英文旗帜与文本垂直居中；语言名称字段在浅色/深色下均为 40px 表单高度，旗帜、输入框和删除按钮同行居中，键盘焦点环与占位颜色正常；添加语言后即时出现新行。
- 术语专搜中英文均只显示术语结果，不加载内容卡；无匹配时显示明确空状态。术语详情分隔线后正文间距增加约 20px。
- 拦截公开钩子响应验证 `#id`/class 目标可获得同款 Tooltip；路由分别发送 article 和 code surface、内容 ID 与站点语言。脚本模式同时覆盖 `glossary.mount(glossary.select(".site-brand")[0])` 与原生 `document.querySelector()` 节点传参。
- 术语编辑页在 1440/390 实际打开“页面触发”空态、新建表单和 JavaScript 危险编辑器，无脚本错误；脚本模式显示警告且仅管理员可选择。
- 前端完整检查 357 项、读者端/管理端隔离生产验收通过；代码复制定向 4 项通过。后端设置/术语/展示定向 23 passed、1 skipped（专用 PostgreSQL 库未配置）；`alembic check` 无模型差异。
