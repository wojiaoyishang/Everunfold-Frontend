# ADR 0078：默认父主题、子主题继承与前台钩子

日期：2026-11-07。状态：接受，实施与验收分别记录。

用户要求现有主题作为默认父主题，新主题可局部覆盖前台页面、单页、组件和样式。ADR0077仅完成控件发现，尚未支持全站展示继承；本决定补全该边界。

采用显式父链、具名组件、可组合模板与追加式插入钩子，沿固定本地目录自动发现。Argon保持缺省；子主题省略的部分自动继承，ParentThemeComponent可组合父实现；ID选择优先于通用模板。选择由服务端实例配置管理，不新增后端主题业务字段。前台授权预览复用相同组件/模板/样式上下文，后台不跟随公开主题。

完整约定见[主题规范](../architecture/frontend-themes.md)。不复制整套Argon源码，不用任意文件路径或数据库脚本装配，不改业务契约、私有数据和公开缓存职责。主题是部署方可信代码，不宣称是恶意代码沙箱。后续主题管理UI若需要全节点一致启用，应另外发布后端契约；本轮不把本地实例选择冒充全站后台设置。
