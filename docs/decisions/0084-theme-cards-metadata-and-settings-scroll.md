# ADR 0084：主题卡片、展示元数据与设置分区滚动

日期：2026-11-09。状态：已实现；[验收](../handoff/theme-cards-and-navigation-verification.md)。

用户要求右侧设置导航自然滚动到目标分区，主题切换使用卡片，主题作者可配置特色图片及开发者信息。

设置目录继续由实际挂载的分区生成。普通点击与键盘激活使用原生平滑滚动，沿既有scroll-padding/scroll-margin避开管理顶栏，更新URL片段并聚焦分区；修饰键保留原链接语义。减少动态偏好使用即时定位，初次深链恢复仍即时处理。滚动高亮与页末短分区规则保持。

ThemeDefinition提供可选title、description、preview、author{name,url}、homepage、repository、license；类型取后端settings 1.14的InstalledTheme字段。Node自动发现主题，统一校验并只导出展示字段，组件/模板/钩子不进部署清单；继承和执行能力仍由原主题注册器管理。元数据不从父主题隐式继承，避免错误归属作者；未声明字段保持可用。

后端扩展已安装主题DTO，沿原鉴权节点登记及目录查询保存/返回。URL复用原安全路径/HTTP(S)规则，拒绝执行协议、凭据、协议相对地址及控制字符；不由后端抓取图片或源码。选择主题仍要求所有启用节点的登记描述一致。PostgreSQL只保存选择的稳定ID，元数据不另建后台编辑数据库；无迁移。

主题卡片显示特色图、简介、开发者、版本、父主题、声明的许可证和相关链接。图片可用既有静态资源空间或HTTP(S)地址；内置示意图位于public/reference/themes，防止被内容路由守卫当成文章。缺图/加载失败使用占位，链接独立于选择按钮。选择只修改设置工作稿，保存并应用后生效；保留“实例默认”，不把空值擅自改为固定主题ID。

开发重启时实际出现Turbopack持续entry restart，关闭本机Next版本支持的dev文件系统缓存选项后恢复稳定。保留进程内热更新及生产构建缓存，不删除.next内部文件或改变公开缓存一致性规则。现象与缓存复用相关属于当前实例诊断，未声称所有环境均会复现；过程见验收。
