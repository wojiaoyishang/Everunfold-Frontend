# ADR 0082：荣誉墙作为独立前端注册页面

日期：2026-11-07。状态：已实现；[验收](../handoff/honors-page-verification.md)。

用户要求把浏览器中的`/myhonor`复刻为前端注册页面。沿现有独立插件模型新增`core.honors`，所有声明、表单、图片控件、过滤/日期模型、展示与界面文案留在src/plugins/honors，经setup贡献页面和组件；不增加中央装配项、业务API或数据库迁移。

保留原页按类记录时间、荣誉/任职说明与证书的形式，提供网格/时间线、分类/年份/关键词筛选及证书弹窗。后台模型复用主题控件和SDK媒体选择器。显示模型容忍旧值和额外字段，拒绝可执行URL；配置继续由已有页面JSON与应用快照保存，弹层沿用原焦点、退出动画和减少动态规则。

2026-11-09按用户要求，证书弹窗采用固定标题、可滚动图片/说明、固定底部操作栏。只中间内容滚动，操作栏始终位于弹窗底边，保留方向键、边界禁用、查看原图和关闭回焦。实现局限于本插件布局，无注册身份/版本、数据或后端接口变化。

原站容器直连受到验证页阻挡，网页文本缓存不包含较新的记录，因此使用用户提供的本地备份中该页的公开内容及原图做只读核对和定向导入。24条记录、22张不同原图仅写入本实例页面/媒体数据；来源指纹存私有metadata，不写入插件种子数据，不执行旧PHP、兼容短代码或整库导入。原网站、原备份和其他已有页面不改。
