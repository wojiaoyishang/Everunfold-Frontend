# ADR 0171  术语插件清单同步与标题开锁图标

状态为已实现。版本为 ADR0171-1。补充 [ADR 0170](0170-fixed-inspector-and-unlocked-glossary.md)。

在内网迁移站点的实际加密文章验证：`POST /v1/reader/access` 返回 200、正文和阅读凭证，两项术语显示设置均开启。携带该凭证的术语请求及公开术语索引均返回 HTTP 503、业务码 50389「插件部署尚未同步」；跨源预检与数据库迁移检查通过。插件路由在匹配正文前比较进程加载的插件构建指纹与数据库中登记的指纹。旧统一部署向导对已有库只做检查和配对，未随新产物重新登记插件，所以无法靠前端 DOM 装饰恢复。之前的异步正文注入修复保留。

统一部署的「构建并启动」「初始化数据库并构建启动」及显式 `start` / `run` 在数据库检查和配对成功后，用即将启动的后端代码执行已有的插件登记命令。已有目录锁防止另一份运行产物被抢先替换清单。登记幂等并沿用后端的锁、审计与可靠投递；保留词条、启停选择、数据库结构及受限阅读边界。容器和 systemd 的普通重启仍只运行已有产物，单独检查保持只读。现有容器可就地补同步，操作见[术语表指南](../development/glossary.md#发布与排错)。

标题用主题的闭锁与开锁图标表示两种状态。开锁保留完整锁身与一侧连接的锁梁，另一侧有清晰开口；解锁后同位置淡切，不旋转笔画。减少动态模式直接切换，读屏仍能感知状态。

验证：隔离的真实部署复现同一个 50389，正常启动准备同步后索引恢复 200；运行中的实例拒绝为另一启动流程同步。独立的 API 复现确认同一个阅读凭证在手动同步前后由 50389 恢复为 200，GET 仍不返回受限匹配，无凭证 POST 仍拒绝。内置浏览器解锁后检查到 12 处术语和弹窗、闭锁/开锁截面、390px 宽度及减少动态。前端 435 项检查和生产构建通过。统一部署常规 45 项通过，启用真实服务的集成用例另行通过。内网现场仅诊断，未应用上线操作。
