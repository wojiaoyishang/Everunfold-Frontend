# ADR 0140：后台标识与节点部署配置

日期 2026-11-13。补充 [后台工作台](0021-admin-theme-and-workspace.md)与[节点状态](0131-node-cache-management-and-backend-events.md)。

后台侧栏、手机导航和登录入口使用「站点设置 → 基本资料」的站点名称和站点图标。首次加载读取当前节点已应用的设置，成功保存后立即更新当前工作台。无站点名称时显示 Everunfold。图标为空或加载失败时，后台显示书本图标，登录入口显示叶子图标。注册和找回密码共用登录入口的标识。

「部署配置」位于「节点状态」并参与该页的快速导航。卡片只读，显示当前前端实例的节点标识、公开站点地址、浏览器后端地址、设置副本与快照来源等信息。节点缓存下拉菜单选择其他节点时，部署配置仍指向当前实例。系统设置集中维护验证码规则，沿用独立保存接口。

设置副本目录根据运行配置和节点来源生成。公开快照目录采用当前连接实际使用的快照根目录，独立连接模式下包含 `sources/<source_epoch>`。界面显示项目内的相对目录，来源 UUID 用 `<source_epoch>` 表示。项目外的挂载只显示目录类型，未绑定后端来源时在设置副本一行注明。

两处变更沿用现有设置字段、权限和部署配置。
