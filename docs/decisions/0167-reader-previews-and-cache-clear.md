# ADR 0167  受限文章预览、更多组件与清空节点缓存

状态为已实现。版本为 ADR0167-1。

## 旧封面副本

受限文章的封面属于公开预览。上一版修复了新投影，已落盘的旧版本可能还没有封面。Worker 在既有投递任务中核对当前版本，后端「重新同步」也做同一检查。仅当现有投影漏掉了仍有封面的已发布受限文章时，按现有投影和可靠投递流程生成新版本。旧版本内容保持不可变，无封面文章不触发反复修复。修复保留正文、正文媒体和摘要访问限制。

## 阅读页和更多组件

限时内容倒计时依据浏览器当前时间和 `opens_at`，页面重新可见时校准。到点沿原有阅读入口向服务端确认。解锁后的推荐区采用普通文章的卡片间隔。注册页面载入时显示居中的不定进度条，组件就绪时交叉淡出淡入，遵循减少动态偏好。

前端附带 `core.more-components` 插件，提供折叠区、提示框、人物分组、姓名与寄语、视频播放器，沿用页面构建器及媒体库。旧站实际内容由页面编辑器保存。

## 清空节点缓存

「设置 → 节点状态与维护 → 节点缓存」提供「清空缓存」。确认框显示选中的节点，并说明当前副本消失后读者页面可能暂时不可用。管理员确认后由后端验证设置写权限、来源和 CSRF，经节点接收器的专用内部路径执行并记录审计。

操作删除选中节点及当前站点来源的公开内容、站点设置和节点策略的全部当前与历史副本，版本下限和当前内容校验记录保留。接收器串行处理写入与清空，丢弃低于已记录版本的迟到投递。清空后执行「重新同步全部」恢复。配置、媒体和构建产物属于各自的存储范围。

Settings 契约升级至 1.47.0。更新 API、Worker 和前端构建产物。无需新增数据库迁移。
