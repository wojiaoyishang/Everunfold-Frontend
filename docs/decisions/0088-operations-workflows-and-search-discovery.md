# 0088：运营工作流、内容管理与搜索发现

日期：2026-11-09。状态：第一批已交付（评论审核、真实工作台、SEO/站点地图与订阅）；其余路线分批实施。

用户批准按运营完善路线实施，并明确补充站点地图和SEO设置。先完成评论审核/工作台，再推进内容批量管理、搜索发现与订阅，准备隔离迁移/恢复演练及通知/统计能力。保持HTTP容器测试、双仓库、原生短代码、源码插件及可靠发布边界。

- 评论统一持久状态与独立read/moderate权限，历史评论和新提交均可查询/审核/回复/回收。文章、说说、页面共享机制；审批通过才进入公开投影，状态变化与审计、幂等回执、完整快照Outbox同事务。批量操作核对每项期待版本，原文撤回或访问受限后公开评论同步遮蔽。客户端不以验证码通过代替审核。
- 工作台读取真实待办并按权限裁剪：待审评论、最近草稿、排期及失败、译文核对和节点投递状态。没有业务权限时不返回相应数量或标题。
- 内容管理使用现有协作/版本/发布服务；批量操作不绕过所有者、翻译组、合并锁及revision守卫。快速编辑不能直接覆盖Y.Doc或改写已发布快照。
- 搜索发现设置属于站点业务，主题不决定可索引性。站点地图、robots、RSS和结构化数据只消费已应用公开内容；预览、示例、后台、撤回、未列出和受保护正文不进入发现入口。地图使用真实更新时间、canonical和已存在译文，不伪造lastmod，不自动为改址生成别名。robots不是访问权限控制。
- 邮件等可选传输优先作为插件能力，密码/验证令牌及发布事务留在宿主。没有配置的发送渠道明确不可用；未获得收件人与测试授权不向真实邮箱发送。
- 迁移先只读盘点，转换旧调用为原生短代码并报告不能自动转换的内容，不恢复运行时兼容。恢复演练只使用隔离数据库/文件目录，原站、原备份和当前业务数据不覆盖。外部备份仍为运维职责，应用提供可检查的准备/校验工具。

新增功能逐项运行权限、真实数据库/多进程、公开快照一致性和桌面/窄屏视觉验收；阶段结果写入交接。邮件凭据、正式域名、用户内容与演练产物只放被忽略配置或var，不提交Git。
