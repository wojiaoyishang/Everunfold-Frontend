# ADR 0138 自定义页面模板

自定义代码模板由后台保存，拥有独立 UUID 和修订。模板只维护名称、说明与 HTML、CSS、JavaScript 源码及脚本设置。类型目录将其作为可选类型列出。模板没有公开路径。页面仍拥有自己的标题、URL、语言、评论、验证策略和草稿。已有独立源码页继续使用原类型。

模板代码由使用它的页面继承，另存一份草稿或创建译文时仍引用同一模板。已有公开页面使用最近一次已应用的页面设置。模板保存后，已公开子页在同一事务中更新代码，登记一份公开内容版本，并为受影响的路径记录缓存事件。停用、回收与仅保存草稿的页面维持原状态。授权沿用页面读写和发布权限，更新已发布页面的模板源码需要发布权限，启用的脚本由管理员维护。前台继续使用现有的自定义页面沙箱。

新页面可从标题生成站内 URL。后端在原路径锁下检查重名和保留地址，并给出具体校验错误。已保存的 URL 由各页面独立维护。后台操作结果使用导航栏下方居中的共享吐司。

部署先执行数据库迁移 `0058_page_templates`，再重启 API、Worker、Scheduler 及前端。管理契约升级到 pages-v1 1.13.0。公开快照继续使用原页面投影。
