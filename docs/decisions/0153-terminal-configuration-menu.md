# ADR 0153 · 配置总览菜单与终端编辑

状态：已采用。依据：用户要求内部调用来源默认开放本机回环并标注前端到后端方向；连接 URL 回显；手动配置终端属性以支持方向键；启动先显示全部配置项，再提供三个菜单入口。

## 交互

两端 Docker 向导先展示全部常规配置项和当前值，再提供 `1.按次序配置`、`2.修改某配置项`、`3.退出`。编辑后返回总览，退出时选择保存、放弃或返回。保存前统一检查必填项及跨项条件；未配置的自动字段须进入编辑并回车生成，不在保存时静默补齐。

通过 POSIX termios 显式设置非规范输入、回显和换行属性，程序读取方向键序列并绘制可编辑的预填值，结束或中断时恢复原值。左右键编辑光标，上下键调取本项在当前会话中的历史，Ctrl+U 清空；支持 UTF-8、窄终端水平滚动和括号粘贴。历史仅保存在进程内。输入均回显；连接 URL 在总览完整显示，独立密钥在总览遮盖、编辑时显示。

后端新配置的前端内部调用来源默认为 `127.0.0.1, ::1`，令牌校验保持；清空可关闭，跨容器地址按实际连接来源添加。已有显式来源列表保持原值。

## 已有实例与保存

已有配置可读取后按编号编辑，原密钥保留，默认进入已有站点模式。新站点自动生成字段仍允许手输；清空后回车生成新值。切换到迁移模式会清除本次会话新生成的值，要求填写已有值。

使用标准库 tomllib 读取配置，因此向导最低 Python 版本为 3.11。保存保留未编辑的字段和其他环境变量；TOML 统一排版，原注释随原文件备份保留。新文件和备份权限为 0600，各文件通过临时文件替换；检测到会话期间外部修改时拒绝覆盖，写入异常回滚本次已替换文件。自定义宿主数据和环境文件路径沿 Compose 配置读取；前端独立连接文件只更新 active 项。

两仓库各保留相同的 config_ui.py、config_files.py 与标准库终端测试，保持独立运行，不引入第三个依赖仓库。真实伪终端覆盖菜单、光标编辑、历史、回显、保存/放弃、中断恢复及已有字段保留，文件测试覆盖写入异常和并发修改保护。
