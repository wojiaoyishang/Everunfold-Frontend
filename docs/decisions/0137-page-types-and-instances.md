# ADR 0137 · 页面类型与页面实例

2026-11-13。后台「页面类型」列出内置自定义代码类型和前端插件登记的类型，以及各类型已有的页面数量。页面列表按类型筛选。新建时先选类型，再使用该类型的编辑表单和默认值创建页面。

每个实例拥有自己的标题、路径、语言行为、配置和发布状态。书籍类型的实例分别选择封面和文章分类。类型的路径建议只填入尚无实例时的新建表单。保存后页面类型固定，回收和恢复按实例执行。插件尚未就绪时，现有实例仍在页面列表中显示。

后端迁移保留现有 UUID、配置、发布快照和评论。前台继续通过已应用的实现 ID 和版本选择组件。目录和编辑器使用后端 pages-v1 1.12.0，部署清单使用 settings-v1 1.41.0。
