# ADR 0056：原生短代码方向与统一样式库

日期：2026-11-05（Asia/Shanghai）。状态：**需求方向已确认；界面、语法和实施方案待评审，未实施运行切换**。

## 用户已明确

- 去掉旧短代码兼容，转向完全自主定义的新体系，不保留旧语法别名或参数映射。
- 后台需要专门的短代码导航，展示全部可用短代码的样式。
- 允许创建用户自己的纯HTML/CSS样式短代码。
- 部分前端、后端代码注册的短代码只展示，不提供实现编辑。

这取代ADR0004及既有前台说明中把旧展示兼容作为后续目标的部分；原始基线附件保持不变。可信代码装配、数据库不执行任意JavaScript、后端授权、整篇源文保存与公开SSR隔离等边界继续有效。

## 建议方案

在工作空间新增「短代码库」，统一画廊与只读详情；自定义定义使用独立HTML/CSS编辑页、正文插槽与受控参数，保存草稿与应用分开。来源和编辑能力分责，代码注册默认只读，显式开放的配置也不等于实现可编辑。模板应用有版本、影响范围、回退和可靠投递，正文只保存调用源文。

建议新命名空间区分内置、模块与自定义；名字、路由、参数/插槽语法和契约都尚未冻结。安全编译、作用域CSS、预览/SSR一致与资源按需是实现要求，不把任意HTML/CSS直接注入后台或公共根布局。

详细提案与草图验收见[原生短代码设计](../architecture/shortcodes.md)。本轮没有移除运行中的旧解析器、修改文章或新增实际后台路由；移除旧兼容列入新体系正式切换步骤，不把此设计文档当作已经交付。
