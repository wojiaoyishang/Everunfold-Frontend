# ADR 0139：主题推荐插件与插件特色图

版本 ADR0139-1。日期 2026-11-13。补充 [ADR 0083](0083-plugin-activation-usage-confirmation.md) 与 [ADR 0110](0110-theme-and-plugin-preview-artwork.md)。

主题声明的 `recommended_plugins` 随部署清单登记，settings-v1 1.42.0 支持该可选字段。值为最多 100 个互异的插件 ID，登记时排序。省略或设为 `null` 时读取最近的父主题声明，空列表明确关闭推荐。Argon 推荐 9 个功能插件。Paper 继承该清单，示例插件仍可手动启用。

后台「插件管理」按当前前台主题标记推荐条目。「启用所有推荐插件」在「刷新部署清单」旁批量更新开关，包含必需依赖。搜索只影响列表。如果推荐或依赖插件未完成部署，批量按钮暂不可用。用「保存更改」应用整批选择，沿用部署一致性检查、插件使用确认与可靠节点同步。切换主题本身不会改动插件启停。

插件的 `preview` 可以使用已有 URL，也可以声明 `asset:assets/preview.webp` 等包内图片，支持 WebP、PNG、JPEG 和 GIF，单张上限 4 MiB。前端打包后由 `/__plugins/assets/` 提供。后端仅按目录清单公开已声明图片，由 `/v1/extensions/artwork/` 提供，浏览器使用配置的后端地址读取。两种路径都按文件内容生成哈希。停用插件也可查看特色图。列表使用缩略图，详情显示完整画面。

新增字段无需数据库迁移。先更新后端与登记后端插件目录，再构建前端与插件包并上报节点清单。
