# ADR 0038：源码编辑器交互与场景快捷键

日期：2026-11-02。来源：用户要求修复行号错位、完善编辑器样式/功能；追加要求移除短内容下的空白并接管 Ctrl+S。状态：已实现；实际检查见 [验收](../handoff/source-editor-verification.md)。在 ADR 0037 的单篇 Y.Doc、权限与保存边界内实施。

## 排版与控件

CodeMirror 负责行高、折行和行号测量。正文、行号共用 14px/1.75 字体指标；不为 .cm-gutters 添加顶部 padding，不覆盖引擎计算的行高。视觉留白放在正文容器，活动行/行号和配色从后台变量派生。

本段高度/留白规则已被用户随后要求的 [ADR0040](0040-source-editor-spacing-and-minimum-height.md) 替代，下面保留当时决定。

编辑区按内容自然增长，去掉桌面/手机的固定最小高度；达到 540px 后内部滚动。空块保留一行的自然输入高度。不得通过插入空行或固定空白区域撑版。

SourceBlockEditor 只组合工具栏、查找面板、封装 CodeEditor 和位置状态。SourceToolbar、SourceSearchPanel 独立复用；Markdown/HTML 插件各自提供语言、常用动作、插入模板和快捷键。格式变换放 core/editor/source-commands.ts，使用 CodeMirror transaction 的局部修改和选区映射，不整块覆写共享文本。每个工具操作单独形成撤销边界。

## 已实现工具

- 标题 1–6/正文、加粗、斜体、删除线和行内代码；Markdown 的多行有序/无序/任务列表及引用，HTML 的列表/引用模板。
- 链接、代码块、表格、分隔线模板，以及缩进/反缩进。HTML 代码块内的选区会转义；标题变换保留已有 HTML 属性。Markdown 使用 GFM 语言支持，与现有安全预览的常用标记一致。
- 行/列/选中字符状态，自动换行开关、查找/替换/全部替换、大小写区分、前后匹配和可见区高亮。匹配计数最多显示 1000+；高亮只计算可见区并设上界。
- HTML 标签/属性补全、标签自动闭合、括号配对和自动缩进。查找控件由主题封装，不额外打开 CodeMirror 原生搜索面板。进退场及减少动态使用后台偏好。

源码工具是常用编辑辅助，不承诺任意嵌套 Markdown/HTML 的语法树级转换；链接、表格等仍是可手工调整的源码模板。不是所见即所得编辑器，不引入正文脚本执行或有损格式互转。

## 快捷键与保存

源码区 Ctrl/Cmd+B、I 执行对应插件的格式命令，Ctrl/Cmd+F 打开当前块的查找。查找框 Enter/Shift+Enter 前后定位，替换框 Enter 替换；普通按钮保留自身键盘激活语义。Escape 关闭面板并回正文。全篇协同撤销仍复用原 Y.UndoManager。

页面通过共享 useSceneShortcuts 注册 Ctrl/Cmd+S，含 Shift+S 的另存为组合；页面卸载即注销。只接管明确注册的组合，不劫持打印、刷新等其他浏览器快捷键。保存草稿复用原按钮的业务用例、权限、持久截点和幂等请求，不新增保存端点，不绑定快捷发布。

保存中、只读/冲突、离开中、无修改或正在输入法组合时不重复写入；仍拦截已识别保存键，避免弹出浏览器“保存网页”。模态弹窗打开时暂停页面动作。存在未确认的旧操作时，快捷键不隐式重放，用户使用明确的“重试上次操作”处理，避免把曾经的发布误当作保存重试。

快捷保存结束后，待控件恢复可编辑再恢复原焦点；目标已卸载或用户已移动焦点时不抢焦点。新输入出现后显示未保存状态，不沿用上一轮保存提示。

## 数据与依赖

原稳定块 ID、整篇 Y.Doc、相对媒体插入、本人撤销、PostgreSQL 提交后 ACK 与原保存/发布接口不变。查找、换行、光标等界面状态不进入正文、公开缓存或数据库 Schema。

新增直接依赖 @codemirror/search 6.7.2，并显式声明原传递依赖 @codemirror/autocomplete 6.20.4。已核对安装包/官方 npm 元数据的 CodeMirror 6 兼容范围，并在当前锁定的 state/view/language 与 Yjs 绑定中实测。package.json 与 package-lock.json 一起提交，无其他锁定流程。
