# ADR 0187 前端节点的独立监控

每个已配置的前端节点可通过自己的 `/metrics` 提供 Node.js 运行指标，采集请求在本机完成。该入口用独立令牌和直连来源网段验证请求。后端聚合依然通过原内部路径和节点指标令牌采集，同一前端的两条路径读取同一个 worker 指标集合。

三个部署向导的监控白名单按用途保存。Docker 网络名在编辑时换算为当前 CIDR，生成内容可直接用于应用和 Loki 反代。日志由 Alloy 读取本机容器输出或 systemd journal，经独立的来源和请求授权规则进入 Loki。多个节点可用稳定标签区分，共用容器中的前后端可按组件分流。

首次启用时重新编译前端，服务启动后读取监控配置。无需新增端口或数据库迁移。
