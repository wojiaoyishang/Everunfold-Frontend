# ADR 0178 工作台卡片、统计与共享加载状态

状态：已实现。版本：ADR0178-1，2026-11-17。

用户要求工作台可自由布置卡片，程序和插件均可注册，同时统一设置页的读取动画、文章信息排序控件，并改善首页滚轮。用户追加要求增加卡片内边距，编辑模式也保留清楚的卡片轮廓。本轮明确授权提交并推送，覆盖旧交接文件中的历史“不推送”约定。

## 工作台与权限

原计数、快捷入口、最近编辑和排期均为卡片。新增访问趋势、累计浏览排行、7/30/90 天热门文章、安全审计和配置变更。自定义布局采用“进入编辑 → 拖动/箭头排序、调整宽度、添加/移除 → 完成布局”流程，取消不保存；离开未保存页面沿用全局提示。宽度为六列网格中的 1/2/3/6，窄屏折叠；编辑模式的小卡片保留足够操作空间。卡片正文和编辑底栏分区，统一圆角、边框、阴影及约 24px 的留白。

布局存于 PostgreSQL，归属当前登录账号，服务端不接受任意用户 ID。`POST /v1/admin/workspace/layout` 要求会话与 CSRF，提交 revision 乐观并发检查；冲突返回 409。null 表示默认布局，空数组表示主动清空，最多 48 张卡片。暂不可用插件的已有位置保留，启用后可恢复。插件卡片的 UI 权限只是入口过滤，各数据接口继续独立鉴权。

`POST /v1/admin/workspace/analytics` 使用现有工作台鉴权，固定统计范围避免无界查询；内容 own 权限只查自己的内容。安全审计需要 users:manage，配置变更需要 settings:read，只输出操作名、操作者、时间和数量，不传审计详情、IP 或令牌。公开 SSR 和共享公开缓存不保存统计结果或布局。

## 浏览统计与迁移

迁移 `0067_workspace_cards` 新建账号布局、文章日计数和统计起点。既有浏览量保留；时间分布从部署此迁移后开始，不捏造旧数据。接受一次文章浏览时，在同一事务原子累加总数与 UTC 日计数，沿用原有来源与频率检查；密码文章允许统计，已撤回内容不接受浏览、不进入排行榜。日计数仅有文章 ID、日期和计数，不记录访客身份。

## 共享界面与插件

设置页、内容目录、通知策略等初次加载复用 `AdminLoadingState`，程序与插件 SDK 共用动画、读屏状态和减少动态支持，不逐页写纯文字占位。信息顺序复用 `ReorderList` 和 `ReorderButtons`，支持拖动及带名称的上下箭头。

程序卡片集中声明；插件在同步 setup 中用 workspaceCards.register 注册并声明具名组件，运行时仅在后台装配。命名必须归属该插件，冲突/未声明组件被拒绝。卡片的挂起和失败局限于本卡片。开发说明见 [工作台扩展指南](../development/workspace-cards.md)。

## 首页滚轮

参考原 WordPress Argon 的短尾渐进和连续滚轮加速方式。触控板连续像素输入及触摸使用原生滚动；离散鼠标滚轮才应用短尾插值和有上限的连续加速。方向反转立即清除旧方向积累，尊重内部滚动区与减少动态偏好。后台不使用此增强。

## 部署

先更新后端并执行迁移，再更新 API/Worker，最后重建前端主程序及独立插件包。旧插件包不包含新的 SDK 控件和工作台贡献。仅更新源码、继续挂载旧产物不会生效。
