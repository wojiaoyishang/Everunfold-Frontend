# ADR0100：主题私有设置与 `theme_options`

状态：已实现并验证。日期：2026-11-10。来源：用户要求主题设置除主题切换外归主题自身文件夹，不同主题保存不同设置。

## 背景

此前 Argon 的外观、横幅、字体、代码、首页和文章显示表单放在统一后台设置目录，导致主题表现被误认为站点全局字段。直接扩展到 Paper 时会共享同一组设置，切换主题可能覆盖旧主题选择。主题切换本身仍需要公共入口，但主题表现和阅读默认值应随主题拥有。

## 决定

1. `/admin/settings/theme` 只作为公共宿主：提供“已安装主题”切换和当前主题的设置面板，不实现具体主题字段。
2. 每个主题在自身目录提供 `theme-settings.tsx`，当前 Argon 与 Paper 分别位于 `src/themes/argon/` 和 `src/themes/paper/`。宿主按活动主题动态加载对应面板；新增主题不修改中央表单。
3. `PublicSettings.theme_options` 按稳定主题 ID 保存完整主题配置。顶层 `theme` 继续作为当前活动主题的只读兼容投影，供既有公开组件和旧客户端使用；保存时以 `theme_options` 和活动主题投影为准。
4. 主题切换只改变 `extensions.theme`。切换后宿主读取该主题自己的 profile；没有 profile 时以当前旧配置作为首次默认值，首次编辑后保存为独立 profile，之后互不覆盖。
5. 站点资料、导航、页脚、SEO、语言目录、术语提示、验证码、邮件和运行配置不属于主题；继续保存在公共站点或各自业务设置中。
6. 主题 profile 的媒体引用仍由后端统一校验和解析。图片、视频、代码字体和页面字体不能伪造为另一类媒体；停用或缺失主题的配置不删除。

## 理由

- 主题目录成为主题字段、默认值、表单和样式的单一归属，减少跨主题耦合。
- 每个主题都有完整配置快照，切换主题不破坏旧主题下的读者默认值。
- 顶层投影保留现有公开组件兼容窗口，避免一次性破坏所有主题消费者。

## 影响与限制

- `settings` 契约升级为 1.25.0，新增 `site.footer`、`site.author_tagline`、`site.glossary`、`theme.article`、`theme.feed`、`theme_options`、`theme.paper_tone` 等字段。旧设置 JSON 在读取时补默认值，不执行文章数据迁移。
- 主题面板是可信前端代码，不支持后台填写任意 HTML、脚本或动态组件名。
- 新增主题若没有实现面板，文案会明确提示不可用，不能假装当前字段属于该主题。
- 主题继承只继承组件和样式，不自动把父主题的隐藏表单搬到子主题；子主题应显式提供自己的 `theme-settings.tsx`。

## 验证

- 后端真实设置测试覆盖旧值迁移、活动主题投影、多个 profile 独立保存、媒体引用校验和设置契约。
- 前端测试覆盖主题 profile 解析、默认值、独立更新和主题激活不发布其他未保存字段。
- 后台主题宿主会动态加载当前主题面板；Argon 显示外观/横幅/字体/首页/文章/代码/背景，Paper 只显示自己的纸张底色。
