# ADR 0169  文章卡片摘要和编辑侧栏

状态为已实现。版本为 ADR0169-1。

文章摘要旁提供默认关闭的「启用空摘要」。开启只隐藏公开文章卡片上的摘要，原稿和发布数据保留；关闭后恢复正常显示。区块与组件模式共用同一设置。旧草稿和旧副本缺少该字段时按关闭处理。

在密码保护及定时开放前，卡片标题左边显示锁。未启用空摘要时，只有作者明确开启「在加密情况下仍然显示摘要」且填写了摘要，卡片才显示该内容；否则使用固定提示「这是一篇加密的文章，需要输入密码才能阅读。」。提示由主题渲染，不写入原稿或公开摘要字段。自动生成的摘要不在锁定时进入公开 API 或快照。原来填入提示语的按钮移除。

实时编辑器左栏等待时使用共用进度动画并保留读屏状态。后台进度遵循后台动效偏好。双栏区块编辑器的右栏有自己的滚动区域，区块和内容设置标签保持可达，滚到边界也不推动左侧正文；窄屏继续使用分区切换与页面滚动。

设置沿用现有 JSON 存储和渐进兼容的公开字段，无需迁移数据库。先更新前端构建产物以识别新字段，再发布开启空摘要的文章；API 和 Worker 一起更新。
