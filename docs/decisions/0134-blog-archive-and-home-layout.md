# ADR 0134 · 博客旧入口和首页布局

原固定日记目录已由[前端注册书籍页](0135-registered-book-page.md)替换。

`/article` 默认提供按站点时区分年、月的文章归档，`/archives` 保留，显式指定的文章页仍由阅读设置控制。`/gzrj` 从公开快照的 `gzrj` 分类生成日记目录，无内容时显示空状态。`/about` 优先使用已发布的同路径内容，默认读取站点名称、描述和作者。目录中的条目沿用发布地址。网站地图纳入有可索引内容的归档，RSS 和 Atom 沿用原有内容规则。

主题设置中的首页样卡在编辑时同步使用单列、双列或瀑布流样式。密度和布局共用首页 CSS，窄内容列自动回到单列。分类与标签按 ID 从首页过滤，分页根据过滤后的结果计算。

登录发表的评论带会话标记提交。回复通过审核后，普通读者可在账号中心的通知铃铛中打开具体回复，在「通知偏好」中开启邮件。模板和通知策略使用现有入口。

WordPress 内容导入只用于隔离验收，开发环境按当前站点数据渲染。
