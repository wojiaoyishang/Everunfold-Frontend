# ADR0105：后台信息架构、主题导航与术语特色图片

版本：ADR0105-1。状态：已实现并验证。日期：2026-11-10。补充 [ADR0100](0100-theme-owned-settings-profiles.md)、[ADR0104](0104-localized-navigation-and-glossary-hooks.md)。

## 背景

后台原先以“工作空间 / 内容 / 管理”三组承载 20 个入口，媒体、工具、用户、评论和系统配置混在一起；站点设置同时保存站点资料、语言、导航和术语策略。导航存储在 `site.navigation`，名义上紧随主题展示，但切换主题时仍共用同一份菜单。

另外，语言允许自定义多字符标志。原实现按内容宽度直接绘制，长标志会撑开菜单行或挤压名称；术语缺少独立特色图片。

## 决定

### 后台导航

1. 现有入口重排为：概览、内容、内容工具、资源、外观、成员与互动、设置。分类与标签属于内容；“术语表”和“短代码库”进入内容工具；媒体、图标、字体进入资源。
2. 主题设置和导航菜单归入外观。设置组使用“站点 / 连接与安全 / 系统”三个折叠分支，分别承载站点设置，验证码/邮件/应用接入，以及插件/运行/系统状态。
3. 第一轮保留所有现有页面 URL，只重排可信注册表；新增 `/admin/settings/navigation` 作为当前主题导航编辑入口。
4. 当前主题导航写入 `theme_options[themeId].navigation`，`site.navigation` 仅作为旧数据兼容回退。当前主题没有显式导航时继续显示旧导航；保存后使用当前主题自己的菜单，空数组也是有效选择。
5. 后续“多语言翻译”倾向于由管理员维护自定义字符串，落地时作为独立多语言分组承载翻译工作台与界面字符串；邮件模板属于设置中的通知与通信。本轮不创建空页面或不可点击的占位入口。

### 自定义语言标志

6. 所有语言标志使用共享 `LanguageFlag` 固定槽。槽宽不随内容变化，普通标志不会推动语言名称、下拉框或菜单行。
7. 槽内内容实际溢出时才启用慢速往返滚动，并在悬停时播放；正常单旗不会滚动。字体加载或尺寸变化后重新测量，槽外保留可读标题，减少动态偏好下关闭滚动动画。
8. 语言设置、下拉框、添加语言、旗帜选择器、内容语言、页面语言和导航多语言名称统一使用该组件。

### 术语特色图片

9. 术语新增 `feature_media_id`，只接受媒体库中状态可用且 MIME 为图片的媒体，不保存任意远程图片地址。迁移 `0041_glossary_feature_image` 增加可空业务值的非空列，默认空字符串。
10. 管理和公开术语详情返回特色图片解析结果；公开索引按批量方式解析，不逐词条请求。目录卡片、词条详情和 Tooltip 展示特色图片，没有图片时保持原图标/紧凑布局。
11. 术语正文媒体和特色图片纳入媒体删除引用检查，仍被术语引用时阻止删除。

## 契约

- `settings-v1` 升至 `1.29.0`，主题 profile 增加可选 `navigation`。
- `glossary-v1` 升至 `3.5.0`，增加特色媒体 ID 与公开图片描述。
- 插件 `everunfold.glossary` 升至 `1.6.0`，数据库头迁移为 `0041_glossary_feature_image`。

## 验证

- 后台注册测试固定七个分组、内容工具/外观顺序和设置分支；现有权限过滤与路由识别不变。
- 多语言菜单实际检查中，长自定义标志保持 42×38px 控件，普通旗帜不产生滚动，溢出标志悬停后运行 2.8 秒往返动画；桌面和 390px 无横向溢出。
- 术语特色图片通过真实 API 上传、创建、更新、目录、详情与文章 Tooltip 验证；390px 详情单列显示且无横向溢出。
- 导航编辑页实际显示当前主题和旧导航回退提示；保存路径只修改当前主题 profile。
