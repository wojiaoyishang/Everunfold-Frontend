# ADR 0051：私有草稿的前台预览

状态：已实现，2026-11-04。来源：用户要求“为内容增加前台预览”。此前后台正文预览继续保留；以下保存及路由方式为本轮实现选择。

编辑页增加前台预览。已有未改草稿直接打开；新建或有修改时明确显示“保存并预览”，复用原整篇保存/协同提交，成功后才打开已保存内容。先在点击手势保留新标签页以避免异步弹出被拦截，保存失败关闭空页并保留编辑错误，不发布、不绕开冲突/上传/不确定操作保护。预览不展示未保存输入；用户可保存后刷新，页面标明真实修订。

地址为 /admin/content/{article|shuoshuo}/{UUID}/preview，注册为已有类型的私有子路由，无新菜单或密码/令牌参数。沿用 AdminWorkspace 身份与请求边界；仅此注册预览路由改用 BlogShell，不显示后台侧栏。客户端通过生成的 readDraft 直接访问 FastAPI，仍由后端鉴权/CSRF/类型和回收状态检查，数据只留挂载页内存，不使用公开快照、IndexedDB 或本地回退。

SSR 仅携带公开站点主题资料，草稿在身份确认后读取；响应 private/no-store、noindex/nofollow。页面元数据无草稿标题/摘要，不加入站点地图，不写公开渲染缓存。站点公开配置缺失时提示样式尚未就绪；草稿读取失败不回退旧发布正文。返回编辑使用封装 RouteLink，普通公开导航保留原方式。

ArticleCard/ShuoshuoCardView 是正式阅读与预览共用的展示组件，复用正文清理、媒体查看、目录、代码/公式及按引用字体。预览不挂载浏览量、编辑动作查询、点赞/评论/分享写入及推荐/相邻文章。密码/定时草稿可由有编辑权限的用户直接查看正文，但不传出密码、不改变公开访问策略。

后端业务代码、契约及数据库无需变化。前端从生成的 DraftDetail 投影展示字段，不维护第二套业务 DTO。预览的字数估算遵守当前发布算法；未发布的新分类/标签使用展示占位，正式链接/统计仍由发布生成。当前只支持已实现的文章/说说，代码注册页面保留原管理边界。

浏览器真实新建/修改/刷新、媒体/公式/代码、手机、404 重试、匿名 HTTP 与隔离生产检查见[验收](../handoff/content-frontend-preview-verification.md)。跨进程数据库/协同故障本轮未重跑，因为持久管线未修改；不把前端检查替代已有 P0。
