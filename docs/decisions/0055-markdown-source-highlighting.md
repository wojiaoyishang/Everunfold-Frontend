# ADR 0055：Markdown 源码高亮与代码围栏语法

日期：2026-11-04。状态：已实施。来源：用户要求后台Markdown源码模式本身有语法高亮，解决标记接近单色的问题。沿用ADR0044的源码事实与即时视图切换、ADR0052的共享代码编辑框与按需语言加载。

## 决定

- 共享CodeEditor使用独立的 `source-highlight.ts` 配置：标题/链接使用后台强调色，粗体与关键字使用紫色，斜体/语言标签/转义使用棕金色，引用/列表使用青色，行内代码/字符串/数字使用绿色，语法符号使用灰蓝色，删除线/注释继续弱化。保留粗体、斜体、删除线和链接下划线，正文不整体染色。
- 新增四个后台语法语义变量，浅色、显式深色与跟随系统深色都有定义；不把语法颜色当成独立品牌色或页面临时样式。行内代码使用低浓度背景，不改字号、缩进、行号、源文或行高。
- Markdown源码编辑语言在原GFM语法上增加代码围栏的按需语言解析；可视化选区映射继续使用原解析器，公开渲染继续使用原Highlight.js流程。语言名之后的片段JSON参数保留，只用首个语言名选语法。
- 把原代码插入窗口的语法加载抽成共享 `code-language.ts`。围栏与窗口复用语言清单、别名与加载Promise；当前清单含纯文本共18项。未知语言不请求任意模块，失败保持普通文本，代码仅用于编辑和高亮，不执行。
- 高亮不另建正文状态、不写入生成的HTML，不更改整篇保存、撤销、协同持久ACK或发布。共享HTML/公式/代码窗口也消费同一配色；没有新依赖或契约变更。

## 验证

见[实际验收](../handoff/markdown-source-highlighting-verification.md)：源码标记与代码围栏、浅深色、窄屏、视图切换、选区、211项检查与隔离生产构建。此项没有新增动效；按键编辑和已有源码切换即时完成。
