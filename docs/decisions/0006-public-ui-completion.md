# ADR 0006：前台导航、文章展示、评论预览与阅读偏好

- 日期：2026-10-30；验证与交接跨至 2026-10-31（Asia/Shanghai）。
- 状态：已实现前台交互；评论写入仍是明确标注的本页演示。说说类型仅记录需求，尚未迁移或实现。
- 来源：用户要求补齐二级菜单、文章标题/头图、评论效果；随后要求整张首页卡片可点击、保存阅读偏好、背景开关放入设置，以及后续统一文章/说说的 type。
- 替代：ADR 0005 第 3 项“刷新恢复播放”的访问级暂停策略，改为保存明确的播放/暂停选择；其他整站动效、非模态设置、软导航和惯性策略继续有效。

## 参考与范围

只读查看线上 lovepikachu.top 及备份 `wp-content/themes/argon`（Argon 1.3.5）。参考位置包括 header.php 的 toolbarMenuWalker、template-parts/content-single.php、comments.php、functions.php 中评论渲染及说说注册、template-parts/content-shuoshuo*.php。参考信息用于 React 组件设计，不运行旧 PHP、不迁移 WordPress 账户、不写原备份或线上数据。本轮不做后台主题设置。

## 决定

1. 顶栏和侧栏共用 navigation.ts 的父子导航数据。父项链接与展开按钮分开；顶栏支持鼠标移入、按钮、方向键及 Escape，侧栏使用双向高度过渡。实验功能保留原独立应用链接，不伪造登录或后台入口。
2. ArticleHeader 负责有头图/无头图两种标题布局。头图有遮罩、分类、标题与阅读信息，窄屏降低高度；普通页面无图时仍为清晰文本标题。ArticleActions 独立处理留言定位与复制链接。
3. PostCard 用一个真实 AppLink 覆盖卡片，包含标题、图片、摘要和留白。分类、标签、评论链接位于覆盖层之上，继续去各自目的地；不嵌套链接，不用 div click 替代浏览器链接语义。复用现有软导航和 pending 进度。
   复验中文分类/标签时发现路由参数与快照 slug 的编码形态不一致导致 404。两类页面共用 resolveTaxonomy，优先精确匹配，再安全解码一次；筛选及分页都使用命中的权威 slug，补 Unicode 单测与真实 HTTP 检查。
4. 评论按功能放入 components/comments：Section 编排、Item 展示、Composer 表单、Editor 格式/预览/表情、Identity 访客字段、model 纯策略、examples 虚构样例。历史数据使用后端生成类型，经展示适配后保持纯文本；示例/本页行不加入公开 DTO、快照或数据库。
5. 遵守 v2.11 评论基线：全局时间升序、同时间按 ID 稳定排序，回复统一缩进一级，不按父评论重排。当前每页 6 条，引用可定位父评论所在页并聚焦；缺失父项显示文字。历史留言不出现编辑/删除操作。
6. 当前示例和输入交互均明确标注，不冒充真实发布。预览支持有限粗体/行内代码/引用，React 安全输出，任意 HTML 仍按文字展示。昵称/正文必填，网站只接受无凭据的 HTTP(S) 地址；邮箱仅作表单演示，不送给展示条目或存储。添加、回复、赞同仅在当前页面内存生效，刷新/离开页面清除，没有评论写请求。正式提交、审核、身份、限流与通知待后端契约落实。
7. 阅读设置沿用非模态 popover。字号/字体/圆角/阴影/滤镜继续保存到 everunfold.reading-settings，全站动效保存到 everunfold.motion.v1。背景开关移入设置，移除独立悬浮播放按钮。新键 everunfold.background-playback.v2 保存 auto/play/pause：未设置或重置为 auto，跟随本站动效（默认完整，因此默认播放）；明确 play/pause 优先并跨刷新/重新打开保留。隐藏标签暂停不改变偏好；播放受限或失败时在设置中重试。旧访问级暂停键不继承。
8. 说说不是文章分类，也不是正文块类型。未来顶层 content.type 需在后台编辑、导入、API、快照、筛选和前台渲染统一；当前 0.1.0 的 kind 保持兼容，不单改前端生成类型。已确认需求、建议枚举和迁移顺序单独写入 [内容类型衔接](../architecture/content-types.md)。
