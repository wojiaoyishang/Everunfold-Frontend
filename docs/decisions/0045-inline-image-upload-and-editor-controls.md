# ADR 0045 图片上传、展开工具栏和编辑区层次

日期 2026-11-04。状态为已实现。来源为用户本轮连续要求，包括图片快速对齐、图片入口上移、Ctrl+V 图片、多文件占位上传、插入工具直接展开、底部状态合并及中性配色。

## 组件分工

SourceToolbar 与 RichToolbar 直接展示格式、列表、引用、链接、代码、表格、分隔线、图片、媒体附件和上传按钮。链接地址和图片属性继续使用表单。图片选中后展示三个对齐图标并高亮当前值。HTML 使用 figure 对齐，Markdown 图片所在段落需要对齐时使用内嵌 HTML 表达。

EditorStatusBar 统一容纳行列、选区、字符数和可用的换行/查找操作。原独立底部媒体行已移除。工具栏使用表面色与文字色派生的中性浅灰，编辑区使用轻微内阴影，深色随后台变量适配。模式切换按用户明确要求省去动效，其他按钮、弹窗及上传反馈遵循后台动效偏好。

## 上传流程

所有入口复用 UploadQueue、mediaLibraryAdapter、后端媒体上传接口、稳定上传 ID、两文件并发、真实进度和不定进度降级。FilePicker 支持紧凑图标形式。粘贴仅拦截当前块编辑面内的二进制图片，其余粘贴沿用编辑器处理。

文件入队时在光标处写入本地临时 img 标记，src 使用 everunfold-upload:// 加队列 ID。可视化显示内置的动态图片占位，源码显示临时标签和同一上传队列进度。成功通过宿主基于最新块内容的变换替换对应标记，因此多文件完成顺序和上传期间输入均可保留。用户主动删除占位后，成功结果留在媒体库。

停止上传保留重试入口。清除已结束会移除失败或停止的占位，按块清理队列。文件在上传前后均不以传输百分比代替后端保存结果，媒体同哈希复用沿用原接口。

## 保存和恢复

存在上传占位时前端暂停整篇保存、发布和整篇预览，后端也拒绝正式正文中的保留上传标记。源码/可视化仍可切换。单文件失败保留明确反馈，其他文件继续处理。

上传文件内容仅保留在当前会话内存中。刷新后的遗留占位显示中断提示，提供移除入口后重新选择或粘贴。原始文件内容不写入 sessionStorage。新建与已有文章/说说共用上述管线。
