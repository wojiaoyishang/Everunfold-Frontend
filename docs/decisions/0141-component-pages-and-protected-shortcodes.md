# ADR 0141：组件页面和正文内受限区域

状态：已实现。沿用页面、模板、内容草稿和发布快照的身份及权限。

- 新建自定义页面和模板默认使用组件模式；旧记录仍使用源码模式。布局分为全宽、带侧栏、全宽无容器背景和空白。切换编辑方式不改写已经发布的内容。
- 画布只保存带稳定 ID 的组件树。容器承载子组件，组件参数可公开为实例表单字段；模板修订传播结构，子页已经应用的同 ID 参数继续生效。管理预览不写公开数据。
- 文章、说说使用同一组件文档。转换已有正文时可把区块作为初始组件，原区块仍单独保留。组件写入使用独立端点和修订检查；协同编辑仅在区块模式使用。
- 插件通过前端组件注册接口贡献可序列化的组件定义与受信任的渲染实现。HTML、Markdown 与短代码使用现有内容渲染器。代码注册页面用统一阅读语言接口，历史前缀地址兼容访问，但只声明实际页面的规范 URL。
- 短代码的脚本只由管理员配置，按实例在隔离框架运行。回复可见和密码区域由后端裁决；公开内容、搜索与订阅均只接收去除受限正文的投影。密码正文加密依赖部署现有的应用主密钥，详见[操作指南](../development/component-editor.md)。
