# ADR 0059：区块内插入、视频、文字颜色与切换定位

日期：2026-11-05（Asia/Shanghai）。状态：已实施，按本轮用户要求更新ADR0057的文章插入方式，并更新ADR0042/0044的HTML切换选区行为。

## 决定

- 短代码入口移出区块标题栏，放入Markdown/HTML源码及可视化工具栏。选择窗口仍使用已应用目录和同一预览；确认替换当前选区或插入光标处，稳定区块ID及区块数量保持。取消释放捕获的插入选区。
- 本地可视化用短代码调用原文原子和视频原子展示嵌入内容，防止原生分隔符被HTML转义。正文仍保存调用/视频源文，不把这些本地节点写入共享Y.Doc或扩展后端rich Schema。短代码参数和正文目前在源码中修改，样式预览继续使用原选择窗口/正文预览。
- Markdown视频采用`![](site://media/UUID){type=video}`，也接受有标题的图片形调用与尖括号包围的目标URL。`{type=video}`必须紧接右括号；转义、代码块、行内代码及普通图片不变。HTML使用video标签。工具栏视频入口复用媒体库、视频筛选和既有上传/媒体引用链路，不另建传输。
- HTML增加文字颜色：可视化选中文字或在光标处设置颜色，支持常用颜色、六位十六进制值及恢复默认；源码工具提供颜色包裹。仍由textStyle与安全样式白名单保存/显示，不添加任意CSS输入。
- HTML切换保留文本光标/选区，不再自动扩大到整段标签。切换完成后，在新编辑面和内部滚动位置稳定的两帧后，必要时即时滚动到选区，并避让实测顶栏、窄屏预览第二行及区块标题。仍遵循ADR0044的无切换动画要求。
- 区块标题栏在本区块范围内sticky，距顶栏/预览第二行8px。移除编辑页外层无实际高度限制的overflow:auto，区块用overflow:clip保留圆角，避免sticky相对错误滚动容器定位或遮住工具栏；原媒体/源码内部滚动保持。
- 摘要去掉多余分隔线，焦点采用完整边框和轻量环；冲突提示左右与正文区块对齐，内边距10px/12px，不再额外缩进。

## 验证与边界

见[本轮验收](../handoff/editor-inline-tools-verification.md)。没有新依赖、业务契约或数据库迁移；原生调用、媒体稳定引用、源文指纹与发布边界保持。未实现嵌入视频参数面板、短代码原子内的正文排版、跨视图统一撤销、通用布局搭建器。
