# ADR 0002：公开阅读第一版与本地数据链路

- 状态：采用，本阶段落地；完整 CMS 仍按后续里程碑交付。
- 日期：2026-10-30。
- 来源：用户要求前台与基本后端先完成、外观接近现站、结构可复用、分阶段本地提交且由用户推送。

## 本阶段交付

公开首页、文章/普通页面、分类/标签、归档、搜索与历史评论只读展示；后端配置加载、PostgreSQL 模型/显式迁移、Redis 就绪检测、只读公开 API、WordPress 公开数据导入和公开快照导出。没有后台写 API，不在缺少认证和事务设计时提供匿名编辑入口。

当前代码与验证状态以 `docs/handoff/STATUS.md` 为准；该范围不是已通过验收的声明。

## 架构选择

1. 后端按一个内容业务模块拆模型、DTO、数据库访问、服务与路由；UUID 作为新实体 ID，WordPress 来源 ID 独立用于幂等导入。PostgreSQL 是权威源，正文 JSONB 有序块不变，搜索文档为派生数据。
2. 两个本地专用库隔离开发/测试；真实配置留在忽略文件。配置加载以项目根解析，严格验证显式字段与覆盖表；预留 Worker/Scheduler/内部通信字段不代表本阶段已经运行这些功能。
3. `contracts/public-v0.1.schema.json` 定义版本 0.1.0 的公开快照；后端输出数据，前端按确定提交和 SHA256 生成类型。公开业务 OpenAPI 由后端导出，客户端不另建独立字段真相。
4. 当前 Next.js 从显式导出的完整公开快照读取，快照无时间 TTL，普通页面请求不固定回源。导入/变更后的显式导出负责更新整份快照，原子替换。它是本地开发闭环，不是完整 ICP 缓存通知、撤回可靠投递或镜像协议；未接入写业务前不伪造这些能力。
5. 主题遵循本地 Argon 源码与公开设置：紫色 `#673bb7`、星空背景、透明横幅、两栏、8px 圆角、约 16.5px 基础字体。组件与数据服务分离，薄路由复用共同布局；保留深浅色与窄屏导航。
6. 只导入无密码的已发布文章/普通页面、它们的分类标签和已批准评论；不迁移账户、评论联系信息或 WooCommerce 系统页。未知短代码安全降级并报告；不执行旧 PHP 或正文脚本。HTML/Markdown 在可信渲染层按节点过滤和解析媒体。
7. 原公开内容、生成快照和文章媒体默认不进入 Git；仅提交转换工具、契约、代码、去敏统计及必要主题公开资产。旧站目录保持只读。

## 验证与边界

本阶段验证配置错误拒绝、真实 PostgreSQL 约束/公开过滤、Redis 连通、API 分页搜索与不存在/不可用区分、导入幂等/路径和隐私、快照契约、渲染危险 HTML/URL 过滤、前端路由及构建。完整协同/Outbox/撤回/多进程故障、登录与写权限、CDN 和恢复换代留在对应阶段，不以公开快照手工导出替代原基线。

线上站点本轮访问遇到 Cloudflare challenge；本机浏览器工具因不能可靠识别当前 URL 停止操作，未绕过。现阶段视觉依据可追溯到本地主题源码、公开设置及资源；浏览器实际视觉验收须单独补做并如实记录。
