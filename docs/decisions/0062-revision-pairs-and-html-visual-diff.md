# ADR 0062：顶部版本选择与区块并排差异

日期：2026-11-05（Asia/Shanghai）。状态：已实现并完成本轮验收。

## 用户要求

用户希望版本修订像编辑页面：上方选择两个版本，下方按GitHub差异对比的形式查看左右区块，并高亮修改。随后明确HTML可切换可视化/代码，容易实现时优先可视化。此决定细化[ADR0061](0061-cursors-offline-branches-and-version-merges.md)的展示布局，离线基线、持久确认、版本保护与合并锁不变。

## 页面与引用

页面以文章标题、返回编辑和保存版本为顶部结构。“版本修订”区域提供基础版本/对比版本和交换操作；两侧均可选择历史检查点或实时最新版。下方使用整宽的区块差异卡片，历史目录从“版本记录”展开，不再常驻侧栏占用正文宽度。草稿分支/合并记录仍可从同页分类进入。

原路由 `/admin/content/{type}/{id}/versions` 保持；`view=version&selected={左侧}&compare={右侧}` 保存比较双方，`head`表示实时草稿。旧链接缺少compare时仍比较实时最新版。默认无本机恢复分支时选择上一个检查点与最新版，已有显式选择不被轮询替换。历史列表仍分页，已选的两侧版本即使不在当前列表页，也在选择器中保留。

交换按事件发生时的当前URL计算，不使用上一帧的选择闭包；纯读取期间选择器保持可操作。右侧读取独立取消旧请求，响应必须匹配所选版本；读取失败显示错误和重试，不能回退到另一份正文继续显示错误比较。刷新、交换与快速再次选择都保留对应关系。

## 区块差异

- 沿稳定区块ID配对，标题显示原位置到新位置，区分新增、移除、顺序、格式和文字变化。区块可展开/收起，标题在本块内避让导航吸顶。
- Markdown默认源码；HTML默认安全渲染后的可视化。每块标题提供独立“可视化/源码”切换，切换或展开不改写源文，切换后保持区块标题可见。模式属于本页临时状态，刷新恢复按格式的默认值。
- 源码复用既有CodeMirror MergeView，左右行号对齐、红/绿行背景、增删符号及行内高亮。默认保留修改上下文；显示完整正文时展开未改区块和未改行。没有新增依赖。
- 可视化沿既有安全渲染，再添加派生文本标记。匹配相同段落等叶子块，避免新增段落牵连未修改正文；结构间纯空白不生成标记。代码/公式继续由原功能渲染，标签、样式和媒体属性的精确差异以源码视图核对。派生标记绝不写入历史、共享文档或发布正文。
- 桌面并排，窄屏将左右内容依次展示并重复标明版本；页面保持一个纵向滚动面，源码长行换行，不扩大页面宽度。浅/深色与减少动态复用后台变量/偏好。

## 边界与验证

请求仍由core/generated客户端执行，主题只展示；没有后端接口、契约、依赖或数据库变化。当前工作草稿、历史快照、合并结果和公开发布继续分离。没有实现任意HTML结构的逐元素或像素差异；正文渲染使用当前可信渲染器和已应用定义，精确历史源文可从源码查看。
