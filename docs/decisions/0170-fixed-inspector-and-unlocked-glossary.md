# ADR 0170  固定编辑面板与解锁后的术语

状态为已实现。版本为 ADR0170-1。

桌面文章、说说、组件内容及自定义/注册页面的设置使用同一个 EditorInspector。面板固定在后台顶栏下方到视口底部，标题或标签独立于可滚动的设置区；正文保留页面滚动。滚动到侧栏边界不带动正文，滚动条在悬停或键盘焦点进入时显示。窄屏沿用分区或文档布局，不增加第二层滚动；实时编辑的嵌入式设置继续由原有左侧容器承载。组件内容的设置开关只在窄屏显示，桌面面板始终可用。

加密文章阅读页的标题左侧显示锁图标。当前阅读请求成功后，同一个标题切换为开锁图标，锁梁旋转抬起；尊重阅读区减少动态偏好，并为读屏提供状态。密码表单继续通过异步请求在当前组件内替换正文，不触发页面重载或导航。阅读回执与正文仍只保留在挂载页面内，不写入共享缓存。

原术语装饰只扫描一次 DOM。术语请求先于异步组件完成，或正文容器随后替换 innerHTML 时，术语可漏注入。共用装饰器现在观察正文的子节点与文本变化，补充新出现的匹配，沿用总数量限制；装饰自身时暂停观察，避免递归。清理仅移除本实例生成的装饰，卸载后断开观察。仍跳过链接、代码、控件及显式忽略区，受保护文章仅在原有富文本标记容器中装饰，避免操作 React 管理的普通标题/控件。

受限术语继续使用已有阅读回执请求，不退回公共索引，也不将正文用于浏览器公共缓存。请求失败时浏览器控制台报告状态码与内容 ID，不输出回执、密码或正文；旧后端插件未升级或网络异常需按日志处理，DOM 修复不替代插件启用与授权。无后端业务、契约或数据库修改，本次需重新构建前端主体。
