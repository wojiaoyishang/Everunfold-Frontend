# ADR 0061：光标协作、离线分支与独立版本页

日期：2026-11-05（Asia/Shanghai）。状态：已实现并完成本轮验收；长期容量和跨浏览器覆盖见验收边界。

## 用户确认与替代

用户要求正文实时保存、光标与选区共享、点击成员定位；掉线冻结个人最后确认的基线，继续编辑产生独立本地分支，在线成员继续工作。旧历史视为可删除草稿，最新版不可删除；正式合并期间整篇最新版只读，在线尚未确认的输入及输入法最后提交仍须保留。用户随后明确版本对比采用独立页面，替代弹窗，便于可视化查看修改。

此决定替代 ADR0044 中正文只在显式保存时提交的阶段选择。源码原样保留、两种视图均可编辑、稳定区块编号、PostgreSQL 提交后 ACK、前台发布与工作草稿分离等边界保持。

## 文档与持久化

- collaboration 2.0.0 的新编辑器请求 source_first。每块以源文 Y.Text 为唯一正文，CodeMirror 与 Tiptap 均是投影；旧 rich 文档换代时保留基线，不重放旧 epoch 的未确认队列。旧缓存显式转为待比较的恢复分支。
- PostgreSQL 同事务写实时草稿、Yjs 增量和去重回执，再 ACK。显式保存产生检查点；空闲10秒且距上次检查点至少60秒时，存在差异才自动生成检查点。Redis 只保存临时在线状态及通知。
- 浏览器用 IndexedDB 保存状态、稳定 outbox/ACK 和独立分支。按站点、已验证账号、文章隔离；活动队列再按页面会话隔离，复制窗口得到新身份，刷新保留原身份。事务合并记录，不能覆盖另一标签页的队列。
- 密码、visibility、opens_at 和权限不进入共享文档或本地正文导出。历史/分支/合并媒体纳入删除守卫；软删除历史保留内部基线。新 epoch 同样保留已移除块源文，导出包含 removed_blocks。

## 光标、选区与本人撤销

身份和颜色由服务器确定，同账号不同窗口可区分。位置以 Yjs 相对位置传输，适应远端插入；源码和单个 Markdown/HTML 可视化块显示光标及选区，成员按钮定位到区块/光标并避让吸顶栏。状态栏不因 presence 变化重置整个表单，自身成员标签保持稳定。

正文、共享属性和区块结构使用宿主本人 UndoManager，源文初始化与可撤销的区块插入分开，撤销插入仍保留他人写入的块源文。撤销不跨刷新保存。跨多个区块连续选择仍不支持。

## 离线分支与在线竞争

断连立即冻结个人确认基线并暂停编辑，醒目显示重新连接/继续本地编辑。继续后正文只写独立本机分支；网络恢复不会自动覆盖线上。分支上传携带基线 epoch/序号、原始字段及未确认回执，服务器对本人已提交但丢失 ACK 的操作选择性推进共同基线。源文投影重叠无法安全映射时也转入恢复分支，并要求人工复核。

所有写入口在相同草稿锁和持久合并租约检查下串行：输入先提交则纳入目标；合并先获得锁则迟到更新返回40980，客户端保留为恢复分支。中文 composition 结束前不强行销毁编辑面，最后确认文本不能丢失。已发布内容和其他文章不受该锁影响。

## 版本页与合并事务

入口为编辑页的“版本”，路由 `/admin/content/{type}/{id}/versions`，查询参数保留所选历史/分支/合并记录，可直接打开或刷新。版本目录与对比区并列；窄屏目录可收起。页面自身滚动，不再叠加版本弹窗滚动容器。

可视化对比沿安全渲染标记文本增删，展示新增/删除/移动区块；源码对比提供对齐行号、变化背景及行内差异，可折叠未改部分。可以选择其他检查点作为比较对象。代码、公式和媒体的完整源文差异以源码视图为准，渲染标记不会写回正文。

三方合并按稳定区块 ID 判断增删修改、顺序、文本和属性；保留原始换行与空白，重叠/结构歧义列出冲突。60秒租约由所有者每15秒续期，合并结果独立编辑并自动保存到本机和服务器。暂停/超时解除最新版占用，结果仍保留。相同目标恢复时保留结果与已确认决策，未决原分支冲突继续待处理；目标变化时重新比较原分支，并明确提示上次结果仍在记录/恢复草稿中，不自动重放旧决策。

完成时同事务验证所有冲突已处理、目标未变化、权限/正文/媒体有效，保存检查点及线上父版本/来源分支，切换 epoch、推进最新版并解锁。旧连接恢复新基线，旧 outbox 不能穿透换代；完成请求可幂等重取。离开活动合并前可取消离开或保存并暂停解锁。

## 实现与验证

显式0017迁移已应用于本容器和测试环境；生成契约固定在后端已提交产物，前端不独立定义业务字段。新增 `@codemirror/merge` 精确锁定6.12.3，MIT，用于只读源码对比和展示差异计算；兼容现有 CodeMirror 6 的依赖范围，依据[上游](https://code.haverbeke.berlin/codemirror/merge)及 npm 元数据核对。

后端真实多进程、前端检查、生产路由隔离、双窗口及真实输入法验收见[本轮记录](../handoff/cursor-versions-verification.md)，操作说明见[版本与离线恢复](../development/draft-versions.md)。没有实现物理GC/压缩、浏览器外的离线冷启动、跨块选区、细粒度ACL或任意离线分支的无人审查合并。
