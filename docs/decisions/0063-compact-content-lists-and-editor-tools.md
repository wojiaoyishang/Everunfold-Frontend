# ADR 0063：紧凑内容列表与编辑工具入口

日期：2026-11-05（Asia/Shanghai）。状态：已实现并完成本轮检查。

## 用户要求

文章和说说列表有封面时用缩略图替代左侧类型图标，参考WordPress补充作者、分类、标签、评论和日期，压缩每行高度并提供搜索。另按本轮前一个要求调整链接编辑框、稍放大工具栏图标，并提供清楚的短代码插入按钮。

## 列表与私有契约

- 两种内容类型复用同一列表和行组件。桌面采用标题、作者、分类、标签、评论、日期、操作七列；左侧46px封面与标题、单行摘要组成主列。常规行最小82px，长标题和窄屏可自然增高。置顶、示例和未发布修改保留标记。
- 封面沿稳定媒体ID解析当前可用原件，浏览器按需加载、裁切显示；未提供、不可用或加载失败时回退到类型图标。不会从正文猜封面，也不会把解析后的URL写回草稿。
- content-admin发布1.6.0，查询结果采用专用DraftListItem，在原概要上增加cover_url/categories/tags/comment_count/pinned。DraftDetail及协同消息保持原契约，列表不暴露正文数组、访问密码或整份编辑设置。前端从已提交的后端d42cb8b生成。
- 后端批量解析当前页封面和已审核通过的评论数量，避免逐行查询。分类、标签、置顶取当前工作稿；已发布条目的日期取发布时间，其他条目取最后修改时间；工作稿与公开发布保持分离。
- 搜索表单按按钮或Enter提交；标题、摘要、正文、作者、分类及标签使用同一个后端关键词查询，按当前类型和状态过滤。百分号和下划线仍按文字处理。分页回到第一页，支持清除、刷新、失败重试，重复点击当前状态不清空结果。输入中的关键词与已提交的关键词分离，中文输入不会逐字触发查询。
- 较窄屏幕改为带字段标签的紧凑排列，320px保留封面、元数据和操作，无水平表格滚动。主题只负责展示；请求状态和契约客户端仍归core/generated。

## 编辑工具

共享ShortcodeButton使用独立短代码图标与“短代码”文字，接入Markdown/HTML的源码、可视化工具栏及版本合并结果编辑器。沿原captureInsertion/ShortcodePicker在当前区块光标或选区插入原生调用，不增加区块，不引入旧方括号语法。合并结果使用自己的编辑回调与媒体解析缓存；暂停、权限变化或不可编辑时禁止插入。

主要工具图标从14px增至18px，常规点击区域32px；源码窄屏34px。工具栏允许换行，不把正文状态栏或公式内部SVG一起放大。

链接弹层沿共享ActionPopover锚定和退场/焦点机制，保留340px期望宽度并随窄屏收缩。新增标题、克制的输入焦点、分隔操作区和取消按钮；已有链接才展示“移除链接”。新建链接用空输入及地址占位符，提交去掉首尾空白，沿现有协议校验。没有改变链接、正文保存或协同协议。

## 边界

本轮没有增加批量操作、排序、列显示偏好、分类/标签独立筛选、封面派生尺寸、全文检索索引或新的数据库迁移。分类和标签列显示名称；搜索仍是当前数据库查询，不承诺大规模全文检索性能。历史界面与参考图不作为直接复制WordPress设计的要求。

检查与截图见[本轮验收](../handoff/content-list-tools-verification.md)，操作见[内容管理](../development/content-management.md)及[编辑器指南](../development/editor-plugins.md)。
