# ADR 0014：按页面注册动态请求与演示基线

日期：2026-10-31。状态：**已实现基础请求；真实认证、持久浏览计数和评论增量未实现**。来源：用户授权先做假登录/浏览量、顶栏状态图标，测试后端离线有/无缓存；随后要求面板不写死业务明细，各页面自行注册所需能力。

## 决定

- 保持 ADR 0013 的首屏边界：Next.js 从合法公开快照输出正文、SEO、导航和历史评论；浏览器直连公开 FastAPI 地址补充动态数据，指标不参与页面导航完成条件。
- 状态图标只聚合**当前页面已经注册的请求**，无请求时显示尚未检查。公共面板不固定列出浏览量、身份或评论；页面用 `usePageRequest` 登记请求，必要时用 `useStatusSlot` 注册额外面板内容。离开页面、最后一个使用者卸载时释放登记，过期响应不能重新添加状态。
- 按随后视觉反馈，状态面板采用紧凑的状态标题、页面扩展和底部更新操作三部分；移除图标右下圆点，同步中由封装的 `LoadingRing` 沿按钮圆周转动，中心图标保持静止。没有百分比承诺；减少动态时外圈静态显示，配色跟随主题。
- 请求注册与面板展示分开：注册请求无需提供可见明细，注册面板也不会自动产生网络请求。相同页面/键共享进行中的工作，键需包含模块和影响响应的资源/参数；不能把不同账号、资源或查询共用一个键。
- 本轮文章页注册演示身份及演示切换控件；列表页不请求身份，只按可见真实 ID 批量读取演示指标。示例说说没有真实 ID，不发业务请求。其他页面可以登记不同能力，公共状态组件不需增加条件分支。
- 统一 GET 传输处理真实 HTTP 状态、响应外壳与生成 Schema 校验、8 秒超时（含读响应体）、取消；协调层只对网络/超时和 502/503/504 最多重试一次，退避约 1.5–1.8 秒。429、校验、权限和明确不存在不自动重试。不后台轮询；网络恢复、前台恢复且距上次尝试至少 30 秒、手工重新检查才触发更新。
- 列表指标最多 20 个 ID 一批，24ms 合并窗口；按页面代次、内容 ID 和本次登记令牌防止旧结果覆盖。指标只保留在页面内存，不存 localStorage/公开快照，重新检查时隐藏，成功后在固定空间淡入（200ms，服从减少动态设置）。未知与真实零值不同。

## 后端演示契约

后端 `38ff722` 发布 `reader-preview-v0.1.schema.json`，版本 `0.1.0-preview.1`；公开正文/快照仍为 `0.1.0`，展示草案仍为 `0.2.0-preview.1`。前端通过 `contract:sync` 从已提交产物生成类型、校验 Schema 和客户端，来源 commit 与 SHA256 记录在 `reader-preview-source.json`。

`[reader_preview].enabled` 默认 false，关闭时端点返回 404；仅本机联调配置显式开启。`GET /v1/reader-preview/identity` 返回选择的 guest/member 演示身份，`GET /v1/reader-preview/metrics` 返回按公开内容 ID 派生的模拟数值。响应明确 `mode: demo`，私有/草稿/撤回/未知 ID 不泄露；GET 不记账、不写库、不创建 Session、不授予权限、不迁移旧账户。

请求使用 `credentials: omit` 和 `cache: no-store`；成功响应 `Cache-Control: private, no-store`。这是演示读取客户端，**不能直接用于真实 Cookie 登录**。接真实用户态时另行落实 Session、跨源 Cookie/CSRF、账号隔离与权限契约；页面中的演示登录结果不能控制真实业务授权。

## 离线与缓存含义

这里的“有缓存”是 Next.js 节点磁盘已有有效完整公开快照，不是浏览器 HTTP 缓存，也不是持久化用户态。真实停止测试 FastAPI 进程后：有快照的首页/文章保持 200，正文、SEO 和历史评论保留；补充指标失败隐藏，身份恢复为未确认，状态图标可重试。无快照的首页/文章由现有入口返回 503、noindex、no-store、Retry-After，不伪装成 404 或成功空页面。

离线并不证明缓存永远安全：已有撤回/转受限事实不得恢复旧正文。当前尚无完整节点撤回通知/可靠同步链路，本轮离线测试只验证既有合法快照读取与可选请求隔离，不把它升级成生产缓存 P0 全部通过。
