# ADR 0020：登录成功过渡与会话校验生命周期

日期：2026-11-01（Asia/Shanghai）。来源：用户要求登录成功后等待动画完成再跳转，无返回地址时管理员默认进入后台，并报告已登录时直接访问 `/admin` 停在身份确认。

状态：已实现。替代 ADR 0019 中“所有账号缺省返回前台”的回跳决定；通用登录文案、440px 简洁卡片、共享主题与认证边界保持有效。

## 返回目的地

- 先区分“没有 `next` / 空 `next`”与“明确要求返回 `/`”。缺省值保留到真实会话确认后再决定：管理员为 `/admin`，普通账号为 `/`。
- 明确指定的安全返回地址优先；管理员带 `next=/` 仍回首页。现有白名单仅 `/`、`/admin`，保留查询和片段；非法地址回退 `/`，普通账号请求后台目标仍回前台。
- 新登录和已有有效登录共用同一规则。前端目的地不是授权，`/admin` 必须再次通过真实 `/v1/admin/session` 数据库角色校验。

## 成功反馈与页面切换

- `LoginPage` 只接收真实登录结果；`LoginSuccess` 承担成功图标、文本及导航衔接，`login-handoff` 负责可取消的动画顺序。取得成功后可以预取目标页面，但不立即替换路由。
- 完整动态下：约 1 秒的成功反馈（淡入、勾选绘制及停留），随后约 220ms 的卡片轻微上移/淡出，再执行 `router.replace`。卡片保留可读透明度，在目标页面较慢时不先消失成空背景。
- 阶段之间等待真实动画完成；暂停、接口不支持或结束信号丢失时有有界兜底，不能永久卡在成功动画。卸载、目的地改变和偏好变化清理旧动画、计时器与未执行的跳转。
- 减少动态时仅保留约 450ms 的静态成功反馈，不等待运动动画。进入管理页后仍由后端校验结果决定是否展示工作区。

## 会话校验

- `core/auth/session-check` 为每次页面挂载建立独立控制器；正在进行的读取由初次加载、焦点恢复、历史恢复和重试共用。重复事件不得取消请求并重置 8 秒传输截止时间。
- 已确认后台在焦点恢复时后台复核，不反复拆掉整个工作区切回加载卡片。重新读取失败或角色失效后立即清除已确认视图；不使用本机缓存身份继续授权。
- 校验超时、连接失败、无效响应均进入明确失败态；401 回登录，403 显示无权限。迟到请求不能覆盖后续登录结果，卸载/Strict Mode 的旧控制器不能更新新页面。
- 无新增端点、契约、Cookie 字段、数据库迁移或依赖；Session 仍只在页面内存中，浏览器直连 FastAPI，响应继续 no-store，公开缓存不接触身份。

## 验证与限制

见 [登录与空后台验收](../handoff/authentication-frontend-verification.md) 最新追加。真实浏览器覆盖登录成功、管理员缺省回跳、显式首页回跳、已登录直达/刷新后台、退出与未登录回跳；并发焦点/迟到请求/8 秒超时/动画取消由自动化回归覆盖。

首次常规 Edge 直达后台未稳定复现用户报告的永久等待；代码审计确认旧焦点监听会中止并重开校验，本轮消除该等待被反复延长的条件并验证上述路径。不能据此宣称所有网络、扩展或脚本加载故障都已复现。普通账号仍仅验证目的地策略，不向实际库增加测试用户。
