# ADR 0080：Paper作为精简的子主题起点

日期：2026-11-07。状态：已实现；[验收记录](../handoff/paper-starter-verification.md)。

用户要求Paper更简约，方便他人二次开发。将Paper收敛为theme.ts与styles.ts两个文件，组件、模板和钩子全部继承默认Argon；样式只调整背景、导航、横幅、边框和行距，配色及阅读偏好继续使用父主题变量。

移除Paper专属的横幅包装、人物页模板和页脚说明。多级父组件组合、ID模板与继承钩子的生产验证迁入隔离测试夹具；扩展方法仍保留在开发指南，避免入门主题承担测试示例的复杂度。

由于移除了paper.people、paper.footer-note和public.hero的本地实现，主题版本升为2.0.0。主题发现、安装清单、动态选择、插件运行和后端契约沿用原机制；不新增设置、依赖或数据库迁移。现有子主题若直接引用旧Paper具名实现，需要自行提供替代实现。
