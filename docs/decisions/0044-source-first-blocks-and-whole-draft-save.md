# ADR 0044 源码底稿与整篇保存

日期 2026-11-04。状态为已实现。用户要求 HTML 和 Markdown 共用前端源码底稿，取消 HTML 单块应用，整篇保存才提交正文。用户随后明确区块视图切换即时完成，HTML 源码选区包含完整元素标签。本决定替代 ADR0042 中当前插件的实时富文本绑定、手工源码应用和切换动画。

## 内容和界面

每个块以原始 HTML 或 Markdown 字符串为内容。可视化是派生编辑面。切换只读取底稿，保持原有空行、缩进、实体、属性引号和标签拼写。HTML 可视化修改按词元差异局部回写，Markdown 先尝试文字局部回写，再限于受影响的块生成语法。无法保留结构的修改留在源码中完成，安全预览继续使用统一清理。

HTML 默认可视化，Markdown 默认编写并保留桌面分屏。模式控件位于块标题栏右侧，直接切换并恢复焦点。HTML 从可视化切到源码时选择最小完整包含元素，多元素选择覆盖对应同级范围。Markdown 按源文位置与可视化文字、图片映射，重复文字按出现顺序定位。

## 本地输入和事务

现有草稿的正文输入由宿主按稳定块 ID 暂存，sessionStorage 按后端地址、已验证账号和草稿隔离。两个标签页分别保存各自未提交输入。正文暂存和原有 IndexedDB/Y.Doc 更新队列分责，属性与块结构继续沿用共享草稿。插件通过 value/onChange、宿主媒体回调和封装编辑面工作。

保存复用 POST /v1/admin/content/collaboration/commit。契约 collaboration1.2 增加 block_sources，每项包含 id、type、base_hash、content。前端先取得已确认共享截点，再计算原始内容 SHA256。后端在文档行锁内验证该截点与当前头部，拒绝已变化或移除的块。随后将精确源码、旧客户端使用的 rich 派生片段、协同增量、媒体引用、正式修订和幂等回执写入同一事务。

冲突保留本地输入，用户可导出和查看最新版本。保存失败可按同一 operation_id 重试。HTTP 成功后本地正文等到相应持久序号到达再解除等待。已保存且源码相同的恢复副本会合并收敛。旧整篇 JSON 写入限制、真实账号权限、公开发布边界和 PostgreSQL 提交后 ACK 继续适用。

## 兼容和限制

旧 source/acquire、renew、release、apply 接口及世代检查保留给已有客户端。新插件切换不调用这些接口。旧暂存内容仍包含在导出数据中，旧标签页升级后需手动刷新。

正文撤销目前由各编辑面处理，源码与可视化的撤销历史分开，HTML 模式切换会重建编辑面。共享属性与结构的撤销仍由宿主 Y.Doc 处理，跨视图统一历史留待后续。sessionStorage 在关闭标签页或浏览器限制下的保留能力有限，导出是手工恢复入口。大文档、复杂源码映射、跨块选区和实机 IME 仍需专项验证。
