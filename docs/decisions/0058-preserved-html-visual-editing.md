# ADR 0058：保留HTML源文的可视化修改

日期：2026-11-05（Asia/Shanghai）。状态：已实施，验收见[记录](../handoff/native-shortcodes-verification.md)。

用户明确：即使从HTML源码编辑，也应允许通过可视化修改，不能禁止。此前自定义class、属性或布局标签导致整个块回退为rawHtml原子，并显示“在源码模式编辑”；这不符合新要求。

本地可视化投影增加保留原始标签/属性的容器、文字块和行内格式。文字、选择替换、加粗等操作仍走已有ProseMirror编辑；修改通过验证投影的源文拼接写回，只变动涉及的部分，保留其余引号、类名、数据属性、实体和换行。行内自定义包装是可继承的mark，替换整段文字不会顺带丢掉span。

这套投影只用于本地HTML编辑，不改变共享Yjs的可信schema或后端rich字段契约。新属性不直接发成协同rich更新；仍由原始块源文/基准指纹与整篇保存负责提交。公开输出继续安全过滤。可视化DOM只接收有界展示属性，不执行源文事件或脚本；注释/脚本/SVG等非文字节点单独保留，不能再让它们锁住所有相邻正文，也不声明为任意SVG/布局的图形编辑器。

自定义短代码模板复用同一HTML编辑能力；代码注册定义的只读权限继续由其业务来源决定，不因HTML可视化要求而开放系统实现编辑。
