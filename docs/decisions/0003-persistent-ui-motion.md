# ADR 0003：持久前台外壳与原视频动效

- 状态：采用并已验证本阶段公开前台。
- 日期：2026-10-30。
- 依据：用户要求接入原动态背景、增加灵动性、优雅切换文章/界面，继续整理可复用组件和目录；保留已运行前端热更新服务。

## 决定

1. RootLayout 唯一挂载公共 BlogShell，视频、顶栏、侧栏与共享交互状态常驻；页面只输出主体和目录/公开站点数据桥接，避免每页重复外壳。
2. 沿用 Next Link/Form 和 React transition；真实同源正文链接限正文容器增强，不自研路由器，不接管外链、资源、下载、修饰键和纯 hash。保留浏览器历史。
3. 纯导航目标判断和目录注册状态位于 core/navigation；Argon 的过渡/展示状态留在主题组件。目录注册采用所有权 token，防卸载或错误路径残留/清错新页。
4. 用户提供的原文件确为 WebM/VP9，保留类型和字节作为主题资产。video 静音循环、行内播放，背景按用户/系统偏好与可见性管理；不可用时退回静态图片。
5. 使用原生 CSS/React 动效，不引入大动画依赖、实验路由 API、全局帧循环或影片渲染框架。保持紫色、星空和 Argon 布局，正文只做短入场和 pending 反馈。
6. CSS 拆为 8 个有序职责文件，入口只导入。代码结构、动画与 reduced-motion 共同维护；无 JS 或减少动态效果时内容仍可见。
7. 构建检查在临时独立副本运行，当前开发服务不受 .next 覆盖影响；用户拥有的前端继续运行。业务 API、数据库和快照契约本轮不变。

## 结果与边界

16 项测试、默认 Turbopack 独立生产构建、14 项页面 HTTP 回归及内置浏览器实际导航/视频/手机交互通过，证据见交互动效验证记录。这个决定不扩展为后台编辑、协同、任务或缓存撤回已完成。

继续按阶段本地提交；用户自行推送远程。新增页面应复用当前外壳、导航和主题组件，不再复制布局；组件、样式与测试的职责见前台架构文档。
