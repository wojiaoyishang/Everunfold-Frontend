# ADR 0015：阅读反馈、同步失败与真实评论点赞

日期：2026-10-31。来源：用户要求去掉离线浏览量空位、末尾按钮右对齐、简化错误页、提示文章同步失败、真实点赞回调及按页面请求的圆周进度。状态：前后端已实现；构建、自动检查及部分桌面浏览器核验通过。剩余视觉核验边界见 [验收记录](../handoff/reader-feedback-verification.md)。

## 阅读与界面

- 未成功的浏览量不保留横向空位，成功后展开。可选指标不参与文章导航就绪。
- 同步进度为本页挂钩登记能力的已结束数/总数，失败也算结束并保留失败状态；不是字节进度、后端任务进度或可靠快照同步证明。重试属于原项目，换页释放。更新 ADR 0014 的纯装饰环约定。
- 直接访问不存在地址仍是 404；快照不可读是 503、noindex/no-store，不返回空正文。两种页面使用明确文案和中性排版。
- 已加载索引中的文章链接携带“已知内容”导航意图；准备或 Next 提交失败时保留原页，横幅提示“后端同步失败”。不改变服务端公开过滤、不回退客户端旧正文，该标记不是授权或已同步证明。

## 点赞协议与范围

真实点赞仅覆盖公开文章的已审核历史评论。示例和仅本页留言不写入正式存储。评论发布、真实 Session、说说点赞、真实浏览量仍未交付。

- 权威契约 `comment-likes-v0.1.schema.json` 0.1.0。GET `/v1/comments/likes?ids=...` 最多 50 条；PUT `/v1/comments/{comment_id}/like` 提交明确 `{liked: bool}`，不使用翻转接口。
- `X-Everunfold-Visitor` 是浏览器按后端隔离保存的随机 UUID4，仅标识匿名点赞偏好，不是账户或授权。库中只保存 SHA256，不采集 IP/邮箱，不返回其他访客标识。
- 浏览器直连 FastAPI，credentials omit；CORS 精确允许来源，PUT 拒绝非允许 Origin，无 Cookie 隐式授权。清除标识后视为新访客；本轮不声称生产反刷或跨设备身份去重。
- 显式迁移 `0002_comment_likes` 创建 `(comment_id, visitor_hash)` 主键及级联外键。每次复核公开条件，评论行锁/唯一约束防止跨进程重复计数；提交后才 ACK，失败回滚。动态点赞不改变正文快照，不发布正文缓存事件；正式审计和可靠外发基础设施另行实施。
- 前端等确认才更新，加载图标代替爱心并阻止重复点击。网络/超时反馈未确认，不自动重试写入；再次显式提交仍是目标状态。刷新读取真实状态，旧页迟到结果不能更新新页。成功/失败使用主题全局反馈组件。

## 验证与部署

后端 PostgreSQL 覆盖幂等、取消、隐藏过滤、多个独立进程重复点赞与新连接持久读取；字段/错误外壳、CORS、库不可达分别验证。部署显式执行迁移，不在启动时建表。前端检查断网、慢请求、错误恢复、窄屏、主题及减少动态；实际结果见本轮验收和 STATUS。
