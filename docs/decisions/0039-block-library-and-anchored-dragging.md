# ADR 0039：注册区块库与按 ID 拖放

日期：2026-11-03。来源：用户确认拖入添加、手柄排序、紧凑区块头和右侧区块库方案，并要求修复确认框样式、首行紧贴工具栏。状态：已实现，检查见 [验收](../handoff/block-composer-verification.md)。不改变 ADR0037 的协同、权限和发布边界。

## 界面与注册

区块库从可信 blockEditors 注册表生成，注册项提供名称和说明；Markdown/HTML 仍各用自己的编辑插件。桌面复用右侧空间，在区块库与内容设置间切换，正文列宽不随切换变化；设置控件保持挂载。手机保留正文/内容设置切换，通过封装的非模态弹出区块库点击添加。

正文块使用稳定 ID 作为 React key，顶部仅显示六点手柄、类型、序号和操作菜单。菜单保留上移、下移、到开头/末尾、源文格式切换和共享 ConfirmPopover 删除。原文不做有损格式转换；切换语言适配器时允许重新装配该适配器，排序不重建 CodeMirror/Y.Text。

每个块前及末尾有插入位置。桌面可从区块库拖入，或先选择位置再点击类型；手机直接打开对应位置的区块库。正文区域只有手柄发起排序，选择正文不发起拖拽。鼠标越过6px启动；触摸手柄长按240ms、容差6px启动。键盘空格/Enter拾起、方向键/Home/End选位置、再次放下、Esc取消；区块库的Enter保留点击添加。所有按钮复用主题封装。

## 提交与协同

拖动中只更新本地预览：插入线、原位占位和轻量浮动缩略卡，不挂载第二个编辑器。松手后生成一次 insert/move 命令，包含源 ID 和目标 before ID；null 表示末尾。核心在最新文档上解析 ID，拒绝失效源/目标、重复 ID、超128块和无效操作。不使用拖动开始时的数组索引，也不把旧整篇 JSON 写回协同草稿。

整篇仍为一个 Y.Doc。新块创建自己的 Y.Map/Y.Text；移动只调整 order，保留所有已有文本对象和墓碑。一条结构操作在一个 LOCAL transaction 内执行，前后 stopCapturing，成为一次本人撤销；其他会话的文字不被撤销。更新继续经过原 IndexedDB 合并、稳定更新 ID、持久 ACK 和 PostgreSQL 截点保存管线，不新增 HTTP/WS 协议或数据库迁移。

键盘选择位置直接保留目标引用，避免快速放下时最后一帧碰撞测量滞后；鼠标按指针位置选最近插入线。目标失效由核心拒绝，不复活已移除块。同时移动相同块依然只承诺既有 CRDT 的收敛及投影去重，不保证两位操作者的意图同时实现。

## 样式、动效与边界

DragAndDrop 封装传感器、中文读屏提示、碰撞和滚动；BlockComposer 组合区块库/结构命令，BlockFrame/Header 管理局部展示。预览进入 admin-root 下的独立层，避开页面变换产生的定位偏差。仅外层页面接收边缘自动滚动，CodeMirror 自身滚动不被劫持。移动后使用 FLIP/短暂强调，遵循后台减少动态；拖动时暂停保存、发布、撤销及预览切换。

区块头按钮样式只匹配直接子元素，不影响嵌套确认框。共享确认按钮保持至少64px、不收缩、不换行。320px 下工具栏允许自然排列，无裁切。

本段高度/留白规则已被用户随后要求的 [ADR0040](0040-source-editor-spacing-and-minimum-height.md) 替代，下面保留当时决定。

按用户最新要求，CodeMirror 内容顶部 padding 为0、底部12px；首行紧贴工具栏，行号交给 CodeMirror 同步测量，不用空行撑高。颜色均从后台变量派生。

## 依赖与未覆盖项

增加 @dnd-kit/core 6.3.1，实际用于鼠标、触摸、键盘与预览；依赖清单和 npm 锁文件共同提交。已核对官方 npm peerDependencies（react/react-dom >=16.8），并在当前 React19/Next16 锁定环境构建和浏览器验证。没有直接引入未使用的 sortable/utilities 依赖。

参考：[官方安装与包说明](https://dndkit.com/legacy/introduction/installation/)、[键盘传感器](https://dndkit.com/legacy/api-documentation/sensors/keyboard/)。本实现封装了该版本接口，后续升级须重新核验，不混用新版包的 API。

未覆盖手机实机长按、多点触控、系统输入法、长文/大量区块压力及跨块连续选区。当前移动区块库以点击添加为主，不承诺从手机弹层拖到页面；手机已有块可通过手柄或操作菜单排序。

添加按钮的当前统一交互见 [ADR0041](0041-block-insert-picker-feedback.md)：所有屏幕直接弹出选择器，修复原桌面按钮仅选中右侧区块库而无可感知反馈的问题。
