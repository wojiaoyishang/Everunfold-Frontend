# ADR 0037：注册式编辑器与整篇草稿协同

日期：2026-11-02。来源：用户批准先实现一版 Markdown / HTML 插件编辑器和文章协同。状态：试用版已实现，实际验收与未执行项见 docs/handoff/collaborative-editing-verification.md。

持久块类型仍为 markdown/html，插件 ID 与版本独立。只加载编译进前端的可信插件；宿主负责块结构、媒体、全篇本地撤销、协同与保存。首版两种编辑器均为 CodeMirror 6 源码编辑，按类型使用不同语言、工具栏与安全预览。暂不做跨编辑器连续文字选区或富文本 HTML 反向转换。

每篇已有草稿只初始化一个 Y.Doc。标题、摘要、SEO 文本为 Y.Text；稳定块 ID 映射到各自 Y.Text，顺序为 Y.Array，移除使用墓碑且保留块。访问密码、可见性、开放时间、账号与权限不进入 CRDT。结构与正文均经过服务器校验。分类/标签等首版采用字段级最后写入策略，文本用 CRDT 合并。插件不能各自上传或发布整篇 JSON。

后端使用 pycrdt 0.14.10，前端固定 Yjs 13.6.33、y-codemirror.next 0.3.6 与 CodeMirror 6（main 分支绑定 Yjs 14，不能直接照搬）。已实测中文及组合表情二进制双向互通。WebSocket 17.4 供 Uvicorn 协同传输使用。依赖版本与锁文件同交付。

公开路由与快照不接触协同内容。浏览器以真实 Cookie+CSRF 请求一次性短期票据，票据只在 socket 首帧提交；WS 路径为 /ws/v1/collab/{draft_id}，不可依赖 Path=/v1 的认证 Cookie 自动随 WS 发送。每次写入及空闲轮询复核数据库中的会话、账号权限和草稿状态。Redis 仅存协同在线状态/连接租约/通知，名称与队列、快照缓存隔离。

PostgreSQL 保存初始状态、当前二进制状态、连续 committed_seq 与不可变更新/去重回执。同一 update_id 相同哈希和操作者重复应答同一 seq；不同内容拒绝。持久 ACK 仅在事务提交之后发出。Yrs 不重新编码缺少前置依赖的更新，因此这类更新必须拒绝确认，不能悄悄丢弃。客户端本地状态及 outbox 在 IndexedDB 同事务写入，只有服务器 ACK 才删除 outbox；远端更新不能重新作为本地提交。

发布/保存接口接受确认过的序号，服务器从持久状态重建该截点，并复用原草稿审计、幂等回执和公开分发事务；之后的协同更新继续留在草稿，不被 HTTP 应答覆盖。旧的整篇 JSON save/publish 对已开协同文档返回冲突。媒体引用保守累计，避免协同尚未手动保存或撤销时文件被删除。

首版保留全部更新回执/日志，尚不删除历史增量；当前完整状态是检查点。历史 GC、长期大文档压测、细粒度编辑权限、离线跨账号恢复、富文本编辑器与跨块选区留待后续。不得将这版试用结果称为完整协同生产验收。

实施补充：本机缓存写入须在单个 IndexedDB 事务内合并状态/outbox/ACK，并通知其他标签页读取；不能用最后写入覆盖。导出包含移除块的源文，便于离线编辑遇到远端删除后找回。会话失效恢复只读取本页已授权内存副本，不保留后台操作权限。
