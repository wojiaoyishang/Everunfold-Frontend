# ADR 0142：统一实时编辑工作区

状态：已实现。

- 页面、模板、文章和说说复用同一个实时工作区。顶栏、左栏和真实页面 iframe 在编辑模式加载前即确定位置。模式到达或切换时只替换左栏内容，不重挂预览。窄屏左栏覆盖在预览上，按需展开。
- 顶栏显示文档名称、发布状态、设备、预览与主保存操作；更多保存操作放在下拉菜单。左栏按需显示组件库、属性、正文区块、源码、参数或设置。结构导航按需浮在画布上，不占固定侧栏。按用户要求避免重复标题和描述，保留必要提示及无障碍名称。
- 组件在主题渲染的实际预览中选择、排序和编辑。整张组件卡片可用鼠标直接拖动、触屏短按住拖动或键盘拾起。独立网格有稳定的网格布局、按设备列数和嵌套能力。已保存的旧容器网格继续按原属性渲染。
- 标题点击后在原位置编辑。HTML 和 Markdown 通过组件下方的同一编辑浮层修改，画布实时显示经安全渲染的结果。画布和属性栏均可打开浮层，保留源码模式和取消操作。右键菜单支持在画布或侧栏点击外部关闭。
- 区块模式沿用协同正文编辑器和版本保存，由左栏修改区块后更新右侧实际页面。源码模式沿用 HTML/CSS/JavaScript 的沙箱策略。两者与组件模式共用设备切换及保存位置。
- 现有受权限保护的管理表单保存、发布和解析版本，通过同源、所有者窗口、会话和递增序号递交变更，文档按既有后端契约验证。预览本身不发布、不提交读者操作，短代码脚本预览规则不变。
- 常规页面和实时侧栏共用设置字段及分组，按可用宽度分栏或折叠。顶栏眼睛按钮通过已验证窗口握手打开带当前编辑内容的独立前台预览。纯预览由工作区菜单切换。
- 无后端代码、接口契约或数据库迁移。见[操作指南](../development/component-editor.md)。
