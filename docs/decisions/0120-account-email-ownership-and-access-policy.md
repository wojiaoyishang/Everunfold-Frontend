# ADR0120：账号邮箱归属与认证策略

日期：2026-11-12。状态：已实施。扩展 [ADR0115](0115-account-email-verification-and-admin-mutations.md)。

- 「成员与互动 → 访问与安全」由 `access:manage` 保护。登录和邮箱发码的人机验证规则共用现有验证码提供方和修订；认证邮件选择现有 SMTP 配置，未指定时使用默认配置。仅浏览器会话可读写访问策略，写操作校验 CSRF 和期待修订。
- 自助邮箱验证在同一弹窗处理人机验证、发码状态和重发。队列接收与 SMTP 接收分开显示；发信失败、投递未知与验证码过期有独立提示。重发成功后旧请求失效。更换邮箱成功前保留原地址，成功后只合并邮箱与资料修订。
- 「用户管理 → 编辑用户」的审核需要 `users:manage` 和 `users:verify_email`。人工通过单独记录 `email_reviewed_at`，不设置代表邮箱控制权的 `email_verified_at`。通过和撤销记录操作者、目标及原因；撤销时清除两种状态并使活动请求失效。
- 迁移 `0048_verified_email_review` 对通过验证码的邮箱按 `lower(btrim(email))` 唯一化，遇到冲突或空白已验证邮箱停止迁移，不合并账号。业务通知仅向仍有效的本人验证邮箱投递。
- 契约为 `accounts-v1 1.7.0` 和 `captcha-v1 1.6.0`。公开注册、邮箱登录、找回密码和 2FA 尚未启用；邀请注册仍以基线为准。
