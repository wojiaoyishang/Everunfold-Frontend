# ADR0106：验证码归并系统设置与分组分区导航

版本：ADR0106-1。状态：已实现并验证。日期：2026-11-11。补充 [ADR0064](0064-desktop-settings-section-navigation.md) 与 [ADR0105](0105-admin-navigation-and-glossary-media.md)。

## 背景

后台“设置”原先把验证码作为与系统设置并列的直属入口。验证码属于全站运行与安全策略，独立入口让设置组继续膨胀；同时系统设置、验证码规则、节点策略和部署信息分散在两页，管理员需要跨页确认。

右侧快速导航此前只生成平铺分区链接。系统设置归并后包含多个验证码分区，平铺目录已难以表达“节点与发布 / 验证码 / 部署信息”的层级。

## 决定

1. 验证码配置面板嵌入 `/admin/settings/system`，按“验证方式、登录验证、阅读验证、评论验证、API Key 请求”展示。
2. 后台左侧“设置”仍保持直属入口，不恢复父/子折叠菜单；移除独立“验证码设置”入口，系统设置成为唯一可见入口。
3. `/admin/settings/captcha` 作为兼容地址临时重定向到 `/admin/settings/system#captcha-provider`。验证码页面、读写路由和权限边界继续保留，不把独立验证码修订并入普通站点设置修订。
4. 验证码面板继续使用自己的 GET/PATCH `/v1/admin/captcha`、`expected_revision`、CSRF、保存栏、撤销和未保存修改保护。归并只改变后台信息架构与展示位置，不改变业务契约。
5. `SettingsSection` 增加可选 `group` 元数据；快速导航按 DOM 顺序把相邻同组分区渲染为一级分组标题和二级可点击分区，未设置分组或只有一组时继续呈现原平铺结构。
6. 当前分组标题随二级分区高亮，分区沿用 `aria-current="location"`、稳定 hash、焦点移动、滚动观察和减少动态行为。手机端继续隐藏右侧目录。
7. 异步加载的分区出现前，带 hash 的首次恢复保持等待，不把“尚未挂载”误判为“目标不存在”；目标挂载后再定位和聚焦。该规则兼容验证码面板异步读取。

## 当前分组

- 节点与发布：节点策略、站点与主题发布。
- 验证码：验证方式、登录验证、阅读验证、评论验证、API Key 请求。
- 部署信息：部署配置。

## 影响

- 无后端业务、契约、数据库迁移或公开快照变化。
- 验证码与节点策略仍各自保存、各自处理版本冲突；同页存在多个独立表单时，各自的未保存修改都纳入账号离开保护。
- 新设置页可以逐步采用分组，不要求一次性改写所有现有页面。

## 验证

真实后台数据与当前开发组件的混合实页检查确认：验证码入口从左侧隐藏；系统设置显示三个分组标题和八个二级分区；旧验证码地址跳转后定位、聚焦并高亮“验证方式”；390px 不显示右侧目录且无横向溢出；视觉检查期间没有设置写请求或脚本错误。

完整前端检查359项、`verify:admin`隔离生产验收通过。具体记录见[验收](../handoff/system-settings-captcha-navigation-verification.md)。
