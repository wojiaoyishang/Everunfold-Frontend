# ADR 0034：固定链接、分类标签与文章访问

日期：2026-11-02。用户在 ADR 0033 实施过程中补充要求：视觉参考 WordPress，标题置顶，按标题生成根级地址、点编辑修改；分类采用勾选树和常用分类，标签采用常用程度字号云；加入文章密码与定时开放。

## 本轮决定

- 新内容首次保存按标题生成 `/{标题别名}.html`，无 posts 前缀；同名自动加序号，无标题用稳定 ID。已有地址保持，修改标题不自动改址；可编辑完整路径，改址不建立历史重定向。
- 新系统分类通过专用管理用例持久化父分类关系，勾选为内容关联；所有/常用切换，新增后立即勾选。名称在同类型内唯一，暂不支持同名不同父级或分类移动。标签支持逗号分隔添加、移除和常用标签云；次数来自新系统已发布内容的实际关联，不造样例热度，不恢复旧博客正文。
- 密码保护与发布状态独立；使用 Argon2 哈希，仅工作稿和发布内容的私有列保存哈希。输入、响应回执、审计修订和公开快照均不存原密码；操作指纹对密码部分使用按操作 ID 加盐的内存困难派生，重试保留同一 ID。
- 定时开放仅在密码保护下设置。开放前可凭密码提前读取；到点按后端时间自动公开，不等同未来发布时间。访问即时按策略判断；Worker 刷新已到点的派生快照，复用原 Scheduler tick 和可靠 Outbox，更新与 release 同事务，重复 Worker 不重复升版。未运行投递进程时动态读取仍按到点策略，公开 SSR 快照在投递恢复后更新。
- 未解锁正文、摘要、媒体映射、封面、SEO 自定义描述和正文统计不进入公开 DTO/SSR/磁盘快照。公开页只有标题等壳和密码/开放提示。POST `/v1/reader/access` 校验密码与真实来源 IP 的限流，限制 Origin、请求大小并返回 private/no-store；密码不放 URL、浏览器存储或共享缓存。解锁内容只留当前页面内存，刷新需重新输入；不创建长期授权 Cookie。
- 媒体仍是公开静态资源，文章保护不会使原文件保密。修改密码/访问策略后按发布版本生效；草稿输入不会提前改变前台。
- 数据库显式迁移 0012；content-admin 1.3、public 0.4（接受 0.1/0.2/0.3），独立 content-access 1.0。以上覆盖 ADR 0033 的稳定 ID 默认新地址、平级分类和本轮不做密码/开放的旧范围说明。

## 验收

必须验证双 API 的密码正确/错误、来源拒绝、限流、明文未落回执和修订；公开快照/搜索不泄露受限正文，公开转受限后旧版本不能回流；真实 Worker/Scheduler/Node 到点开放、只升一次版本、离线补发；标题路径重名和稳定性、父分类与真实使用次数；界面键盘、动效和手机布局。
