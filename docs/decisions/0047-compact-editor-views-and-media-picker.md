# ADR 0047 紧凑视图切换与大媒体选择器

日期：2026-11-04。状态：已实现并完成本机浏览器检查。来源：用户要求合并编辑器模式按钮、单击直接切换、加深更多图标，以及参照 WordPress 放大媒体选择窗口。

## 区块视图控件

Markdown 和 HTML 块头都只保留一个视图切换图标，与更多操作菜单分开。复用 EditorViewToggle、封装 Button 和 SVG Icon；图标及可访问名称表达下一次操作，aria-description 说明当前视图。移除并列的编写/源码/可视化按钮，不使用下拉菜单选择视图。

- Markdown 默认源码。桌面单击依次切换源码、可视化、分屏、源码；宽度不超过 800px 时只在源码与可视化之间切换。桌面分屏缩窄时显示可视化，重新加宽恢复分屏偏好。
- HTML 默认可视化，单击在可视化与源码间切换。
- 切换保留同一份源文与选区映射，不产生草稿保存；源码/可视化即时切换继续遵守用户指定的无动画例外。
- 更多操作仍为独立菜单。提高图标大小、笔画及对比度，默认不画多余方框，悬停及展开沿用后台语义色与反馈。

## 媒体选择窗口

文章两种编辑器与站点/主题媒体字段共用 MediaPickerDialog。保留独立媒体库详情和图片编辑窗口，不复制上传或业务请求。

桌面窗口距离视口四周 24px，标题、上传文件/媒体库标签和底部操作区固定。左侧搜索、类型筛选、网格/列表和文件，右侧显示所选附件资料；两侧可各自滚动。手机使用全屏纵向布局，资料在文件下方，底部确认始终可达。深浅色、键盘标签导航、焦点恢复及关闭动画复用现有封装。

点击文件只暂选，确认退场后才交给调用方，取消不改正文或设置草稿。上传页提供大选择/拖放区，仍使用统一多文件队列、真实进度/不定进度回退、稳定请求 ID 和逐项错误。上传允许类型由调用方用途决定，不被浏览页临时过滤项误改。

附件侧栏只读显示文件、尺寸、日期、替代文本、说明、描述及地址。编辑资料和处理图片仍在独立媒体库，不将侧栏展示误称为资料编辑。此轮不改契约、后端、数据库或存储路径。
