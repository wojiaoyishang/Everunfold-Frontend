# ADR 0177  阅读字体、页脚与媒体选择器

状态为已实现。版本为 ADR0177-1。

「主题设置 → 字体缩放」为当前主题保存 75% 至 150% 的默认值，初始为 100%。右下角阅读设置可覆盖该值，偏好保存在当前浏览器。「恢复默认」清除覆盖并沿用站点配置。公共主题容器继承 `--public-font-scale`，固定字号乘该倍数，相对字号继承已缩放的父字号。正文字号设置仍提供独立的基础值。自定义内容 CSS、正文内联字号和重新构建的独立插件样式沿用这一比例。

横幅开启打字效果时，逐个显示文字字素。主标题光标短暂停留后消失，间隔一拍再开始打副标题。减少动态模式直接显示完整文本。移动端展开侧栏时隐藏页面和侧栏的纵向滚动条，侧栏内容仍可滚动。

页脚在主内容栏底部使用主题色渐变。「站点设置 → 页脚」使用 HTML 源码编辑器保存 `site.footer.html`，点「填入默认 HTML」可把可编辑的署名模板写入编辑器。自定义内容使用正文 HTML 规则渲染。留空时自动显示 Argon 原作者与 Everunfold 重构署名，也显示已配置的旧版权说明和链接。站点地图仍使用原有地址。

媒体选择器将当前文件或当前组交给媒体目录优先排序。空字段可以回看同一账号、媒体类型和选择模式下上次确认的文件。已经加入组的文件继续标为已添加。搜索、类型筛选、回收站和权限规则仍由媒体目录处理，置顶排序在分页前完成。

设置契约 1.51.0 增加以上持久设置和 `MediaQuery.pinned_ids`，沿用现有数据库字段。先更新 API，再构建配套前端。
