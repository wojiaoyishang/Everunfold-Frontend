# ADR 0067：大语言目录的正文切换与顶栏顺序

日期：2026-11-06（Asia/Shanghai）。状态：已实施；补充ADR0066及其后的语言样式微调。

用户要求去掉前台语言图标中的国旗，模拟大量语言的自然展示，并明确将连接状态与语言图标互换位置。国旗仍用于语言条目，不作为顶栏图标的角标。

## 展示规则

- 顶栏按DOM及键盘顺序显示连接状态、语言、搜索，前后台语言按钮都只使用语言图标；语言菜单、正文条目和语言设置中的标志保留。
- 文章与说说共用正文语言组件。不超过3个真实译文成员时，当前语言优先，其余平铺；超过3个时只显示当前成员及“更多语言 +其他成员数”。3是展示阈值，不限制语言目录、翻译组或搜索结果数量。
- 手机隐藏“更多语言”文字，保留+数量和展开图标；长自定义语言名就地省略，完整名称可在标题提示及列表中查看。不依赖客户端宽度决定成员集合，避免SSR与水合不一致。
- 弹层显示全部真实版本，当前项有勾。名称、规范代码、当前界面名、英文名和语言原生名可搜索；忽略大小写和组合重音。显示名称仍取配置值，搜索别名不改写它；浏览器不认识的自定义代码仍可按代码和配置名称检索。
- 只有结果区滚动，搜索栏保持；列表保留稳定高度，过滤不会把输入框推来推去。复用ActionPopover与封装表单/输入/链接，使用原生Tab/Enter/Escape和轻关闭；弹层关闭后不留下可聚焦的隐藏字段。颜色、选中、焦点及减少动态沿用主题。
- 无JavaScript时提供有高度上限的原生链接回退，不依赖客户端拼出译文地址。

## 数据与实现边界

只使用后端公开投影中的translations和实际成员路径，不根据全站语言目录制造译文。查询和折叠不保存设置，不复制正文，不改变发布/访问策略、canonical/hreflang或分组事实。条目仍可指向允许发现的密码壳，并保留锁标志。

正文组件从顶栏切换组件中拆出；小型语言搜索模块独立于旗帜数据集，避免公开切换器为搜索加载完整旗帜目录。useT复用已有插值引擎处理计数，显示文案支持中英文程序包。

## 模拟与验收

新增仅允许系统临时目录中everunfold-build-*副本的模拟生成器，建立3/4/50语言文章和50语言说说。它使用完整公开契约与现有不可变文件存储，拒绝写真实实例目录；没有向开发业务库添加语言或译文。

实际检查、限制及截图见[大目录语言入口验收](../handoff/language-overflow-verification.md)。前后端业务契约、数据库迁移与依赖不变，本轮不新增后台目录上限、自动翻译或大规模渲染容量承诺。
