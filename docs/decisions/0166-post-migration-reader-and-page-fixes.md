# ADR 0166  博客迁移后的阅读与组件页修复

状态为已实现。版本为 ADR0166-1。

## 受限文章

已发布文章的封面是列表和标题区可公开展示的元数据。本条更新 [ADR 0034](0034-wordpress-editor-access-and-taxonomy.md) 中的封面可见性。公开投影和前端副本继续拒绝受限正文、正文资源映射、摘要、评论和自定义 SEO 字段。解锁响应恢复文章自身的有效分类与标签。只用于受限文章的词项不进入公开目录或计数，读者可以在解锁后看到名称。

术语表契约升级至 3.9.0。公开 GET 按现行阅读权限计算命中；解锁后用同一路径的 POST 并提交文章范围的阅读回执。后端校验回执与当前文章，复用正文术语匹配及词条发布规则。授权响应留在当前阅读会话，沿用悬浮提示与脚注。见 [ADR 0099](0099-article-scoped-glossary-tooltips.md) 与 [ADR 0101](0101-glossary-rules-and-reader-ui.md)。

## 页面构建器与主题

后台目录从页面详情抄取摘要模型需要的字段，组件树和已解析媒体属于详情。保存了 `site://media/…` 的页面仍可在目录中查看并进入编辑。

构建器提供进度条，包含可编辑的标签和 0–100 百分比。编辑器预览与读者页使用同一主题渲染，静态内容保留标签和数值。

寄语页和其他等待插件组件的入口使用不定进度条，保留无障碍状态和锚点恢复。逐字标题每个字形在延迟结束后回到默认的可见状态，两种动效均遵循减少动态偏好。

## 部署后

更新后端并重新构建前端。本次无新增数据库迁移，需同步后端术语插件 1.9.0 的清单。统一部署仓库依次运行 `./setup.sh build`、`./setup.sh migrate`、`./setup.sh start`，其中 `migrate` 会登记插件。在独立后端运行时可使用实际配置执行 `python -m tools.register_backend_plugins --apply`。

现有内容副本为不可变版本，发布一次页面或文章更新会重新生成副本，等前端节点确认新版本后再检查首页封面。后台重新同步会重发当前版本。

如需恢复迁移前的技能展示，在「关于」页的构建器里添加六个进度条并发布。原值为 Python 65%、易语言 55%、HTML 35%、JavaScript 33%、PHP 20%、C# 和 C++ 5%。之前选用的淡入动画可在主题设置中切换回逐字动画。
