# ADR 0162：显式配置路径、Base64 配对与本机连接编辑

状态：已实现。日期：2026-11-16。版本：ADR0162-1。

## 问题与决定

用户要求配置路径无歧义，默认项目根 `config.yaml`；前端未连接后端时仍可在浏览器新增和编辑连接，保存有明确反馈；后端需要可控日志等级和实际拒绝原因。

两端 setup 和运行程序以外部 `CONFIG_FILE` 指定唯一配置文件。未设置时仅使用项目根 `config.yaml`，相对路径基于项目根；缺失、空值或无效配置立即失败，不自动回退 TOML。显式旧 TOML 继续支持，浏览器编辑要求部署 YAML。后端显式 CLI 参数优先。前端新增锁定的 yaml 依赖，支持 Node 22，拒绝重复键、无效类型、过大输入及别名展开；参考 [yaml 官方文档](https://eemeli.org/yaml/)。

Docker 助手把宿主所选配置的父目录挂到 `/config`，明确传入容器路径；前端可写、后端只读，源码/产物与数据继续挂 `/workspace` 和 `/data`。不复制配置到另一代码目录或构建产物，不再由前端运行时读取派生 TOML / env。直接运行镜像默认 `/workspace/config.yaml`。目录挂载支持原子替换，单文件 bind mount 会收到清晰失败提示。

前端本机密码鉴权与后端连通状态独立，保留精确 Host/Origin、HTTPS、HttpOnly/SameSite 会话、限流和请求大小限制。只对本机密码开放连接编辑；后端管理员证明仍可查看本机状态和切换已有项，全站管理继续依赖后端管理员。此决定替代 ADR0130/0161 中仅离线允许本机密码的规则。

连接保存在同一 YAML 的 `connection_profiles`，令牌保存在 `environment` 并用引用关联；读取接口只有“已配置”标记，没有秘密。保存可修改活动项或新增并选用，最多 16 项；已有令牌留空保留。修订检查、与 setup 共用的独占锁、0600 临时文件和原子重命名防止覆盖并发编辑。界面显示成功、绝对路径和重启要求，不关闭页面。接收器拒绝继续使用过期身份/令牌，重启后加载新值；无需编译。首次内联转为多连接需重发公开内容以填充来源隔离缓存。

前端部署启动检查对后端未就绪给出详细警告，仍启动本机配置入口；显式 `check` 保持失败退出码。语法或必要凭据配置错误仍停止。内部地址检测不跳转至发布 URL。

后端增加 `[Everunfold access]`，记录控制台启停、Host/HTTPS/TLS代理与内部接口来源、节点存在/启用和令牌拒绝原因；不记录令牌、密码、正文、查询参数或任意异常文本。相同拒绝节流 30 秒。自动 Docker CIDR 只作用于内部 API 允许来源，不是可信 TLS 代理配置；导出连接 Base64 只登记绑定，节点成员关系/启用仍由 `/_nodes` 管理。

后端 setup 分别配置 API / Celery Worker / Scheduler 日志等级，默认 INFO / WARNING / INFO，已有值保留；容器与原生入口一致。Scheduler 记录状态转变，避免心跳刷屏。

## Base64 节点配对

按用户要求，后端导出默认直接输出标准 Base64（UTF-8 的 `everunfold-node-connection/v1` JSON），不再创建跨容器交接文件。数据仅包含当前节点 ID、后端发布 URL、来源 UUID 与双向令牌。导出仍登记内部绑定，不自动添加或启用节点成员。

前端 setup 可粘贴编码，`--connection-base64` 提示输入或接收临时 `EVERUNFOLD_CONNECTION_BASE64`；Docker 仅向一次性配置工具传入，原生导入后清除，不带到应用进程。生成的导入命令不包含秘密。浏览器解码只填入表单，不自动保存或请求导入 URL；内部 URL、来源 IP 和容器参数保持原值。校验大小、标准编码、UTF-8、协议版本、URL、非零 UUID、令牌长度/方向，失败不部分写入也不回显输入。旧 JSON/env 文件仅保留兼容导入。

Base64 不提供加密，复制结果属于节点凭据。它不替代两端运行配置；各自仍通过 `CONFIG_FILE` 加载 YAML。

## 验证边界

通过配置路径、权限与原子失败、跨来源拒绝、会话轮换和并发修订测试；独立 Node 进程验证 YAML 凭据与重启边界。界面在内置浏览器验证后端失败时解锁、编辑和保存反馈。构建、静态检查、完整测试和限制记在各仓库 STATUS。

未访问用户生产服务器，不能据此判定其原 404 / 403 的具体原因。环境无 Docker daemon，网络与启动编排使用命令桩；实际镜像/挂载需部署机验证。
