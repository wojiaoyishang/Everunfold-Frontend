# ADR 0046 编辑区容器、锚定表单与可视化表格

日期 2026-11-04。状态：已实现。来源：用户指出链接弹层裁切，并要求移除外层顶部栏、透明背景及上移正文。

## 展示调整

去掉正文外层的“编辑 / 预览 / 草稿”栏，整篇预览移至页面顶部操作区，点击后可返回编辑。外层正文容器不再提供背景、边框和内边距，各区块保留自己的工具栏、模式切换、拖动手柄和边界。手机顶部操作采用紧凑三列，避免预览入口额外占一行。

## 锚定表单

ActionPopover 接受期望宽度，由既有定位器按视口与边距约束。链接及图片表单使用340px期望宽度，内部按实际可用宽度布局；不能仅隐藏横向滚动来掩盖溢出。一般操作菜单仍使用228px。

打开表单时聚焦第一个输入控件，保留输入框的方向键及Home/End语义；纯操作菜单继续支持方向键导航。Escape、点击外部关闭和进退场沿用共享实现。表单依当前链接/图片属性重新绑定，避免快速对齐后再次打开仍显示旧值。

## 表格导入与源码保留

本轮实际操作发现，HTML的直接单元格文字未转换为编辑引擎要求的段落结构，点击会触发无效内容错误。HTML、Markdown和HTML粘贴共用可视化结构适配，空单元格与紧凑列表补齐编辑面段落，原始字符串及共享草稿转换器不改。

源码回写先沿用词元局部拼接。合并/拆分涉及源码没有的隐式段落时，只允许重建唯一变化的顶层table；必须核对修改前后完整语义投影，表格之外的源码逐字节保留。普通文字编辑继续局部回写，单纯切换视图不重排源码。嵌套或自定义结构无法验证时保留原有拒绝和源码编辑提示。

本轮不修改后端、数据库、协同保存协议或媒体上传流程。源码/可视化切换不加动画的既有用户要求继续生效。实际检查见[本轮验收](../handoff/editor-canvas-popover-verification.md)。
