# ADR 0050：结构化公式编辑器与主题吐司

状态：已实现，2026-11-04。来源：用户确认完整 LaTeX 编辑器方案，并要求粘贴图片使用主题全局吐司、压缩公式操作区、扩大正文、修复区块库与矩阵模板。补充 ADR0049，不修改后端正文契约。

## 决定与边界

Markdown/HTML 共用 FormulaEditorDialog。MathLive 0.111.4 提供结构化输入、占位槽、选区、撤销和矩阵操作；源码复用 CodeEditor/CodeMirror，增加 LaTeX 高亮及命令/结构补全。KaTeX 继续负责阅读渲染并校验编辑结果兼容性，不保存 MathLive 的内部树或派生 HTML。

窗口只维护一份 LaTeX 字符串。有效源码更新可视化；无效源码保留输入及最后有效的可视化，显示诊断、禁止插入。仅打开或开关源码不重排原文；实际可视化输入可以生成新的 LaTeX 排布。插入在退场后写回本页底稿，文章仍整篇保存；取消不改正文。不新增公式端点、共享节点或数据库字段。

模板分类搜索、结构化占位和中文数学键盘共用。定位采用有界唯一匹配，重复/不可识别时明确不定位；矩阵命令须确认光标处于数组内部，避免在外部制造无关环境。源码与结构化输入撤销历史独立，接收新的有效源码会重置后者；不承诺任意 LaTeX 的无损转换或跨视图统一历史。

窗口与引擎按打开时动态加载，本地版本化字体使用 swap，关闭自动远程字体目录与声音。键盘限定在窗口内，清理后恢复宿主配置；异步初始化不抢走源码焦点。前台阅读仍只按正文引用加载 KaTeX，不加载 MathLive。

## 布局和全局通知

显示方式、键盘与源码开关并入标题栏，移除重复的“文章中的效果”，校验保留。编辑面占剩余高度，共用紧凑底栏；手机上下排列，分类和模板横向滚动。模板使用固有高度；界面图标尺寸只命中按钮直接子 SVG，不能覆盖 KaTeX 内用于竖线/根号的 SVG。区块库显式使用 gap、行高和分隔，不依赖被全局段落样式覆盖的 margin。

根布局装配轻量 ToastProvider。主题 useToast 按稳定 ID 发布/更新通知，封装进度、动作、状态、关闭和退场。InlineUploadToasts 只适配原统一队列：逐文件真实进度、不定进度回退、100% 后仍正在保存、成功/复用、停止/重试、失败移除占位。成功自动消失，焦点/悬停暂停计时，失败持续到处理。媒体库保留完整队列视图；吐司不接管传输、保存或删除。

新增 mathlive@0.111.4（MIT），锁文件、本地字体和许可证随代码提交。官方依据：[React 集成](https://mathlive.io/mathfield/guides/react/)、[Mathfield API](https://mathlive.io/mathfield/api/)、[KaTeX 选项](https://katex.org/docs/options)。使用见[指南](../development/formula-editor-and-toasts.md)，实际覆盖和限制见[验收](../handoff/formula-editor-verification.md)。
