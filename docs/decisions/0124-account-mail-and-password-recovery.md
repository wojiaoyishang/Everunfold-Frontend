# ADR 0124：账户邮件模板与自助找回密码

日期 2026-11-12。注册验证码、邮箱验证、找回密码重置码和密码重置成功提醒分别使用「通知模板」中的邮件模板。它们使用认证发信配置，由 Worker 投递，不使用业务通知策略。包含重置码或验证码的模板必须在启用的正文中保留对应变量；主题和 HTML 属性禁止使用该变量。

「访问与安全」提供默认关闭的全站找回密码开关。匿名用户在原浏览器发起请求，站点仅向已验证的邮箱发送高熵一次性重置码。有效期最长 30 分钟，且不超过匿名会话有效期。请求响应与账号是否存在无关。重置码与浏览器、账号修订、验证邮箱及策略世代绑定。关闭开关会使之前的重置码失效，重新开启不恢复旧码。

成功重置会撤销浏览器会话和旧 API 密钥，保留两步验证，并排队发送密码重置提醒。用户随后正常登录。重置码只在等待投递期间保留明文，Worker 领取后清空。上线前显式执行迁移 `0052_password_recovery`，更新 API、Worker、Scheduler 和前端。
