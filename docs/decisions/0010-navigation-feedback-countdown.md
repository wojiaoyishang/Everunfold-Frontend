# ADR 0010：单行导航反馈与自动收起

日期：2026-10-31。状态：已实现，功能提交 `26087e0`。本决定按用户新要求更新 ADR 0009 的反馈展示，不改变其页面准备/路由/历史逻辑及已知框架回退边界。

## 已确认要求与实现

- 横幅仍作为导航下缘的通栏延伸，改成一行颜文字与提示；移除关闭、取消、重试和继续阅读按钮。桌面高 48px，窄屏高 44px。原页始终可以继续操作，再次点击链接会重新发起导航。
- 失败先短暂变红、轻抖一次，然后恢复主题表面并显示 5 秒，再自动收起。失败包含超时及不可用/不存在等同类结果，不留下无法关闭的提示。
- 工程初值：红色强调 900ms、文字轻抖 460ms；随后 5000ms 倒计时。统一常量定义在 core/navigation/transaction.ts，界面用 CSS 变量消费同一保持时长，不维护第二个 5 秒初值。
- 倒计时使用横幅整块底色，右边缘从右向左退去，文字保持原位；退去边缘有跟随主题色的细光晕和四颗上浮、消散的小气泡。动画只有提示存在时运行，使用 CSS transform/opacity，不增加 JS 帧循环或粒子依赖。
- 失败定时器归 NavigationTransaction 所有。新导航、历史返回和取消内部意图会清除旧计时器，并检查请求 ID，防止旧提示倒计时清掉新页面反馈。没有自动重试请求。
- 减少动态模式关闭抖动和气泡装饰，仍保留红色提示与表达剩余时间的倒计时。真实文本继续提供 alert/status，装饰标记 aria-hidden，不依赖颜色表达失败。

## 维护边界

NavigationProgress 仅展示状态；删除不再使用的上下文 cancel/retry 导出、对应图标和按钮样式。核心取消机制继续用于新选择、相同地址及 popstate，不能因移除按钮删掉竞争请求保护。

没有新增依赖、后端接口、配置或缓存；没有数据迁移、导入或推送。慢加载阈值仍为 5 秒，导航总超时仍为 20 秒。检查与截图见 [导航交付验证](../handoff/frontend-navigation-verification.md)，复查步骤见 [网络预览指南](../development/navigation-network-preview.md)。
