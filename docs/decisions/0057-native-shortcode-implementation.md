# ADR 0057：原生短代码协议、模板目录与发布

日期：2026-11-05（Asia/Shanghai）。状态：已实施，验收范围见[记录](../handoff/native-shortcodes-verification.md)。落实ADR0056，替代其未冻结语法及独立投递资源建议。

用户给出`{{< gallery id="123" >}}`与`{{< notice type="warning" >}}…{{< /notice >}}`，授权确定细节；本实现采用该形式，单体/容器由注册定义决定，参数双引号、JSON字符串转义、有界嵌套、代码区字面保护。自定义名称使用custom命名空间，身份及已应用类型固定，不保留WordPress方括号别名。错误调用保留源文并给出诊断。

后台统一目录组合可信后端注册、显式前端注册与数据库自定义模板；来源与编辑能力分开，只有自定义项可经服务端写入。自定义HTML可通过源码与可视化双向修改，CSS由后端AST编译并限定作用域；无数据库JS和远程代码安装。

草稿、应用、归档与应用历史分别管理；主库定义/版本/审计/Outbox同事务。公开编译目录使用PublicSettings中的正式shortcodes字段和现有public-settings投递，复用已经验收的节点代次、持久回执、重试/乱序恢复，避免再建平行协议。此选择不同于ADR0056的独立资源提案；模板仍是独立业务表/模块，不并入theme任意JSON，普通设置写入不得篡改目录。

首版应用确认说明全站范围，没有精确文章引用数量。归档不破坏已发布调用。文章插入器按现有稳定ID区块命令添加原始调用，复用整篇保存/协同，不保存预览DOM。WordPress备份和既有正文不修改；旧样例标记继续作为普通文字，明确保留影响。

详细语法、限制、API/契约与配额见[短代码架构](../architecture/shortcodes.md)。
