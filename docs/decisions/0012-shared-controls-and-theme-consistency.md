# ADR 0012：统一控件、配色与定位反馈

日期：2026-10-31。状态：已实现，最终验证记录见交接。来源为用户连续反馈：导航右侧滚动条缺口、页面控件必须自封装、推荐区域滚轮横移、主题颜色完整联动、点击评论 @ 对象在滚动停止后强调原评论。

## 决定

1. 主题的基础交互控件集中在 `components/ui/`。Button/TextField/TextArea/TextLink/Form/Dialog/Popover 保留原生语义、ref 与事件；Checkbox/Switch/RangeField/Select/ColorPicker/HorizontalRail 提供主题外观或实际复用行为。页面不再直接输出这些原生控件，ESLint 加入边界检查；AppLink/SearchForm 仍是站内导航入口。
2. 两处搜索类型选择共用 SearchContentType + Select。选择面板使用原生 top layer 与 light-dismiss，外观由主题绘制；支持方向/Home/End、Enter/空格、Escape、Tab、文字查找、禁用项和选项滚动。提交仍是 `q/type` GET；无 JavaScript 的搜索页提供单选组降级，不把浏览器默认 select 作为正常界面。
3. 颜色选择改为主题面板，提供十六进制文本与 RGB 滑块；非法文本保留输入并显示错误，不应用到主题。复选框和滑块自行绘制，底层保留原生键盘/触摸行为。子面板按视口约束定位，Escape/完成回到触发按钮，外部点击保持自然焦点。
4. 页面控件、分页、侧栏标签、图片工具、焦点/选中、阴影和卡片染色从 accent/brand-accent/surface 等变量派生；自选色下深浅表面也联动。brand-accent 用于白字填充，accent 用于正文强调；错误色、头像识别色、原图/视频保持独立。颜色偏好继续使用原持久层，没有第二套设置缓存。
5. 原生页面滚动条轨道在导航高度内绘制同一不透明品牌底色，顶端透明时同步透明；html/body 使用一致的页面滚动条宽度。导航高度为统一变量（桌面 71px，窄屏 80px）。保留稳定 gutter，不以 100vw 撑宽文档，也不创建自绘页面滚动容器。
6. 推荐列表复用 HorizontalRail，将可消费的纵向 wheel 转为横向阻尼滚动。到两端或无溢出时交还页面；横向/Shift/缩放和触摸保留原生。减少动态直接定位。监听、动画帧和订阅在卸载时释放，移除会与逐帧插值冲突的吸附。
7. 评论定位在分页 DOM 就绪后执行；共享滚动函数区分到达与用户中断，只有真正停稳才回调。useCommentLocation 随后聚焦目标并做约 2 秒头像柔光/作者名字提亮，重复点击可重播；减少动态使用同时间的静态头像/名字提示。新定位、卸载或中断不会高亮过期目标，写评论入口只聚焦编辑器。

## 影响和边界

- 更新 ADR 0007 的控件实现、ADR 0008 的推荐滚轮/配色、ADR 0011 的轨道衔接与定位时序；保留其内容、安全、存储及其他已确认边界。
- 不引入依赖；未变更后端、业务字段/契约、快照、正式评论接口或后台主题配置。无障碍语义继续依赖 HTML，不能把“自封装”理解成重写浏览器本身。
- 原生 top layer 和滚动条仍受浏览器实现影响；跨平台/辅助技术覆盖如实写入验证记录。系统分享、全屏等明确平台功能不替换成假界面。

具体测试、复查入口和限制见 [本轮验证](../handoff/frontend-shared-controls-verification.md)。
