# ADR 0070：云端面板账号入口与头像就绪动效

日期：2026-11-06（Asia/Shanghai）。状态：已实现并验收，更新ADR0069中的前台侧栏入口；账号权限/契约/头像配额保持。

## 用户要求

后台菜单改为“应用程序接入”；移除前台侧栏独立账号导航，把账号中心入口放到右上角云端同步面板。已登录用户有头像时，加载完成后先打钩，再以头像替换顶栏图标。用户提供图片用于测试头像。

## 实现

- 菜单、面包屑及页面标题统一命名，保留稳定路径`/admin/settings/api-keys`，英文为Application integrations。
- 现有云端按钮继续打开同一个面板。上方显示真实账号、头像与“进入账号中心”；匿名显示登录入口，无法确认显示重试。链接使用既有私有账号路由，等待面板退场后导航，保留新标签页/键盘语义。
- 浏览器组件使用生成的Session客户端，身份仅在当前组件内存中，SSR无账号/头像/CSRF，不能混入ReaderStore、公开快照或持久偏好。首次读取、重新打开、显式重查、焦点/恢复在线及到期时复核，复用原有取消/迟到响应与后台检查保护。
- 头像加载成功且初次页面加载结束后，约620ms描边打钩，随后180ms显现30px圆形头像；账号ID和URL变化才重新建立这一过程。已经显示的头像在后续动态请求中保留，加载环继续表达请求进度；重查/打开面板不重播。无头像或图片失败回退云图标；减少动态直接显现，不等待装饰动画，动画取消有900ms上界兜底。
- 头像成功与页面数据成功分别展示。部分失败/离线时头像保留小型云状态标记，面板仍列出原聚合状态、失败数和重查，不能用账号打钩宣称页面全部同步成功。
- 面板复用原生Popover、共享定位/退出和焦点。长内容按视口扩展后滚动，不沿用Select的固定320px上限；关闭时只在焦点仍属该面板或body时返回触发器，避免抢其他控件的焦点。

## 验收和范围

实际浏览器与自动检查见[验收记录](../handoff/header-account-entry-verification.md)。用户提供图片通过现有受限上传/保存流程应用到当前管理员；原图、生成头像及含该图截图不提交仓库。后端代码、契约、数据库结构、其他资料字段和文章/设置不变；保持HTTP及`0.0.0.0`，具体设备地址不入文档。
