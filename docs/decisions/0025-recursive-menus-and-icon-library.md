# ADR 0025：递归菜单、共享图标库与代码页面边界

日期：2026-11-01。状态：**递归菜单、图标库和基础图片/视频媒体库已实现并验证；内容链接选择和自定义代码页面为已确认需求、待实施设计。**

## 来源与替代范围

用户指出旧菜单行的图标下拉与排序/移除控件重叠，要求允许递归子菜单，并要求独立图标库与菜单选择器复用。用户同时明确后续链接可选择文章/页面，自定义代码页面通过注册出现于「页面」，后台只编辑公开选项和通用开关，不编辑代码。

本决定替代 ADR 0024 首批设置中的“两级菜单”范围和单行编辑布局，不改变设置事实源、版本化投递、权限和公开快照无 TTL 等既有决定。原始 v2.11/v0.14 不修改。

## 已实现决定

1. 菜单使用同一种递归节点，树内 ID 唯一。无两级/三级产品上限；全树 256 项及请求体大小限制用于资源保护。编辑器分为结构树和单项表单，深层缩进封顶但显示真实层数。更改父菜单携带整个分支，禁止将节点移入自己或后代。
2. 顶栏、桌面侧栏和移动菜单读取同一递归树，按展示区域实现交互。桌面侧栏使用独立递归弹出菜单，悬停/按钮/方向键打开，不推高卡片；移动端是连续抽屉，点击整行在原位展开/收起，父菜单地址由独立的小链接图标打开，无子菜单项直接导航。两者分别实现，不能把后台树编辑器或桌面弹层复用为手机菜单。节点 ID 用于交互状态，允许多个菜单使用同一 URL。
3. 新增 `/admin/icons`，菜单弹窗复用同一 `IconBrowser`。53 个内置 SVG 图标来自现有图标组件，上传资源来自后端。控件使用共享封装，主题变量、键盘焦点、Escape 和减少动画偏好沿用现有基线。
4. 图标上传范围：静态 SVG/PNG/WebP，最大 1 MiB，位图边长至多 2048，拒绝动画位图和含脚本、外链、样式等主动内容的 SVG。SVG 以图片加载，不注入页面 DOM；不重写原始文件。
5. 后端保存稳定 `media:<UUID>` 引用，数据库记录 storage_id/object_key/hash/status；前端不上传到 public。`[media]` 配置支持独立资源 Base URL 与相对/绝对 Uploads Path，默认后端 `/media` 分发。`ObjectStorage` 是存储替换边界，CDN 直传协议仍待实施。
6. 文件发布前记录 staging，文件通过不可覆盖的原子创建发布，ready 状态与审计同事务提交。上传 ID 与操作者共同决定资源身份，未知结果可使用同一 ID 重试。公开路由只分发 ready 且未软删除的记录，文件落盘但数据库提交失败时不公开。
7. 公开设置携带后端派生的 `icon_urls`，客户端传入映射不作为事实源。切换 Base URL 后执行重新同步；派生 URL 变化产生新的设置修订并投递所有启用节点，不能覆盖已经确认的历史版本文件。地址未变时沿用原修订重投，保留已有丢失副本恢复行为。

## 本轮追加：通用资源选择与公开展示

- 用户追加要求所有图片/视频地址字段提供媒体选择。settings 1.2.0 增加有界原始字节上传/类型查询；头像、背景图、背景视频记录稳定媒体 ID，后端校验类型并派生 URL，手填地址清空关联。`/admin/media` 与表单弹窗共用浏览器；42px 缩略图与输入框同行，点击后单独预览。
- 图片支持静态 JPEG/PNG/WebP（20 MiB、边长至多 8192）与安全 SVG（1 MiB）；视频支持 MP4/WebM（128 MiB）。视频仅作有界容器检查，没有转码/完整解码保证。上传说明和限制见 [媒体指南](../development/media-library.md)。
- 桌面侧栏弹出有淡入/横移/轻模糊和退出动画，移动端展开有高度/透明度过渡；均遵循减少动态偏好。移动抽屉无卡片间隙、圆角和外阴影，顶部色块铺满，搜索与个人资料用间距/分隔线组织。
- 公告最终按用户修订恢复在首页内容列表上方。此前尝试的首次弹窗/导航栏收纳方案已撤销，不保留另一份公告内容或“已读”缓存。最新追加：settings 1.3.0 增加可选 notice_title，原 notice 保留作正文；无标题用正文预览，超过一行显示展开入口，标题与正文同时存在时也可展开。原位高度过渡、可收起、空公告隐藏，按实际容器宽度测量，不按字符数猜测。

## 后续设计与限制

内容选择接口、自定义页面注册、页面开关/选项持久化见 [页面注册设计](../architecture/registered-pages.md)。本轮没有页面代码编辑器、任意代码上传/执行、通用运行时插件加载器或内容选择假接口。

基础媒体页现支持图片/视频上传、查询与表单选择；仍没有变体、引用计数、编辑/删除/回收 UI、自动孤儿清理或 CDN 上传接管。原文件保留；后续迁移不得改变已发布媒体 ID 和 object_key。当前单一原件记录可演进为媒体/位置/变体模型，不能将它当成完整媒体生命周期已完成。

## 验证与后果

后端 100 项测试包含独立数据库、多个 API、Redis、Worker、Scheduler、Node 接收器下的并发重试、审计回滚、公开就绪门控、递归菜单投递与 Base URL 变更的新修订。前端检查、生产隔离验证与浏览器结果见 [验证记录](../handoff/menu-icons-verification.md)。Windows 本机进程故障验证不等于断电、集群共享盘或对象存储生产验收。
