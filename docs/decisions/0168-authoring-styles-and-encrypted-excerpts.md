# ADR 0168  内容样式和加密摘要

状态为已实现。版本为 ADR0168-1。

密码保护的文章默认隐藏摘要。作者可以在访问权限中开启「在加密情况下仍然显示摘要」，使用手写内容或填入预设提示语。留空时正文自动截取的摘要继续受保护。定时开放前适用同一规则。公开 API 和前端副本通过显式字段识别获准公开的摘要，正文、CSS 和正文媒体仍按原有门禁返回。

文章、说说可以在内容设置中编辑额外 CSS。组件页面和模板提供全局 CSS，模板实例可在共享样式之后追加当前页面自己的 CSS。单个组件在「样式 → 自定义样式」编辑 CSS。额外样式使用共用 CodeMirror 编辑器和同一套预览、发布渲染。普通选择器与 `:scope` 限于当前内容、页面或组件。支持 `@media` 和 `@supports`。语法错误、外部资源引用及其他特殊规则会显示提示，相关样式不应用。源码模式的 HTML、CSS 和 JavaScript 仍由独立页面沙箱处理。

进度条支持纯色、渐变、条纹和分段，以及配色、高度、端点与百分比显示。填充色和底色复用项目调色盘，可选预设、连续色面、色相和 HEX。已有进度条使用同样的标签和百分比。实时预览及扩展组件的可见等待状态使用动画，读屏保留状态，减少动态时使用静态指示。

页面说明复用共用编辑器的纯文本模式和既有字段扩展。键盘可退出输入框，说明受 500 字限制。说明和 CSS 都经过原有保存、版本管理和同步流程。

这次变更使用已有 JSON 存储，无需数据库迁移。升级 API、Worker、前端主体和插件产物后再使用新字段。
