# ADR0109：插件管理本地搜索

版本：ADR0109-1。状态：已实现并验证。日期：2026-11-11。补充 [ADR0105](0105-admin-navigation-and-glossary-media.md)。

## 背景

插件管理会同时显示前端、后端和前后端组合插件。插件数量增加后，滚动静止列表逐个查找名称、作者或版本效率较低。

## 决定

1. 插件管理顶部增加即时搜索，使用共享搜索输入样式和图标，不提交表单，不新增查询接口。
2. 搜索覆盖稳定插件 ID、名称、说明、版本、作者、页面 ID、短代码、组件名和“验证码提供方”能力标记。查询经过 NFKC 规范化并忽略大小写。
3. 搜索只改变当前已加载目录的可见行，不改变启停开关、详情弹窗、刷新按钮、节点部署记录或设置草稿。
4. 无匹配时显示明确空态；清空搜索恢复全部插件。移动端工具栏自然换行，不产生横向溢出。

## 影响

- 仅前端筛选，不保存搜索词，不增加设置修订或网络请求。
- 插件启用状态仍只由原有设置保存和部署同步流程决定。

## 验证

当前12个插件行搜索“术语”缩小为2行且均包含匹配文本；搜索无结果时显示空态，清空后恢复12行。390px无横向溢出，页面脚本错误为0，未提交设置写请求。
