# ADR 0122：站点邮件品牌与评论审核确认

日期 2026-11-12

内置评论、账号邮箱验证、定时发布及节点同步邮件共用表格布局和内联样式。站点名称、描述、作者、头像和主题色来自站点设置。邮件品牌设置可以指定公开站点地址、图标、主题色和帮助链接。公开地址留空时取第一个可用的公开前端配置。缺少地址时，内置模板隐藏相应 HTML 按钮。缺少图标时显示站点名称。邮件品牌设置随通知修订保存和审计。

站点品牌、收件人和邮件发送原因只加入邮件的渲染上下文。事件变量仍按对应事件提供。邮箱验证码由认证 Worker 渲染和投递，按剩余时间和账号验证或注册用途填充。已保存模板继续使用自身的主题、正文和 HTML 开关。模板页面可以把内置版本载入草稿查看，再单独保存。

评论待审核邮件提供通过、拒绝和查看链接。链接只携带评论 UUID 和待确认的操作，登录后读取评论的当前版本。明确确认后，现有审核 API 校验权限、CSRF、修订和待审核状态，并沿用幂等回执、审计和前台同步。已处理评论显示当前结果。站内通知保留相对地址，旧模板的 `resource.review_url` 仍可定位到评论。

HTML 可视化画布和下方预览使用同一个示例渲染结果。画布内点击文字、链接或图片可以编辑原始模板，保留变量和其余源码。示例中的帮助链接在缺少配置时使用演示地址，实际投递按邮件品牌设置生成帮助链接。
