# ADR 0145 · 页面与模板版本历史

页面和自定义页面模板的「版本」入口复用文章的历史列表、左右版本选择和差异查看。恢复写入新草稿，历史不可改写。页面恢复保留原有启停状态、类型、语言关联和模板绑定。模板子页的历史保存自身设置和参数，共享结构从模板历史查看。

模板的已应用代码与草稿独立存储。创建模板即得到首个可用版本。已有模板在后台先保存草稿，然后读取引用清单并确认应用。恢复时也展示引用清单。应用请求绑定模板版本及未回收子页的 ID、修订和公开状态。有变动时必须重新查看并确认。子页的已应用设置用于更新公开投影，草稿保留独立。旧客户端可用原保存接口直接更新未暂存草稿的模板，已经暂存的草稿只可通过确认应用接口公开。

数据库迁移 `0063_page_versions` 以现有模板版本、页面草稿以及不同版本的最后一次应用快照作为历史起点。此前未留存的版本无法恢复。私有历史和操作回执由后台会话访问，公开快照只使用应用结果。发布与缓存通知、版本快照和审计同事务提交。

「隐藏页面标题」默认关闭，作用于主题自动生成的正文标题，仍保留文档标题、导航、语言入口和 SEO。这个设置参与预览、保存、应用和页面版本历史。

`reply-only` 和 `password-area` 由后端注册为只读内置短代码。公开发布阶段用不透明标记替换正文；后端解锁接口验证阅读权限及审核通过的评论或口令。前端只绘制占位和解锁交互。密码正文加密存储，成功解锁响应禁止共享缓存。
