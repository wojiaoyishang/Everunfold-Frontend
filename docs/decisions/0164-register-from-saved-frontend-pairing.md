# ADR 0164：沿用已保存配对登记前端

状态：已实现；公开地址交互由 [ADR 0165](0165-pairing-runtime-and-frontend-origins.md) 替代，以下保留原决定。日期：2026-11-16。版本：ADR0164-2。

部署助手已经保存节点 ID、内部接收器 URL、私有 HTTP 选项和双向令牌引用。后端 `/_nodes` 将未登记的有效配对列为待设置公开地址。配对来源包括当前配置中的部署助手字段及已经导出的内部绑定，数据库中已有的绑定优先。

操作员通过节点控制台填写真实的前端发布 URL 并确认启用状态。首次登记配对可初始化空的运行清单。内部绑定、成员变更、审计以及启用所需的重发计划和同一修订号一起提交。旧文件清单含已有节点时仍通过原有命令导入。存在有效内部绑定的节点继续使用其已有连接。

节点控制台状态只额外返回待登记的节点 ID。真实内部地址和令牌引用由服务端使用。保存 setup 或查看状态都不激活节点。前端向后端上报和后台投递仍依赖运行清单中的启用节点。Base64 导出继续负责向前端交接配对信息。
