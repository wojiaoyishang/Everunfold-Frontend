# ADR0076：目录页面、插件短代码与开放配置

**后续覆盖：**统一插件目录、开放具名控件及生成物不入Git由[ADR0077](0077-unified-plugin-theme-schema-and-artifact-boundaries.md)按用户最新要求实施；下文保留阶段决定。

日期：2026-11-07。来源：用户明确要求页面放入src/custom_pages、短代码通过src/plugins内的插件触发注册，新增实现不再修改多个中央分支；移除registrations目录，配置按JSON键值宽松保存。用户随后明确缓存不用迁移，原var忽略与运行状态保持。

## 决定

可信页面各有独立目录，index.ts声明稳定身份、版本、默认配置和可选表单字段，render.tsx及组件/样式留在同一目录。统一构建工具扫描固定本地目录，生成静态装配代码，收集页面清单、渲染器及语言能力；页面渲染不再回退到某个特定组件。

可信前端插件各有独立目录，index.ts导出稳定插件ID、版本和同步setup。只有插件setup获得注册上下文；短代码定义不会自行登记。插件贡献同一份参数/渲染/预览/媒体选择/按需样式，宿主由该目录派生后台只读目录和正文解析，拒绝重复插件ID、短代码ID/调用名及占用后端保留项。没有运行时下载代码或管理后台安装插件。

开发启动和生产构建生成静态入口，检查模式拒绝过期产物。移除中间registrations目录；显式部署命令直接将本地声明通过stdin交给后端安装器。构建/开发不写数据库，后端继续验证启用节点版本一致，不授予浏览器登记代码的能力。

PageRegistration新增defaults；fields只描述可选表单控件，不再是后端存储白名单。首次登记将字段缺省值与defaults合成初始配置，后续登记不覆盖已有工作稿或应用配置。PageValue.options保存任意JSON键值，包括未知字段、深层对象、数组、布尔、有限数字及null；保存是完整对象替换，不裁剪或自动补齐字段。只限制JSON对象、有限数字、最多32层/256KiB及原整页512KiB。前端负责解释值与安全展示，字符串不因存储而变成可执行HTML或URL。

后台提供表单/JSON配置切换，无字段时直接编辑JSON；表单编辑保留未声明键。JSON语法无效时保留输入、阻止保存/应用并维持最后有效预览；离开保护仍包括无效输入。私有内部元数据独立修订/接口，不能进入公开options、SSR或快照。

## 影响与验收

pages契约升1.4；原公开options结构未变，无数据库迁移。旧清单缺省defaults为空，既有ID/版本/路径/数据不变；后端接收stdin也保留显式文件参数供其他部署工具使用。新增目录/删除插件、冲突/缺入口、配置无损、未知实现503、前后台样式/预览、双API/Worker/Node可靠投递及生产回归须实际验证后写交接。后端先提交权威契约，前端再固定SHA生成。

src/generated内的契约与可复现构建产物参与Git；运行时公开副本位于被忽略的var，不是src/generated。按用户最新指示不迁移缓存。
