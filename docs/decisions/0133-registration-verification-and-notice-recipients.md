# ADR 0133：注册一次验证与用户通知接收人

用户明确要求注册邮箱验证不重复，并允许为「注册成功」「新增用户」选择接收对象。本决定修订 [ADR0132](0132-account-notification-events.md) 的固定管理员设置。

验证码注册成功时即保存邮箱验证状态，只登记「注册成功」。账号中心对同一已验证地址拒绝再次发码；更换邮箱仍需验证新地址，只有这一类账号中心验证会登记「邮箱已验证」。管理员人工审核与实际邮箱验证仍分开。

两个用户通知可配置指定用户、角色或权限；保留已有规则，默认仍为管理员站内通知。普通成员在账号中心读取自己的站内通知，后台入口及其授权边界保留。模板继续提供账号名、显示名称；只有具备用户管理权限的接收人得到默认后台详情链接。

通知契约 1.7.0 增加账号收件箱读写接口，复用现有投递数据，无需数据库迁移。
