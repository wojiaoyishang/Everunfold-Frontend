# ADR 0154：根目录配置与统一部署助手

- 状态：已实现，Docker 实机验收待部署环境提供 daemon
- 日期：2026-11-15
- 范围：前后端配置、首次部署、构建和运维入口
- 衔接：ADR 0150、0152、0153；本决定替代 ADR 0153 的标准库终端实现和 Docker 专属入口

## 背景

用户要求彩色交互、自动生成且可编辑的密钥、实际数据库连接检查、明确的镜像标识与配置后自动构建；文档必须分开描述 Docker 从零构建和不使用 Docker。随后明确要求配置脚本脱离 docker 目录，两端统一编辑项目根目录 config.yaml。

## 决定

1. 每个项目在根目录提供 `setup.sh`。无参数先选择部署方式，`--docker` / `--native` 显式选择。助手实现与锁定工具依赖放 `deploy/`，Dockerfile、Compose、容器入口仍在 `docker/`。
2. 根目录 `config.yaml` 是部署配置来源。保存应用字段、环境变量、Docker 参数、助手状态及可选的独立后端连接清单。权限为 0600 并忽略 Git；不提交真实配置。运行 TOML / env 是自动生成文件，构建、启动、检查前重新生成。现有业务加载器保持原格式，普通部署无需手动维护这些派生文件。
3. 无根 YAML 时可加载原 Docker / 原生实例目录中的旧配置，首次保存导入。保留其他应用字段和环境变量，独立连接只更新 active 项。切换部署方式保留密钥，默认数据路径按模式生成；数据本身不自动搬迁。
4. 使用锁定 Textual 实现总览、顺序和按项编辑、颜色、键盘/鼠标、异步连接检测。URL 回显，密钥总览遮盖、编辑可见。历史只留在会话，退出恢复终端。新站点主密钥、TOTP、管理员和节点控制台凭据自动生成，可编辑；已有站点不自动轮换主密钥。
5. PostgreSQL 检测真实认证、SELECT 1 和代码迁移版本；Redis/Broker 执行 PING。检查有超时，不执行迁移。初始化只允许空库；升级迁移需显式选择。前端检查后端公开和内部就绪入口，实际启动前再用应用配置加载器检查。
6. 后端基于已有节点登记机制导出单节点连接 JSON，前端导入 ID、UUID、发布 URL 和方向令牌。不复制数据库、应用主密钥。多个节点保持独立令牌。公开地址和启停继续由 `/_nodes` 管理。
7. Docker 配置工具用宿主 UID/GID 写根配置，不挂 Docker socket。宿主脚本构建应用镜像，构建日志实时回显。镜像/阶段/日志包含 Everunfold 组件与源码版本。启动不自动迁移、不重新编译前端。
8. 前端主体输出新版本目录，插件先编译到暂存批次；全部成功才选择产物，文件写入失败回滚。独立插件保持原增量发布方式。接收器默认只映射宿主回环，供受限 HTTPS 代理使用。
9. 原生模式复用配置助手和根 YAML，uv 管理工具和后端锁定依赖，前端仍由 Node/npm 构建。生成的环境变量直接传给子进程，不 source 文件。支持整端前台运行和单进程托管。

## 验证与限制

- 覆盖旧配置导入、根 YAML 优先级、双模式往返、秘密值稳定、独立 active 配置、原文件备份、并发修改、失败回滚、终端编辑/恢复/颜色、异步结果失效、小终端布局。
- Docker 命令桩验证宿主编排：失败不继续启动/激活、重启不重建、外部目录和重复挂载目标处理。Compose v2 渲染验证镜像名、UID/GID、IPv6 及独立端口。
- 隔离 PostgreSQL/Redis 实测初始化、迁移核对、节点导出；真实原生五进程启动，API `/health/ready` 200，前端首次缺快照为预期 503，接收器拒绝无凭据请求。真实 Next.js 生产构建与六个独立插件构建通过。
- 未更改现有运行实例配置、数据库或服务。当前环境没有 Docker CLI/daemon/socket，未执行真实镜像构建和跨容器通信，命令桩和 Compose 渲染不能替代该验收。
- 本次没有执行新测试站点的完整公开同步；发布与同步机制复用原实现。原生构建直接更新该检出的 `.next`，回滚须保留独立代码/构建目录。

工具依赖兼容信息依据 [Textual 官方文档](https://textual.textualize.io/) 与 [PyYAML 6.0.3 元数据](https://pypi.org/project/PyYAML/6.0.3/)，固定依赖和锁文件随交付提交。
