# ADR 0176  术语短代码与插入表单

状态为已实现。版本为 ADR0176-1。根据用户确认，术语弹窗通过前端主体注册的 `glossary` 显式关联一段正文。触发区能容纳原有排版。弹窗支持纯文本、按当前语言读取已发布词条及单独的 Markdown 或 HTML 内容区。后端沿用公开术语详情接口。

解析保留原生短代码配对。超限仍跟踪结束标记，按可见内容降级。弹窗说明由同一正文渲染链白名单过滤，嵌套说明以单层映射传给浏览器，按触发层显示。术语自动匹配跳过已标记区域，摘录和关键词匹配忽略弹窗说明。加密内容沿正文读取权限交付。

「站点设置 → 短代码」保存 1 至 64 的源码嵌套限制，默认 32。设置契约 1.50.0 同时把限值送到公开设置和后台短代码目录。可选字段用于兼容未带限值的旧副本，数据库沿用原字段。词条引用链按已打开词条的 ID 防止循环。

快捷插入和样式查看支持前端插件通过 `PluginShortcode.editor` 注册自定义 React 组件。编辑器用完整调用和宿主交互。宿主校验最外层调用归属、语法及参数，再使用同一段源码预览与插入。默认仍由定义生成表单。示例与完整语法见[短代码插入表单和调用规范](../development/shortcode-authoring.md)。
