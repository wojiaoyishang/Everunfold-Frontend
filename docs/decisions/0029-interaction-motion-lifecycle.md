# ADR 0029：交互动效与弹窗退场生命周期

状态：已实现；2026-11-01。来源：用户要求给新确认窗口增加动画，并规定所有交互必须有动画反馈。细化 ADR 0012 与 ADR 0028，不改变删除业务或后端契约。

## 决定与范围

- 控件封装负责动效。`shared.css` 新增 `interaction-motion.css`，为封装按钮、链接与输入提供低优先级的颜色/边框/阴影/透明度/按压过渡；现有控件的特定动画仍可覆盖。复选框补上按压与禁用透明度过渡，不在业务页面复制一套按钮。
- 确认窗口以 280ms 淡入、小幅上移/缩放进入；内容与操作行轻微错峰。关闭以 190ms 淡出/收缩退出，遮罩同步。按钮悬停、按下、禁用/恢复，操作等待、错误和范围文案变更均有轻量反馈。范围提示保留最小高度，减少复选时跳动。
- `ConfirmDialog.onConfirm` 返回 `boolean | Promise<boolean>`：`true` 进入退场，`false` 保持打开；异常保留弹窗并显示错误。调用者在 `onConfirmed` 中关闭/导航/刷新；取消也在退场完成后调用 `onCancel`。业务请求即时发起，不等待入场动画；等待和退场期间阻止重复确认。
- 展示层 `useDialogDismiss` 统一登记一次退出动作。`afterDialogMotion` 等待当前元素的有限动画，不等待无限加载旋转；取消动画也能结束等待。无动画时立即完成，旧浏览器 API 不可用或动画停滞最多等 500ms。卸载清理后不再执行过期的关闭/导航回调。
- 退场期间保留原生模态和下层隔离，退场后统一恢复触发点焦点。业务强制卸载（路由被移除等）可以直接清理，不执行遗留回调，也不取消或重发已被后端受理的请求。
- 前台与后台分别读取自己的动效偏好。显式完整/轻量动效优先；跟随系统时服从减少动态。减少动态禁用进退场，交互无需多等一个固定时长，继续保留焦点、禁用态及文字反馈。

## 接入

```tsx
<ConfirmDialog
  open={confirmOpen}
  title="确认这次操作？"
  error={requestError}
  onCancel={() => setConfirmOpen(false)}
  onConfirm={() => executeAction()} // 成功返回 true；不要在这里卸载
  onConfirmed={() => {
    setConfirmOpen(false);
    refreshList();
  }}
/>
```

媒体删除和未保存修改提示已接入。删除选项、同哈希判定、预览/摘要/回执仍在 core 与后端；主题仅消费结果。本轮不新增依赖、服务端接口或数据库变更。持续开发中的其他交互按 development-8 验收；共享默认过渡不等于已经穷尽验证每一个历史页面的专属动画。

## 验证

- `npm run check`：lint、严格类型、格式、123 项测试通过。新增测试覆盖有限动画汇合、无限旋转不阻塞、减少动态、动画中断、卸载取消以及缺失 API/停滞兜底。
- `npm run verify:admin`：隔离生产构建、8 条登录/后台路由及离线设置校验通过，未重启 Next3000 或 API8001。
- 内置浏览器检查真实 `ui-confirm-enter`（280ms）、`closing` 状态下的 `ui-confirm-leave` 与动作锁定；退场后只移除确认层，焦点返回删除按钮。选项切换的范围文案使用独立反馈动画。
- 320px 窄屏无横向溢出；Escape 触发退场。后台减少动态时窗口与遮罩均为 `animation: none`，取消立即结束；测试后恢复原「轻量动效」偏好及视口。
- 通过本轮创建且未保存的临时标题验证「放弃修改」成功回调：退场期间附件窗仍在，结束后回列表。未保存到后端，未点击任何实际删除确认；两个既有文件保持原状。
