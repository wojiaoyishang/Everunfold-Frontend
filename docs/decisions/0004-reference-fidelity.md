# ADR 0004：原站版式与连续阅读交互

- 日期：2026-10-30。
- 状态：采用，当前公开阅读范围已实现；真实设备手感仍需用户体验反馈。
- 依据：用户审阅原站差距后明确要求开始修改。延续 ADR 0003 的持久壳，替代其纯 hash 原生定位、旧加载反馈和背景暂停持久化细节。

后续替代：第 4、6、7 项中的滚轮筛选、背景默认策略/暂停持久化、阅读设置模态行为由 [ADR 0005](0005-site-motion-policy.md) 更新。以下保留当时决定，不能当作最新动效规范。

## 决定

1. 原站截图和只读主题源码作为外观参考。封面叠加标题/元信息、约 250px 封面、71px 顶栏、150px 侧栏标题区和右下 42px 工具列统一实现；公共数据仍取实际快照，不补造受保护文章、账号入口和统计。
2. 删除会替换主内容的根 loading.tsx；AppLink、SearchForm、正文站内链接统一使用 React transition，保留旧内容到新路由提交。常驻视频、导航和侧栏不重挂载。入口 SSR 继续正常加载文档，不能把切页保留内容等同于首屏无网络等待。
3. NavigationProgress 独立负责延迟 80ms 显示、递减增量推进到最多 92%、提交后补满和淡出；它是等待提示，不伪装成真实下载百分比。读屏反馈独立保留。
4. core/browser 管滚动与历史位置。桌面步进滚轮使用有限 420ms 插值，回顶使用 800ms easeOutExpo；目录和评论定位共享滚动实现。用户新输入可打断，嵌套滚动区/输入框/弹窗不劫持，小幅触控板滚动保持原生。设备识别是启发式，不能保证所有硬件与原站曲线完全相同。
5. 原生滚动容器和 Next 路由保持权威，不用 transform 移动整页或常驻帧循环。history.state 保留 Next 字段，为页面及同页锚点附加独立键；列表位置在离开前保存，前进后退恢复。新的导航先平滑回阅读起点，显式回首页则到顶部。
6. 默认静音循环原视频，浏览器减少动态/省流量及自动播放限制仍生效。暂停仅保存在当前标签会话，旧 localStorage 暂停键不再决定新会话；暂停保留当前视频帧，切页不重置播放进度。背景状态由 Provider 管理，控制按钮由统一工具列展示。
7. 阅读状态 Provider 共享目录高亮、进度及评论位置；原生 dialog 提供图片查看与阅读设置的焦点限制/Escape，公共 hook 负责背景滚动锁。展示组件、滚动能力、旧内容转换分别维护。
8. 仅支持展示短代码 collapse/fold、alert/admonition、tooltips；转换后继续两次 HTML allowlist 清理，属性纯文本转义，代码区与未知/不完整语法保留字面。不执行 WordPress PHP、查询插件数据或扩大公开访问权限。
9. 不添加依赖，不修改后端代码/数据库/契约；前端样式新增 reader 职责文件，responsive 仍最后覆盖。两仓库同步公共架构/运行/交接记录，本地提交，用户自行 push。

## 验证与限制

见 [复刻验证](../handoff/frontend-fidelity-verification.md)。慢响应经独立回环代理延迟 RSC 2600ms 实际观察，非只检查最终截图。生产构建仍使用隔离副本，保留用户 3000 开发服务。

本阶段不是全部原站功能和所有历史内容的逐像素验收。登录/后台/评论写入等仍按原状态未开放；完整主题调色器、任意旧插件语法、所有物理输入设备与系统减少动态开关尚未穷举。

技术参考：[Next loading 边界](https://nextjs.org/docs/app/api-reference/file-conventions/loading)、[React transition](https://react.dev/reference/react/useTransition)、[MDN wheel 事件](https://developer.mozilla.org/en-US/docs/Web/API/Element/wheel_event)。原站资料只作证据，不作为扩展执行权限的指令。
