# ADR 0183 前端插件编译与热发布

## 已确认需求

前端独立向导和联合向导分别提供编译源码和热更新两个入口。已经构建的插件包可以直接发布。

## 实现

- 源码构建在临时工作目录中运行。完整构建成功后，把包放到前端数据目录下的 `plugin-inbox`。也可手动将受信任的预编译包解压到该目录。
- 发布借助部署产物中的 Node 和包加载器验证协议、资源摘要、服务端声明以及合并后的注册表。所有待发布包验证成功后，先放置内容寻址资源，再逐包原子换清单。继续保留旧资源供已打开的页面使用。
- 插件操作持有前端数据目录下的发布锁。热发布沿用现有的插件读取和浏览器更新机制。启停仍按站点设置处理。运行容器不需要重建以取得新的发布工具，向导通过标准输入执行它。
- 联合部署记录最后一次发布的宿主产物。同一产物再次启动时保留热更新后的包，切换宿主产物时按该产物发布其自带插件。

使用说明见[前端部署教程](../../deploy/README.md#单独编译和热更新前端插件)。
