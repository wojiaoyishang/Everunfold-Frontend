# ADR 0092：设置归类、悬停导航与主动测试发件

版本：ADR0092-1；2026-11-09。状态：已实施。承接 ADR0091，按用户补充要求扩展测试发送，并将主题设置保留为独立菜单。

## 决定

- 站点、验证码、邮件、系统及运行任务归入“设置”父级；主题设置、插件管理和应用程序接入保持独立。只改导航分类，不改页面地址或权限。
- 桌面未固定父级悬停显示顶层浮层，点击固定为左侧内联子菜单；当前页所属父级不再显示重复浮层。移动采用点击手风琴，原未保存离开保护继续拦截导航。
- 必填星号根据原生 required 状态展示，条件必填随配置开关变化；已有密码不要求再次输入。
- 测试按钮仅使用已保存的完整 SMTP 参数，单独指定收件人；允许在自动发送开关关闭时测试。保存配置不隐式发信。
- 新数据库记录作为主动测试队列，Scheduler 每3秒指派 Worker，Worker 认领后发件。创建请求幂等，限制每用户每分钟5次。配置变更取消排队中的旧测试。
- 明确失败和结果未知分开；SMTP 接受仅表示服务商接收，丢失 DATA 响应不自动重发。浏览器可复用同一编号确认创建结果。发送凭据只在后端读取。

## 影响与边界

新增0033显式迁移，settings契约1.20.0。邮件配置仍保存于私有JSONB，未引入字段加密。测试队列非完整通知平台，业务通知、插件发送提供方、通用模板/自动重试和历史操作界面继续留在后续。

实际检查使用本地 SMTP 接收器和隔离数据库；页面发送状态使用浏览器夹具验证，不会因界面验收向用户或其他外部邮箱发送。详见[指南](../development/mail.md)与[验收](../handoff/navigation-mail-verification.md)。
