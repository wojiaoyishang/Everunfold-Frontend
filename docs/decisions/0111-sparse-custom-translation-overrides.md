# ADR0111：只读语言包与数据库翻译覆盖

版本：ADR0111-1。状态：已实现并验证。日期：2026-11-11。补充 [ADR0066](0066-configurable-languages-and-grouped-translations.md)。

## 背景

前端程序文案以 `src/core/i18n/en.json` 为基础，中文原文是默认值；后端也有只读命名空间消息目录。若允许后台直接修改这些 JSON，部署更新会覆盖管理员设置，并让代码来源、翻译修订和回滚边界混乱。

## 决定

1. `zh-CN` / `en` 内置 JSON 是只读基线，不通过后台修改，也不把整套基础词典复制进数据库。
2. PostgreSQL 只保存稀疏覆盖：作用域、语言、消息键/原文、值、原文哈希、修订、操作人和时间。删除覆盖即恢复基础 JSON。
3. 解析顺序固定为：数据库覆盖 → 当前语言内置包 → `ui_locale` 基础包 → 原文。前端 Provider 与后端消息缓存使用同一优先级。
4. 覆盖按 `public`、`admin`、`backend` 分域。相同原文字符串可分别为前台和后台设置不同翻译。
5. 前端公开/后台覆盖随 `PublicSettings.translations` 进入现有可靠设置快照，因此 SSR、缓存和节点应用沿用现有版本/回执流程；公开快照只包含程序文案，不含用户内容。
6. 后端只读取 `backend` 覆盖层。启动时加载，保存后立即刷新当前 API 进程，并以30秒周期重新读取数据库，保证多进程最终一致；数据库故障时继续使用内置消息。请求用 `X-Site-Locale` 携带实际语言、`X-Site-UI-Locale` 携带基础界面包，后者用于未命中时的内置回退。
7. 保存校验语言必须已启用，同一 `scope + locale + key` 不得重复，值不能超过4000字符；译文可以省略原文中的可选单花括号字段，但不得新增原文不存在的字段。覆盖保存与设置投递意图在同一事务提交。
8. 文章标题、正文、评论、用户名、分类标签名称等用户内容永远不是翻译键；翻译功能只处理注册过的程序文案。

## 契约

- `settings-v1` 升至 `1.30.0`。
- `PublicSettings` 增加可选 `translations` 结构化映射。
- 新增 `GET/PATCH /v1/admin/settings/translations`。
- 迁移 `0042_translation_overrides` 增加 `translation_revisions` 与 `translation_overrides`。

## 后台界面

“多语言 → 翻译字符串”提供前台、后台和 API 消息三个范围。支持语言、状态和文本搜索，按40项分页，单条恢复默认和批量保存。默认文本始终来自只读目录，后台只编辑覆盖值。

## 验证

隔离数据库验证了覆盖写入、公开设置投影、占位符拒绝、后端消息缓存和删除恢复。前端验证自定义覆盖优先于英文内置值，并能用于不同界面语言；管理页完成桌面/390px 实页检查，无脚本错误或设置写入。

## 模板缺省兼容（2026-11-11）

安全插值只替换调用方明确提供的单花括号命名字段，双花括号和复杂模板语法原样保留。缺失字段不抛异常，前端保留占位符，后端记录警告并返回可用文本；空白覆盖回退到基础译文。该兼容层不执行任意模板语言或代码，只是为未来受控模板渲染保留安全边界。
