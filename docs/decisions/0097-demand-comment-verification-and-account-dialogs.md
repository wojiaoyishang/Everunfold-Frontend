# ADR 0097：评论发送时验证与账号离开确认

版本：ADR0097-1，2026-11-10。状态：已实现，检查见[验收](../handoff/comment-submit-verification.md)。承接[页面评论SDK](0096-managed-page-comments-and-plugin-sdk.md)。

## 决策

默认主题的正式评论表单不在页内显示验证码，也不在挂载时请求评论挑战。先做本地字段校验；有效输入点击发送后，按需请求当前规则。无需验证码时直接调用既有提交接口；需要验证时通过项目ConfirmDialog承载CaptchaField，兼容本地图片和第三方插件。确认及退场完成后才发送，取消/Escape不写入、保留草稿与回复目标并恢复焦点。输入在发送周期临时锁定，避免回执清空其间新输入。

useCaptcha增加可选lazy模式、显式prepare及reset；默认自动模式保留，登录、阅读和插件既有用法不变。prepare失败抛出，不能把挑战缺失当作无需验证；关闭后清除内存挑战/答案，下一次发送重新检查规则。默认评论反馈使用主题颜文字横幅，checking/sending为不定进度，只有收到有效服务器回执才显示待审核成功、清空正文。验证失败/断网/503/超时保留输入；结果未确认也不能生成本地成功记录。稳定operation_id只在确认成功后重置，重试可使用新挑战但保持原提交编号；不自动重试POST。

共享ConfirmDialog提供可选submitOnEnter，验证码输入启用，排除中文输入法组合事件；其他确认默认不变。项目封装HTML dialog提供焦点约束、退出动画及主题，不调用浏览器alert/confirm/prompt。

账号中心以AccountNavigationProvider聚合当前表单脏状态，站内离开、切换资料标签与退出使用同一共享确认。取消保留当前标签和输入，确认后才离开或执行退出。账号中心不再注册beforeunload原生警告；后台原有保护保留。浏览器自身的关闭/刷新不能用站内组件同步阻断，不伪装成已实现的系统退出确认。

前台同步面板增加退出登录，复用CSRF logout接口。只有收到合法匿名回执才更新本地身份，失败仍保留现有身份并显示未确认结果。会话更新以同页事件和BroadcastChannel广播无凭据提示，接收者向后端重新确认，不传播身份/CSRF、不写storage、不手工删Cookie。已确认退出的提示触发前景重查并清除旧身份缓存，断网也不保留旧头像；取消旧请求后迟到响应不得污染内部lastReady或新失败状态。

## 边界

后端仍是评论、验证码、审核与会话事实来源；无契约/迁移/后端业务变化。HTML沙箱及阅读回执规则不变。插件自行实现的评论UI仍由插件管理视觉流程，公共SDK保留既有自动验证码默认值；本次弹窗行为由标准主题表单实施。示例评论仍明确标记为本页演示，正式内容后端离线不降级为示例提交。横幅不是公开评论通知，也不代表已通过审核。
