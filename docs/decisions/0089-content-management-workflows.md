# 0089：内容筛选、分类管理与协作快速编辑

日期：2026-11-09。状态：已实现；实际执行范围与限制见验收。

本阶段落实ADR0088的内容管理部分：多条件筛选与排序、独立分类/标签管理、列表快速编辑、批量编辑/回收/恢复，最后补齐受保护内容解锁后的评论交互。迁移演练、邮件与统计仍留在后续阶段。

- 文章/说说继续按翻译组展示一行；筛选匹配任一译文，实际修改明确指定语言版本ID，不隐式扩大到所有译文。筛选和分页随列表地址保留，高级筛选折叠展示。
- 快速编辑只提交明确修改的元数据。服务端锁定工作稿，核对修订与实时更新时间，将差异写入原Y.Doc并保留正文与epoch，持久更新、检查点、审计和回执同事务；在线编辑器沿已有持久水位读取。保存不自动发布，不改冻结排期正文，合并锁仍阻止写入。
- 批量至多50个明确ID，先检查全部权限、状态和版本，再同事务应用；任何失败整批回滚。操作ID绑定用户及请求，重试返回原回执。回收已发布内容仍要求发布权限并可靠撤回；恢复不会自动发布。
- 分类/标签保持原ID与slug。名称索引保留改名前名称，合并指向目标，删除保留墓碑；旧草稿、离线输入及历史版本重新提交时按当前目录解析，避免旧名称复活。别名只用于分类身份解析，不建立页面URL重定向。
- 管理分类需全站编辑范围；读取数量遵守内容权限。修改分类先展示影响，重新核对目录修订及影响范围，更新工作稿中的分类元数据与当前公开关联，历史版本原文保持；应用后通过原可靠投递刷新前台。分类层级拒绝循环。
- UI使用共享表单、确认、图标与主题变量。每完成可见组件立即做桌面/窄屏检查；验收同时覆盖多语言、取消/失败、协作并发、版本冲突、权限、回执重试和前台同步。

- 所有上传入口通过共享拖放边界进入既有队列；保留格式/大小/权限限制，嵌套区域不重复上传，不接管文本/块拖动。文件夹不递归上传。
- 受保护页面解锁响应独立于公开页面模型；评论及点赞使用仅内存的目标绑定阅读回执，失效后重新解锁。

实现与实际边界见[开发指南](../development/content-operations.md)、两仓库STATUS及[验收](../handoff/content-operations-verification.md)。新增迁移显式执行；地址、凭据、浏览器夹具和截图只放忽略目录。分阶段本地提交，不push。
