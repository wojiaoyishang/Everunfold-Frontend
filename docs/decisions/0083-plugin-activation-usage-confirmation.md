# ADR 0083：插件启停使用检查与页面目录可见性

日期：2026-11-08。状态：已实现；检查结果见[验收](../handoff/plugin-activation-usage-verification.md)。

用户要求未启用插件的注册页面不出现在页面列表，启停前扫描其内容是否已应用，有使用时提醒并允许继续。

页面目录沿后端现有available判断过滤不可用的注册页，包含主动停用、实现缺失或节点登记不一致。自定义源码页保持原规则。单页按ID读取、工作稿、应用快照、私有元数据和修订均保留；重新启用且部署一致后恢复原条目。打开的页面目录跟随插件运行目录修订重新读取。

开关仍先改设置工作稿，在保存时对已保存配置与整个工作稿求有效启停差异，统一调用settings 1.13的POST /v1/admin/extensions/usage。该只读业务查询要求settings:write，浏览器仍验证Session、Origin和CSRF，响应private/no-store。只返回注册状态与使用数量，不返回文章标题、路径、受限正文、用户或私有元数据；不增加内容读取授权。

归属取所有已存前端部署清单的并集，不受当前启停过滤。按稳定页面ID统计未回收且有应用快照的注册页面；按原生短代码调用名统计已发布正文及定时计划冻结版本，每个内容对每个插件最多计一次。仅未应用工作稿、历史版本和回收站不计；已单独停用但仍保留应用快照的页面会提醒。源代码示例中的转义、代码围栏、行内代码和HTML代码/注释/属性不作为调用。扫描不执行插件、模板或JavaScript；不能推断脚本动态调用或任意配置间的隐式依赖。

有使用或缺失归属清单时，用项目ConfirmDialog说明启用/停用方向及计数；“继续并保存”提交检查时捕获的整个设置工作稿，“取消”保留未保存输入并恢复触发按钮焦点。无使用直接保存，切换后又改回无需检查。查询失败不保存、不伪造零使用；保存失败保留弹窗及原设置工作稿。同步锁避免重复提交，原设置修订冲突、部署一致性、事务/审计及可靠节点应用检查继续生效。

该检查是保存前的影响提示，不锁住其他人员的内容编辑，也不替代正式启用校验。检查后产生的新引用可能不在本次计数中。直接调用原设置API仍可管理启停；使用检查接口是客户端预检协议，不是新的服务端强制批准凭据。没有数据库迁移或新增依赖。
