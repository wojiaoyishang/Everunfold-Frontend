# ADR 0011：评论焦点、表情排版与主题滚动条

日期：2026-10-31。状态：已实现；来源为用户对评论截图及全站滚动条的反馈。沿用 ADR 0007 的共用评论组件和前端演示边界，不改变评论接口、存储或导航时序。

## 选择与原因

- 原颜文字与 Emoji 共用窄网格，导致一个表情在格内断行。EmotionPicker 显式区分 Emoji、颜文字和贴纸；颜文字按钮按内容宽度排列，只在按钮之间换行。分组仍保留原生按钮、aria-pressed 和键盘操作，插入/预览复用现有逻辑。
- 选中分组使用轻量主题底色；键盘焦点采用 2px 主题色内描边，避免被动画面板裁切。只在正文输入框获得焦点时强调编辑器外框，工具栏操作不再连带点亮整框；验证错误仍用独立红色边框。窄屏工具栏可换行，所有操作保持可见。
- 表情布局从 reader-tools.css 拆到 emotion-picker.css，清理已不用的旧 composer-emotions 样式，保留单一维护入口。
- 全站滚动条集中在 scrollbars.css；页面、设置、评论输入框、代码、横向推荐等使用同一组主题变量。原生滚动条显示为细圆角滑块，悬停/拖动加深，深浅色及自选主题同步；页面轨道宽 12px，内部滚动区 10px，滑块透明内边距使视觉更轻。
- 保留原生滚动、根 scrollbar-gutter 和现有惯性策略，不创建自绘滚动容器、监听器或拖拽实现。支持 WebKit 伪元素的引擎使用圆角细节；其他引擎用标准 scrollbar-color/width。系统强制颜色模式不启用自定义滚动条。

## 兼容与验证

标准滚动条非 auto 值会覆盖 WebKit 伪元素，故两条样式路径互斥，参考 [MDN 的覆盖说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-webkit-scrollbar)。未引入依赖。浏览器样式实现及系统覆盖滚动条行为仍可能不同，不能由单个引擎的检查推断全部平台已验收。

实际检查、截图位置与复查步骤见 [评论与滚动条验证](../handoff/frontend-comment-scroll-verification.md)。本轮仅修改主题展示；真实评论发布、审核及完整导入仍待后续。
