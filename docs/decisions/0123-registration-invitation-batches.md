# ADR 0123：批量邀请码与自定义有效期

日期 2026-11-12。按用户要求，访问与安全沿用通用设置保存栏，邀请码生成可以输入数量、选择具体到期日期和时间，或设为永久有效。

批量生成一次提交 1–100 个邀请码。指定到期时间时使用带时区的绝对时间；永久有效用空的到期时间表示。所有邀请码仍只可注册一次，也可由管理员撤销。明文只在生成响应中返回，管理员可以一次复制整批。旧的按天数生成单个邀请码的 API 继续可用。

数据库迁移 `0051_invitation_expiry` 保留已有邀请码的到期时间并允许空值。部署时先显式迁移数据库，再更新后端与前端。若库中有永久邀请码，降级前必须为它们安排到期时间或移除相应记录。
