# ADR 0136 · Markdown 分屏工具栏与画廊多选

2026-11-13 已实现。用户要求分屏共用工具栏、修正短代码字段对齐，并为画廊启用媒体多选。

Markdown 分屏只在区块顶部展示一条工具栏。进入源码或可视化区时，工具栏跟随当前编辑区。也可以用顶部的「源码」「可视化」按钮明确指定操作区域。各区保留自身的选区和排版命令。短代码、媒体、代码块和公式等继续使用打开时捕获的插入位置。宽度不超过 800 像素时沿用单栏编辑，HTML 视图继续沿用现有模式。

短代码插入弹窗使用统一的字段标签、等高控件和固定底部操作区。参数在宽屏横向对齐，在窄屏逐项排列。配置、预览和调用源码同窗可见，画廊空预览随列数更新。

共用媒体选择器默认为单选。声明媒体参数的短代码可以在一次打开中从媒体库或上传队列选择多个文件。搜索、分页和切换列表时保留已选项，可在列表或选中清单取消选择。确认退场后按选择顺序追加虚拟媒体引用，已添加的媒体不可重复选择。媒体库添加次数受插件给出的总数限制，手工源码继续使用已发布定义的验证规则。画廊的媒体库上限为 20 张。
