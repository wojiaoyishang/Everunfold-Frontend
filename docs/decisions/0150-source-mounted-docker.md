# ADR 0150 · 源码挂载的双容器部署

## 决定

后端将宿主代码只读挂到 `/workspace`，将实例配置、媒体及上传临时文件放到可写的宿主 `/data`。锁定依赖保留在镜像中。API、Celery Worker 和 Scheduler 独立运行，迁移与插件登记显式执行。

前端同一个镜像提供 `build` 和 `deploy` 模式。编译模式将源码只读挂到 `/workspace`，在临时目录里编译，成功后把产物发布到宿主输出目录。部署模式将该产物目录挂到 `/workspace`，启动 Web 和接收器。另挂宿主 `/data` 保存配置、设置、公开快照和插件。现有插件编译器可以独立发布兼容插件。主题随主体构建。

## 影响

一次部署默认有两个长期运行的业务容器，前端构建临时启动一个使用同镜像的构建器。在 Compose 修改 `FRONTEND_ARTIFACT_DIR` 后重建运行容器即可切换主体。前端产物按完整版本保存，部署者按回滚需求保留版本。环境、挂载和启动顺序见各仓库 [Docker 指南](../../docker/README.md)。
