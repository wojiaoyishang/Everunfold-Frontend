# ADR 0172  同步错误提示与直接翻牌

状态为已实现。版本为 ADR0172-1。补充 [ADR 0016](0016-anchored-popovers-and-failure-pages.md) 的错误页和小游戏行为。

公开内容首轮未收到、清空后等待恢复，或已知新修订的完整副本尚不可用时，使用「站点数据尚未同步」。引导管理员检查前端 `[Everunfold sync]` 和后端 Worker 投递日志。术语页面收到后端明确的插件清单不同步响应时，独立提示检查后端部署日志；页面不显示后端业务错误码。其他接口故障和副本格式、摘要或来源检查失败沿用普通错误页。页面保留真实 503、禁止缓存和索引，并建议 60 秒后重试。有完整快照却找不到路径时仍返回 404；禁止回退已被新修订替代的旧正文。站点未同步时管理入口仍独立可达。

日志记录稳定的故障类别和已脱敏的底层原因，重复的读取报错按类别节流。独立 503 页面在无脚本、无本地快照和后端离线时仍可显示指导文案。统一部署可在宿主机运行 `./setup.sh logs`。反代需保留上游 503 的正文，否则自定义错误模板会覆盖这些提示。

配对卡片在交互脚本就绪后可直接点击或按键。第一次有效翻牌才洗牌开局，并翻开选中的牌；翻开第二张才计一次尝试。「重新开始」开局后显示，清空进度并将焦点移回第一张牌。无脚本时卡片保持不可操作。无需新依赖、后端契约或数据库迁移。
