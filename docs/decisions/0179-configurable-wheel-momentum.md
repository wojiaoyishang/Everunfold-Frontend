# ADR 0179 可配置的鼠标滚轮惯性

状态为已实现。版本为 ADR0179-1，2026-11-17。

「主题设置 → 滚轮惯性」保存当前主题的默认值，沿用公开设置的版本控制、权限与节点同步。首页右下角以及其他公开阅读页的「阅读设置 → 滚轮惯性」提供相同的控件。访客的调整立即生效，按字段保存在当前浏览器。同源标签页会收到偏好变更。「恢复站点滚动设置」清除滚动覆盖，重新采用主题默认值。

| 配置 | 默认值 | 可调范围 |
| --- | --- | --- |
| 启用滚轮惯性 | 开启 | 开启或关闭 |
| 惯性时长 | 70 ms | 30–150 ms |
| 每格滚动距离 | 100% | 50–200% |
| 连续滚动加速 | 80% | 0–100% |

数值每次调整 5 个单位。惯性时长控制滚轮松开后的衰减速度，值越大，尾段越长。加速百分比是同向连续滚轮的额外距离上限，0% 关闭加速。方向反转时清除旧方向积累。触控板连续像素滚动、触屏和内部滚动区沿用原生行为，启用「减少动态」时也使用原生滚动。

设置契约 1.52.0 增加可选的 `theme_options.<theme>.wheel_scroll`。旧配置与快照缺省时沿用原有手感。存储继续使用现有设置 JSON。部署先更新后端 API 与 Worker，再重新构建和部署前端，无需数据库迁移。
