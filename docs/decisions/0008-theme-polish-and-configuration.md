# ADR 0008：主题阅读布局与可配置边界

日期：2026-10-31。状态：前台调整已实现；后台配置与缓存设计仅记录需求和工程约束，待后续单独实现。

## 决定与来源

用户截图要求减少首页杂项、收紧说说、保持上下篇位置、恢复原站横向图片推荐，并明确顶栏与侧栏共享菜单、品牌及侧栏信息应允许后台设置。用户后续要求主题色同时作用于左侧卡片和顶部导航。本决定细化 ADR 0006/0007 的主题展示，不改变原始 v2.11/v0.14 的权限、配置归属和缓存边界。

## 已实现

- 首页筛选收进非模态阅读设置，以独立浏览器存储保存；显式 URL 优先，筛选通过公开查询参数驱动现有服务端列表。不使用 Cookie 个性化共享 SSR，搜索/说说归档不被首页偏好劫持。
- 顶栏与侧栏继续共用 siteNavigation，并保留后端传入的名称。首页仅有一个“站点概览”标签时不再输出该按钮；文章有目录时保留真正的目录/概览切换。
- 说说卡片缩小内边距、头像、正文间距和图片预览；展开全文仍可阅读全部内容。列表使用可收缩的单列网格，防止长代码撑宽窄屏页面。
- ArticleNeighbors 与 RelatedArticles 分开编排，共用 StoryCover。上下篇按发布时间和稳定 ID 排序，不随置顶状态或首页筛选变化。两格一直存在，边界是不可点击的文字占位；真实链接使用虚化封面。
- 推荐保持现有公开标签/分类相关性排序，显示最多六条横向图片卡片；标题叠图、统一裁切、轻投影、键盘焦点可见和原生横向滚动。没有封面时使用主题渐变和图标，不用随机图伪造内容。
- 正文后续区、推荐、评论和列表使用共同的间距变量。新增交互继续服从现有减少动态模式。
- 品牌填充色与链接文字色职责分开；导航、侧栏标题渐变/卡片底色和顶部进度均跟随主题色，使用颜色过渡。原外观存储/首屏初始化继续复用，不建立第二套主题状态。
- 用户补充的图标约定：界面方向箭头必须使用统一 SVG Icon，禁止用 Unicode 箭头/尖括号字形充当图标。已替换长内容展开/收起、分页和图片切换；脚注返回使用明确的“返回”文字链接，正文中的用户原文不做替换。

## 后续约束

后台可编辑区域与配置持久化/失效依赖见 [主题配置与缓存边界](../architecture/theme-configuration.md)。本轮未增加配置写接口、菜单树契约或数据库迁移。不能把原型参考菜单视为正式后台配置；正式版本仍由后端发布，前端生成消费。

结果、检查和手工路径见 [本轮验证](../handoff/frontend-theme-polish-verification.md)。所有改动分阶段本地提交；远程推送由用户执行。
