# ADR 0157：组合部署操作与统一 HTTP 响应

- 状态：已实现；原生构建/初始化/启动、HTTP 与浏览器验证通过；Docker daemon 实机验证待部署机执行
- 日期：2026-11-15
- 来源：用户确认后端已运行，要求新增“初始化数据库并构建启动”、指定根路径文案、统一所有 API 错误并关闭 FastAPI 两种文档
- 衔接：ADR 0156；沿用 JSON 外壳、真实状态及文件/流等协议例外

## 决定

1. 后端助手增加“初始化数据库并构建启动”，CLI `init-deploy`，Docker 与原生均支持。构建所需运行依赖/镜像后，调用现有显式空库初始化，复检成功再启动。只构建一次；自动初始化开关关闭也可执行，不改开关值。已有库跳过、不重设账号，旧版本拒绝自动升级。失败不继续启动或替换旧容器。前端不展示此操作，共用助手代码同步。
2. `GET /` 返回成功 JSON，`msg` 使用用户指定原文“当我离去的时候，让我的思想来到你的身边，正如那夕阳的余晖，映在寂静星空的边缘。”，不依赖数据库、不代替就绪探针。
3. HTTP JSON 保持 `success/code/msg/data`，整数业务码、真实 HTTP 状态，`data=None` 可省略。复用现有异常处理器；应用通用错误声明覆盖全部业务路由，修复此前部分路由 OpenAPI 缺失默认错误的问题。CORS 预检沿用 Starlette 的来源、方法、头校验，只将成功/失败正文改为统一 JSON。
4. 非 JSON 的 4xx/5xx 应用响应在 ASGI 发送边界转换成统一错误，不缓冲成功文件或流，不回显内部正文。保留重复 Cookie 及 Allow、Retry-After、Content-Range、CORS 等协议头，重新计算正文长度。HTML、CSS、文件、流、WebSocket、重定向以及 HEAD/204/304 语义保持原协议。应用之外的反代错误、HTTP 报文解析失败和已发送响应后的断流不由该层改写。
5. 节点控制台 API 成功值放 `data`、错误提示放 `msg`，登录/管理等 4xx/5xx 统一外壳。内置 HTML 同步解析并在原页面显示登录失败，保留独立会话、Origin 校验与私有缓存。业务码和 Retry-After 不丢失。
6. 关闭 `docs_url`、`redoc_url` 和 `openapi_url`，包括 Swagger OAuth 回调路径；HTTP 访问返回统一 404。保留 `create_app().openapi()` 与 CLI 离线导出。业务 OpenAPI 快照更新为 0.1.1，对齐当前已存在路由及错误声明；前端生成客户端不消费该 OpenAPI 文件，既有 DTO 契约和锁定文件不变。

## 验证与限制

- 默认后端测试 353 通过、85 项依赖专用数据库/Node 环境的测试跳过；原全局 OpenAPI 错误声明失败已解决。新增覆盖根文案、关闭文档、全部标准 HTTP 4xx/5xx 异常、422/响应校验、存储错误、未处理异常、业务码及限流头、CORS、原生错误正文、文件 206/416、HTML 与无正文响应。首次 416 测试的预期头缺少 `bytes` 单位，按实际协议修正后通过。
- 两端助手各 28 项：后端 26 通过/2 跳过，前端 20 通过/8 后端专用项跳过。覆盖组合操作确认/取消、开关保持、构建一次、初始化早于创建服务、失败保留旧容器。
- 隔离 PostgreSQL/Redis 上真实执行 `setup.sh --native init-deploy` 两次，首次在自动开关关闭时构建依赖并初始化，API/Worker/Scheduler 持续运行，`/health/ready` 200；重复操作保留账号密码和数据，开关仍为关闭。
- 双 Uvicorn worker 实测根路径、文档 404、4xx/5xx、CORS 和节点独立登录/读取。未处理异常由服务器关闭连接，故故障注入逐次使用新连接验收，不把连接池复用竞态当成 HTTP 正文。
- 内置浏览器核对新按钮的 80×24 布局及彩色显示；控制台在桌面和 390px 核对错误密码、登录、状态/指标读取和退出。TUI SVG 的中文叠字属导出字体宽度限制，真实 PTY/布局测试另行覆盖。
- 本环境没有 Docker daemon，未构建/启动真实容器；未修改用户实际配置、数据库或运行服务。

官方行为参考：[FastAPI 文档开关](https://fastapi.tiangolo.com/tutorial/metadata/#docs-urls)。CORS 与错误响应的细节同时依据仓库锁定的 FastAPI/Starlette 源码核对。
