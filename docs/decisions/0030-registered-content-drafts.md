# ADR 0030：注册式内容类型与基础草稿管理

状态：2026-11-01 用户批准文章/说说注册式管理与基础增删改查；当前交付范围见 STATUS。

## 决定

- 文章、说说为两个独立的一等内容类型，通过后端可信 ContentTypeRegistry 注册。注册描述标签、图标、顺序、标题/摘要能力和编辑器槽位；前端按固定后端提交生成描述与 API 客户端，不另写业务类型表。新增类型复用草稿用例，不复制服务。
- 本阶段交付可持久化的草稿 CRUD、搜索分页、简单 Markdown 块编辑/预览、回收站/恢复。创建与保存立即写 PostgreSQL；当前没有发布按钮。正式发布、撤回、索引及可靠快照分发另做纵向交付，不能将仅保存草稿宣称为已发布。
- 工作草稿存 content_drafts，完整历史及操作者存 content_draft_revisions；不复用当前只读导入快照作为工作草稿。未来发布应沿用草稿 ID，并显式生成独立公开版本。原 contents 表及公开契约本次不改，避免草稿更新穿透到线上内容或撤回后继续回退旧快照。
- 正文保留有序稳定 UUID 块，本期编辑器仅 Markdown；不是完整混合块编辑器或 Y.Doc 协同实现。后续协同必须沿用稳定身份并通过显式迁移接入，不能平行建立另一套草稿事实源。
- 所有写入由 FastAPI 复核管理员及 CSRF/Origin。expected_revision 防并发覆盖；operation_id 与动作/正文摘要绑定，持久回执在多进程重试时返回同一结果，不重复建文或升版。内容、完整修订审计、回执同事务，提交后才成功应答。
- 删除为可恢复回收，恢复也校验版本；本阶段不开放物理删除。草稿及历史中的媒体引用纳入已有媒体删除守卫，写正文与删媒体沿用同一引用锁。
- 示例数据只由显式 seed 命令添加，带 is_demo 标记，固定请求 ID 保证重跑不覆盖用户修改；服务启动和数据库初始化不自动填示例。
- 代码页面保持独立目录与生命周期，不注册为可写文章类型、不提供代码编辑。前端预留可信目录，页面选项保存、路由挂载和后端页面 manifest 协议仍按 registered-pages.md 后续实现。
- 类型注册缺失时拒绝该类型写入而保留所有数据；后台前端组件注册仅选择已编译的编辑器，不按后端返回值执行代码。类型清单变化需要按契约重新生成/部署；运行时清单用于发现失配，不授予权限。

## 验收边界

真实双 API 与隔离 PostgreSQL 验证幂等创建、冲突、审计失败回滚、回收/恢复、匿名/降权/CSRF 拒绝、草稿不进入公开源。前端验证失败保留输入、冲突后可对照最新内容、请求晚到不覆盖已打开编辑器、未保存关闭确认、窄屏和减少动态。尚未实现正式发布时，不做缓存同步完成的伪提示。
