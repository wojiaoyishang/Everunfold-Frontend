# ADR 0036：就地确认与有权限的编辑入口

日期：2026-11-02。状态：按用户追加要求实施。来源：正文块垃圾桶使用 tooltip 一样的就地删除确认；前台在真实身份与该文章编辑权确认后显示编辑超链接；编辑页操作移至右上；后台不显示无实际帮助的介绍文字。

## 已实施

- 本地未保存正文块的移除使用共享 `ConfirmPopover`，放在垃圾桶旁边，提供取消/删除、取消优先焦点、Escape/点外关闭、视口约束和定位就绪门控。气泡退场结束后才修改草稿；中断/卸载有取消与有界等待，减少动态直接完成。删除后焦点转到相邻正文块，最后一块不可删除。
- 这是明确的轻量本地编辑场景，替代 ADR 0028 对此操作的模态选择。真正数据库删除、撤回、放弃未保存修改继续使用既有 `ConfirmDialog`；不在页面另写确认逻辑，也不把气泡当保存成功。
- 编辑页右上排列查看前台、撤回、保存草稿、发布；标题/固定链接保持顶置。移除静态“编辑文章”“草稿已修改……”介绍区；实际保存结果仍在操作位置反馈，未保存离开/冲突/错误处理保留。窄屏操作自然组成两列。
- 移除侧栏宣传语、工作台欢迎/介绍段及重复页面简介。后台文案只保留功能名称、会影响用户选择的说明、范围/风险和真实状态；不要以介绍文字填充空白。
- 后端 GET `/v1/admin/content/actions?id={UUID}` 复用编辑端的真实账户/当前角色校验，确认目标对应有效已发布内容、未回收工作稿和已注册类型；只返回可执行动作的 ID/类型，无正文或账号资料。没有可编辑目标返回 `edit: null`；匿名401、无权403，响应 private/no-store。当前编辑能力仅开放真实管理员，不宣称已实现作者/自定义角色权限。
- content-admin **1.4.0**，契约来源提交 `d31b359`；public0.4/content-access1.0仍以fe1a651为来源，数据库0012和settings1.6不变。
- 前台文章（含密码壳）及说说详情的元信息可渐显“编辑”；只在浏览器收到肯定动作后出现，匿名/无权/失败隐藏，不从演示访客身份推断。复用按页请求注册和生成客户端，GET带真实Session凭据，结果仅在当前页面内存。回到标签页重新检查，进行中隐藏旧入口；SSR/磁盘公开快照无私有动作。
- 前端只识别本地可信类型注册与当前内容 ID，再生成后台地址；跳转后的后台与写接口再次校验权限，超链接从来不是授权凭证。

## 验证

双 API 真实检查匿名401、管理员肯定动作、当前角色改为普通用户403、未知/未发布目标无动作、no-store；角色在隔离测试库恢复。浏览器验证渐显与跳转到正确内容、就地取消/删除/最后一块限制、Escape回焦点和减少动态。完整检查及截图见 [验收](../handoff/editor-workspace-verification.md)。不为测试退出用户当前浏览器账号。
