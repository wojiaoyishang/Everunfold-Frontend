# ADR 0174  记住文章解锁与列表导航

状态为已实现。版本为 ADR0174-1。补充 [ADR 0169](0169-article-card-excerpts-and-editor-sidebar.md) 的卡片摘要，以及 [ADR 0170](0170-fixed-inspector-and-unlocked-glossary.md) 的就地解锁。

密码文章验证成功后，当前站点的 `localStorage` 只保存按后端及文章 ID 隔离的阅读回执和到期时间。时限沿用 Redis 回执的 30 分钟，恢复阅读不延长时限。摘要和正文只存在于相应浏览器组件内存。跨标签页监听读者状态，回执到期或被后端拒绝时恢复密码提示与闭锁显示。验证码单独保护的内容沿用原流程。

`POST /v1/reader/access/resume` 按当前文章恢复正文，沿用初次解锁的阅读回执。`POST /v1/reader/access/excerpt` 只返回文章 ID 与摘要，遵守当前发布的「启用空摘要」。两者核对回执的文章、来源、凭据及读取规则，并发送 `private, no-store`。重新发布、改密、撤回或规则变化使旧回执失效。未解锁的公开卡片沿用公开投影。已记住的卡片使用前台动态更新流程单独加载摘要，公开页面首屏及共享缓存不含回执、私有摘要或正文。

后台固定链接控件对有效站内路径提供新窗口链接。编辑按钮与路径点击分开。数字分页共用首尾和当前页附近的页码，较短的页数完整显示，较长的间隔用省略号，管理端保留左右箭头及当前页标记。页面目录在筛选后按 12 条分页。

阅读契约更新至 1.12.0。先更新后端 API，再重新构建新版前端；本次无需数据库迁移。
