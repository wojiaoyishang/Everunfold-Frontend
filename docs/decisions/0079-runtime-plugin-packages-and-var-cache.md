# ADR 0079：独立插件包、透明开发构建和扩展管理

日期：2026-11-07。状态：已实现，验收见docs/handoff/independent-plugins-verification.md。

用户确认主题仍在开发时写源码并随主程序构建，部署后只切换已构建主题；插件由独立编译器处理，主程序不导入或打包src/plugins源码。开发者继续在src/plugins/<目录>编写TSX、模型和样式，npm run dev自动构建、监听与更新。生产插件在plugins/<目录>，不增加版本号子目录；内容摘要由工具生成，SDK协议号用于兼容检查。根cache合并到var/cache，原公开副本/设置保持原var位置。

SDK区分纯声明/共享逻辑与浏览器React能力。固定的宿主SDK提供React/JSX运行时、主题控件、表单、页面上下文、数据资源、媒体选择和生命周期；插件不导入宿主内部源码。共享短代码仍走宿主过滤/媒体规则；首期动态React组件在浏览器加载，不声称支持任意Next Server Component或Server Action的安装。未知组件保持提示占位与配置。

插件构建先写完整带摘要资源，最后原子发布清单。服务端同步加载单文件CJS共享定义，缓存按摘要失效并移除旧require缓存，不向浏览器提供Node入口；浏览器按清单加载ESM和CSS并共用宿主React。失败保留最后可用产物。开发更新只影响对应插件；React Refresh尽力保持兼容组件状态，Hook结构变化可重挂载，宿主草稿不随插件代码替换丢失。生产编辑会话固定已加载构建，普通重新访问取得新代码。

后端保存公开扩展偏好（主题选择/插件停用列表），沿现有设置事务、审计与可靠投递同步；部署清单由受信节点登记。管理端显示实际已部署主题/插件和节点状态，可切换主题、启用/禁用插件。权限继续由FastAPI、Session/CSRF及内部真实IP AND Token执行；浏览器不能提交执行代码。插件停用不删除页面/配置/源文，缺失整页实现仍按原503边界。部署清单更新不覆盖既有页面数据，页面应用仍需显式操作。

新增接口、真实多进程检查、构建产物迁移与开发指南先后落地，最终状态和未完成能力写入交接。旧“前端不可运行时新增插件”的约束由本次明确授权覆盖，不扩大为不受信任的远程代码安装或自动业务数据库迁移。


结果：根cache及临时兼容链接均移除；后台主题/插件管理、settings1.12、节点目录表0027、独立SDK/编译器和dev/start协调器就绪。开发刷新复用Next锁定版本内置的React Refresh运行时，不能另注入一个晚于ReactDOM初始化的运行时；后者会使插件状态重置。生产编辑路径覆盖无/edit后缀的页面编辑器、new及实时预览。目录使用ETag，浏览器定期检查不代替持久投递。生产React插件先客户端挂载，RSC/Server Action和通用后端deferred资源未扩展。
