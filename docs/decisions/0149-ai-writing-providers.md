# ADR 0149 · AI 写作多服务商

日期 2026-11-14。扩展 [后台字段钩子与 AI 写作](0147-admin-form-hooks-and-ai-writing.md) 和 [后台插件页面与菜单](0148-admin-plugin-navigation.md)。

管理员在「设置 → AI 写作助手 → 模型服务商」维护多个兼容接口。每项有名称、接口地址、模型 ID、可选 API Key 和稳定 ID。保存后可针对当前服务商测试连接。设为默认的服务商在生成弹窗中预选。编辑者可按名称和模型改选，点击生成才发送已审阅的素材。一次请求绑定确认时所选的服务商和配置修订。生成入口的场景选项继续使用全局开关和字段开关。

配置页使用共享的右侧快速导航，可跳转到通用、模型服务商和生成入口。字段开关使用易于点击的整行标签。插件列表的配置弹窗使用同一份表单。

服务商配置接口仅向有设置权限的后台会话提供地址和是否已保存密钥的状态。编辑器只收到可选服务商的 ID、名称、模型及默认值。模型请求仍由 Worker 发出，使用既有的地址来源校验和 HTTPS 密钥限制。带密钥的服务商更换来源时必须替换或移除该密钥。配置发生变化时，尚未发送的请求沿用配置修订检查。

后端升级先显式运行数据库迁移 `0065_ai_writing_providers`。现有单服务商配置迁为默认服务商，保留模型、加密密钥、总开关和字段开关。协调更新 API、Worker、Scheduler 和前端插件包，并登记两个插件清单。前端类型沿用后端 OpenAPI 生成流程。
