# ADR 0066：可配置语言、原文合并列表与语言选择器

日期：2026-11-06（Asia/Shanghai）。状态：已实施；取代 ADR0065 的未实施提案，以本轮用户的后续修正为准。

用户明确要求：文章和说说的译文不能独占后台列表行，入口与原文合并；中英文只是初始配置，语言目录由设置管理；标志默认国旗emoji并可自定义；已有本语言界面包时不再称作“回退自己”；默认语言及中文前缀均可修改。最后的界面反馈要求修复顶栏溢出，将标志改为可搜索的选择弹窗，并把新增分为备选语言和自定义语言。

## 内容身份与事务

- 显式迁移0018_content_languages增加翻译组及草稿语言，原内容各为独立原文组，现有ID、URL、正文、协同房间、历史、访问策略和媒体保留。组内规范化语言代码唯一，类型一致。
- 每种语言仍是独立草稿/Y.Doc/历史/发布/评论指标。关联不是任意CRDT字段，历史恢复不改语言身份。创建可空白或复制已提交原文/公开版本，并生成新块ID；不复制密码和未确认更新。
- 关联命令复用权限、CSRF、全局引用锁、组/内容版本、持久幂等回执、合并锁及审计。关系/发布投影/release/Outbox同事务；完整公开发布刷新同组链接。原文更新只提示译文待检查。
- 默认管理查询先按所有语言匹配关键词/状态，再按组去重、计数和分页，行锚定原文。行内语言菜单显示各版本状态；语言筛选仍返回原文行。回收站按原文状态归属，单独回收的译文从原文面板恢复。列表整组回收明确提示范围并校验全部成员版本。

## 语言目录与界面包

- SitePreferences.language_catalog属于既有版本化站点设置JSONB，包含default_code和语言列表。每项为code/name/flag/prefix/enabled/ui_locale。语言代码采用BCP47形式并规范大小写；目录及单组成员不设固定数量上限，仍受现有设置传输64KiB、预留后60KiB及公开快照8MiB的实际容量限制。
- 新增入口提供可搜索备选语言和自定义语言；备选不构成允许列表。标志是展示文字，默认按地区/常用语言映射生成国旗emoji，可选择270个Unicode旗帜或自定义emoji/短标志，不作为语言身份。
- 已安装的程序语言包与内容语言分开。目前程序包为简体中文、英文；这些行显示“本语言界面”，不提供回退自己。其他语言选择缺包时的回退界面；不会自动翻译正文或用户填写的站点、菜单、分类和标签名称。
- 默认语言必须启用；仅默认语言可留空前缀，也可为默认语言设置前缀，包括中文。更换默认语言保留新默认项原有前缀，原先空前缀项改为其代码前缀；其他值可继续手动修改。
- 禁用停止新建和全站入口，不撤下已有公开内容；被草稿/回收项/公开记录使用的代码不可删除，改代码视作移除旧代码。前缀不可重复、占用系统路径或与已发布内容的语言导航地址冲突；发布内容也检查这些保留地址。

## 前台路由与语言运行时

- 实际已发布内容的路径和language优先于前缀猜测；语言/前缀修改不改写已有文章地址。新地址使用配置前缀。
- 前缀代码页由既有catch-all直接分发到共享CodePage，不做内部rewrite，避免默认前缀与首页rewrite产生循环。默认语言有前缀时，无前缀代码入口临时跳转至该前缀；未知正文路径仍404，不伪造译文地址。
- 公开SSR按URL/真实内容身份选择语言，覆盖外来内部头；Cookie只在水合后恢复导航偏好，不改变相同URL的共享HTML。后台界面切换在当前Provider内完成，不重建Y.Doc或清空表单。
- 前台顶栏及正文语言入口只使用真实已发布且可发现的关系；密码版本继续各自验证。代码页、信息流、归档、推荐/相邻文章按组择优；搜索默认当前语言，明确“所有语言”后才跨语言匹配，分页前去重。
- 可索引版本有独立canonical及公开译文双向hreflang，Sitemap同源；草稿和受限正文不进入替代索引。
- 后端只读字典在模块装配前加载，ContextVar按请求设置并finally恢复。X-Site-Locale/Accept-Language选择程序消息包，业务code不变；无请求任务显式传locale。内容筛选language独立传递，不把界面包代号当作内容身份。

## 契约与部署

content-admin1.8.0、settings1.10.0、public0.6.0、presentation0.2及collaboration2.0相关详情字段由后端导出；前端仅从已提交产物生成。公开语言目录GET /v1/languages，后台生成客户端使用受保护GET /v1/admin/content/languages；关系操作在 /v1/admin/content/translations/*。

部署先备份并显式迁移0018，再更新契约对应前端/接收器与后端API、Worker、Scheduler；新设置字段依旧走完整可靠投递，不依赖旧接收器猜字段。实际配置、测试地址与凭据不进入交接。
