# ADR 0040：恢复编辑留白与十行最小高度

日期：2026-11-03。状态：已实现并在内置浏览器验证。来源：用户最新明确要求“加回顶格间隙”，并为区块提供固定高度或默认十行。此决定替代ADR0038的无最小高度、ADR0039的首行紧贴规则，其余协同/拖放边界不变。

## 当前规则

Markdown/HTML共用的CodeEditor在正文顶部和底部各保留16px。编辑区以十行可见文本的高度作为下限；当前字号14px、行高1.75，下限为10×24.5+32=277px。超过十行后按内容增长，达到原有540px上限后内部滚动。

这是界面最小高度，不向正文、草稿或协同文档插入空行。只有实际存在的行才显示行号。行号列高度铺满编辑区，保留引擎的长文最小高度；通过height:auto/align-self:stretch覆盖CodeMirror默认height:100%，不重写引擎计算的行号位置或行高。

规则在共享code-editor.module.css中实施，两种编辑插件与桌面/手机一致生效，无新组件、依赖、接口、数据库或用户设置。

## 实际检查

- 1280px桌面：新建空Markdown块，正文和行号栏均277px；顶部留白16px，第一行与行号1的top一致。
- 320px：切换为空HTML块，同为277px、16px顶部留白且行号对齐，无横向溢出。
- 输入30行：内容与行号栏均767px，编辑滚动容器为540px并正常内部滚动；清空后回到277px。
- 已有三行Markdown和HTML在重新载入后排版正确。所有临时输入和格式切换已恢复，临时新建页未保存/发布；原已保存试用草稿内容未改。
- 本轮检查为内置浏览器实测、目标CSS的Prettier检查和git diff --check，均通过；改动仅涉及CSS和交接文档，没有重复运行上一轮158项测试/生产构建或协同P0。仍未执行触摸/IME实机测试。
