# ADR0110：主题与插件特色图预览

版本：ADR0110-1。状态：已实现并验证。日期：2026-11-11。补充 [ADR0084](0084-theme-cards-metadata-and-settings-scroll.md)、[ADR0105](0105-admin-navigation-and-glossary-media.md) 与 [ADR0109](0109-plugin-settings-search.md)。

## 背景

主题详情的预览图在宽高比受视口高度限制时可能按图片比例收缩，导致弹窗图片区域右侧出现空白。插件已支持 `preview` 元数据，但此前只在详情中显示，列表没有统一的特色图入口。

## 决定

1. 主题详情预览容器固定为满宽，图片使用 `object-fit: contain` 与居中定位；容器高度受视口上限约束时，图片在内部等比缩放，保留完整画面。
2. 插件列表复用同一特色图能力：优先使用前端插件 `preview`，没有时使用后端插件 `preview`。缩略图裁切填充固定槽，无图时显示插件图标。
3. 插件详情将预览图放入满宽、居中的自适应容器，使用 `contain` 展示完整图片；图片加载失败时不显示破图，详情其余信息仍可阅读。
4. 图片继续经共享 `resourceUrl` 校验，只接受同源路径或 HTTP(S) 地址，不执行 HTML 或脚本。
5. 主题详情和插件详情继续使用各自现有 Dialog、焦点、取消和关闭动效，不新增第二套弹窗。

## 影响

- 仅前端展示变化，无后端契约、设置修订或数据库迁移。
- 主题卡片和插件列表缩略图使用裁切填充；详情大图使用完整等比展示，两者用途不同。

## 验证

模拟插件预览元数据后，插件列表出现缩略图，详情大图左右留白对称且居中；主题详情 Argon 预览图片与容器等宽，右侧空白消失，`object-fit=contain`、居中偏移不超过1px。弹窗无脚本错误。
