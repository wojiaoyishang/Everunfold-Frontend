# ADR0101：术语匹配规则与分级阅读弹层

版本：ADR0101-8。日期：2026-11-10。状态：代码、主库显式迁移、隔离写入测试及本地 Chromium UI 测试通过；真实触屏与读屏器验收待完成。补充 [ADR0099](0099-article-scoped-glossary-tooltips.md)。

## 决定

1. 术语标题与正文匹配解耦。新增 `auto_match_title` 和 `match_rules`：规则分为 `literal` / `regex`，支持单条启停、大小写、ASCII 整词边界、优先级。新词条默认启用“术语标题本身”规则，编辑器将其固定显示为第一条默认规则；标题变化后自动更新，测试预览与正文匹配共用后端规则生成函数。
2. `aliases` 与 `match_rules` 完全解耦：别名始终参与正文匹配和公开检索；`match_rules=NULL` 与空数组都表示没有额外规则。普通/正则规则只补充标题和别名之外的匹配方式，不会自动成为公开别名。后台使用独立 `TokenField` 维护别名。
3. 后端文章级 `for-content` 仍是事实来源。后端只计算当前公开文章实际命中的文字，返回 `matched_patterns`（实匹配字面值、大小写、边界和优先级）并保留兼容 `matched_texts`；浏览器仅按这些字面值装饰安全可见文本节点，不下载全站规则和索引。
4. 正则使用明确受限的 Python 3.12 正则子集：表达式最多 160 字符、最多 6 处非嵌套有限重复（上限 32）、最多 6 处分支且每处至多 6 选项；拒绝无限重复、断言、反向引用、空宽度结果等危险构造。每规则最多采集 40 个命中、总计 200 种文字；请求正文依旧受页面可见内容范围约束。预览 POST `/admin/preview` 走相同引擎，仅检验给定的短样本，不持久化。
5. 默认 `popup_source=content`。悬浮提示直接显示完整术语正文，复用共享安全富文本渲染和代码/公式/媒体处理；可主动打开原生 dialog 放大阅读。`popup_source=summary` 时才显示简短提示摘要。摘要字段允许空字符串，标题和路径片段是仅有的必填表单字段；正文预览按钮通过共享 `SettingsSection` 头部操作位位于“术语正文”标题右侧。
6. 表格作为 Argon 主题共享 `.article-content` 样式实现，列宽默认铺满、清晰表头与斑马纹，窄屏只滚动表格区域。文章、说说、术语详情、弹层和统一草稿预览复用，不向后台管理数据表格传播正文样式。表格滚动容器由共享 `ContentMarkupView` 在挂载时提供，键盘可聚焦。
7. 新增显式迁移 `0038_glossary_matching_rules` 与插件契约 `glossary-v1 3.2.0`；站点设置契约升至 `1.26.0`，默认提示来源改为正文。插件 1.3.0 解耦别名与额外规则。不修改文章快照、原 WordPress 数据或其他业务模型；未经迁移不得部署新服务。
8. SQLAlchemy 的可空 JSONB `match_rules` 使用 `JSONB(none_as_null=True)`，使 Python `None` 写入 SQL NULL，满足 `match_rules IS NULL OR jsonb_typeof(match_rules) = 'array'` 检查约束。否则更新旧词条时会把 Python `None` 编码为 JSONB `null`，触发数据库 IntegrityError 并使保存返回 503。
9. 必填提示只由控件的原生 `required` 语义和共享 CSS 生成一次星号，页面级 `SettingsText` 不再重复渲染标记。空摘要不输出空段落：公开目录、词条详情和 Tooltip 均只在摘要有内容时显示。
10. 首级 Tooltip 使用主题色紧凑卡片，不再直接塞入整篇正文：摘要非空时显示摘要，为空时只渲染第一个非空正文区块；完整正文通过「查看详情」打开，独立页面继续由「打开词条页面」在新窗口进入。定位按实际卡片尺寸选择上下方向并夹在视口内，正文内部滚动、操作栏固定；长标题保留原生 `title`；别名为正文顶部可换行标签，最多展示四个并用 `+N` 汇总其余别名。桌面悬停停留180ms，定位完成并绘制透明首帧后用双帧触发320ms淡入/240ms淡出；减少动态仅保留160ms/120ms透明度过渡和固定位置。词条详情页基础信息与正文之间使用12px间距和主题分隔线。
11. `/glossary` 不再提供独立搜索框；公开术语按标题、摘要和别名并入“全部内容”全局搜索结果。搜索语言列表来自站点已配置语言目录，显示各自旗帜并保留“所有语言”图标；默认当前语言，与类型控件紧凑对齐，选择具体语言后结果与URL保持该语言。
12. Tooltip 提供完整进退场动画，完整说明 dialog 和术语目录/详情卡片提供入场与退出动画，全部遵循减少动态偏好。术语契约升至 3.2.0，插件升至 1.3.0；仅行为与展示变化，不新增数据库迁移。

## 限制与后续验证

- 文章命中来源是 Markdown/HTML 的安全文本近似；内联拆分、全文规格化导致的字形差异和短代码动态输出，仍可能使浏览器装饰与后端筛选存在偏差。不得称作完整 DOM 正则扫描。
- 规则冲突只对普通字面值执行静态重复校验；无法预判两条任意正则是否相交。执行时以优先级与最长结果决定。
- 后端隔离 PostgreSQL 测试库执行了迁移、创建（摘要空白且 match_rules 为 SQL NULL）、默认标题预览、文章命中、更新、冲突及归档流程，术语测试验证“空额外规则仍保留独立别名”；核心开发库已显式升级到 `0038` 并同步插件 1.3.0。Playwright Chromium 在 1440、390 和 320 验证必填单星号、独立别名、全局术语搜索、搜索语言旗帜、紧凑控件间距、Tooltip/详情层/术语页面动画、长标题省略和边缘定位；`alembic check`、Ruff 与定向 mypy 通过。真实账号登录页含 CAPTCHA，未绕过验证码；真实触屏、读屏器和完整减少动态矩阵仍需实页验收。
