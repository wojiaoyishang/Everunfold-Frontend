# ADR 0131：节点缓存管理与后端变更事件

缓存管理查询的是所选前端接收器的真实磁盘状态。后端通过既有节点绑定认证代理查询，分开返回磁盘版本、期望版本和投递回执。浏览器不调用内部端点。重发使用现有同步 Outbox；清理只处理选中节点、当前来源下已被验证的新版本取代的旧文件。保留当前副本、内容意图和来源绑定，不扫描历史来源、媒体或框架缓存。公开副本维持无 TTL。

影响公开副本的操作由后端在生成版本的事务中登记 `cache-event-1` 事件。Scheduler 定期唤醒 Worker，Worker 独立向已登记且启用的可信后端插件投递。插件回调不会阻塞发布事务，也不依赖后台页面或节点回执。投递使用租约、稳定 ID 和有界重试，不保证到达顺序；插件按 ID 去重，并根据来源与版本处理乱序。

后端迁移为 `0054_cache_events`，前端锁定 settings-v1 1.39.0。操作与部署见[缓存管理指南](../development/cache-management.md)。
