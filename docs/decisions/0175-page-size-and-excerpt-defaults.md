# ADR 0175  后台每页数量与文章摘要默认值

状态为已实现。版本为 ADR0175-1。延续 [ADR 0174](0174-remembered-reading-and-pagination.md) 的数字分页和固定链接编辑。

后台文章、说说与页面列表的左下角提供每页 10、12、20、30、50 条的选择，默认 12。各列表的选择分别保存在本机浏览器。更改数量会回到第一页并保留筛选条件。内容列表按选择请求后端分页，页面目录对筛选后的结果分组。

站点设置新增「摘要设置」。文章发布时优先使用单篇手写摘要。留空时使用站点指定的固定摘要，或按设置的字符上限从正文生成摘要。自动摘要默认最多 180 字符，可设为 1 至 1000。设置在文章发布或重新发布时生效。密码保护仍要求单篇作者明确允许公开手写摘要，站点默认摘要在公开卡片上遵循文章门禁。

固定链接编辑复用后台主次按钮，短宽度下按钮组可换到下一行。确定和取消动作支持原有键盘入口。

设置契约升级至 1.49.0。先更新后端，再重新构建前端。数据库沿用现有设置字段。
