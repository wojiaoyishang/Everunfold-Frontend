# ADR 0135 · 前端注册书籍页

本决定替换 ADR 0134 的固定日记目录。书籍页由前端插件 `core.book` 声明，默认路径为 `/book`。后台沿用注册页的草稿、预览、发布、停用和改址机制。首次登记时停用，发布后可用页面的实际路径加入菜单和站点地图。

书名与简介使用页面标题和说明。选项保存封面图片地址、书籍副标题及文章分类 ID。分类选择器列出可用分类，包括尚无公开文章的分类。公开目录从本地公开快照提取标题、日期、标签和链接，按发布时间从新到旧排列，每页八篇，同一语言组只取一篇。受限文章不进入目录。预览、翻页和公开读取使用同一规则。

宽屏同时展示封面与目录，窄屏上下排列。默认封面由 CSS 绘制，媒体库可以替换背景图片。旧站只用于版式参考。
