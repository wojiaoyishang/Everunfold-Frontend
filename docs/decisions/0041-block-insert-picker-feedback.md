# ADR 0041：添加入口统一弹出区块选择器

日期：2026-11-03。来源：用户反馈“添加区块按钮点了没有反应”。状态：已实现并验收。前端实现4349f8a；不改变原插入命令或协同管线。

## 原因与当前行为

已在内置浏览器复现：原桌面末尾按钮只设置anchor并选中右侧区块库，没有打开选择框；当区块库本来已打开时，既没有新块也没有可感知反馈。手机另有弹出选择器，两个入口行为不一致。

块前加号、末尾添加和手机工具栏均复用BlockLibraryPicker。点击直接打开有进退场的共享ActionPopover，类型仍从注册表生成；选择类型后插入到该入口对应的位置并聚焦新编辑器。Escape关闭并将焦点还给按钮。桌面右侧区块库仍可点击或拖入。

选择器显式传递自己的before ID，不依赖另一个入口修改后的共享anchor。插入仍调用宿主原命令，成功才关闭选择器；只读、预览及128块上限仍禁用入口。弹窗中的普通选择项与可拖动卡片共用展示组件，但只有侧栏卡片注册拖拽，避免重复注册同一个palette ID。

## 实际验证

- 1280px：末尾按钮立即打开Markdown/HTML选择；选HTML后由3块变4块，撤销恢复3块。
- 右侧处于内容设置时，点击第2块前加号，弹窗明确显示位置；键盘Enter选择Markdown，原HTML顺移到第3块，焦点进入新第2块。HTML插入也通过。
- Escape关闭选择器，焦点还给添加按钮。右侧HTML卡片仍可鼠标拖入对应位置，新增与单步撤销均通过。
- 320px：末尾选择器显示正常，选HTML后实际添加并聚焦第4块，无横向溢出；撤销后恢复3块。
- 最终完整npm run check通过：lint、严格类型、格式及158项既有测试；git diff --check通过。主题修复未增加只复述实现的测试，本轮未重跑生产构建或后端数据库/P0。

所有试验插入均由本人撤销，试用草稿最终源文/顺序与正式修订不变，保存按钮恢复禁用；没有保存或发布新版本。默认视口已恢复，开发服务及编辑页保留。前后端协议/数据库不变，未推送。
