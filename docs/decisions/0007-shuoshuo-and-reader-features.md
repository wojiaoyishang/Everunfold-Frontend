# ADR 0007：说说与共用阅读能力

日期：2026-10-31。状态：用户已授权实施，按阶段交付。本文不改变生产就绪边界。

## 范围

优先完成主题通用前台：说说混排/归档/详情、评论格式与贴纸、图片阅读、搜索类型、推荐分享、偏好与正文工具。高中日记、关于页及其他特色页面留待自定义页面阶段；不开发后台主题设置，不做全量导入。

## 契约与样例

- 后端维护 0.2.0-preview.1 展示草案，前端从确定的提交生成类型；运行中 0.1.0 API、数据库和公开快照保持不变，正式迁移另行验收。
- 顶层 type 为 article/shuoshuo/page；已发布 0.1 数据经一个适配层转换。说说暂用明确标注的虚构样例，不写入快照/数据库，不计入真实文章统计；正式导入后替换数据提供者。
- 评论/点赞演示与真实发布分别标注，不保存邮箱和密码。访问状态可演示，正式校验/审核/通知仍由后端提供。受限投影不能携带正文、摘要或媒体映射，浏览者状态不能进入公共快照。
- 不手改生成类型，不为原型引入第二个业务字段权威源。草案未来升级需明确 type 迁移和兼容策略。

## 前端组织

主题使用内容类型分发，文章和说说保持独立卡片/详情头部；共用正文、图片、评论、分享、时间和偏好能力。路由保持轻量，样例数据集中维护。原生链接/键盘/修饰键行为保留，说说不能用整卡链接覆盖正文图片与互动。

正文继续使用受控 Markdown/HTML；评论支持的格式通过安全元素渲染，历史纯文本不重新解析。功能检查覆盖受限正文不泄漏、未知类型、混合查询/分页、危险链接与代码区语法保留，以及实际浏览器交互。

## 分阶段证据

主题偏好保存在浏览器，不扩展后台主题配置；PUBLIC_SITE_URL 是服务端可选部署配置，仅提供公开 canonical / Open Graph 地址，省略时不臆造 localhost 或 API 域名。系统分享/复制按钮使用当前访问地址。脚注只转安全纯文本说明；不引入完整代码高亮/公式/播放器库，旧站明确关闭或未确认使用的能力仍按实际内容需要再加。

前台实现已完成本轮主要批次，具体已验证/未执行项以 handoff/frontend-reader-verification.md 为准。验证码、正式审核/身份、密码/定时解锁仍只有边界约定，不能用前端遮盖或伪成功替代后端授权。

契约阶段：新增草案 Schema 与导出工具，校验无标题规则、受限投影和定时开放时间；未装配新 HTTP 路由，未改数据库。前端实施与最终检查结果见后续 handoff/STATUS.md，不以此文代表已全部完成。
