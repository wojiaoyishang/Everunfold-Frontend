# ADR 0180 共用视频播放器

状态为已实现。版本为 ADR0180-1，2026-11-17。

文章、说说和页面共用播放器。组件模式从媒体组添加「视频播放器」。区块模式从区块库添加或拖入「视频」，确认设置后保存为独立 HTML 区块，区块标题栏提供重新配置入口。短代码库注册 `video`，HTML 工具栏的视频按钮提供普通视频插入和短代码视频插入。普通视频插入继续从媒体库生成原生 HTML。

媒体库视频通过现有媒体 ID 解析。视频直链使用原生控件。Bilibili 和 YouTube 视频链接用各平台的视频 ID 生成嵌入地址，浏览器加载对应的平台播放器。支持最大宽度、静音自动播放、标题及来源支持的封面、字幕和循环选项。默认跟随内容宽度并手动播放。最大宽度接受 320 至 1920 像素，容器宽度较小时自动缩小。

正文区块保存原始短代码，组件树保存单独的配置字段。HTML 源文仍由原过滤规则处理。短代码的播放器在 HTML 过滤后按已验证的设置生成。现有「更多组件」视频引用可继续由原组件读取，并使用共用播放器。仅需重新构建前端。

迁移「关于网站」时，在组件中选择已上传的开场视频，设置最大宽度 800 像素，启用静音自动播放和循环，再应用页面修订。

文章、说说与页面编辑器共用「编辑方式」选择器。文章与说说的组件模式在主编辑页显示带实时预览入口的编辑区，切换仍走原有草稿确认和版本检查。页面的实时预览、前台预览、保存草稿共用次要操作样式。

首页卡片在约一个半视口的范围内准备显示。快速跳转到可见卡片时立即显示。文章封面和说说图片进入同一范围后开始加载，图片规则独立于减少动态偏好。
