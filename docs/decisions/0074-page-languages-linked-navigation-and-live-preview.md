# ADR 0074：页面多语言、菜单内容关联与实时预览回执

状态：2026-11-06，已实施；实际验证范围见交接验收。

## 内容与语言

文章和说说共用既有语言组及独立发布。手动创建的页面新增独立语言组；语言来自站点目录，不限定两个。每个语言保留独立源码、路径、修订及启用状态。目录仅显示组原文一行，语言入口集中在该行和编辑器；可新建/复制、关联独立页面、解除关联、标记已核对。复制时保持停用、关闭脚本；启用脚本仍需管理员明确确认。回收某语言只影响该页，若原文被回收则选择仍有效成员作为组入口，避免把剩余译文藏掉；恢复仍停用。注册页面不加入用户语言组，由可信实现自行处理多语言。当前core.people显式选择语言路径能力，共用人物选项和界面字典；真实内容地址优先，代码别名不能覆盖已占用路径。

列表启停是单独的版本保护命令，不等同于应用草稿。主库保留最近应用源文；开关只能恢复该源文，保留后来保存的草稿字段。没有可恢复应用源文时，首次启用必须明确确认应用已保存草稿。旧停用页面不从快照镜像反向恢复源文。启用时重新检查路径占用、实现可用性与脚本权限；状态、公开投影、审计、幂等回执和可靠Release同事务。停用不回滚保存的草稿、不重设译文核对基线。

## 导航

菜单可保存资源类型和稳定ID，保留原有手动链接能力。查询入口只提供已发布文章/说说和已启用页面的ID、标题、当前应用路径、语言，不返回正文/草稿/内部元数据。前台在完整公开内容与设置投影上按ID解析；当前语言有同组已发布成员时优先使用，否则使用关联项。改址须发布/应用后生效；停用、撤回、转私有或回收后隐藏该入口，禁止回退到过期手填地址。资源关联不绕过内容访问权限，不建立历史别名。

## 实时预览

退出当前工作界面和页面内导航/返回由主题弹窗处理，嵌入编辑器不创建浏览器原生离开提示。浏览器直接关闭标签页、强制刷新不能替换成自定义弹窗。文章/说说沿原协作持久化及离线恢复；页面仍明确保存草稿或应用。

父窗口为编辑会话分配随机通道；编辑投影带递增修订，接受精确来源、实际窗口和当前通道。修改立即进入等待状态，短延迟后发出投影；右侧渲染完成后确认同一修订，旧确认不能结束新等待。源码页面还等待隔离文档的匹配渲染标识；只重建该沙箱，不重载左侧输入。等待超时可重试，保留未保存修改。切换设备/拖动宽度不重建编辑会话。

人物寄语复用主题Dialog、焦点圈定/回归、Escape/遮罩关闭和进退场。打开播放有限烟花，减少动态时省略，关闭或结束清理特效；寄语纯文本随右侧投影更新。

## 发布顺序

显式迁移0026，发布pages1.2/settings1.11.1/public0.8及内容投递content-admin1.12契约，提交后由前端按精确SHA生成。主库/权限/可靠投递需真实多进程P0，UI需实际浏览器检查；验收完成前不得把设计描述视为全部已验证。

同一处已有启用Switch时不再添加重复的已启用/已停用badge；草稿、回收与核对状态独立保留。文章/说说/页面语言按钮的数量统一使用居中的独立文本区域，避免inline-flex标签与裸文本基线错位。

HTML源码变化替换内层srcdoc沙箱实例，避免反复导航造成联合历史增长；保留不透明来源和脚本默认关闭策略。就绪确认还核对实际当前iframe窗口，源码A→B→A时也不能接受已移除窗口的旧确认。不创建本站来源的作者源码Blob地址。
