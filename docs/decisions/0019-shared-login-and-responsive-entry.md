# ADR 0019：通用账号登录与自适应入口

日期：2026-11-01（Asia/Shanghai）。来源：用户要求继续优化登录界面，明确登录不限于管理员，去掉管理相关文案，背景自适应，并进一步放松表单间距；随后明确桌面入口应相对小、简洁清爽。

状态：已实现。继承 ADR 0018 的真实认证、缓存与后台权限边界；本决定替代其中“登录页仅作管理员入口、缺省返回后台”的展示与回跳约定。后端契约、数据库及权限规则不变。

## 登录与权限

- `/login` 是通用账号入口，默认登录成功后返回 `/`。已有有效会话同样按目的地进入，不要求普通用户先退出再登录。
- 当前 `next` 白名单仅有 `/`、`/admin`，保留其查询与片段。外站、协议相对地址、反斜线、控制字符、其他路径和登录页循环均回退到 `/`。将来增加个人中心等目的地时再显式扩展，不直接接受任意地址。
- 显式从后台进入时使用 `/login?next=/admin`；真实管理员继续进入 `/admin`，普通账号返回前台。前端回跳不是授权，后台依然向 FastAPI 复核当前数据库角色。
- 登录页文案为“登录你的账号”等中性表达；真正的后台及其权限确认仍使用管理相关称谓。会话、CSRF、凭据请求和 no-store/noindex 保持 ADR 0018，不向公开 SSR、快照或持久存储注入身份。

## 展示与组件

- 桌面采用最大 440px 的单列卡片，移除左侧展示区、书页装饰、重复欢迎语和底部署名，仅保留站点/返回入口、标题与表单。浅色表面、细边框和轻阴影沿用主题变量；内部有独立留白，内容超过可用高度时允许正常滚动。
- 移动端沿用单列结构，600px 以下保留更宽松的字段间隔和 54px 控件高度；文字保持 16px，不靠缩小内容塞进屏幕。320px 进一步调整外边距和头部间距，保留正常纵向滚动。
- `ManagementEntry` 继续统一登录、身份确认和可恢复失败状态。`FormField` 统一标签、前缀图标与错误外观，组合既有 `TextField`、`PasswordField`、`Button`；不直接在页面写原生交互控件。
- 背景沿用现有 2560×1600 营地图片。固定视口容器中，定位层按原比例铺满、底部对齐，竖屏将画面重心移到营地；内部动画层负责漂移，图片与 SVG 火光使用同一个坐标平面。定位 transform 不与动画 transform 共用元素，避免构建转换后漂移覆盖居中位置。
- `management.css` 保留共用与后台工作区样式，`scene.css` 负责背景，`entry.css` 负责入口卡片与响应式，由路由组布局统一按序导入。主题色、深浅色与减少动态继续消费统一偏好。

## 验证与范围

本轮检查与截图见 [登录界面验收追加](../handoff/authentication-frontend-verification.md)。前端真实管理员登录、退出和两种回跳已实测；普通账号目的地策略由单元测试覆盖，本轮不向实际数据库增加测试用户。注册、个人中心、普通用户退出入口、找回密码及后台业务仍按后续阶段实现。
