# ADR 0033：分栏编辑工作台与基本内容属性

日期：2026-11-02。用户要求参考 WordPress 的顶、左右结构，编辑体验介于经典与区块编辑器之间；允许添加多个块，完整编辑器功能后续细化。

本页保留初次实施范围；默认地址、分类层级、密码/定时开放由 [ADR 0034](0034-wordpress-editor-access-and-taxonomy.md) 替代，标题位置、日期控件和后台面板由 [ADR 0035](0035-admin-panels-and-editor-controls.md) 补充。实际完成和检查见验收，不把下文旧阶段限制当作当前状态。

## 本次实施范围

- 一个独立编辑页：顶部保存/预览/发布；正文主区；注册式属性面板。文章与说说共享宿主、媒体能力和提交链路，标题/摘要等按类型变化。
- 有序 Markdown/HTML 文本块，稳定 ID，基本添加、删除、上下移动与安全预览；不把每段拆块，不交付富文本工具栏、Y.Doc、协同或任意脚本执行。
- 单篇路径、展示发布时间、封面媒体 ID、平级分类/标签、置顶、评论开关、SEO 标题/描述存入工作草稿，正式发布才更新公开投影。原始发布时间不因普通修改自动重置；未来时间不能冒充定时发布。
- 首次留空路径继续使用稳定 ID 默认地址；可手动填写自定义路径。系统路由和其他内容占用路径拒绝发布；改址后旧路径失效，无别名和自动重定向。
- 分类标签暂为平级、按名称归一化的内容关联；新建关联在发布事务中生效。建议项只取新系统分类标签，不恢复旧博客文章充数。层级分类管理另做。
- 媒体插入复用媒体库和统一上传队列，正文存 site://media/{id}；后端提供 URL 映射。封面用稳定 ID；草稿/公开投影/完整修订引用受删除守卫保护。
- content-admin 1.2.0；公开快照 0.3.0 接受旧 0.1/0.2，展示契约追加可选 SEO 字段。0011_editor_settings 显式迁移，仅新增字段不删原数据。旧管理客户端不带 settings 时保留已有属性。
- 草稿保存、发布、索引、审计、完整 release 与 Outbox 沿用同事务；媒体映射、分类标签、封面、正文顺序进入发布版本。权限/请求不进入主题。

## 后续与验收

不开放密码/登录访问、定时发布/开放、审核、作者切换、多语言、任意自定义 CSS、完整插件运行时。现有评论发布仍是明确标示的前台演示；关闭评论禁止写入入口，保留已有留言阅读。

必须检查真实双 API、Worker/Scheduler/Node 同步：多块/属性发布、草稿隔离、改址旧地址失效、路径冲突、媒体引用保护、回滚和旧版本不回流。界面检查桌面/手机、进退场与减少动态、失败输入保留。最终结果记录到 STATUS 和本轮验收，不以本页声明替代测试。
