# ADR 0064：桌面设置页分区导航

日期：2026-11-05（Asia/Shanghai）。状态：已实现并通过本轮检查。

## 来源与页面

用户希望在桌面设置页右侧加入导航，快速跳到指定设置。三个既有设置页复用同一布局：站点设置包含基本资料、导航菜单、搜索展示；主题设置包含色彩与外观、站点横幅、字体、代码块、背景；系统设置包含节点策略、站点与主题发布、部署配置。

1200px及以上为左侧表单、右侧固定分区目录；小于1200px隐藏目录，保留原单栏表单。导航距56px顶栏20px，正文和保存栏只占左列，短视口中的目录可独立滚动。主题颜色、焦点和动效沿后台统一变量，支持深色及减少动态。

## 分区、锚点与位置

SettingsSection使用显式稳定ID和实际标题，SettingsLayout从当前已挂载的分区生成目录，不复制另一份标题配置。DOM变化及尺寸变化按requestAnimationFrame合并读取，离开页面释放观察器、滚动、尺寸和hash监听。

入口使用封装TextLink和原生hash锚点，支持键盘、打开带锚点的页面、刷新及浏览器前进后退。异步设置加载后恢复初始锚点与目标焦点，不重新挂载表单。共享后台根已保留72px滚动空间，分区只增加8px，避免与顶栏预留叠加。实际跳转约在顶栏下24px，浮点位置留1px容差。

滚动时高亮已到达导航栏下方的分区；页面到底时通常高亮最后一项。短分区在页底无法滚到栏下时，优先保留可见且获得焦点的锚点，避免点击“站点与主题发布”后误选相邻的“部署配置”。高亮通过aria-current=location表达，键盘目标保留可见焦点。

导航只改变当前页位置，不提交、重载或丢弃设置。原有保存/撤销、版本和投递流程保持，无后端、契约、依赖或迁移变化。没有增加设置项全文搜索、窄屏目录或逐字段目录；新增分区必须提供唯一稳定ID。

实页结果与边界见[验收](../handoff/settings-section-navigation-verification.md)，使用方式见[设置指南](../development/settings.md)。
