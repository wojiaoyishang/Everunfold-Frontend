# ADR 0071：可配置用户身份预设

日期：2026-11-06（Asia/Shanghai）。状态：已实现并验证；用户已明确授权加入可自定义的编辑/审稿人等预设及调整密码文案。

## 实现决定

保留admin/user基础角色和最后管理员保护，身份预设保存可复用的成员权限组，不成为可提升至管理员的新角色。初始提供可修改/删除的“编辑”和“审稿人”，管理员可增删改；审稿人在现有编辑工作流中需要读取/编辑/发布能力，默认说明明确这一范围。原账号不会自动套用任何预设。

管理员管理全站预设；有users:manage的委托管理者只能读取/应用未超过自身权限的预设，不能改全站预设。创建、修改、移除要求当前操作人密码、Session/CSRF、期待版本、稳定操作ID和审计，Key不能管理。预设支持已有按应用划分的能力目录和own/all范围，不能凭名字或客户端提交权限绕过后端校验。

应用预设在用户创建/保存事务中按预设ID及期待版本读取，服务端复制权限并验证授权上限；用户保存名称/ID/修订的来源快照用于展示，不参与鉴权。修改/删除预设不会改动既有用户或其Key；显式重新应用才更新权限，使用既有会话/Key/WS失效链路。手工修改权限转为自定义；资料单独保存保留身份快照。管理员不能套用成员预设，降级仍走原管理员保护。

0022新增user_permission_presets及用户来源快照JSONB，预设软删除且名称按casefold去重。账号管理统一先取既有跨进程事务锁，保证预设更新/删除与应用互斥；同期待版本只允许一次更新。操作回执不保存密码；旧用户请求未传preset字段时保持旧幂等指纹。

用户管理顶部增加“身份预设”入口和独立私有配置页，用户创建/编辑可选择并预览权限、再按需微调。列表/资料页显示应用时的身份名。密码文案统一为“当前管理员密码”。前后端已交付；操作与精确检查见[账号指南6](../development/accounts.md)及[验收记录](../handoff/user-presets-verification.md)。
