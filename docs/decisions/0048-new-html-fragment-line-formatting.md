# ADR 0048 新增 HTML 片段分行

日期：2026-11-04。状态：已实现并通过真实草稿保存。来源：用户要求 HTML 可视化回车、插入内容时，对新增源码尽量分行整理，同时保留原文排布。

HTML 原始字符串继续作为底稿。可视化变化先经过既有词元局部拼接；仅当变化新增块级结构时，由 formatHtmlAddition 整理新增片段，不对整篇源码做格式化。

- 新段落、标题、图片/图注、列表、引用及表格结构在块边界分行；新容器内容按层级缩进。
- 沿用附近的换行符与基础缩进，新增缩进使用现有制表符或两空格风格。
- 单纯修改文字、行内样式或属性不额外换行；pre/code 内的空格与换行不改写。
- 未受影响的源码保留大小写、属性、实体、空行及排布。切换视图本身不做整理。
- 整理后的完整语义投影必须与目标一致，否则退回原来的局部结果；无法安全回写时仍保留源码编辑提示。ADR0046 已有的单个变化表格有限回写规则继续有效。

整篇保存、协同截点、冲突校验与 block_sources 端点不变，没有新增单块应用/保存按钮。此轮只调整本页编辑面生成的源文，不修改共享转换器、数据库或后端契约。

单元回归覆盖段落分行、CRLF/缩进、嵌套列表/引用、实体与旧源码保留、行内修改及 pre。内置浏览器验证可视化 Enter、新表格及 Ctrl+S 真实保存；详情见[验收记录](../handoff/editor-media-picker-verification.md)。
